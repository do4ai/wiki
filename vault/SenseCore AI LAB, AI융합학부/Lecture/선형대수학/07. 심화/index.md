# 07. 심화

이 단원은 앞 단원의 도구를 넘어서는 심화 주제를 다룹니다. 대각화가 안 되는 행렬의 조르당 표준형, 이차형식과 정부호성, 텐서와 크로네커 곱을 개관합니다.

# 이 단원에서 배우는 것

- 조르당 표준형으로 대각화 불가능한 행렬을 다룹니다.
- 이차형식과 정부호성으로 곡률과 최적화를 봅니다.
- 텐서와 크로네커 곱으로 고차원 구조를 표현합니다.

# 이 단원을 읽는 순서

- 21강에서는 조르당 표준형을 개관합니다.
- 22강에서는 이차형식과 정부호성을 다룹니다.
- 23강에서는 텐서와 크로네커 곱을 입문합니다.

# 이 단원을 마치면 할 수 있는 것

- 대수적 중복도와 기하적 중복도의 차이를 설명할 수 있습니다.
- 이차형식의 정부호성을 고윳값과 주소행렬식으로 판정할 수 있습니다.
- 크로네커 곱의 기본 성질을 계산에 사용할 수 있습니다.
