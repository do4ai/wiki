# 02. 행렬과 연립방정식

이 단원은 여러 식을 한 표로 묶는 행렬을 다룹니다. 행렬 연산을 정의하고, 가우스 소거로 연립방정식을 체계적으로 풀며, 계수, 역행렬, LU 분해, 행렬식으로 행렬의 성질을 읽습니다.

# 이 단원에서 배우는 것

- 행렬의 덧셈, 곱셈, 전치의 정의와 성질을 다룹니다.
- 가우스 소거와 행 사다리꼴로 연립방정식을 풉니다.
- 계수(rank)로 해의 존재와 유일성을 읽습니다.
- 역행렬과 LU 분해, 행렬식을 계산하고 해석합니다.

# 이 단원을 읽는 순서

- 4강에서는 행렬 연산을 정의합니다.
- 5강에서는 가우스 소거와 계수를 다룹니다.
- 6강에서는 역행렬과 LU 분해를 배웁니다.
- 7강에서는 행렬식과 그 성질을 다룹니다.

# 이 단원을 마치면 할 수 있는 것

- 임의의 연립방정식을 가우스 소거로 풀 수 있습니다.
- 정사각 행렬의 가역성을 계수와 행렬식으로 판정할 수 있습니다.
- LU 분해로 방정식을 효율적으로 풀 수 있습니다.
