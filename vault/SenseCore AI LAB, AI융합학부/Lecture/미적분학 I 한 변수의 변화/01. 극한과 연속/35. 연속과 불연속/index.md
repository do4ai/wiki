# 35강. 연속과 불연속

34강에서 극한과 함숫값이 별개임을 확인했습니다. $f(x)=\dfrac{x^{2}-1}{x-1}$은 $x\to 1$에서 극한이 $2$이지만 $f(1)$은 정의되지 않았습니다.

그런데 다항식에서는 그냥 대입하면 됐습니다. 두 경우의 차이가 무엇입니까. 이 강의는 **극한과 함숫값이 일치하는 상황**에 이름을 붙이고, 그 이름이 왜 미적분학 전체에서 가장 중요한 조건이 되는지 봅니다.

연속은 뒤에서 계속 가정으로 등장합니다. 36강의 중간값 정리와 최대·최소 정리가 연속을 요구하고, 49강의 미적분의 기본정리도 연속을 요구합니다. 그러니 이 조건이 무엇을 보장하고 무엇을 막아 주는지 정확히 알아야 합니다. 막아 주는 것을 알려면 **연속이 아닌 예**를 봐야 하므로 이 강의는 반례를 많이 다룹니다.

## 이 강의에서 할 수 있게 되는 것
- 연속의 정의를 세 조건으로 나누어 확인할 수 있습니다.
- 불연속점을 찾고 그 종류를 분류할 수 있습니다.
- 연속함수의 연산 규칙으로 복잡한 함수의 연속성을 판정할 수 있습니다.
- 구간에서의 연속을 정의하고 끝점을 한쪽 연속으로 처리할 수 있습니다.
- 어느 점에서도 연속이 아닌 함수와 한 점에서만 연속인 함수를 예로 들 수 있습니다.

## 문제 1. 극한과 함숫값이 일치한다는 것은 무슨 뜻인가

> **문제.** 다음 세 함수가 $x=1$에서 어떻게 다른지 설명하세요.
> (가) $f(x)=x+1$
> (나) $g(x)=\dfrac{x^{2}-1}{x-1}$
> (다) $h(x)=\begin{cases}\dfrac{x^{2}-1}{x-1},&x\ne 1\\ 5,&x=1\end{cases}$

**생각의 실마리.** 세 함수는 $x\ne 1$에서 값이 모두 같습니다. 다른 것은 $x=1$에서 벌어지는 일뿐입니다. 각각에서 함숫값이 있는지, 극한이 있는지, 둘이 같은지를 따로 확인해 봅니다.

**풀이.** 세 항목을 각각 확인합니다.

(가) $f(1)=2$로 함숫값이 있습니다. $\displaystyle\lim_{x\to 1}f(x)=2$로 극한도 있습니다. 두 값이 같습니다.

(나) $g(1)$은 분모가 $0$이라 정의되지 않습니다. 극한은 $x\ne 1$에서 약분해 $2$입니다. **함숫값이 없습니다.**

(다) $h(1)=5$로 함숫값이 있습니다. 극한은 $x\ne 1$인 주변만 보므로 여전히 $2$입니다. **둘이 다릅니다.**

세 경우가 갈리는 지점이 분명합니다. (가)만 함숫값과 극한이 모두 있고 서로 같습니다.

**이 문제에서 배우는 것: 연속의 정의.**

함수 $f$가 점 $a$에서 **연속**이라는 것을 다음과 같이 정의합니다.

$$\lim_{x\to a}f(x)=f(a)$$

이 한 줄이 실제로는 **세 가지를 동시에 요구합니다.**

1. $f(a)$가 정의되어 있습니다.
2. $\displaystyle\lim_{x\to a}f(x)$가 존재합니다.
3. 두 값이 같습니다.

(나)는 1번이 깨졌고 (다)는 3번이 깨졌습니다. 연속성을 확인할 때는 항상 이 셋을 순서대로 봅니다.

$\varepsilon$과 $\delta$로 적으면 다음과 같습니다.

$$\forall\varepsilon>0,\;\exists\delta>0,\;\forall x,\;\big(\lvert x-a\rvert<\delta\;\to\;\lvert f(x)-f(a)\rvert<\varepsilon\big)$$

34강의 극한 정의와 비교하면 두 곳이 달라졌습니다.

| | 극한 | 연속 |
|---|---|---|
| 왼쪽 조건 | $0<\lvert x-a\rvert<\delta$ | $\lvert x-a\rvert<\delta$ |
| 목표값 | 임의의 $L$ | 반드시 $f(a)$ |

**$0<$가 사라진 것**이 핵심입니다. 극한은 $x=a$를 일부러 빼고 봤지만 연속은 $x=a$를 포함해서 봅니다. $x=a$일 때 $\lvert f(a)-f(a)\rvert=0<\varepsilon$은 언제나 참이므로 조건을 빼도 실제로 달라지는 것은 없지만, **$f(a)$가 정의되어 있어야 문장이 성립한다**는 점에서 요구가 강해집니다.

연속을 말로 옮기면 이렇습니다. **입력을 조금만 바꾸면 출력도 조금만 바뀝니다.** $\varepsilon$이 출력의 허용 오차이고 $\delta$가 입력의 허용 오차입니다. 이 성질이 있어야 근삿값을 넣고 근삿값을 얻는 계산이 뜻을 가집니다.

**바로 확인.**

**확인 1-1.** $f(x)=\begin{cases}x^{2},&x\ne 2\\ 3,&x=2\end{cases}$는 $x=2$에서 연속입니까?

*답.* 아닙니다. 극한은 $4$이고 함숫값은 $3$이라 세 번째 조건이 깨집니다.

**확인 1-2.** 확인 1-1의 함수를 $x=2$에서 연속이 되도록 고치세요.

*답.* $f(2)=4$로 바꾸면 됩니다. 그러면 $f(x)=x^{2}$과 같아집니다.

**확인 1-3.** 연속의 정의에서 극한 정의와 달라진 두 곳을 쓰세요.

*답.* 조건에서 $0<$가 빠졌고, 목표값이 임의의 $L$이 아니라 반드시 $f(a)$입니다.

## 문제 2. 연속이 깨지는 방식에는 몇 가지가 있는가

> **문제.** 다음 세 함수의 $x=0$에서의 불연속을 각각 설명하고, 세 경우가 어떻게 다른지 정리하세요.
> (가) $f(x)=\dfrac{\sin x}{x}$ (단 $f(0)=0$)
> (나) $g(x)=\dfrac{\lvert x\rvert}{x}$ (단 $g(0)=0$)
> (다) $h(x)=\dfrac{1}{x^{2}}$ (단 $h(0)=0$)

**생각의 실마리.** 문제 1에서 연속의 세 조건을 세웠습니다. 세 함수 모두 함숫값은 정의되어 있으므로 1번 조건은 통과합니다. 그렇다면 극한 쪽에서 무엇이 잘못되는지 봅니다. 극한이 있는데 값이 다른 경우, 좌우가 달라 극한이 없는 경우, 값이 한없이 커지는 경우로 갈립니다.

**풀이.** (가) 34강 문제 4에서 $\displaystyle\lim_{x\to 0}\dfrac{\sin x}{x}=1$을 증명했습니다. 극한은 존재하지만 $f(0)=0$이므로 다릅니다. 함숫값을 $1$로 고치기만 하면 연속이 됩니다.

(나) 34강 문제 2에서 좌극한이 $-1$, 우극한이 $1$로 달라 극한이 없음을 확인했습니다. 함숫값을 무엇으로 바꿔도 연속이 되지 않습니다. 좌우 두 값 중 하나만 맞출 수 있기 때문입니다.

(다) $x\to 0$에서 $\dfrac{1}{x^{2}}$이 한없이 커지므로 극한이 없습니다. 함숫값을 바꿔 고칠 수 없고, 심지어 함수가 그 점 근처에서 유계도 아닙니다.

세 경우를 정리하면 **고칠 수 있는가**와 **좌우가 각각 수렴하는가**로 갈립니다.

**이 문제에서 배우는 것: 불연속의 분류.**

| 종류 | 조건 | 예 | 고칠 수 있는가 |
|---|---|---|---|
| 제거가능 불연속 | 극한은 존재하는데 $f(a)$와 다르거나 정의되지 않습니다 | $\dfrac{\sin x}{x}$ | 함숫값 하나만 고치면 됩니다 |
| 도약 불연속 | 좌극한과 우극한이 각각 존재하지만 다릅니다 | $\dfrac{\lvert x\rvert}{x}$ | 고칠 수 없습니다 |
| 무한 불연속 | 한쪽 이상이 무한대로 발산합니다 | $\dfrac{1}{x^{2}}$ | 고칠 수 없습니다 |

이 분류에 들어가지 않는 경우도 있습니다. 34강 문제 5의 $\sin\dfrac1x$은 좌극한과 우극한이 모두 존재하지 않으면서 유계이므로 위 셋 중 어디에도 딱 맞지 않습니다. 이런 경우를 진동 불연속이라고 부르기도 합니다.

**제거가능 불연속**이라는 이름이 뜻하는 바를 정확히 새깁니다. **점 하나의 값만 바꿔서 연속으로 만들 수 있다**는 뜻이며, 그 새 값은 반드시 극한값이어야 합니다. (가)에서 $f(0)=1$로 두면

$$f(x)=\begin{cases}\dfrac{\sin x}{x},&x\ne 0\\ 1,&x=0\end{cases}$$

이 되어 $\mathbb{R}$ 전체에서 연속입니다. 이렇게 만든 함수는 뒤에서 자주 쓰이며, 함수를 정의역 끝까지 매끄럽게 이어 붙이는 표준 방법입니다.

**바로 확인.**

**확인 2-1.** $f(x)=\dfrac{x^{2}-4}{x-2}$의 $x=2$에서의 불연속은 어떤 종류이고 어떻게 고칩니까?

*답.* 제거가능 불연속입니다. 극한이 $4$이므로 $f(2)=4$로 정의하면 연속이 됩니다.

**확인 2-2.** $f(x)=\dfrac{1}{x}$의 $x=0$에서의 불연속은 어떤 종류입니까?

*답.* 무한 불연속입니다. 좌우가 각각 음의 무한대와 양의 무한대로 발산합니다.

**확인 2-3.** 도약 불연속을 함숫값 하나를 바꿔 고칠 수 없는 이유를 쓰세요.

*답.* 좌극한과 우극한이 다르므로 극한 자체가 없고, 함숫값은 하나뿐이라 두 값을 동시에 맞출 수 없기 때문입니다.

## 문제 3. 복잡한 함수의 연속을 어떻게 판정하는가

> **문제.** 다음 함수들이 연속인 점을 모두 구하세요.
> (1) $f(x)=\dfrac{x^{2}+1}{x^{2}-3x+2}$
> (2) $g(x)=\sqrt{4-x^{2}}$
> (3) $h(x)=\sin(x^{2}+1)$

**생각의 실마리.** 매번 정의로 확인하는 것은 비효율적입니다. 기본 함수가 연속임을 인정하고, 연속함수를 조합해도 연속이라는 규칙을 쓰면 판정이 계산으로 끝납니다. 대신 조합 규칙에 붙는 조건을 확인해야 합니다. 나눗셈에서는 분모, 근호에서는 안쪽 부호입니다.

**풀이.** (1) 분자와 분모가 모두 다항식이므로 각각 연속입니다. 몫은 분모가 $0$이 아닌 점에서 연속이므로 분모의 근을 찾습니다.

$$x^{2}-3x+2=(x-1)(x-2)=0$$

따라서 $x=1$과 $x=2$를 뺀 모든 실수에서 연속입니다. 두 점은 분자가 $0$이 아니므로 무한 불연속입니다.

(2) 근호 안이 $0$ 이상이어야 하므로 정의역이 $4-x^{2}\ge 0$, 즉 $-2\le x\le 2$입니다. 이 구간에서 $4-x^{2}$이 연속이고 $\sqrt{\;}$가 $0$ 이상에서 연속이므로 합성도 연속입니다. 구간 $[-2,2]$ 전체에서 연속이며, 끝점 $\pm 2$에서는 한쪽 연속입니다.

(3) $x^{2}+1$이 모든 실수에서 연속이고 $\sin$도 모든 실수에서 연속이므로 합성은 모든 실수에서 연속입니다.

**이 문제에서 배우는 것: 연속함수의 연산.**

$f$와 $g$가 $a$에서 연속이면 다음이 모두 $a$에서 연속입니다.

$$f\pm g,\qquad fg,\qquad cf,\qquad \frac{f}{g}\;(g(a)\ne 0)$$

증명은 34강의 극한법칙을 그대로 옮기면 됩니다. 예를 들어 곱의 경우

$$\lim_{x\to a}(fg)(x)=\lim f(x)\cdot\lim g(x)=f(a)g(a)=(fg)(a)$$

입니다. **연속의 정의가 극한의 언어로 쓰여 있으므로 극한법칙이 곧바로 연속의 법칙이 됩니다.**

합성에 대해서는 한 줄이 더 필요합니다.

> $g$가 $a$에서 연속이고 $f$가 $g(a)$에서 연속이면 $f\circ g$는 $a$에서 연속입니다.

28강에서 정의한 합성이 여기서 성질을 물려받습니다. 순서에 주의합니다. $f$의 연속성은 $a$가 아니라 **$g(a)$에서** 필요합니다.

기본 함수의 연속성을 정리해 둡니다. 이후에는 이 목록을 인용해 판정합니다.

| 함수 | 연속인 범위 |
|---|---|
| 다항함수 | 모든 실수 |
| 유리함수 | 분모가 $0$이 아닌 점 |
| $\sqrt{x}$ | $x\ge 0$ |
| $\sin x$, $\cos x$ | 모든 실수 |
| $\tan x$ | $x\ne\dfrac{\pi}{2}+n\pi$ |
| $a^{x}$ | 모든 실수 |
| $\log_{a}x$ | $x>0$ |
| $\lvert x\rvert$ | 모든 실수 |

이 목록과 연산 규칙을 합치면 **초등함수는 정의된 곳에서 모두 연속**이라고 말할 수 있습니다. 그래서 실전에서 불연속을 찾을 때는 **정의되지 않는 점과 조각별로 정의된 함수의 경계점**만 확인하면 됩니다.

**바로 확인.**

**확인 3-1.** $f(x)=\dfrac{x}{x^{2}-9}$가 연속인 점을 모두 구하세요.

*답.* 분모가 $0$이 되는 $x=3$과 $x=-3$을 뺀 모든 실수입니다.

**확인 3-2.** $f(x)=\sqrt{x-1}$의 정의역과 연속인 범위를 쓰세요.

*답.* 정의역은 $x\ge 1$이고 그 범위 전체에서 연속입니다. $x=1$에서는 우측 연속입니다.

**확인 3-3.** $f(x)=\cos(\sqrt{x})$가 연속인 범위를 쓰고 근거를 쓰세요.

*답.* $x\ge 0$입니다. $\sqrt{x}$가 $x\ge 0$에서 연속이고 $\cos$이 모든 실수에서 연속이므로 합성이 연속입니다.

## 문제 4. 조각별로 정의된 함수는 어디를 봐야 하는가

> **문제.** $f(x)=\begin{cases}x^{2}+1,&x<2\\ ax+b,&2\le x<5\\ 3x,&x\ge 5\end{cases}$가 모든 실수에서 연속이 되도록 $a$와 $b$를 정하세요.

**생각의 실마리.** 각 조각은 다항식이라 그 안에서는 저절로 연속입니다. 문제가 될 수 있는 곳은 조각이 바뀌는 경계점 $x=2$와 $x=5$뿐입니다. 각 경계에서 좌극한, 우극한, 함숫값 셋이 모두 같아야 한다는 조건을 세웁니다.

**풀이.** 경계점 두 곳만 확인합니다.

**$x=2$에서.** 좌극한은 왼쪽 식으로 계산해 $2^{2}+1=5$입니다. 우극한과 함숫값은 가운데 식으로 계산해 $2a+b$입니다. 연속이려면

$$2a+b=5$$

**$x=5$에서.** 좌극한은 가운데 식으로 $5a+b$입니다. 우극한과 함숫값은 오른쪽 식으로 $15$입니다. 연속이려면

$$5a+b=15$$

두 식을 연립합니다. 7강의 소거법으로 두 번째에서 첫 번째를 빼면

$$3a=10,\qquad a=\frac{10}{3}$$

첫 식에 넣으면 $b=5-2a=5-\dfrac{20}{3}=-\dfrac{5}{3}$입니다.

검산합니다. $x=2$에서 $2\cdot\dfrac{10}{3}-\dfrac{5}{3}=\dfrac{20-5}{3}=5$로 맞고, $x=5$에서 $5\cdot\dfrac{10}{3}-\dfrac{5}{3}=\dfrac{50-5}{3}=15$로 맞습니다.

**이 문제에서 배우는 것: 구간에서의 연속과 경계점 처리.**

조각별로 정의된 함수의 연속을 확인하는 절차는 다음과 같습니다.

1. 각 조각이 자기 구간 안에서 연속인지 봅니다. 대개 초등함수라 자동입니다.
2. **경계점에서만** 좌극한, 우극한, 함숫값 셋을 계산해 비교합니다.

경계점에서 셋이 모두 같아야 한다는 것이 조건의 전부이며, 미지수가 있으면 그것이 방정식이 됩니다.

구간에서의 연속도 정리해 둡니다. $f$가 열린구간 $(a,b)$의 모든 점에서 연속이면 **그 구간에서 연속**이라고 합니다. 닫힌구간 $[a,b]$에서는 끝점을 따로 다룹니다.

| 위치 | 요구 조건 |
|---|---|
| 내부의 점 | $\displaystyle\lim_{x\to c}f(x)=f(c)$ |
| 왼쪽 끝점 $a$ | $\displaystyle\lim_{x\to a^{+}}f(x)=f(a)$ (우측 연속) |
| 오른쪽 끝점 $b$ | $\displaystyle\lim_{x\to b^{-}}f(x)=f(b)$ (좌측 연속) |

끝점에서 한쪽만 요구하는 이유는 **바깥쪽에는 함수가 정의되어 있지 않기 때문**입니다. 문제 3의 (2)에서 $\sqrt{4-x^{2}}$이 $x=2$에서 좌측 연속이라고 한 것이 이 경우입니다.

이 구별은 36강에서 결정적입니다. 최대·최소 정리가 **닫힌구간**을 요구하는데, 끝점을 포함하지 않으면 정리가 무너지기 때문입니다.

**바로 확인.**

**확인 4-1.** $f(x)=\begin{cases}x+c,&x<1\\ 3x,&x\ge 1\end{cases}$이 연속이 되는 $c$를 구하세요.

*답.* $x=1$에서 좌극한이 $1+c$이고 우극한이 $3$이므로 $c=2$입니다.

**확인 4-2.** 조각별 함수에서 연속을 확인할 때 어디만 보면 됩니까?

*답.* 조각이 바뀌는 경계점만 보면 됩니다. 각 조각 내부는 초등함수라 자동으로 연속입니다.

**확인 4-3.** 닫힌구간의 끝점에서 한쪽 연속만 요구하는 이유를 쓰세요.

*답.* 끝점 바깥에는 함수가 정의되어 있지 않아 그쪽에서 다가가는 극한을 말할 수 없기 때문입니다.

## 문제 5. 어느 점에서도 연속이 아닐 수 있는가

> **문제.** 34강 심화 3의 디리클레 함수 $D(x)=\begin{cases}1,&x\text{가 유리수}\\ 0,&x\text{가 무리수}\end{cases}$에 대하여
> (1) $D$가 모든 점에서 불연속임을 보이세요.
> (2) $f(x)=xD(x)$는 $x=0$에서만 연속임을 보이세요.

**생각의 실마리.** (1)은 34강 심화 3에서 극한이 어디서도 존재하지 않음을 이미 보였습니다. 연속의 두 번째 조건이 깨지므로 결론이 바로 나옵니다. (2)는 34강 심화 5에서 본 것과 같은 구조입니다. 앞에 곱해진 $x$가 값의 차이를 눌러 주는지 봅니다.

**풀이.** (1) 34강 심화 3에서 임의의 $a$에 대해 $\displaystyle\lim_{x\to a}D(x)$가 존재하지 않음을 보였습니다. 연속의 두 번째 조건이 깨지므로 $D$는 모든 점에서 불연속입니다.

(2) 먼저 $x=0$에서 연속임을 보입니다. $D(x)$의 값이 $0$ 아니면 $1$이므로

$$\lvert f(x)-f(0)\rvert=\lvert xD(x)-0\rvert=\lvert x\rvert\,\lvert D(x)\rvert\le\lvert x\rvert$$

입니다. 임의의 $\varepsilon>0$에 대해 $\delta=\varepsilon$으로 잡으면 $\lvert x\rvert<\delta$일 때 $\lvert f(x)-f(0)\rvert\le\lvert x\rvert<\varepsilon$이므로 연속입니다.

이제 $a\ne 0$에서 불연속임을 보입니다. $a$에 수렴하는 유리수 수열 $x_{n}$과 무리수 수열 $y_{n}$을 잡습니다. 그러면

$$f(x_{n})=x_{n}\cdot 1\to a,\qquad f(y_{n})=y_{n}\cdot 0=0\to 0$$

입니다. $a\ne 0$이므로 두 극한이 다르고, 34강 문제 5의 판정에 의해 $\displaystyle\lim_{x\to a}f(x)$가 존재하지 않습니다. 따라서 불연속입니다.

**이 문제에서 배우는 것: 연속의 국소성.**

이 두 예가 알려 주는 것은 **연속이 점마다 따로 정해지는 성질**이라는 사실입니다. 한 점에서 연속인지 아닌지는 그 점의 아주 가까운 주변만 보고 정해집니다. 그래서 다음과 같은 일이 모두 가능합니다.

| 상황 | 예 |
|---|---|
| 모든 점에서 연속 | 다항함수 |
| 한 점에서만 불연속 | $\dfrac{\lvert x\rvert}{x}$ (값을 채운 것) |
| 모든 점에서 불연속 | 디리클레 함수 $D$ |
| 한 점에서만 연속 | $xD(x)$ |

네 번째가 특히 직관을 거스릅니다. 그래프를 그릴 수 없는 함수이기 때문입니다. **"연속이면 붓을 떼지 않고 그릴 수 있다"는 설명은 직관을 돕는 비유일 뿐 정의가 아닙니다.** 정의는 어디까지나 $\varepsilon$과 $\delta$이며, 이 예들이 정의가 비유보다 넓다는 것을 보여 줍니다.

(2)의 증명에서 쓴 부등식이 요령이었습니다. $D(x)$의 값을 모르더라도 **$0\le D(x)\le 1$이라는 유계성만으로** 충분했습니다. 정확한 값을 알 필요 없이 크기만 눌러 잡으면 되는 이 방식은 34강 심화 5와 같으며, 해석학에서 계속 쓰입니다.

**바로 확인.**

**확인 5-1.** $D$가 유계인데도 어디서도 연속이 아닌 이유를 쓰세요.

*답.* 유계는 값의 크기를 제한할 뿐이고 연속은 값의 변화를 제한합니다. $D$는 값이 $0$과 $1$ 사이에 있지만 아무리 좁은 구간에서도 두 값을 모두 취하므로 변화가 억제되지 않습니다.

**확인 5-2.** $f(x)=x^{2}D(x)$는 어디서 연속입니까?

*답.* $x=0$에서만 연속입니다. $\lvert f(x)\rvert\le x^{2}$이므로 $0$에서 연속이고, $a\ne 0$에서는 두 수열이 $a^{2}$과 $0$으로 갈리므로 불연속입니다.

**확인 5-3.** "연속이면 붓을 떼지 않고 그릴 수 있다"가 정의가 아닌 이유를 예로 드세요.

*답.* $xD(x)$는 $x=0$에서 연속이지만 그래프를 그릴 수 없습니다. 비유는 직관을 돕지만 정의를 대신하지 못합니다.

## 유형 총정리(치트시트)

| 개념 | 정의 |
|---|---|
| 점에서 연속 | $\displaystyle\lim_{x\to a}f(x)=f(a)$ |
| 세 조건 | $f(a)$ 존재, 극한 존재, 두 값이 일치 |
| $\varepsilon$과 $\delta$ | $\lvert x-a\rvert<\delta\to\lvert f(x)-f(a)\rvert<\varepsilon$ |
| 우측 연속 | $\displaystyle\lim_{x\to a^{+}}f(x)=f(a)$ |
| 구간에서 연속 | 내부는 양쪽, 끝점은 안쪽 방향만 |

| 불연속 종류 | 특징 | 고칠 수 있는가 |
|---|---|---|
| 제거가능 | 극한은 있는데 값이 다릅니다 | 값 하나를 고칩니다 |
| 도약 | 좌우 극한이 각각 있으나 다릅니다 | 고칠 수 없습니다 |
| 무한 | 한쪽 이상이 발산합니다 | 고칠 수 없습니다 |
| 진동 | 좌우 극한이 없고 유계입니다 | 고칠 수 없습니다 |

| 판정 절차 | 무엇을 봅니까 |
|---|---|
| 초등함수 | 정의되지 않는 점만 봅니다 |
| 유리함수 | 분모의 근을 봅니다 |
| 근호와 로그 | 정의역 조건을 봅니다 |
| 조각별 함수 | 경계점만 봅니다 |
| 합성함수 | 안쪽은 $a$에서, 바깥쪽은 $g(a)$에서 확인합니다 |

## 종합 문제 드릴

> **문제 6.** $f(x)=3x^{2}-x+7$은 어디서 연속입니까?

*답.* 다항함수이므로 모든 실수에서 연속입니다.

> **문제 7.** $f(x)=\dfrac{1}{x-4}$의 불연속점과 그 종류를 쓰세요.

*답.* $x=4$이며 무한 불연속입니다.

> **문제 8.** $f(x)=\dfrac{x^{2}-9}{x+3}$의 $x=-3$에서의 불연속을 분류하고 고치세요.

*답.* 약분하면 $x-3$이므로 극한이 $-6$입니다. 제거가능 불연속이며 $f(-3)=-6$으로 정의하면 연속이 됩니다.

> **문제 9.** $f(x)=\begin{cases}2x+1,&x<3\\ x^{2}-2,&x\ge 3\end{cases}$이 $x=3$에서 연속인지 판정하세요.

*답.* 좌극한이 $7$이고 우극한과 함숫값이 $7$이므로 연속입니다.

> **문제 10.** $f(x)=\begin{cases}\dfrac{x^{2}-1}{x-1},&x\ne 1\\ k,&x=1\end{cases}$이 연속이 되는 $k$를 구하세요.

*답.* 극한이 $2$이므로 $k=2$입니다.

> **문제 11.** $f(x)=\tan x$의 불연속점을 모두 쓰세요.

*답.* $x=\dfrac{\pi}{2}+n\pi$ ($n$은 정수)이며 모두 무한 불연속입니다.

> **문제 12.** $f(x)=\sqrt{x^{2}-4}$의 정의역과 연속 범위를 쓰세요.

*답.* $x^{2}-4\ge 0$이므로 $x\le -2$ 또는 $x\ge 2$이고, 그 범위 전체에서 연속입니다. $x=\pm 2$에서는 각각 한쪽 연속입니다.

> **문제 13.** $f(x)=\lvert x-3\rvert$은 $x=3$에서 연속입니까?

*답.* 연속입니다. 좌극한과 우극한이 모두 $0$이고 함숫값도 $0$입니다. 절댓값은 뾰족하지만 연속입니다.

> **문제 14.** $f(x)=\dfrac{\lvert x\rvert}{x}$의 불연속을 분류하세요.

*답.* $x=0$에서 도약 불연속입니다. 좌극한이 $-1$, 우극한이 $1$입니다.

> **문제 15.** $f(x)=\sin\dfrac{1}{x}$ (단 $f(0)=0$)의 $x=0$에서의 불연속을 분류하세요.

*답.* 진동 불연속입니다. 좌우 극한이 모두 존재하지 않지만 함수는 유계입니다.

> **문제 16.** $f$와 $g$가 $a$에서 연속이면 $\dfrac{f}{g}$도 연속입니까?

*답.* $g(a)\ne 0$일 때만 연속입니다. $g(a)=0$이면 $\dfrac fg$가 $a$에서 정의되지 않습니다.

> **문제 17.** $f(x)=\begin{cases}ax+3,&x\le 1\\ x^{2}+b,&x>1\end{cases}$이 연속이고 $f(2)=7$일 때 $a$와 $b$를 구하세요.

*답.* $f(2)=4+b=7$에서 $b=3$입니다. $x=1$에서 $a+3=1+b=4$이므로 $a=1$입니다.

> **문제 18.** 연속함수의 합성이 연속임을 서술할 때 안쪽과 바깥쪽의 연속성을 어느 점에서 요구합니까?

*답.* 안쪽 $g$는 $a$에서, 바깥쪽 $f$는 $g(a)$에서 연속이어야 합니다.

## 심화 문제

> **심화 1.** 연속의 $\varepsilon$과 $\delta$ 정의에서 $0<\lvert x-a\rvert$의 $0<$를 빼도 되는 이유를 설명하세요.

*답.* $x=a$일 때 조건이 자동으로 성립하기 때문입니다.

*풀이.* $x=a$를 넣으면 결론이 $\lvert f(a)-f(a)\rvert=0<\varepsilon$이 되고, $\varepsilon>0$이므로 언제나 참입니다. 따라서 $x=a$를 포함하든 빼든 전체 명제의 진리값이 같습니다.

다만 두 정의가 **요구하는 바는 다릅니다.** 연속은 $f(a)$가 식에 등장하므로 $f(a)$가 정의되어 있어야 문장을 적을 수조차 없습니다. 극한은 $f(a)$를 쓰지 않으므로 그런 요구가 없습니다.

**남는 것.** 같은 조건을 빼도 되지만 그 조건이 있던 자리가 두 개념의 차이를 만듭니다. 문제 1에서 (나)가 극한은 있는데 연속이 아니었던 이유가 이것입니다. 정의를 비교할 때는 **명제의 진리값만이 아니라 그 명제를 쓸 수 있는 조건까지** 봐야 합니다.

> **심화 2.** $f$가 $a$에서 연속이고 $f(a)>0$이면 $a$의 어떤 근방 전체에서 $f(x)>0$임을 증명하세요.

*답.* 부호가 국소적으로 유지됩니다.

*풀이.* $\varepsilon=\dfrac{f(a)}{2}>0$으로 잡습니다. 연속이므로 어떤 $\delta>0$이 있어서 $\lvert x-a\rvert<\delta$인 모든 $x$에서

$$\lvert f(x)-f(a)\rvert<\frac{f(a)}{2}$$

입니다. 절댓값을 풀면 $f(x)>f(a)-\dfrac{f(a)}{2}=\dfrac{f(a)}{2}>0$입니다.

**남는 것.** $\varepsilon$을 아무 값이나 잡은 것이 아니라 **결론이 나오도록 골랐습니다.** $\dfrac{f(a)}{2}$로 잡아야 아래 경계가 양수로 남습니다. $\varepsilon$을 고르는 이 감각이 해석학 증명의 핵심이며, 36강에서 중간값 정리를 증명할 때 이 결과가 그대로 쓰입니다.

> **심화 3.** $f$가 $[a,b]$에서 연속이고 모든 유리수 점에서 $f(x)=0$이면 $f$가 항등적으로 $0$임을 보이세요.

*답.* 구간 전체에서 $f\equiv 0$입니다.

*풀이.* 임의의 $c\in[a,b]$를 잡습니다. 29강에서 확인한 대로 유리수는 실수 위에 빽빽하므로 $c$에 수렴하는 유리수 수열 $x_{n}$이 존재합니다. $f$가 연속이므로 34강 문제 5의 수열 판정에 의해

$$f(c)=\lim_{n\to\infty}f(x_{n})=\lim_{n\to\infty}0=0$$

입니다. $c$가 임의였으므로 모든 점에서 $f(c)=0$입니다.

**남는 것.** **연속함수는 빽빽한 집합 위의 값만으로 완전히 결정됩니다.** 유리수는 셀 수 있는데도 실수 전체의 값을 정해 버립니다. 이것이 연속이라는 조건의 힘이며, 디리클레 함수가 이 성질을 갖지 못하는 이유는 연속이 아니기 때문입니다. 두 연속함수가 모든 유리수에서 같으면 모든 실수에서 같다는 따름 정리도 여기서 나옵니다.

> **심화 4.** 토메 함수 $T(x)=\begin{cases}\dfrac{1}{q},&x=\dfrac{p}{q}\text{ 기약분수}\\ 0,&x\text{가 무리수}\end{cases}$는 모든 무리수에서 연속이고 모든 유리수에서 불연속임을 설명하세요.

*답.* 연속인 점과 불연속인 점이 모두 무한히 많은 예입니다.

*풀이.* 유리수 $a=\dfrac{p}{q}$에서는 $T(a)=\dfrac1q>0$인데, $a$에 수렴하는 무리수 수열에서 값이 $0$이므로 극한이 $T(a)$와 다릅니다. 불연속입니다.

무리수 $a$에서는 $T(a)=0$입니다. 임의의 $\varepsilon>0$에 대해 $\dfrac1q<\varepsilon$이 되도록 $q$를 크게 잡습니다. 분모가 $q$ 이하인 기약분수는 $a$ 주변의 유한한 구간에 유한개뿐이므로, 그 점들을 모두 피하도록 $\delta$를 작게 잡을 수 있습니다. 그 범위의 $x$에서는 무리수면 $T(x)=0$이고 유리수면 분모가 $q$보다 커서 $T(x)<\varepsilon$입니다. 따라서 연속입니다.

**남는 것.** 문제 5에서 "한 점에서만 연속"인 예를 보았는데, 여기서는 **연속인 점이 무리수 전체**입니다. 연속인 점의 집합이 어떤 모양일 수 있는지가 상당히 복잡하다는 것을 보여 줍니다. 참고로 정반대는 불가능합니다. 모든 유리수에서 연속이고 모든 무리수에서 불연속인 함수는 존재하지 않음이 알려져 있습니다.

> **심화 5.** $f$와 $g$가 연속일 때 $\max(f,g)$도 연속임을 증명하세요.

*답.* 최댓값을 절댓값으로 표현하면 바로 나옵니다.

*풀이.* 두 실수에 대해 다음 항등식이 성립합니다.

$$\max(u,v)=\frac{u+v+\lvert u-v\rvert}{2}$$

확인해 봅니다. $u\ge v$이면 $\lvert u-v\rvert=u-v$이므로 오른쪽이 $\dfrac{2u}{2}=u$입니다. $u<v$이면 $\lvert u-v\rvert=v-u$이므로 오른쪽이 $v$입니다.

따라서

$$\max(f,g)=\frac{f+g+\lvert f-g\rvert}{2}$$

이고, 합과 차와 상수배가 연속을 보존하며 $\lvert\cdot\rvert$도 연속이므로 합성까지 연속입니다.

**남는 것.** 경우를 나눠 증명하려 하면 경계에서 두 조각이 만나는 지점을 따로 다뤄야 해 번거롭습니다. **항등식으로 바꿔 이미 아는 연산으로 표현하면** 경우 나누기가 사라집니다. 이 수법은 최솟값에도 통합니다. $\min(u,v)=\dfrac{u+v-\lvert u-v\rvert}{2}$입니다.

> **심화 6.** 연속함수가 유계라고 말할 수 있습니까? 반례를 들고, 어떤 조건을 붙이면 참이 되는지 말하세요.

*답.* 일반적으로는 거짓이며 닫힌구간 조건이 필요합니다.

*풀이.* 반례가 여럿 있습니다. $f(x)=x$는 $\mathbb{R}$ 전체에서 연속이지만 유계가 아닙니다. 정의역을 유한한 구간으로 좁혀도 안 됩니다. $f(x)=\dfrac1x$는 열린구간 $(0,1)$에서 연속이지만 $x\to 0^{+}$에서 한없이 커지므로 유계가 아닙니다.

**닫힌구간** $[a,b]$에서 연속이면 유계가 됩니다. 이것이 36강에서 증명할 최대·최소 정리의 앞부분입니다.

**남는 것.** 두 반례가 각각 무엇을 알려 주는지 구분합니다. 첫 번째는 **구간이 유한해야 한다**는 것이고, 두 번째는 **끝점을 포함해야 한다**는 것입니다. 36강의 정리에 "닫힌"과 "유계인" 두 조건이 모두 붙는 이유가 이 두 반례에 하나씩 대응합니다. 정리의 가정은 장식이 아니라 각각이 막고 있는 반례가 있습니다.

## 코드 검산

연속은 극한으로 정의되므로 코드로 증명할 수 없습니다. 대신 불연속점 근처에서 값이 어떻게 갈리는지, 그리고 경계점에서 두 조각이 실제로 만나는지 확인합니다.

```python
import numpy as np

h = np.array([1e-1, 1e-2, 1e-3, 1e-4])

# 문제 2: 세 가지 불연속이 어떻게 다른지 봅니다.
print(np.round(np.sin(h) / h, 6))          # [0.998334 0.999983 1.       1.      ]
print(np.abs(h) / h, np.abs(-h) / (-h))
# [1. 1. 1. 1.] [-1. -1. -1. -1.]
print(1 / h**2)                            # [1.e+02 1.e+04 1.e+06 1.e+08]

# 문제 3: 유리함수의 불연속점은 분모의 근입니다.
x = np.linspace(0, 3, 3001)
den = x**2 - 3*x + 2
print(np.round(x[np.abs(den) < 1e-12], 6))                       # [1. 2.]

# 문제 4: 경계점에서 세 값이 만나는지 확인합니다.
a, b = 10/3, -5/3
left2, mid2 = 2.0**2 + 1, a*2 + b
mid5, right5 = a*5 + b, 3*5.0
print(np.isclose(left2, mid2), np.isclose(mid5, right5))         # True True
print(round(mid2, 10), round(mid5, 10))                          # 5.0 15.0

# 문제 5: x*D(x) 는 0 에서만 값이 붙습니다.
def D(v):                      # 유한 소수는 유리수로 취급합니다
    return 1.0 if float(v).is_integer() or abs(v * 1000 - round(v * 1000)) < 1e-12 else 0.0

rat = np.array([0.5, 0.1, 0.01, 0.001])          # 유리수 표본
irr = np.array([np.sqrt(2) / 10**k for k in range(1, 5)])   # 무리수 표본
print([round(float(v * D(v)), 6) for v in rat])      # [0.5, 0.1, 0.01, 0.001]
print([round(float(v * D(v)), 6) for v in irr])      # [0.0, 0.0, 0.0, 0.0]

# 0 근처에서는 두 표본 모두 0 으로 눌립니다.
small_r = np.array([1e-3, 1e-4, 1e-5])
print([round(float(v * 1.0), 6) for v in small_r])   # [0.001, 0.0001, 1e-05]
print(bool(np.all(np.abs(small_r * 1.0) <= np.abs(small_r))))    # True

# 심화 5: max(u, v) 를 절댓값으로 표현한 항등식
u = np.array([-3.0, 1.0, 2.5, 7.0])
v = np.array([4.0, 1.0, -2.5, 0.0])
print(bool(np.allclose(np.maximum(u, v), (u + v + np.abs(u - v)) / 2)))   # True
print(bool(np.allclose(np.minimum(u, v), (u + v - np.abs(u - v)) / 2)))   # True
```

출력이 주석과 모두 일치합니다. 첫 세 줄이 세 가지 불연속을 나란히 보여 줍니다. $\dfrac{\sin x}{x}$는 값이 $1$로 모여 제거가능이고, $\dfrac{\lvert x\rvert}{x}$는 좌우가 $1$과 $-1$로 갈려 도약이며, $\dfrac{1}{x^{2}}$은 값이 $10^{8}$까지 치솟아 무한 불연속입니다.

다섯 번째 검산에는 한계가 있습니다. 부동소수점으로는 무리수를 정확히 저장할 수 없으므로 여기서 쓴 $D$는 진짜 디리클레 함수가 아니라 **유한 소수만 유리수로 판정하는 흉내**입니다. 실제 디리클레 함수는 어떤 프로그램으로도 계산할 수 없습니다. 문제 5의 결론은 손으로 한 증명에서만 나오며, 코드는 그 모양을 짐작하게 해 줄 뿐입니다.

## 부록. 기호 정리

| 기호 | 읽는 법 | 뜻 |
|---|---|---|
| $f$가 $a$에서 연속 | continuous at $a$ | $\displaystyle\lim_{x\to a}f(x)=f(a)$입니다 |
| 제거가능 불연속 | removable | 값 하나를 고치면 연속이 됩니다 |
| 도약 불연속 | jump | 좌우 극한이 각각 있으나 다릅니다 |
| 무한 불연속 | infinite | 한쪽 이상이 발산합니다 |
| $D(x)$ | 디리클레 함수 | 유리수에서 $1$, 무리수에서 $0$입니다 |
| $[a,b]$에서 연속 | 닫힌구간에서 연속 | 내부는 양쪽, 끝점은 안쪽 방향입니다 |

다음 36강에서는 연속이라는 조건이 실제로 무엇을 보장하는지 봅니다. 닫힌구간에서 연속인 함수는 중간값을 반드시 취하고 최댓값과 최솟값을 반드시 가집니다. 심화 6에서 확인한 두 반례가 그 정리의 가정이 왜 필요한지 그대로 설명합니다.
