# 38강. 곱, 몫, 연쇄법칙

37강에서 도함수를 정의하고 멱법칙을 얻었습니다. 그러나 정의로 매번 계산하는 것은 비효율적입니다. $\left(x^{3}+2x\right)^{10}$을 정의로 미분하려면 전개부터 해야 합니다.

이 강의는 **함수를 조합했을 때의 도함수**를 구하는 규칙을 만듭니다. 합과 상수배는 쉽게 나옵니다. 그러나 곱은 그렇지 않습니다. $(fg)'=f'g'$이라고 생각하기 쉽지만 이는 거짓이며, 31강에서 $\sum a_{i}b_{i}\ne\left(\sum a_{i}\right)\left(\sum b_{i}\right)$였던 것과 같은 종류의 착각입니다.

여기서 얻는 세 규칙, 특히 **연쇄법칙**은 이후 모든 계산의 기반이 됩니다. 216강 이후 신경망의 역전파가 연쇄법칙을 층마다 반복 적용하는 것이므로, 이 강의의 내용이 그대로 딥러닝의 학습 알고리즘이 됩니다.

## 이 강의에서 할 수 있게 되는 것
- 합과 상수배의 미분법을 정의에서 유도할 수 있습니다.
- $(fg)'=f'g'$이 거짓임을 반례로 보이고 올바른 곱의 미분법을 유도할 수 있습니다.
- 몫의 미분법을 쓰고 언제 쓸지 판단할 수 있습니다.
- 연쇄법칙으로 합성함수를 미분할 수 있습니다.
- 여러 규칙이 섞인 식에서 어느 규칙을 어느 순서로 쓸지 정할 수 있습니다.

## 문제 1. 더하기와 상수배는 어떻게 되는가

> **문제.** $f$와 $g$가 미분가능할 때
> (1) $(f+g)'=f'+g'$임을 정의로 증명하세요.
> (2) $(cf)'=cf'$임을 정의로 증명하세요.
> (3) $\dfrac{d}{dx}\left(3x^{4}-5x^{2}+7\right)$을 구하세요.

**생각의 실마리.** 두 증명 모두 정의에 넣고 차분몫을 정리하면 됩니다. 34강의 극한법칙 중 합의 법칙과 상수배의 법칙을 쓸 수 있는 모양으로 만드는 것이 목표입니다. 그 법칙을 쓰려면 각 극한이 존재해야 하는데, 그 조건은 가정에서 이미 주어졌습니다.

**풀이.** (1) 정의에 넣습니다.

$$\frac{(f+g)(x+h)-(f+g)(x)}{h}=\frac{f(x+h)+g(x+h)-f(x)-g(x)}{h}$$

$f$끼리 $g$끼리 묶습니다.

$$=\frac{f(x+h)-f(x)}{h}+\frac{g(x+h)-g(x)}{h}$$

두 차분몫의 극한이 각각 $f'(x)$와 $g'(x)$로 존재하므로 34강의 합의 법칙을 적용할 수 있습니다.

$$(f+g)'(x)=f'(x)+g'(x)$$

(2) 같은 방식입니다.

$$\frac{cf(x+h)-cf(x)}{h}=c\cdot\frac{f(x+h)-f(x)}{h}$$

$c$가 $h$와 무관한 상수이므로 극한 밖으로 나갑니다. 따라서 $(cf)'=cf'$입니다.

(3) 두 규칙과 멱법칙을 합쳐 씁니다.

$$\frac{d}{dx}\left(3x^{4}-5x^{2}+7\right)=3\cdot 4x^{3}-5\cdot 2x+0=12x^{3}-10x$$

**이 문제에서 배우는 것: 미분의 선형성.**

두 결과를 합쳐 **미분의 선형성**이라고 합니다.

$$(\alpha f+\beta g)'=\alpha f'+\beta g'$$

31강에서 시그마의 선형성을 다뤘는데 미분도 같은 성질을 가집니다. 두 연산 모두 **더하기를 그대로 통과시키고 상수를 밖으로 내보냅니다.** 이런 연산을 선형연산이라고 부르며, 62강 이후의 선형대수학에서 이 구조를 정면으로 다룹니다.

증명에서 결정적이었던 것은 **극한법칙을 쓸 수 있는 모양으로 차분몫을 쪼갠 것**입니다. 그리고 극한법칙을 쓰려면 각 극한이 존재해야 하므로, $f$와 $g$가 미분가능하다는 가정이 반드시 필요합니다. 34강 심화 6에서 확인한 대로 한쪽 극한이 없으면 합의 법칙을 쓸 수 없습니다.

다항함수의 미분은 이제 기계적으로 됩니다.

$$\frac{d}{dx}\left(a_{n}x^{n}+\cdots+a_{1}x+a_{0}\right)=na_{n}x^{n-1}+\cdots+a_{1}$$

**바로 확인.**

**확인 1-1.** $\dfrac{d}{dx}\left(2x^{5}-x^{3}+4x\right)$를 구하세요.

*답.* $10x^{4}-3x^{2}+4$입니다.

**확인 1-2.** $\dfrac{d}{dx}\left(\dfrac{1}{x}+\sqrt{x}\right)$를 구하세요.

*답.* $x^{-1}$과 $x^{1/2}$로 보고 멱법칙을 쓰면 $-x^{-2}+\dfrac{1}{2}x^{-1/2}=-\dfrac{1}{x^{2}}+\dfrac{1}{2\sqrt{x}}$입니다.

**확인 1-3.** 미분의 선형성과 31강의 시그마 선형성이 어떤 점에서 같습니까?

*답.* 둘 다 덧셈을 그대로 통과시키고 상수를 밖으로 내보냅니다. 이런 성질을 가진 연산을 선형연산이라고 합니다.

## 문제 2. 곱의 도함수는 도함수의 곱인가

> **문제.** (1) $f(x)=x^{2}$, $g(x)=x^{3}$일 때 $(fg)'$과 $f'g'$을 각각 계산해 비교하세요.
> (2) 올바른 공식을 정의에서 유도하세요.

**생각의 실마리.** (1)은 $fg=x^{5}$이므로 멱법칙으로 바로 계산됩니다. (2)에서 정의에 넣으면 $f(x+h)g(x+h)-f(x)g(x)$가 나오는데, 이 식에는 차분몫이 보이지 않습니다. 37강 문제 3에서 쓴 수법을 떠올립니다. **차분몫이 나타나도록 억지로 만듭니다.** 여기서는 같은 항을 빼고 더하는 방법을 씁니다.

**풀이.** (1) $fg=x^{2}\cdot x^{3}=x^{5}$이므로 $(fg)'=5x^{4}$입니다.

한편 $f'=2x$이고 $g'=3x^{2}$이므로 $f'g'=6x^{3}$입니다.

두 값이 다릅니다. 예를 들어 $x=1$에서 $5$와 $6$입니다. **$(fg)'\ne f'g'$입니다.**

(2) 정의에 넣습니다.

$$\frac{f(x+h)g(x+h)-f(x)g(x)}{h}$$

분자에 $f(x+h)g(x)$를 빼고 더합니다. 값은 변하지 않습니다.

$$=\frac{f(x+h)g(x+h)-f(x+h)g(x)+f(x+h)g(x)-f(x)g(x)}{h}$$

앞 두 항에서 $f(x+h)$를, 뒤 두 항에서 $g(x)$를 묶습니다.

$$=f(x+h)\cdot\frac{g(x+h)-g(x)}{h}+g(x)\cdot\frac{f(x+h)-f(x)}{h}$$

이제 각 항이 극한을 가집니다. $f$가 미분가능하므로 37강 문제 3에 의해 연속이고 따라서 $f(x+h)\to f(x)$입니다. 나머지 두 차분몫은 각각 $g'(x)$와 $f'(x)$로 갑니다.

$$(fg)'(x)=f(x)g'(x)+g(x)f'(x)$$

검산합니다. $f=x^{2}$, $g=x^{3}$이면 $x^{2}\cdot 3x^{2}+x^{3}\cdot 2x=3x^{4}+2x^{4}=5x^{4}$로 (1)과 일치합니다.

**이 문제에서 배우는 것: 곱의 미분법.**

$$(fg)'=f'g+fg'$$

외우는 방법이 있습니다. **앞의 것만 미분하고 뒤의 것만 미분해서 더합니다.** 두 항이 필요한 이유를 직관으로 말하면, 곱이 변하는 원인이 두 가지이기 때문입니다. $f$가 변해서 곱이 변하고 $g$가 변해서도 곱이 변하므로 두 기여를 더합니다.

증명에서 쓴 **빼고 더하기**는 해석학에서 가장 자주 쓰는 수법입니다. 목표 형태가 보이지 않을 때 중간 다리가 될 항을 넣었다 빼서 두 조각으로 쪼갭니다. 33강 심화 5에서 합을 앞뒤로 쪼갠 것도 같은 성격입니다.

증명 안에서 **$f$의 연속성을 썼다**는 점도 기억합니다. $f(x+h)\to f(x)$가 필요했고, 그것은 37강에서 증명한 "미분가능하면 연속"에서 나왔습니다. 앞 강의의 결과가 여기서 재료로 쓰입니다.

세 개 이상의 곱으로 확장됩니다.

$$(fgh)'=f'gh+fg'h+fgh'$$

**한 번에 하나씩만 미분한 항들을 모두 더합니다.** 25강의 귀납법으로 임의의 개수까지 확장됩니다.

**바로 확인.**

**확인 2-1.** $\dfrac{d}{dx}\left[(x^{2}+1)(x^{3}-2)\right]$를 곱의 미분법으로 구하세요.

*답.* $2x(x^{3}-2)+(x^{2}+1)\cdot 3x^{2}=2x^{4}-4x+3x^{4}+3x^{2}=5x^{4}+3x^{2}-4x$입니다.

**확인 2-2.** 확인 2-1을 전개한 뒤 미분해서 같은 답이 나오는지 확인하세요.

*답.* 전개하면 $x^{5}+x^{3}-2x^{2}-2$이고 미분하면 $5x^{4}+3x^{2}-4x$로 일치합니다.

**확인 2-3.** $\dfrac{d}{dx}\left[x\cdot x\cdot x\right]$를 세 개 곱의 규칙으로 구하고 멱법칙과 비교하세요.

*답.* $1\cdot x\cdot x+x\cdot 1\cdot x+x\cdot x\cdot 1=3x^{2}$이고 멱법칙 $3x^{2}$과 같습니다.

## 문제 3. 나눗셈은 어떻게 미분하는가

> **문제.** (1) $\left(\dfrac{1}{g}\right)'$을 정의로 구하세요.
> (2) 이 결과와 곱의 미분법으로 $\left(\dfrac{f}{g}\right)'$을 유도하세요.
> (3) $\dfrac{d}{dx}\dfrac{x^{2}+1}{x-3}$을 구하세요.

**생각의 실마리.** (1)에서 정의에 넣으면 분수의 차가 나오므로 4강의 통분으로 정리합니다. (2)에서는 $\dfrac{f}{g}=f\cdot\dfrac{1}{g}$로 보면 곱의 미분법을 쓸 수 있습니다. 새 공식을 처음부터 만들 필요가 없습니다.

**풀이.** (1) 정의에 넣고 통분합니다.

$$\frac{1}{h}\left(\frac{1}{g(x+h)}-\frac{1}{g(x)}\right)=\frac{1}{h}\cdot\frac{g(x)-g(x+h)}{g(x+h)g(x)}$$

분자의 부호를 뒤집어 차분몫을 만듭니다.

$$=-\frac{g(x+h)-g(x)}{h}\cdot\frac{1}{g(x+h)g(x)}$$

$g$가 연속이므로 $g(x+h)\to g(x)$이고, $g(x)\ne 0$이면 극한을 취할 수 있습니다.

$$\left(\frac{1}{g}\right)'=-\frac{g'}{g^{2}}$$

(2) $\dfrac{f}{g}=f\cdot\dfrac{1}{g}$로 보고 곱의 미분법을 씁니다.

$$\left(\frac{f}{g}\right)'=f'\cdot\frac{1}{g}+f\cdot\left(-\frac{g'}{g^{2}}\right)=\frac{f'}{g}-\frac{fg'}{g^{2}}$$

통분합니다.

$$=\frac{f'g-fg'}{g^{2}}$$

(3) $f=x^{2}+1$, $g=x-3$이므로 $f'=2x$, $g'=1$입니다.

$$\frac{2x(x-3)-(x^{2}+1)\cdot 1}{(x-3)^{2}}=\frac{2x^{2}-6x-x^{2}-1}{(x-3)^{2}}=\frac{x^{2}-6x-1}{(x-3)^{2}}$$

**이 문제에서 배우는 것: 몫의 미분법.**

$$\left(\frac{f}{g}\right)'=\frac{f'g-fg'}{g^{2}}\qquad(g\ne 0)$$

곱의 미분법과 달리 **순서가 중요합니다.** 분자에서 $f'g$가 먼저이고 $fg'$이 뒤이며 부호가 뺄셈입니다. 순서를 바꾸면 부호가 뒤집혀 틀립니다.

부호를 확인하는 방법이 있습니다. $f=1$인 특수한 경우를 넣어 보면 $f'=0$이므로 $-\dfrac{g'}{g^{2}}$이 나와야 합니다. 공식에 넣으면 $\dfrac{0\cdot g-1\cdot g'}{g^{2}}=-\dfrac{g'}{g^{2}}$으로 맞습니다. 순서를 바꿔 외웠다면 여기서 부호가 틀리므로 걸러집니다.

$g\ne 0$ 조건도 잊지 않습니다. 35강에서 유리함수가 분모의 근에서 불연속이었고, 불연속점에서는 37강의 대우에 의해 미분도 불가능합니다.

**몫의 미분법을 쓰지 않는 편이 나은 경우**도 있습니다. 분모가 단항식이면 나눠서 멱법칙으로 처리하는 것이 빠릅니다.

$$\frac{x^{3}+x}{x^{2}}=x+x^{-1}\;\;\Longrightarrow\;\;\frac{d}{dx}=1-x^{-2}$$

몫의 미분법으로 해도 같은 답이 나오지만 계산이 길어집니다. **공식을 아는 것과 언제 쓸지 아는 것은 다릅니다.**

**바로 확인.**

**확인 3-1.** $\dfrac{d}{dx}\dfrac{x}{x^{2}+1}$을 구하세요.

*답.* $\dfrac{1\cdot(x^{2}+1)-x\cdot 2x}{(x^{2}+1)^{2}}=\dfrac{1-x^{2}}{(x^{2}+1)^{2}}$입니다.

**확인 3-2.** $\dfrac{d}{dx}\dfrac{2x^{3}-x}{x}$를 두 가지 방법으로 구하세요.

*답.* 나눠서 $2x^{2}-1$로 만들면 도함수가 $4x$입니다. 몫의 미분법으로 해도 $\dfrac{(6x^{2}-1)x-(2x^{3}-x)}{x^{2}}=\dfrac{4x^{3}}{x^{2}}=4x$로 같습니다.

**확인 3-3.** 몫의 미분법에서 분자의 순서를 바꾸면 어떻게 확인할 수 있습니까?

*답.* $f=1$을 넣어 봅니다. 올바른 공식이면 $-\dfrac{g'}{g^{2}}$이 나오고, 순서가 뒤집혔다면 부호가 반대로 나옵니다.

## 문제 4. 합성함수는 어떻게 미분하는가

> **문제.** (1) $y=(x^{2}+1)^{3}$을 전개해서 미분하세요.
> (2) 결과를 $3(x^{2}+1)^{2}$과 비교하고, 무엇이 더 곱해져 있는지 확인하세요.
> (3) 일반적인 규칙을 세우고 $y=(3x+5)^{10}$에 적용하세요.

**생각의 실마리.** (2)에서 안쪽 함수를 그대로 두고 바깥쪽만 멱법칙으로 미분한 것이 $3(x^{2}+1)^{2}$입니다. 실제 답과 얼마나 차이 나는지 나눠 보면 무엇이 빠졌는지 보입니다. 그 빠진 것이 안쪽 함수와 어떤 관계인지 살핍니다.

**풀이.** (1) 전개합니다. 20강의 이항정리를 씁니다.

$$(x^{2}+1)^{3}=x^{6}+3x^{4}+3x^{2}+1$$

미분하면

$$y'=6x^{5}+12x^{3}+6x$$

(2) $3(x^{2}+1)^{2}=3(x^{4}+2x^{2}+1)=3x^{4}+6x^{2}+3$입니다.

실제 답을 이것으로 나눠 봅니다.

$$\frac{6x^{5}+12x^{3}+6x}{3x^{4}+6x^{2}+3}=\frac{6x(x^{4}+2x^{2}+1)}{3(x^{4}+2x^{2}+1)}=2x$$

**$2x$가 더 곱해져 있습니다.** 그런데 $2x$는 안쪽 함수 $x^{2}+1$의 도함수입니다.

(3) 규칙을 세웁니다. $y=f(g(x))$이면

$$y'=f'(g(x))\cdot g'(x)$$

**바깥 함수를 미분하되 안쪽을 그대로 넣고, 거기에 안쪽 함수의 도함수를 곱합니다.**

$y=(3x+5)^{10}$에 적용합니다. 바깥이 $t^{10}$이고 안쪽이 $3x+5$입니다.

$$y'=10(3x+5)^{9}\cdot 3=30(3x+5)^{9}$$

**이 문제에서 배우는 것: 연쇄법칙.**

$$\big(f\circ g\big)'(x)=f'\big(g(x)\big)\cdot g'(x)$$

라이프니츠 표기로 적으면 구조가 더 잘 보입니다. $y=f(u)$이고 $u=g(x)$일 때

$$\frac{dy}{dx}=\frac{dy}{du}\cdot\frac{du}{dx}$$

$du$가 약분되는 것처럼 보여 외우기 쉽지만, 37강에서 확인한 대로 이것은 분수가 아니므로 **약분은 기억을 돕는 비유일 뿐 증명이 아닙니다.**

증명의 뼈대는 이렇습니다. $u=g(x)$, $k=g(x+h)-g(x)$로 두면

$$\frac{f(g(x+h))-f(g(x))}{h}=\frac{f(u+k)-f(u)}{k}\cdot\frac{k}{h}$$

이고 $\dfrac{k}{h}$가 $g$의 차분몫입니다. $h\to 0$에서 $g$가 연속이므로 $k\to 0$이고, 두 인수가 각각 $f'(u)$와 $g'(x)$로 갑니다. 다만 $k=0$이 되는 경우를 따로 다뤄야 해서 완전한 증명은 조금 더 손이 갑니다.

연쇄법칙을 쓰는 절차를 정리합니다.

1. **바깥과 안쪽을 나눕니다.** 무엇을 먼저 계산하게 되는지 보면 안쪽입니다.
2. 바깥을 미분하되 **안쪽을 그대로 넣습니다.**
3. **안쪽의 도함수를 곱합니다.**
4. 안쪽이 또 합성이면 다시 반복합니다.

세 겹 이상이면 계속 이어집니다.

$$\big(f(g(h(x)))\big)'=f'\big(g(h(x))\big)\cdot g'\big(h(x)\big)\cdot h'(x)$$

**바깥에서 안쪽으로 차례로 미분해 모두 곱합니다.** 216강의 역전파가 정확히 이 곱을 층 수만큼 이어 붙이는 계산이며, 층이 깊어질수록 곱해지는 인수가 늘어나 값이 사라지거나 폭발하는 문제가 여기서 비롯됩니다.

**바로 확인.**

**확인 4-1.** $\dfrac{d}{dx}(x^{3}-2x)^{5}$를 구하세요.

*답.* $5(x^{3}-2x)^{4}\cdot(3x^{2}-2)$입니다.

**확인 4-2.** $\dfrac{d}{dx}\sqrt{x^{2}+9}$를 구하세요.

*답.* 바깥이 $t^{1/2}$이므로 $\dfrac{1}{2}(x^{2}+9)^{-1/2}\cdot 2x=\dfrac{x}{\sqrt{x^{2}+9}}$입니다.

**확인 4-3.** $\dfrac{d}{dx}\left(\left(x^{2}+1\right)^{3}+2\right)^{4}$를 구하세요.

*답.* 세 겹입니다. $4\left((x^{2}+1)^{3}+2\right)^{3}\cdot 3(x^{2}+1)^{2}\cdot 2x$입니다.

## 문제 5. 여러 규칙이 섞이면 어느 것부터 쓰는가

> **문제.** 다음을 미분하세요.
> (1) $y=x^{2}\sqrt{x^{2}+1}$
> (2) $y=\dfrac{(2x+1)^{3}}{x^{2}}$
> (3) $y=\left(\dfrac{x-1}{x+1}\right)^{4}$

**생각의 실마리.** 식의 **가장 바깥 구조**가 무엇인지 먼저 봅니다. 곱이면 곱의 미분법, 몫이면 몫의 미분법, 합성이면 연쇄법칙으로 시작하고, 그 안의 조각을 각각 처리합니다. 순서를 잘못 잡으면 계산이 길어집니다.

**풀이.** (1) 가장 바깥이 **곱**입니다. $f=x^{2}$, $g=\sqrt{x^{2}+1}$로 두고 곱의 미분법을 씁니다.

$g$를 미분할 때 연쇄법칙이 필요합니다. 확인 4-2에서 $g'=\dfrac{x}{\sqrt{x^{2}+1}}$입니다.

$$y'=2x\sqrt{x^{2}+1}+x^{2}\cdot\frac{x}{\sqrt{x^{2}+1}}=2x\sqrt{x^{2}+1}+\frac{x^{3}}{\sqrt{x^{2}+1}}$$

통분해 정리하면

$$=\frac{2x(x^{2}+1)+x^{3}}{\sqrt{x^{2}+1}}=\frac{3x^{3}+2x}{\sqrt{x^{2}+1}}$$

(2) 가장 바깥이 **몫**입니다. 그런데 분모가 단항식이므로 문제 3에서 말한 대로 나누는 편이 낫습니다.

$$y=(2x+1)^{3}\cdot x^{-2}$$

곱으로 보고 곱의 미분법과 연쇄법칙을 씁니다.

$$y'=3(2x+1)^{2}\cdot 2\cdot x^{-2}+(2x+1)^{3}\cdot(-2x^{-3})$$
$$=\frac{6(2x+1)^{2}}{x^{2}}-\frac{2(2x+1)^{3}}{x^{3}}$$

$\dfrac{2(2x+1)^{2}}{x^{3}}$으로 묶습니다.

$$=\frac{2(2x+1)^{2}}{x^{3}}\Big[3x-(2x+1)\Big]=\frac{2(2x+1)^{2}(x-1)}{x^{3}}$$

(3) 가장 바깥이 **합성**입니다. 바깥이 $t^{4}$이고 안쪽이 $\dfrac{x-1}{x+1}$입니다.

안쪽을 몫의 미분법으로 미분합니다.

$$\left(\frac{x-1}{x+1}\right)'=\frac{1\cdot(x+1)-(x-1)\cdot 1}{(x+1)^{2}}=\frac{2}{(x+1)^{2}}$$

연쇄법칙으로 합칩니다.

$$y'=4\left(\frac{x-1}{x+1}\right)^{3}\cdot\frac{2}{(x+1)^{2}}=\frac{8(x-1)^{3}}{(x+1)^{5}}$$

**이 문제에서 배우는 것: 규칙을 고르는 순서.**

미분할 식을 보면 **가장 바깥 연산을 먼저 찾습니다.** 그것이 어느 규칙으로 시작할지를 정합니다.

| 가장 바깥이 | 시작할 규칙 |
|---|---|
| 덧셈이나 뺄셈 | 선형성으로 항별로 나눕니다 |
| 상수배 | 상수를 밖으로 빼냅니다 |
| 곱 | 곱의 미분법 |
| 몫 | 몫의 미분법 (분모가 단항식이면 나누는 편이 낫습니다) |
| 거듭제곱이나 함수 적용 | 연쇄법칙 |

시작한 뒤 각 조각을 미분할 때 다시 이 표를 봅니다. 재귀적으로 적용하면 어떤 초등함수든 미분됩니다.

계산을 짧게 하는 요령도 정리합니다.

- **미분 전에 식을 간단히 할 수 있으면 먼저 합니다.** (2)에서 분모를 $x^{-2}$로 올린 것이 그 예입니다.
- **미분 후에는 공통인수로 묶습니다.** (2)와 (3)에서 묶어 정리하니 훨씬 짧아졌습니다.
- **답의 모양을 예측해 둡니다.** 연쇄법칙을 쓰면 안쪽 함수의 거듭제곱이 하나 줄어든 형태가 남습니다.

**바로 확인.**

**확인 5-1.** $y=x^{3}(2x-1)^{4}$을 미분하세요.

*답.* 곱의 미분법으로 $3x^{2}(2x-1)^{4}+x^{3}\cdot 4(2x-1)^{3}\cdot 2$입니다. 묶으면 $x^{2}(2x-1)^{3}\big[3(2x-1)+8x\big]=x^{2}(2x-1)^{3}(14x-3)$입니다.

**확인 5-2.** $y=\dfrac{1}{(x^{2}+1)^{3}}$을 미분하세요.

*답.* $(x^{2}+1)^{-3}$으로 보고 연쇄법칙을 쓰면 $-3(x^{2}+1)^{-4}\cdot 2x=-\dfrac{6x}{(x^{2}+1)^{4}}$입니다.

**확인 5-3.** 미분할 식을 보고 가장 먼저 무엇을 판단합니까?

*답.* 가장 바깥 연산이 무엇인지 판단합니다. 그것이 어느 규칙으로 시작할지를 정합니다.

*답.* $1\cdot(x^{2}+2)+(x+1)\cdot 2x=3x^{2}+2x+2$입니다.

> **문제 8.** $\dfrac{d}{dx}\dfrac{x+1}{x-1}$을 구하세요.

*답.* $\dfrac{(x-1)-(x+1)}{(x-1)^{2}}=\dfrac{-2}{(x-1)^{2}}$입니다.

> **문제 10.** $\dfrac{d}{dx}\sqrt{3x+1}$을 구하세요.

*답.* $\dfrac{1}{2}(3x+1)^{-1/2}\cdot 3=\dfrac{3}{2\sqrt{3x+1}}$입니다.

> **문제 11.** $(fg)'=f'g'$이 거짓임을 $f=g=x$로 보이세요.

*답.* $fg=x^{2}$이므로 $(fg)'=2x$입니다. 그러나 $f'g'=1\cdot 1=1$입니다. $x=1$에서 $2$와 $1$로 다릅니다.

> **문제 13.** $y=(x^{2}+3)^{4}$의 $x=1$에서의 접선의 기울기를 구하세요.

*답.* $y'=4(x^{2}+3)^{3}\cdot 2x$이고 $x=1$에서 $4\cdot 64\cdot 2=512$입니다.

> **문제 14.** $\dfrac{d}{dx}\left[x^{2}(x+1)^{3}\right]$을 구하고 공통인수로 묶으세요.

*답.* $2x(x+1)^{3}+x^{2}\cdot 3(x+1)^{2}=x(x+1)^{2}\big[2(x+1)+3x\big]=x(x+1)^{2}(5x+2)$입니다.

> **문제 15.** $\dfrac{d}{dx}\dfrac{x^{4}+x^{2}}{x^{2}}$를 가장 짧은 방법으로 구하세요.

*답.* 나누면 $x^{2}+1$이므로 도함수는 $2x$입니다. 몫의 미분법을 쓸 필요가 없습니다.

> **문제 16.** $y=\left((2x+1)^{2}+3\right)^{5}$를 미분하세요.

*답.* $5\left((2x+1)^{2}+3\right)^{4}\cdot 2(2x+1)\cdot 2=20(2x+1)\left((2x+1)^{2}+3\right)^{4}$입니다.

> **문제 17.** 곱의 미분법 증명에서 왜 $f$의 연속성이 필요합니까?

*답.* $f(x+h)\to f(x)$를 써야 하기 때문입니다. 이것은 37강의 "미분가능하면 연속"에서 나옵니다.

> **문제 18.** $\dfrac{dy}{dx}=\dfrac{dy}{du}\cdot\dfrac{du}{dx}$에서 $du$가 약분되는 것처럼 보이는데 이것을 증명으로 볼 수 있습니까?

*답.* 없습니다. $\dfrac{dy}{dx}$는 분수가 아니라 하나의 극한 기호이므로 약분은 기억을 돕는 비유일 뿐입니다.

## 심화 문제

> **심화 1.** 곱의 미분법을 25강의 귀납법으로 $n$개의 곱까지 확장하세요.

*답.* 한 번에 하나씩만 미분한 항을 모두 더한 것이 됩니다.

*풀이.* $P(n)$을 "$(f_{1}f_{2}\cdots f_{n})'=\sum_{i=1}^{n}f_{1}\cdots f_{i}'\cdots f_{n}$입니다"로 둡니다.

$n=1$이면 자명합니다. $P(k)$를 가정하고 $F=f_{1}\cdots f_{k}$로 두면 $f_{1}\cdots f_{k+1}=Ff_{k+1}$이므로 곱의 미분법에 의해

$$(Ff_{k+1})'=F'f_{k+1}+Ff_{k+1}'$$

입니다. 귀납 가정으로 $F'$을 펼치면 $i=1$부터 $k$까지의 항이 나오고, 여기에 $Ff_{k+1}'$이 $i=k+1$인 항으로 붙습니다.

**남는 것.** 같은 함수를 $n$번 곱하면 $\left(f^{n}\right)'=nf^{n-1}f'$이 나오는데, 이것이 연쇄법칙을 멱함수에 적용한 결과와 같습니다. **두 규칙이 서로 어긋나지 않는다**는 확인이며, 규칙들이 하나의 일관된 체계를 이룬다는 증거입니다.

> **심화 2.** 연쇄법칙의 증명에서 $k=g(x+h)-g(x)$가 $0$이 되는 경우를 어떻게 처리해야 합니까?

*답.* $k$로 나누는 단계가 무너지므로 보조함수를 도입합니다.

*풀이.* 앞의 스케치는 $\dfrac{f(u+k)-f(u)}{k}$를 만들었는데, $k=0$이면 이 분수가 정의되지 않습니다. $g$가 상수함수이거나 진동하며 같은 값을 반복하면 실제로 그런 $h$가 얼마든지 있습니다.

해결책은 다음 함수를 도입하는 것입니다.

$$\Phi(k)=\begin{cases}\dfrac{f(u+k)-f(u)}{k},&k\ne 0\\ f'(u),&k=0\end{cases}$$

$f$가 $u$에서 미분가능하므로 $\displaystyle\lim_{k\to 0}\Phi(k)=f'(u)=\Phi(0)$이고, 35강 문제 2의 제거가능 불연속을 메운 것이므로 $\Phi$는 $k=0$에서 연속입니다. 그러면 $k$의 값과 무관하게

$$f(g(x+h))-f(g(x))=\Phi(k)\cdot k$$

가 성립하고, 양변을 $h$로 나눠 극한을 취하면 $f'(u)g'(x)$가 나옵니다.

**남는 것.** 35강에서 제거가능 불연속을 극한값으로 메우면 연속이 된다고 했는데, 그 조작이 여기서 **증명을 완성하는 도구**로 쓰였습니다. 분모가 $0$이 될 수 있는 자리를 함수 정의로 우회하는 이 수법은 해석학 전반에서 반복됩니다.

> **심화 3.** $f$가 미분가능하고 $f(x)\ne 0$일 때 $\dfrac{d}{dx}\lvert f(x)\rvert$를 구하세요.

*답.* $\dfrac{f(x)}{\lvert f(x)\rvert}f'(x)$이며 부호함수를 곱한 것과 같습니다.

*풀이.* $\lvert f\rvert=\sqrt{f^{2}}$으로 보고 연쇄법칙을 씁니다.

$$\frac{d}{dx}\sqrt{f^{2}}=\frac{1}{2\sqrt{f^{2}}}\cdot 2ff'=\frac{ff'}{\lvert f\rvert}$$

$f>0$이면 $f'$이고 $f<0$이면 $-f'$입니다. 즉 $f$의 부호를 $f'$에 곱한 것입니다.

$f(x)=0$인 점에서는 이 식이 정의되지 않으며, 실제로 37강 문제 4에서 본 대로 그런 점에서 뾰족점이 생겨 미분 불가능한 경우가 많습니다.

**남는 것.** 절댓값을 $\sqrt{(\cdot)^{2}}$으로 바꾸면 연쇄법칙으로 처리할 수 있습니다. 35강 심화 5에서 $\max$를 절댓값으로 바꿔 연속성을 얻은 것과 같은 발상입니다. **다루기 어려운 연산을 이미 아는 연산의 조합으로 바꾸는 것**이 공통 전략입니다.

> **심화 4.** 곱의 미분법을 37강 심화 1의 근사 관점으로 설명하세요.

*답.* 두 변화량의 곱이 무시할 만큼 작기 때문에 두 항만 남습니다.

*풀이.* $f$와 $g$가 각각 $\Delta f$와 $\Delta g$만큼 변한다고 하면 곱의 변화는

$$(f+\Delta f)(g+\Delta g)-fg=f\Delta g+g\Delta f+\Delta f\Delta g$$

입니다. 이것을 $h$로 나누면 처음 두 항은 각각 $f\dfrac{\Delta g}{h}$와 $g\dfrac{\Delta f}{h}$로 도함수에 수렴합니다. 마지막 항은

$$\frac{\Delta f\Delta g}{h}=\Delta f\cdot\frac{\Delta g}{h}$$

이고 $\Delta f\to 0$이며 $\dfrac{\Delta g}{h}\to g'$이므로 전체가 $0$으로 갑니다.

**남는 것.** 넓이로 그리면 분명합니다. 가로 $f$, 세로 $g$인 직사각형을 양쪽으로 조금 늘리면 늘어난 넓이가 오른쪽 띠, 위쪽 띠, 그리고 모서리의 작은 사각형입니다. **모서리 사각형은 두 변화량의 곱이라 훨씬 작아 무시됩니다.** 이 관점이 다변수로 확장되면 93강 이후의 전미분이 됩니다.

> **심화 5.** $y=f(x)^{g(x)}$ 꼴은 어떤 규칙으로도 바로 미분되지 않습니다. 왜 그런지 설명하고 처리 방법을 제시하세요.

*답.* 밑과 지수가 모두 변해 멱법칙도 지수법칙도 쓸 수 없습니다. 로그를 취해 처리합니다.

*풀이.* $x^{n}$은 지수가 상수라 멱법칙이 쓰이고, $a^{x}$는 밑이 상수라 39강의 지수함수 미분이 쓰입니다. 둘 다 변하면 어느 쪽도 적용되지 않습니다.

처리 방법은 양변에 로그를 취하는 것입니다. $f>0$이라 하고

$$\ln y=g(x)\ln f(x)$$

양변을 미분하면 왼쪽은 연쇄법칙으로 $\dfrac{y'}{y}$가 되고 오른쪽은 곱의 미분법으로 처리됩니다. 자세한 계산은 39강에서 로그의 도함수를 얻은 뒤에 합니다.

**남는 것.** 31강에서 로그가 곱을 합으로 바꾼다고 했는데, 여기서는 **거듭제곱을 곱으로 낮춰** 다룰 수 있는 형태로 만듭니다. 로그미분법이라 부르며, 인수가 여러 개인 곱이나 복잡한 분수를 미분할 때도 계산을 크게 줄여 줍니다.

> **심화 6.** 연쇄법칙을 $n$겹 합성에 적용하면 인수가 $n$개 곱해집니다. 이것이 깊은 신경망에서 어떤 문제를 일으키는지 설명하세요.

*답.* 인수의 크기에 따라 곱이 지수적으로 사라지거나 폭발합니다.

*풀이.* $n$겹 합성의 도함수는 각 층의 도함수를 모두 곱한 것입니다.

$$\big(f_{n}\circ\cdots\circ f_{1}\big)'=\prod_{i=1}^{n}f_{i}'(\cdot)$$

각 인수의 크기가 평균적으로 $r$이라면 전체 크기가 대략 $r^{n}$입니다. 33강에서 확인한 대로 $r<1$이면 $r^{n}\to 0$이고 $r>1$이면 발산합니다.

층이 $50$겹이고 각 인수가 $0.9$라면 곱이 $0.9^{50}\approx 0.005$로 줄어들고, $1.1$이라면 $1.1^{50}\approx 117$로 커집니다.

**남는 것.** 이것이 기울기 소실과 기울기 폭발입니다. 216강 이후의 역전파에서 실제 문제로 나타나며, 잔차 연결이나 정규화 같은 기법이 인수의 크기를 $1$ 근처로 유지해 이 곱이 무너지지 않게 만드는 장치입니다. **연쇄법칙이라는 순수한 계산 규칙이 딥러닝 구조 설계의 이유가 됩니다.**

## 코드 검산

미분 규칙은 항등식이므로 여러 점에서 양변을 비교하면 확인됩니다. 도함수는 차분몫으로 근사해 대조합니다.

```python
import numpy as np

x = np.linspace(0.5, 3.0, 6)
h = 1e-6

def num_diff(fn, t):
    return (fn(t + h) - fn(t - h)) / (2 * h)     # 대칭 차분몫

# 문제 2: (fg)' = f'g + fg' 이고 f'g' 가 아닙니다.
f, g = lambda t: t**2, lambda t: t**3
fp, gp = lambda t: 2*t, lambda t: 3*t**2
print(np.allclose(num_diff(lambda t: f(t)*g(t), x), fp(x)*g(x) + f(x)*gp(x)))   # True
print(np.allclose(num_diff(lambda t: f(t)*g(t), x), fp(x)*gp(x)))               # False
print([round(float(v), 4) for v in 5*x**4])    # 올바른 (fg)'
# [0.3125, 5.0, 25.3125, 80.0, 195.3125, 405.0]
print([round(float(v), 4) for v in 6*x**3])    # 잘못된 f'g'
# [0.75, 6.0, 20.25, 48.0, 93.75, 162.0]

# 문제 3: 몫의 미분법
q  = lambda t: (t**2 + 1) / (t - 3)
qp = lambda t: (t**2 - 6*t - 1) / (t - 3)**2
xs = np.linspace(0.5, 2.5, 5)          # x = 3 을 피합니다
print(np.allclose(num_diff(q, xs), qp(xs)))                                     # True

# 문제 4: 연쇄법칙
c  = lambda t: (t**2 + 1)**3
cp = lambda t: 3*(t**2 + 1)**2 * (2*t)
print(np.allclose(num_diff(c, x), cp(x)))                                       # True
print(np.allclose(num_diff(c, x), 3*(x**2 + 1)**2))                             # False

# 문제 5: 세 문항의 답을 각각 대조합니다.
p1  = lambda t: t**2 * np.sqrt(t**2 + 1)
p1p = lambda t: (3*t**3 + 2*t) / np.sqrt(t**2 + 1)
print(np.allclose(num_diff(p1, x), p1p(x)))                                     # True

p2  = lambda t: (2*t + 1)**3 / t**2
p2p = lambda t: 2*(2*t + 1)**2 * (t - 1) / t**3
print(np.allclose(num_diff(p2, x), p2p(x)))                                     # True

p3  = lambda t: ((t - 1) / (t + 1))**4
p3p = lambda t: 8*(t - 1)**3 / (t + 1)**5
print(np.allclose(num_diff(p3, x), p3p(x)))                                     # True

# 심화 6: n 겹 합성이면 인수가 n 개 곱해집니다.
for r in (0.9, 1.0, 1.1):
    print(r, round(r**50, 6))
# 0.9 0.005154
# 1.0 1.0
# 1.1 117.390853
```

출력이 주석과 모두 일치합니다. 두 번째와 세 번째 줄이 문제 2의 반례를 숫자로 보여 줍니다. 올바른 공식 $5x^{4}$와 잘못된 $f'g'=6x^{3}$이 어느 점에서도 같지 않으며, $x$가 커질수록 차이가 벌어집니다.

여덟 번째 줄도 같은 성격입니다. 연쇄법칙에서 안쪽 도함수를 곱하지 않으면 값이 틀립니다.

한 가지 주의할 점이 있습니다. 여기서 쓴 대칭 차분몫은 37강 심화 6에서 확인한 대로 **미분 불가능한 점에서도 값을 내놓습니다.** 이 검산이 확인해 주는 것은 "규칙으로 구한 도함수가 수치미분과 일치한다"는 것이지 "그 점에서 미분가능하다"는 것이 아닙니다. 미분가능성은 앞선 강의에서 손으로 확인해 두었습니다.

## 부록. 기호 정리

| 기호 | 읽는 법 | 뜻 |
|---|---|---|
| $(fg)'$ | 곱의 도함수 | $f'g+fg'$입니다 |
