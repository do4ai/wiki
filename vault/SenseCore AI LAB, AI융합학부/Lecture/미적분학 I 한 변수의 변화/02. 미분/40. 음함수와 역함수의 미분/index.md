# 40강. 음함수와 역함수의 미분

지금까지 미분한 것은 모두 $y=f(x)$ 꼴이었습니다. $y$가 $x$의 식으로 명시적으로 적혀 있어야 도함수 공식을 적용할 수 있었습니다.

그런데 원의 방정식 $x^{2}+y^{2}=25$는 그런 꼴이 아닙니다. $y$에 대해 풀면 $y=\pm\sqrt{25-x^{2}}$로 두 갈래가 생기고, 27강의 기준으로 보면 이 관계는 함수가 아닙니다. 그렇다면 이 곡선 위의 한 점에서 접선의 기울기를 구할 수 없습니까.

구할 수 있습니다. 39강 문제 2에서 $e^{y}=x$의 양변을 미분해 $\dfrac{dy}{dx}$를 얻었을 때 이미 그 방법을 썼습니다. 이 강의는 그 방법을 정식으로 정리하고, 같은 도구로 역함수와 역삼각함수의 도함수까지 얻습니다.

## 이 강의에서 할 수 있게 되는 것
- 음함수 미분으로 $y$를 풀지 않고 $\dfrac{dy}{dx}$를 구할 수 있습니다.
- 곡선 위의 점에서 접선의 방정식을 구할 수 있습니다.
- 역함수의 도함수 공식을 유도하고 그 뜻을 그림으로 읽을 수 있습니다.
- 역삼각함수의 도함수를 구할 수 있습니다.
- 유리수 지수에 대한 멱법칙을 증명할 수 있습니다.

## 문제 1. $y$를 풀 수 없으면 어떻게 미분하는가

> **문제.** $x^{2}+y^{2}=25$에 대하여
> (1) $y$에 대해 풀면 무엇이 문제가 됩니까?
> (2) 풀지 않고 $\dfrac{dy}{dx}$를 구하세요.
> (3) 점 $(3,4)$에서의 접선의 방정식을 구하세요.

**생각의 실마리.** (2)에서 양변을 $x$로 미분합니다. 왼쪽의 $y^{2}$을 미분할 때가 관건입니다. $y$는 상수가 아니라 $x$에 따라 변하는 값이므로, 38강의 연쇄법칙에 따라 안쪽 $y$의 도함수가 곱해져야 합니다.

**풀이.** (1) $y^{2}=25-x^{2}$에서 $y=\pm\sqrt{25-x^{2}}$입니다. 부호가 두 갈래이므로 하나의 함수로 적을 수 없고, 위쪽 반원과 아래쪽 반원을 따로 다뤄야 합니다. 게다가 $x=\pm 5$에서는 두 갈래가 만나 미분이 어렵습니다.

(2) 양변을 $x$로 미분합니다. **$y$가 $x$의 함수임을 잊지 않습니다.**

$$\frac{d}{dx}\left(x^{2}\right)+\frac{d}{dx}\left(y^{2}\right)=\frac{d}{dx}(25)$$

$y^{2}$은 바깥이 제곱이고 안쪽이 $y$인 합성이므로 연쇄법칙을 씁니다.

$$2x+2y\cdot\frac{dy}{dx}=0$$

$\dfrac{dy}{dx}$에 대해 풉니다.

$$\frac{dy}{dx}=-\frac{x}{y}\qquad(y\ne 0)$$

(3) 점 $(3,4)$를 대입합니다. 이 점이 곡선 위에 있는지 먼저 확인하면 $9+16=25$로 맞습니다.

$$\frac{dy}{dx}\bigg|_{(3,4)}=-\frac{3}{4}$$

접선의 방정식은

$$y-4=-\frac{3}{4}(x-3),\qquad y=-\frac{3}{4}x+\frac{25}{4}$$

**이 문제에서 배우는 것: 음함수 미분.**

$x$와 $y$의 관계가 $F(x,y)=0$ 꼴로만 주어진 것을 **음함수**라고 합니다. 이때 $y$를 풀지 않고 도함수를 구하는 방법이 **음함수 미분**입니다.

절차는 세 단계입니다.

1. 양변을 $x$로 미분합니다.
2. $y$가 나오는 자리마다 **연쇄법칙으로 $\dfrac{dy}{dx}$를 곱합니다.**
3. $\dfrac{dy}{dx}$에 대해 정리해 풉니다.

2번이 전부입니다. 자주 쓰는 형태를 정리해 둡니다.

| 식 | $x$로 미분한 결과 |
|---|---|
| $y$ | $\dfrac{dy}{dx}$ |
| $y^{2}$ | $2y\dfrac{dy}{dx}$ |
| $y^{n}$ | $ny^{n-1}\dfrac{dy}{dx}$ |
| $\sin y$ | $\cos y\dfrac{dy}{dx}$ |
| $e^{y}$ | $e^{y}\dfrac{dy}{dx}$ |
| $xy$ | $y+x\dfrac{dy}{dx}$ (곱의 미분법) |

마지막 줄에 주의합니다. $x$와 $y$가 곱해져 있으면 곱의 미분법을 먼저 쓰고, $y$ 쪽에 연쇄법칙을 적용합니다.

결과가 $x$와 $y$를 **모두 포함한다**는 점도 특징입니다. $\dfrac{dy}{dx}=-\dfrac{x}{y}$처럼 $y$가 남아 있어도 문제없습니다. 곡선 위의 점을 지정하면 $x$와 $y$가 둘 다 정해지기 때문입니다.

기하학적으로 읽으면 $-\dfrac{x}{y}$는 원점에서 그 점으로 가는 반직선의 기울기 $\dfrac{y}{x}$의 음의 역수입니다. **접선이 반지름과 수직**이라는 원의 성질이 계산에서 그대로 나옵니다.

**바로 확인.**

**확인 1-1.** $x^{2}+y^{2}=1$ 위의 점 $\left(\dfrac{1}{2},\dfrac{\sqrt3}{2}\right)$에서 $\dfrac{dy}{dx}$를 구하세요.

*답.* $\dfrac{dy}{dx}=-\dfrac{x}{y}=-\dfrac{1/2}{\sqrt3/2}=-\dfrac{1}{\sqrt3}$입니다.

**확인 1-2.** $xy=6$에서 $\dfrac{dy}{dx}$를 구하세요.

*답.* 곱의 미분법으로 $y+x\dfrac{dy}{dx}=0$이므로 $\dfrac{dy}{dx}=-\dfrac{y}{x}$입니다. $y=\dfrac6x$을 직접 미분한 $-\dfrac{6}{x^{2}}$과 같습니다.

**확인 1-3.** $\dfrac{d}{dx}\left(y^{3}\right)$을 쓰세요.

*답.* $3y^{2}\dfrac{dy}{dx}$입니다.

## 문제 2. 음함수 미분으로 무엇을 더 얻을 수 있는가

> **문제.** (1) $x^{3}+y^{3}=6xy$에서 $\dfrac{dy}{dx}$를 구하세요.
> (2) 유리수 $r=\dfrac{p}{q}$에 대해 $\dfrac{d}{dx}x^{r}=rx^{r-1}$임을 증명하세요.

**생각의 실마리.** (1)은 양변에 $y$가 여러 번 나오므로 항마다 규칙을 적용한 뒤 $\dfrac{dy}{dx}$가 있는 항끼리 모읍니다. (2)에서 $y=x^{p/q}$로 두면 근호가 있어 다루기 어렵지만, 양변을 $q$제곱하면 $y^{q}=x^{p}$라는 다항 관계가 되어 음함수 미분을 쓸 수 있습니다.

**풀이.** (1) 양변을 미분합니다. 오른쪽은 곱의 미분법이 필요합니다.

$$3x^{2}+3y^{2}\frac{dy}{dx}=6\left(y+x\frac{dy}{dx}\right)$$

$\dfrac{dy}{dx}$가 있는 항을 왼쪽에, 나머지를 오른쪽에 모읍니다.

$$3y^{2}\frac{dy}{dx}-6x\frac{dy}{dx}=6y-3x^{2}$$

묶어서 풉니다.

$$\frac{dy}{dx}=\frac{6y-3x^{2}}{3y^{2}-6x}=\frac{2y-x^{2}}{y^{2}-2x}$$

(2) $y=x^{p/q}$로 두고 양변을 $q$제곱합니다.

$$y^{q}=x^{p}$$

이제 양변을 $x$로 미분합니다. 왼쪽에 연쇄법칙을 씁니다.

$$qy^{q-1}\frac{dy}{dx}=px^{p-1}$$

$\dfrac{dy}{dx}$에 대해 풉니다.

$$\frac{dy}{dx}=\frac{p}{q}\cdot\frac{x^{p-1}}{y^{q-1}}$$

$y=x^{p/q}$를 대입합니다.

$$y^{q-1}=x^{\frac{p}{q}(q-1)}=x^{p-\frac{p}{q}}$$

따라서

$$\frac{dy}{dx}=\frac{p}{q}\cdot x^{p-1-p+\frac{p}{q}}=\frac{p}{q}x^{\frac{p}{q}-1}=rx^{r-1}$$

**이 문제에서 배우는 것: 멱법칙의 확장과 정리 요령.**

37강에서 자연수 지수, 심화 2에서 음의 정수 지수를 다뤘고 여기서 **유리수 지수**까지 왔습니다. 실수 지수는 39강의 로그미분법으로 끝냅니다. $y=x^{r}$에서 $\ln y=r\ln x$이므로

$$\frac{y'}{y}=\frac{r}{x},\qquad y'=r\frac{x^{r}}{x}=rx^{r-1}$$

입니다. **모든 실수 지수에서 같은 공식이 성립합니다.**

$$\frac{d}{dx}x^{r}=rx^{r-1}\qquad(r\in\mathbb{R},\;x>0)$$

(1)에서 쓴 정리 요령도 기억합니다.

1. 항마다 미분 규칙을 적용합니다.
2. $\dfrac{dy}{dx}$가 곱해진 항을 **한쪽으로 모읍니다.**
3. $\dfrac{dy}{dx}$로 묶어 나눕니다.

이것이 가능한 이유는 $\dfrac{dy}{dx}$가 식 안에서 **일차로만 나타나기 때문**입니다. 음함수 미분은 언제나 $\dfrac{dy}{dx}$에 대한 일차방정식을 주므로 항상 풀립니다.

한 가지 주의합니다. 3번에서 나눌 때 **분모가 $0$이 아님을 확인**해야 합니다. (1)에서 $y^{2}-2x=0$인 점에서는 접선이 수직이거나 곡선이 특이한 모양을 가지며, 이 곡선은 실제로 원점에서 자기 자신과 교차합니다.

**바로 확인.**

**확인 2-1.** $x^{2}+xy+y^{2}=7$에서 $\dfrac{dy}{dx}$를 구하세요.

*답.* $2x+y+x\dfrac{dy}{dx}+2y\dfrac{dy}{dx}=0$이므로 $\dfrac{dy}{dx}=-\dfrac{2x+y}{x+2y}$입니다.

**확인 2-2.** $\dfrac{d}{dx}x^{5/3}$을 구하세요.

*답.* $\dfrac{5}{3}x^{2/3}$입니다.

**확인 2-3.** $\dfrac{d}{dx}\sqrt[3]{x^{2}}$을 구하세요.

*답.* $x^{2/3}$이므로 $\dfrac{2}{3}x^{-1/3}=\dfrac{2}{3\sqrt[3]{x}}$입니다.

## 문제 3. 역함수의 도함수는 무엇인가

> **문제.** $f$가 전단사이고 미분가능할 때
> (1) $f^{-1}(f(x))=x$의 양변을 미분해 $(f^{-1})'$을 구하세요.
> (2) $f(x)=x^{3}+x$일 때 $(f^{-1})'(2)$를 구하세요.
> (3) 결과를 그래프로 어떻게 읽습니까?

**생각의 실마리.** (1)에서 28강의 역함수 정의 $f^{-1}\circ f=\mathrm{id}$를 식으로 적고 양변을 미분합니다. 왼쪽이 합성이므로 연쇄법칙이 필요합니다. (2)에서 $f^{-1}(2)$를 직접 구하려면 삼차방정식을 풀어야 하지만, 공식은 $f$의 값만 알면 되도록 되어 있습니다.

**풀이.** (1) $f^{-1}(f(x))=x$의 양변을 $x$로 미분합니다. 왼쪽에 연쇄법칙을 씁니다.

$$\left(f^{-1}\right)'\big(f(x)\big)\cdot f'(x)=1$$

$f'(x)\ne 0$이면 나눌 수 있습니다.

$$\left(f^{-1}\right)'\big(f(x)\big)=\frac{1}{f'(x)}$$

$b=f(a)$로 두면 더 쓰기 편한 형태가 됩니다.

$$\left(f^{-1}\right)'(b)=\frac{1}{f'(a)}\qquad\text{단 }f(a)=b$$

(2) $f'(x)=3x^{2}+1$입니다. $f^{-1}(2)$를 구하려면 $f(a)=2$인 $a$를 찾아야 합니다.

$$a^{3}+a=2$$

$a=1$을 넣으면 $1+1=2$로 맞습니다. 따라서 $f^{-1}(2)=1$입니다.

$$\left(f^{-1}\right)'(2)=\frac{1}{f'(1)}=\frac{1}{3+1}=\frac{1}{4}$$

(3) 11강에서 본 대로 $f^{-1}$의 그래프는 $f$의 그래프를 직선 $y=x$에 대해 대칭이동한 것입니다. 대칭이동은 $x$축과 $y$축의 역할을 바꾸므로 **기울기가 역수가 됩니다.** 위 공식이 그 관찰의 식입니다.

**이 문제에서 배우는 것: 역함수의 미분법.**

$$\left(f^{-1}\right)'(b)=\frac{1}{f'\big(f^{-1}(b)\big)}$$

라이프니츠 표기로 적으면 대칭이 뚜렷합니다.

$$\frac{dx}{dy}=\frac{1}{\;\dfrac{dy}{dx}\;}$$

이 공식을 쓸 때 확인할 것이 두 가지입니다.

첫째, **$f'(a)\ne 0$이어야 합니다.** $f'(a)=0$이면 접선이 수평이고, 대칭이동하면 수직이 되어 역함수의 도함수가 존재하지 않습니다. $f(x)=x^{3}$의 역함수 $x^{1/3}$이 $x=0$에서 미분 불가능한 것이 이 경우이며, 37강 문제 4에서 수직접선 유형으로 분류한 예입니다.

둘째, **$f^{-1}(b)$를 알아야 합니다.** 공식이 $f$의 도함수만 요구하지만 그 도함수를 평가할 점은 알아야 합니다. (2)에서 삼차방정식의 근 $a=1$을 찾은 것이 그 단계입니다. 다만 역함수의 **식**을 구할 필요는 없다는 점이 이 공식의 이점입니다.

39강 문제 2에서 로그의 도함수를 구한 것이 이 공식의 적용이었습니다. $f(x)=e^{x}$이고 $f'=e^{x}$이므로

$$\left(\ln\right)'(b)=\frac{1}{e^{\ln b}}=\frac{1}{b}$$

입니다.

**바로 확인.**

**확인 3-1.** $f(x)=x^{5}+2x+1$일 때 $(f^{-1})'(1)$을 구하세요.

*답.* $f(0)=1$이므로 $f^{-1}(1)=0$입니다. $f'(x)=5x^{4}+2$이므로 $f'(0)=2$이고 답은 $\dfrac12$입니다.

**확인 3-2.** $f'(a)=0$이면 역함수의 도함수는 어떻게 됩니까?

*답.* 존재하지 않습니다. 수평 접선이 대칭이동으로 수직이 되기 때문입니다.

**확인 3-3.** 역함수 도함수 공식을 $\dfrac{dx}{dy}$ 표기로 쓰세요.

*답.* $\dfrac{dx}{dy}=\dfrac{1}{dy/dx}$입니다.

## 문제 4. 역삼각함수는 어떻게 미분하는가

> **문제.** (1) $y=\arcsin x$의 도함수를 구하세요.
> (2) $y=\arctan x$의 도함수를 구하세요.
> (3) 두 결과에 근호나 분수만 남고 삼각함수가 사라진 이유를 설명하세요.

**생각의 실마리.** $y=\arcsin x$는 $\sin y=x$와 같습니다. 이 관계식에 문제 1의 음함수 미분을 쓰면 $\cos y$가 나오는데, 답에 $y$가 남으면 곤란하므로 $x$의 식으로 바꿔야 합니다. 16강의 $\sin^{2}+\cos^{2}=1$을 쓰고, 부호를 정할 때 정의역 제한을 확인합니다.

**풀이.** (1) $y=\arcsin x$는 $\sin y=x$이고 $-\dfrac{\pi}{2}\le y\le\dfrac{\pi}{2}$입니다. 양변을 미분합니다.

$$\cos y\cdot\frac{dy}{dx}=1,\qquad \frac{dy}{dx}=\frac{1}{\cos y}$$

$\cos y$를 $x$로 바꿉니다. 16강의 항등식에서 $\cos^{2}y=1-\sin^{2}y=1-x^{2}$이므로

$$\cos y=\pm\sqrt{1-x^{2}}$$

부호를 정합니다. $y$의 범위가 $\left[-\dfrac{\pi}{2},\dfrac{\pi}{2}\right]$이고 그 구간에서 $\cos y\ge 0$이므로 양의 부호입니다.

$$\frac{d}{dx}\arcsin x=\frac{1}{\sqrt{1-x^{2}}}\qquad(-1<x<1)$$

(2) $y=\arctan x$는 $\tan y=x$입니다. 양변을 미분합니다.

$$\sec^{2}y\cdot\frac{dy}{dx}=1,\qquad \frac{dy}{dx}=\frac{1}{\sec^{2}y}$$

16강의 항등식 $\sec^{2}y=1+\tan^{2}y=1+x^{2}$을 씁니다.

$$\frac{d}{dx}\arctan x=\frac{1}{1+x^{2}}$$

(3) 도함수를 구하면 $\cos y$나 $\sec^{2}y$처럼 $y$가 남는데, **삼각함수 사이의 항등식으로 그것을 $\tan y$나 $\sin y$, 즉 $x$로 바꿀 수 있기 때문**입니다. 삼각함수가 하나의 항등식으로 서로 묶여 있어서 가능한 일입니다.

**이 문제에서 배우는 것: 역삼각함수의 도함수.**

| $f$ | $f'$ | 정의역 |
|---|---|---|
| $\arcsin x$ | $\dfrac{1}{\sqrt{1-x^{2}}}$ | $-1<x<1$ |
| $\arccos x$ | $-\dfrac{1}{\sqrt{1-x^{2}}}$ | $-1<x<1$ |
| $\arctan x$ | $\dfrac{1}{1+x^{2}}$ | 모든 실수 |
| $\mathrm{arccot}\,x$ | $-\dfrac{1}{1+x^{2}}$ | 모든 실수 |

여기서도 39강 문제 4의 규칙이 살아 있습니다. **"코"가 붙은 것에는 음의 부호가 붙습니다.** $\arcsin x+\arccos x=\dfrac{\pi}{2}$이므로 양변을 미분하면 두 도함수의 합이 $0$이라는 사실에서 바로 나옵니다.

이 결과들이 놀라운 이유가 있습니다. **삼각함수의 역함수인데 도함수에는 삼각함수가 전혀 없습니다.** 대수적인 식만 남았습니다. 이 사실은 방향을 뒤집어 읽으면 더 유용합니다.

$$\int\frac{dx}{1+x^{2}}=\arctan x+C,\qquad \int\frac{dx}{\sqrt{1-x^{2}}}=\arcsin x+C$$

대수적으로 생긴 식을 적분하면 삼각함수가 나온다는 뜻이며, 50강의 삼각치환이 이 관계를 정면으로 씁니다. 그리고 $\arctan$의 도함수는 59강 이후 확률에서 코시 분포의 밀도와 같은 모양이라 다시 만납니다.

정의역 제한도 반드시 확인합니다. $\arcsin$이 함수가 되려면 27강의 기준에 따라 $\sin$의 정의역을 $\left[-\dfrac{\pi}{2},\dfrac{\pi}{2}\right]$로 제한해야 했고, 그 제한이 (1)에서 부호를 정하는 근거가 되었습니다. **28강에서 역함수 존재 조건으로 정의역을 좁힌 일이 여기서 계산의 근거로 쓰입니다.**

**바로 확인.**

**확인 4-1.** $\dfrac{d}{dx}\arctan(3x)$를 구하세요.

*답.* 연쇄법칙으로 $\dfrac{3}{1+9x^{2}}$입니다.

**확인 4-2.** $\dfrac{d}{dx}\arcsin(x^{2})$를 구하세요.

*답.* $\dfrac{2x}{\sqrt{1-x^{4}}}$입니다.

**확인 4-3.** $\arcsin x+\arccos x=\dfrac{\pi}{2}$를 미분해 두 도함수의 관계를 확인하세요.

*답.* 양변을 미분하면 $(\arcsin)'+(\arccos)'=0$이므로 두 도함수는 부호만 반대입니다.

## 문제 5. 두 양이 함께 변하면 어떻게 다루는가

> **문제.** 반지름이 매초 $2$센티미터씩 늘어나는 원이 있습니다. 반지름이 $10$센티미터일 때 넓이가 초당 얼마나 빠르게 늘어납니까?

**생각의 실마리.** 넓이와 반지름의 관계는 $A=\pi r^{2}$입니다. 그런데 둘 다 시간에 따라 변하므로 양변을 **시간 $t$로** 미분해야 합니다. $r$이 $t$의 함수이므로 연쇄법칙이 필요하며, 이것이 음함수 미분에서 한 일과 같습니다.

**풀이.** 넓이와 반지름의 관계를 적습니다.

$$A=\pi r^{2}$$

양변을 시간 $t$로 미분합니다. $r$이 $t$의 함수이므로 연쇄법칙을 씁니다.

$$\frac{dA}{dt}=2\pi r\cdot\frac{dr}{dt}$$

주어진 값을 넣습니다. $\dfrac{dr}{dt}=2$이고 $r=10$이므로

$$\frac{dA}{dt}=2\pi\cdot 10\cdot 2=40\pi$$

넓이는 초당 약 $125.66$제곱센티미터씩 늘어납니다.

**이 문제에서 배우는 것: 관련 변화율.**

여러 양이 하나의 관계식으로 묶여 있고 모두 시간에 따라 변할 때, 한 변화율에서 다른 변화율을 얻는 문제를 **관련 변화율** 문제라고 합니다.

절차는 네 단계입니다.

1. **양들 사이의 관계식을 세웁니다.** 기하 공식이나 물리 법칙에서 옵니다.
2. **양변을 시간으로 미분합니다.** 변하는 양마다 연쇄법칙으로 $\dfrac{d\cdot}{dt}$가 붙습니다.
3. **주어진 값을 대입합니다.**
4. 구하려는 변화율에 대해 풉니다.

3번의 순서가 중요합니다. **미분을 먼저 하고 값을 나중에 넣습니다.** 값을 먼저 넣으면 그 양이 상수가 되어 버려 변화율이 $0$으로 사라집니다. 위 풀이에서 $r=10$을 처음부터 넣었다면 $A=100\pi$라는 상수가 되어 $\dfrac{dA}{dt}=0$이라는 틀린 답이 나옵니다.

관계식에서 자주 쓰는 것들을 정리합니다.

| 상황 | 관계식 |
|---|---|
| 원의 넓이와 반지름 | $A=\pi r^{2}$ |
| 구의 부피와 반지름 | $V=\dfrac{4}{3}\pi r^{3}$ |
| 직각삼각형의 두 변과 빗변 | $a^{2}+b^{2}=c^{2}$ |
| 원뿔의 부피 | $V=\dfrac{1}{3}\pi r^{2}h$ |
| 닮음비 | $\dfrac{h}{r}=\text{일정}$ |

관련 변화율이 음함수 미분과 같은 계산인 이유는 분명합니다. 둘 다 **여러 변수가 얽힌 관계식을 한 변수로 미분하면서 나머지에 연쇄법칙을 붙이는 것**입니다. 다른 점은 미분하는 변수가 $x$이냐 $t$이냐뿐입니다.

**바로 확인.**

**확인 5-1.** 정육면체의 한 변이 초당 $3$센티미터씩 늘어날 때 변이 $5$센티미터인 순간 부피의 변화율을 구하세요.

*답.* $V=s^{3}$이므로 $\dfrac{dV}{dt}=3s^{2}\dfrac{ds}{dt}=3\cdot 25\cdot 3=225$세제곱센티미터 매초입니다.

**확인 5-2.** 관련 변화율 문제에서 값을 먼저 대입하면 왜 안 됩니까?

*답.* 변하는 양이 상수가 되어 그 변화율이 $0$으로 사라지기 때문입니다. 미분을 먼저 하고 값을 나중에 넣습니다.

**확인 5-3.** 관련 변화율과 음함수 미분이 같은 계산인 이유를 쓰세요.

*답.* 둘 다 여러 변수가 얽힌 관계식을 한 변수로 미분하며 나머지 변수에 연쇄법칙을 붙이는 것이기 때문입니다.

## 종합 문제 드릴

> **문제 6.** $x^{2}+y^{2}=9$에서 $\dfrac{dy}{dx}$를 구하세요.

*답.* $2x+2y\dfrac{dy}{dx}=0$이므로 $-\dfrac{x}{y}$입니다.

> **문제 7.** $x^{2}-y^{2}=16$에서 $\dfrac{dy}{dx}$를 구하세요.

*답.* $2x-2y\dfrac{dy}{dx}=0$이므로 $\dfrac{x}{y}$입니다.

> **문제 8.** $xy+y^{2}=4$에서 $\dfrac{dy}{dx}$를 구하세요.

*답.* $y+x\dfrac{dy}{dx}+2y\dfrac{dy}{dx}=0$이므로 $-\dfrac{y}{x+2y}$입니다.

> **문제 9.** $\sin y=x$에서 $\dfrac{dy}{dx}$를 $x$의 식으로 쓰세요. 단 $-\dfrac{\pi}{2}\le y\le\dfrac{\pi}{2}$입니다.

*답.* $\cos y\dfrac{dy}{dx}=1$이고 $\cos y=\sqrt{1-x^{2}}$이므로 $\dfrac{1}{\sqrt{1-x^{2}}}$입니다.

> **문제 10.** $e^{y}+x=y$에서 $\dfrac{dy}{dx}$를 구하세요.

*답.* $e^{y}\dfrac{dy}{dx}+1=\dfrac{dy}{dx}$이므로 $\dfrac{dy}{dx}=\dfrac{1}{1-e^{y}}$입니다.

> **문제 11.** $\dfrac{d}{dx}x^{7/2}$을 구하세요.

*답.* $\dfrac{7}{2}x^{5/2}$입니다.

> **문제 12.** $\dfrac{d}{dx}\sqrt[5]{x^{3}}$을 구하세요.

*답.* $x^{3/5}$이므로 $\dfrac{3}{5}x^{-2/5}$입니다.

> **문제 13.** $f(x)=x^{3}+2x+1$일 때 $(f^{-1})'(4)$를 구하세요.

*답.* $f(1)=4$이므로 $f^{-1}(4)=1$입니다. $f'(x)=3x^{2}+2$이므로 $f'(1)=5$이고 답은 $\dfrac15$입니다.

> **문제 14.** $f(x)=e^{x}$의 역함수 도함수를 공식으로 구하고 $\ln$의 도함수와 비교하세요.

*답.* $\left(f^{-1}\right)'(b)=\dfrac{1}{e^{\ln b}}=\dfrac1b$이고 $\ln$의 도함수 $\dfrac1x$과 같습니다.

> **문제 15.** $\dfrac{d}{dx}\arctan(x^{2})$를 구하세요.

*답.* $\dfrac{2x}{1+x^{4}}$입니다.

> **문제 16.** $\dfrac{d}{dx}\left[x\arcsin x\right]$를 구하세요.

*답.* 곱의 미분법으로 $\arcsin x+\dfrac{x}{\sqrt{1-x^{2}}}$입니다.

> **문제 17.** 구의 반지름이 초당 $1$센티미터씩 늘어날 때 반지름이 $3$센티미터인 순간 부피의 변화율을 구하세요.

*답.* $V=\dfrac43\pi r^{3}$이므로 $\dfrac{dV}{dt}=4\pi r^{2}\dfrac{dr}{dt}=4\pi\cdot 9\cdot 1=36\pi$입니다.

> **문제 18.** 사다리가 벽에 기대어 있고 길이가 $5$미터입니다. 밑이 초당 $1$미터씩 벽에서 멀어질 때 밑이 벽에서 $3$미터인 순간 사다리 꼭대기가 내려오는 속도를 구하세요.

*답.* $x^{2}+y^{2}=25$이고 미분하면 $2x\dfrac{dx}{dt}+2y\dfrac{dy}{dt}=0$입니다. $x=3$이면 $y=4$이고 $\dfrac{dx}{dt}=1$이므로 $\dfrac{dy}{dt}=-\dfrac{3}{4}$입니다. 초당 $0.75$미터씩 내려옵니다.

## 심화 문제

> **심화 1.** 음함수 미분이 언제나 $\dfrac{dy}{dx}$에 대해 풀리는 이유를 설명하세요.

*답.* $\dfrac{dy}{dx}$가 항상 일차로만 나타나기 때문입니다.

*풀이.* 연쇄법칙을 적용할 때 $\dfrac{dy}{dx}$는 항상 **한 번만 곱해집니다.** $y^{n}$을 미분하면 $ny^{n-1}\dfrac{dy}{dx}$이고 $\sin y$를 미분하면 $\cos y\dfrac{dy}{dx}$이며, 어느 경우에도 $\left(\dfrac{dy}{dx}\right)^{2}$ 같은 항은 나오지 않습니다.

따라서 미분한 결과는 $A(x,y)\dfrac{dy}{dx}+B(x,y)=0$ 꼴이고, $A\ne 0$이면 $\dfrac{dy}{dx}=-\dfrac{B}{A}$로 유일하게 풀립니다.

**남는 것.** $A(x,y)=0$인 점이 특별합니다. 그런 점에서는 접선이 수직이거나 곡선이 자기 자신과 교차하는 등 특이한 일이 벌어집니다. 문제 1에서 $y=0$인 점 $(\pm 5,0)$이 원의 좌우 끝이었고 거기서 접선이 실제로 수직입니다. **계산이 막히는 자리가 곡선이 특별한 자리와 정확히 일치합니다.**

> **심화 2.** 음함수 미분이 항상 정당한지, 즉 $F(x,y)=0$이 언제나 $y$를 $x$의 함수로 정하는지 판정하세요.

*답.* 항상 그렇지는 않으며 국소적으로만 성립합니다.

*풀이.* $x^{2}+y^{2}=25$에서 점 $(3,4)$ 근처만 보면 $y=\sqrt{25-x^{2}}$로 하나의 함수가 정해집니다. 그러나 곡선 전체를 보면 각 $x$에 $y$가 둘씩 대응해 함수가 아닙니다.

또 $x^{2}+y^{2}=0$은 점 $(0,0)$ 하나뿐이라 함수를 정하지 못하고, $x^{2}+y^{2}=-1$은 실수해가 아예 없습니다.

정확한 조건은 음함수 정리라는 이름으로 알려져 있으며, 심화 1의 $A(x,y)\ne 0$이 그 조건에 해당합니다. 완전한 서술은 93강 이후 다변수 미적분에서 편미분을 배운 뒤에 가능합니다.

**남는 것.** 우리가 한 계산은 **"함수가 정해진다면 그 도함수는 이것이다"**를 구한 것입니다. 존재 자체는 따로 보장해야 하며, 33강 문제 5에서 극한이 존재함을 먼저 확인하고 방정식을 세운 것과 같은 순서 문제입니다. 실전에서는 곡선 위의 점이 주어지고 그 근처에서 매끄러운 경우가 대부분이라 문제가 되지 않습니다.

> **심화 3.** $x^{y}=y^{x}$에서 $\dfrac{dy}{dx}$를 구하세요. ($x,y>0$)

*답.* 로그미분법과 음함수 미분을 함께 씁니다.

*풀이.* 양변에 자연로그를 취합니다.

$$y\ln x=x\ln y$$

양변을 $x$로 미분합니다. 양쪽 모두 곱의 미분법이 필요하고 $y$에는 연쇄법칙이 붙습니다.

$$\frac{dy}{dx}\ln x+\frac{y}{x}=\ln y+\frac{x}{y}\cdot\frac{dy}{dx}$$

$\dfrac{dy}{dx}$ 항을 모읍니다.

$$\frac{dy}{dx}\left(\ln x-\frac{x}{y}\right)=\ln y-\frac{y}{x}$$

$$\frac{dy}{dx}=\frac{\ln y-\dfrac{y}{x}}{\ln x-\dfrac{x}{y}}=\frac{y\left(x\ln y-y\right)}{x\left(y\ln x-x\right)}$$

**남는 것.** 39강의 로그미분법과 이 강의의 음함수 미분을 **함께** 썼습니다. 지수에 변수가 있으면 먼저 로그를 취해 내리고, 그러고 나면 남은 것은 음함수 미분입니다. 도구를 순서대로 쌓아 올리면 처음에는 손도 못 댈 것 같던 식이 풀립니다.

> **심화 4.** $(f^{-1})'(b)=\dfrac{1}{f'(a)}$를 정의로 직접 증명하세요.

*답.* 차분몫의 역수 관계에서 나옵니다.

*풀이.* $g=f^{-1}$이라 하고 $b=f(a)$입니다. 정의에 넣습니다.

$$g'(b)=\lim_{y\to b}\frac{g(y)-g(b)}{y-b}$$

$x=g(y)$로 두면 $y=f(x)$이고 $g(b)=a$입니다. $f$가 연속이고 전단사이므로 $y\to b$일 때 $x\to a$입니다. 따라서

$$g'(b)=\lim_{x\to a}\frac{x-a}{f(x)-f(a)}=\lim_{x\to a}\frac{1}{\dfrac{f(x)-f(a)}{x-a}}=\frac{1}{f'(a)}$$

마지막에서 $f'(a)\ne 0$이므로 34강의 몫의 법칙을 쓸 수 있습니다.

**남는 것.** 문제 3에서는 $f^{-1}$이 미분가능하다고 **가정하고** 공식을 구했지만, 이 증명은 그 가정 없이 미분가능성까지 함께 보입니다. 두 논증의 차이를 구분해 두는 것이 중요합니다. **공식을 구하는 것과 존재를 보이는 것은 다른 일입니다.**

> **심화 5.** $y=\arcsin x$의 도함수가 $x\to\pm 1$에서 무한대로 가는 것을 그래프로 설명하세요.

*답.* 원래 함수의 접선이 그 점에서 수평이었기 때문입니다.

*풀이.* $\arcsin$은 $\sin$을 $\left[-\dfrac{\pi}{2},\dfrac{\pi}{2}\right]$로 제한한 것의 역함수입니다. $\sin$은 $y=\pm\dfrac{\pi}{2}$에서 도함수 $\cos y=0$을 가지므로 접선이 수평입니다.

역함수는 $y=x$에 대한 대칭이동이고 수평선은 수직선으로 바뀌므로, 대응하는 점 $x=\pm 1$에서 $\arcsin$의 접선이 수직입니다. 수직 접선은 기울기가 무한대이며, 실제로 $\dfrac{1}{\sqrt{1-x^{2}}}$의 분모가 $0$으로 갑니다.

**남는 것.** 문제 3에서 말한 $f'(a)\ne 0$ 조건이 깨지는 자리가 이곳입니다. 37강 문제 4에서 분류한 **수직접선 유형의 미분 불가능**이며, 세 강의의 내용이 한 점에서 만납니다. 정의역 끝점에서 도함수가 폭발하는 이 현상은 53강의 이상적분에서 다시 다룹니다.

> **심화 6.** 관련 변화율 문제에서 값을 미분 전에 대입하면 왜 틀리는지 문제 5로 구체적으로 보이세요.

*답.* 변수가 상수가 되어 변화율이 사라집니다.

*풀이.* 올바른 순서는 $A=\pi r^{2}$을 먼저 미분해 $\dfrac{dA}{dt}=2\pi r\dfrac{dr}{dt}$를 얻고 $r=10$을 넣는 것입니다. 결과는 $40\pi$입니다.

잘못된 순서로 $r=10$을 먼저 넣으면 $A=100\pi$가 되는데 이것은 상수입니다. 상수를 미분하면 $\dfrac{dA}{dt}=0$이라는 틀린 답이 나옵니다.

무엇이 잘못되었는지 정확히 말하면, $r=10$은 **모든 시각에 성립하는 관계가 아니라 특정 순간의 값**입니다. 미분은 그 순간 주변에서 값이 어떻게 변하는지 보는 연산이므로, 주변 정보를 지워 버리면 계산할 것이 남지 않습니다.

**남는 것.** 34강 문제 1에서 극한이 $x=a$인 점이 아니라 **그 주변**을 본다고 했던 것과 같은 이야기입니다. 미분은 한 점의 값이 아니라 그 점 근처에서의 변화를 재므로, 근처 정보를 유지한 채 계산을 마치고 마지막에 그 점의 값을 넣어야 합니다.

## 코드 검산

음함수 미분의 결과는 곡선 위의 점에서 접선의 기울기이므로, 곡선을 매개변수로 표현해 수치미분과 대조하면 확인됩니다.

```python
import numpy as np

h = 1e-6
def nd(fn, t):
    return (fn(t + h) - fn(t - h)) / (2 * h)

# 문제 1: x^2 + y^2 = 25 에서 dy/dx = -x/y
th = np.linspace(0.3, 1.2, 6)                 # 위쪽 반원의 매개변수
X, Y = 5*np.cos(th), 5*np.sin(th)
upper = lambda t: np.sqrt(25 - t**2)          # y > 0 인 갈래
print(np.allclose(nd(upper, X), -X / Y))                          # True
print(round(float(-3/4), 4), round(float(nd(upper, 3.0)), 4))     # -0.75 -0.75

# 문제 2: 유리수 지수 멱법칙
xs = np.linspace(0.5, 2.0, 6)
for r in (0.5, 2/3, 5/3, -1.5):
    ok = np.allclose(nd(lambda t: t**r, xs), r * xs**(r - 1))
    print(round(r, 4), bool(ok))
# 0.5 True
# 0.6667 True
# 1.6667 True
# -1.5 True

# 문제 3: 역함수의 도함수는 원래 도함수의 역수입니다.
f  = lambda t: t**3 + t
fp = lambda t: 3*t**2 + 1
a = 1.0
b = f(a)
finv = lambda s: np.array([np.roots([1, 0, 1, -v])[-1].real for v in np.atleast_1d(s)])
print(round(float(b), 4), round(float(finv(b)[0]), 6))            # 2.0 1.0
print(round(float(nd(lambda s: finv(s)[0], b)), 6), round(1 / fp(a), 6))
# 0.25 0.25

# 문제 4: 역삼각함수의 도함수
u = np.linspace(-0.8, 0.8, 9)
print(np.allclose(nd(np.arcsin, u), 1 / np.sqrt(1 - u**2)))       # True
print(np.allclose(nd(np.arccos, u), -1 / np.sqrt(1 - u**2)))      # True
v = np.linspace(-3.0, 3.0, 9)
print(np.allclose(nd(np.arctan, v), 1 / (1 + v**2)))              # True

# 심화 5: arcsin 의 도함수는 x -> 1 에서 폭발합니다.
edge = np.array([0.9, 0.99, 0.999, 0.9999])
print(np.round(1 / np.sqrt(1 - edge**2), 3))   # [ 2.294  7.089 22.366 70.712]

# 문제 5: 관련 변화율은 미분을 먼저 하고 값을 넣습니다.
r0, drdt = 10.0, 2.0
print(round(2 * np.pi * r0 * drdt, 6), round(float(40 * np.pi), 6))   # 125.663706 125.663706

# 심화 6: 값을 먼저 넣으면 상수가 되어 0 이 됩니다.
A_const = np.pi * r0**2
print(round(float(nd(lambda t: A_const + 0*t, 1.0)), 6))          # 0.0
```

출력이 주석과 모두 일치합니다. 첫 검산이 문제 1을 확인해 줍니다. 위쪽 반원을 명시적 함수로 적어 수치미분한 값이 음함수 미분으로 얻은 $-\dfrac{x}{y}$와 여섯 점 모두에서 같고, $x=3$에서 정확히 $-0.75$입니다. **$y$를 풀지 않고 얻은 답이 풀어서 얻은 답과 일치합니다.**

세 번째 검산에서 역함수를 삼차방정식의 근으로 수치적으로 구했습니다. $f^{-1}(2)=1$이 나오고 그 점의 도함수가 $0.25$로 $\dfrac{1}{f'(1)}=\dfrac14$과 같습니다.

마지막 두 검산이 심화 6을 대비시켜 보여 줍니다. 올바른 순서로는 $125.663706=40\pi$가 나오지만, 값을 먼저 넣어 상수로 만들면 $0$이 나옵니다.
