# 157강. MCMC와 깁스 샘플링

150강에서 사후분포를 세우고 격자로 계산했습니다. **차원이 하나였기 때문에 가능한 일**이었습니다.

$$p(\theta\mid\mathbf{x})=\frac{p(\mathbf{x}\mid\theta)p(\theta)}{\int p(\mathbf{x}\mid\theta)p(\theta)\,d\theta}$$

**분모의 적분이 문제입니다.** 켤레가 아니면 닫힌 식이 없고, 모수가 열 개만 되어도 격자가 감당하지 못합니다.

**147강 문제 4에서 다른 길도 막혔습니다.** 기각법의 수용률이 $d=20$에서 $2.46\times10^{-8}$이라 독립 표본을 뽑을 수 없었습니다.

$$\text{독립 표본을 포기하고 마르코프 연쇄를 씁니다}$$

**155강 문제 5가 이미 답을 보여 주었습니다.** 목표분포 $\boldsymbol\pi$를 정해 놓고 상세균형을 만족하는 전이를 만들면, **그 연쇄가 저절로 $\boldsymbol\pi$로 갑니다.**

| 이 강의가 푸는 것 | 어디서 막혔던 문제인가 |
|---|---|
| 정규화 상수를 모름 | 150강의 사후분포 |
| 고차원 표집 | 147강 문제 4 |
| 조건부분포만 아는 경우 | 137강의 조건부 구조 |
| 오차 막대 | 155강 문제 4의 유효 표본 크기 |

**대가는 표본 사이의 상관**입니다. 155강에서 잰 적분 자기상관 시간이 여기서 실무의 핵심 지표가 됩니다.

## 이 강의에서 할 수 있게 되는 것
- 메트로폴리스-헤이스팅스로 정규화 상수 없이 표본을 뽑을 수 있습니다.
- 제안의 폭을 수용률과 유효 표본 크기로 조율할 수 있습니다.
- 깁스 샘플링을 세우고 좌표 상관이 미치는 영향을 설명할 수 있습니다.
- 여러 사슬과 R-hat으로 수렴을 진단할 수 있습니다.
- 기울기를 쓰는 제안이 왜 나은지 설명할 수 있습니다.

## 문제 1. 정규화 상수를 모르는 분포에서 어떻게 뽑는가

> **문제.** $\pi(x)\propto x^{2}e^{-2x}$에서 표본을 뽑습니다.
> (1) 메트로폴리스로 사슬을 돌리세요.
> (2) 평균과 분산을 참값과 견주세요.
> (3) 분위수까지 맞는지 확인하세요.

**생각의 실마리.** 155강 문제 5의 메트로폴리스를 연속 상태로 옮깁니다. **수용 판정에 비 $\pi(y)/\pi(x)$만 쓰므로** 정규화 상수가 약분됩니다.

**풀이.** (1)(2) 격자로 구한 참값이 평균 $1.500000$, 분산 $0.750000$입니다.

| 항목 | 값 |
|---|---|
| 수용률 | $0.569623$ |
| 표본 평균 | $1.501602$ |
| 표본 분산 | $0.749955$ |

(3) 분위수까지 견줍니다.

| 분위수 | MCMC 표본 | 격자 참값 | 차이 |
|---|---|---|---|
| $0.10$ | $0.552855$ | $0.551025$ | $0.001830$ |
| $0.25$ | $0.863416$ | $0.863625$ | $0.000209$ |
| $0.50$ | $1.339376$ | $1.337025$ | $0.002351$ |
| $0.75$ | $1.965298$ | $1.960225$ | $0.005073$ |
| $0.90$ | $2.658930$ | $2.661175$ | $0.002245$ |
| $0.99$ | $4.218082$ | $4.202975$ | $0.015107$ |

**분포 전체가 맞습니다.** 평균과 분산만이 아니라 꼬리까지 재현합니다.

**이 문제에서 배우는 것: 메트로폴리스-헤이스팅스.**

> **알고리즘.** 현재 $x$에서 제안 $y\sim q(\cdot\mid x)$를 뽑고 다음 확률로 수용합니다.
> $$\alpha=\min\Bigl(1,\ \frac{\pi(y)\,q(x\mid y)}{\pi(x)\,q(y\mid x)}\Bigr)$$
> 기각하면 $x$에 머뭅니다.

**대칭 제안이면 $q$가 약분되어 $\min(1,\pi(y)/\pi(x))$가 됩니다.** 155강 문제 5의 메트로폴리스이며, 검산이 그것을 씁니다.

| 성질 | 이유 |
|---|---|
| 정규화 상수 불필요 | 비만 씁니다 |
| 상세균형 성립 | 155강 문제 5의 계산 |
| 비주기성 | 기각이 자기 전이입니다 |
| 기약성 | 제안이 모든 곳에 닿으면 됩니다 |
| 로그로 계산 | 149강 문제 2의 아래넘침 회피 |

**다섯째 줄이 실무의 필수**입니다. $\pi$가 우도의 곱이면 아주 작은 수가 되므로 **언제나 $\log\pi(y)-\log\pi(x)$로 비교**합니다.

> **버리는 구간이 필요합니다.** 초기값이 목표분포와 멀면 처음 얼마 동안은 표본이 아닙니다.

**검산에서 앞의 $10\%$를 버렸습니다.** 얼마나 버릴지는 문제 4의 진단으로 정합니다.

**150강에서 격자로 우회한 문제가 이제 풀립니다.** 사후분포가 $p(\mathbf{x}\mid\theta)p(\theta)$에 비례하므로 **분모를 계산하지 않고도 그 비를 쓸 수 있습니다.**

**바로 확인 1.**

**확인 1-1.** 메트로폴리스-헤이스팅스의 수용확률을 쓰세요.

*답.* $\min(1,\ \pi(y)q(x\mid y)/(\pi(x)q(y\mid x)))$입니다.

**확인 1-2.** 정규화 상수가 필요 없는 이유를 쓰세요.

*답.* 비만 쓰므로 약분되기 때문입니다.

**확인 1-3.** 기각이 알고리즘에 주는 성질을 쓰세요.

*답.* 자기 전이가 되어 비주기성을 줍니다.

## 문제 2. 제안의 폭을 어떻게 정하는가

> **문제.** $10$차원 표준정규를 목표로 제안 폭을 바꿉니다.
> (1) 수용률과 자기상관 시간을 재세요.
> (2) 유효 표본 크기가 최대가 되는 폭을 찾으세요.
> (3) 이론이 권하는 값과 견주세요.

**생각의 실마리.** 폭이 작으면 거의 다 수용되지만 조금씩만 움직입니다. 폭이 크면 멀리 제안하지만 대부분 기각됩니다. **가운데에 최적이 있습니다.**

**풀이.** (1)(2) 검산 결과입니다.

| 제안 폭 | 수용률 | 자기상관 시간 | 유효 표본 크기 | 비율 |
|---|---|---|---|---|
| $0.10$ | $0.877295$ | $266.1078$ | $676$ | $0.0038$ |
| $0.30$ | $0.645420$ | $68.1503$ | $2641$ | $0.0147$ |
| $0.75$ | $0.263670$ | $29.3207$ | $6139$ | $0.0341$ |
| $1.50$ | $0.040105$ | $78.1395$ | $2304$ | $0.0128$ |
| $3.00$ | $0.000285$ | $368.8844$ | $488$ | $0.0027$ |
| $10.00$ | $0.000000$ | $180000$ | $1$ | $0.0000$ |

**폭 $0.75$에서 유효 표본이 $6139$개로 최대**입니다. 가장 나쁜 $0.1$의 아홉 배이고 $10.0$의 $6139$배입니다.

**마지막 줄은 한 번도 움직이지 않았습니다.** $20$만 걸음을 걷고 표본 하나를 얻은 셈입니다.

(3) 이론과 견줍니다.

| 항목 | 값 |
|---|---|
| 최적 폭 (검산) | $0.75$ |
| 이론 $2.38/\sqrt{d}$ | $0.7526$ |
| 그때의 수용률 | $0.263670$ |
| 이론 목표 수용률 | $0.234$ |

**이론과 정확히 맞습니다.**

**이 문제에서 배우는 것: 조율의 원리.**

> **최적 스케일링.** 고차원 무작위 걸음 메트로폴리스에서 제안 표준편차를 $2.38\sigma/\sqrt{d}$로 잡으면 수용률이 $0.234$가 되고 효율이 최대가 됩니다.

**$\sqrt{d}$로 나누는 것이 핵심**입니다. 차원이 오르면 제안을 더 작게 해야 하며, **그만큼 사슬이 느려집니다.**

| 폭 | 수용률 | 문제 |
|---|---|---|
| 너무 작음 | $1$에 가까움 | 조금씩만 움직여 상관이 큽니다 |
| 적당함 | $0.234$ 근처 | 효율이 최대입니다 |
| 너무 큼 | $0$에 가까움 | 제자리에 머뭅니다 |

**수용률만 보고 좋아하면 안 됩니다.** $87.7\%$가 수용된 첫 줄이 가장 나쁜 축에 듭니다. **수용률이 높다는 것은 거의 움직이지 않았다는 뜻**일 수 있습니다.

> **판단 기준은 유효 표본 크기입니다.** 155강 문제 4의 $\tau$로 나눈 값이며, **그것만이 실제로 얻은 정보의 양**입니다.

**155강 문제 3의 스펙트럼 간격이 이것의 이론적 배경**입니다. 폭이 나쁘면 $\lvert\lambda_{2}\rvert$가 $1$에 가까워지고 혼합 시간이 길어집니다.

**바로 확인 2.**

**확인 2-1.** 최적 제안 폭을 쓰세요.

*답.* $2.38\sigma/\sqrt{d}$입니다.

**확인 2-2.** 목표 수용률을 쓰세요.

*답.* 약 $0.234$입니다.

**확인 2-3.** 수용률이 높은 것이 언제나 좋은지 쓰세요.

*답.* 아니며 거의 움직이지 않았다는 뜻일 수 있습니다.

## 문제 3. 조건부분포만 알면 되는가

> **문제.** 이변량 정규에서 깁스 샘플링을 돌립니다.
> (1) 조건부분포를 쓰세요.
> (2) 상관에 따라 자기상관 시간이 어떻게 변하는지 재세요.
> (3) 이론과 견주세요.

**생각의 실마리.** 140강 문제 4에서 다변량 정규의 조건부분포를 이미 구했습니다. **$x\mid y\sim\mathcal{N}(\rho y,\ 1-\rho^{2})$**입니다.

**풀이.** (1)(2)(3) 검산 결과입니다.

| 상관 $\rho$ | 표본 상관 | 자기상관 시간 | 유효 표본 | 이론 $\rho^{2}$ |
|---|---|---|---|---|
| $0.00$ | $0.000000$ | $1.0000$ | $270000$ | $0.000000$ |
| $0.50$ | $0.500000$ | $1.6237$ | $166288$ | $0.250000$ |
| $0.90$ | $0.900000$ | $8.9506$ | $30166$ | $0.810000$ |
| $0.99$ | $0.990000$ | $95.1648$ | $2837$ | $0.980100$ |

**$\rho=0$이면 자기상관 시간이 정확히 $1$**입니다. 좌표가 독립이라 깁스가 곧 독립 표집입니다.

**$\rho=0.99$에서 $95.16$**이며 이론값 $(1+\rho^{2})/(1-\rho^{2})=99.50$과 맞습니다.

**이 문제에서 배우는 것: 깁스 샘플링.**

> **깁스 샘플링.** 좌표를 하나씩 골라 **나머지를 고정한 조건부분포**에서 뽑습니다.
> $$x_{j}^{(t+1)}\sim p\bigl(x_{j}\mid x_{-j}^{(t)}\bigr)$$

**언제나 수용됩니다.** 메트로폴리스-헤이스팅스의 특수한 경우로 볼 수 있으며, **제안이 조건부분포이면 수용확률이 정확히 $1$**입니다.

| 항목 | 메트로폴리스 | 깁스 |
|---|---|---|
| 필요한 것 | 비 $\pi(y)/\pi(x)$ | 조건부분포 |
| 조율 | 제안 폭 | 없습니다 |
| 수용률 | $0.234$ 목표 | 언제나 $1$ |
| 약점 | 폭 조율이 어렵습니다 | 좌표 상관에 약합니다 |
| 좌표 갱신 | 한꺼번에 가능 | 하나씩입니다 |

**둘째 줄이 깁스의 매력**입니다. 조율할 것이 없어 자동으로 돌아갑니다.

> **약점은 좌표 상관입니다.** 좌표축 방향으로만 움직이므로 상관이 크면 **좁은 골짜기를 지그재그로 기어갑니다.**

**대처법이 몇 가지 있습니다.**

| 방법 | 내용 |
|---|---|
| 블록 갱신 | 상관된 좌표를 묶어 함께 뽑습니다 |
| 재모수화 | 좌표를 회전해 상관을 없앱니다 |
| 보조변수 | 잠재변수를 넣어 조건부를 단순화합니다 |
| 붕괴 | 일부를 해석적으로 적분합니다 |

**넷째 줄이 147강 심화 2의 라오-블랙웰화**입니다. 적분할 수 있는 것을 적분하면 분산이 줄어듭니다.

**깁스가 자연스러운 자리가 많습니다.** 150강의 계층모형, 213강의 확률그래프모형, 223강의 혼합모형에서 **조건부분포가 켤레라 닫힌 식으로 나옵니다.**

**바로 확인 3.**

**확인 3-1.** 깁스 샘플링의 갱신 규칙을 쓰세요.

*답.* 나머지를 고정한 조건부분포에서 좌표를 하나씩 뽑습니다.

**확인 3-2.** 깁스의 수용률을 쓰세요.

*답.* 언제나 $1$입니다.

**확인 3-3.** 깁스의 약점을 쓰세요.

*답.* 좌표가 강하게 상관되면 느려집니다.

## 문제 4. 언제 믿을 수 있는가

> **문제.** 봉우리 두 개인 목표에서 사슬을 돌립니다.
> (1) 제안 폭과 사슬 길이를 바꿔 가며 사슬별 평균을 보세요.
> (2) R-hat을 계산하세요.
> (3) 어느 경우를 믿을 수 있는지 판정하세요.

**생각의 실마리.** 목표가 $0.5\,\mathcal{N}(-4,1)+0.5\,\mathcal{N}(4,1)$이라 **참 평균이 $0$**입니다. 봉우리 사이가 멀어 넘기 어렵습니다.

**풀이.** (1)(2) 네 사슬을 $-4,-4,4,4$에서 시작한 결과입니다.

| 제안 폭 | 사슬 길이 | 사슬별 평균 | R-hat | 전체 평균 |
|---|---|---|---|---|
| $0.5$ | $20000$ | $(-2.544,\ -0.646,\ -3.978,\ 3.946)$ | $1.6273$ | $-0.8056$ |
| $0.5$ | $200000$ | $(3.695,\ -0.188,\ 1.788,\ -0.525)$ | $1.1411$ | $1.1927$ |
| $3.0$ | $20000$ | $(0.301,\ -0.289,\ -0.282,\ -0.462)$ | $1.0032$ | $-0.1829$ |
| $3.0$ | $200000$ | $(-0.035,\ -0.224,\ -0.062,\ 0.039)$ | $1.0004$ | $-0.0703$ |

**첫 줄이 최악입니다.** 세 번째 사슬은 $-3.978$에 갇혀 있고 네 번째는 $3.946$에 갇혀 **서로 반대 답**을 냅니다. 전체 평균이 $-0.8056$으로 참값 $0$에서 멉니다.

**둘째 줄도 아직 위험합니다.** 길이를 열 배로 늘렸는데 R-hat이 $1.14$이고 전체 평균이 $1.1927$입니다.

**셋째와 넷째 줄이 좋습니다.** 폭을 $3.0$으로 키워 봉우리를 넘을 수 있게 하니 R-hat이 $1.00$이 되었습니다.

(3) **R-hat이 $1$에 가까운 경우만 믿을 수 있습니다.**

**이 문제에서 배우는 것: 수렴 진단.**

> **R-hat.** 사슬 사이 분산 $B$와 사슬 안 분산 $W$를 견줍니다.
> $$\hat{R}=\sqrt{\frac{\frac{n-1}{n}W+\frac{1}{n}B}{W}}$$
> 모든 사슬이 같은 곳을 보면 $B$가 작아져 $1$에 가까워집니다.

**서로 다른 곳에서 출발한 여러 사슬이 필수**입니다. 한 사슬만 보면 **첫 줄의 세 번째 사슬처럼 완벽하게 수렴한 것처럼 보입니다.**

| 진단 | 무엇을 보는가 | 위험 신호 |
|---|---|---|
| R-hat | 사슬 사이 일치 | $1.01$을 넘음 |
| 유효 표본 크기 | 실제 정보량 | 사슬당 $100$ 미만 |
| 궤적 그림 | 눈으로 확인 | 추세나 갇힘 |
| 자기상관 그림 | 상관의 감쇠 | 천천히 줄어듦 |
| 발산 진단 | 기하학적 문제 | 해밀토니안 방법에서 |

## 문제 5. 더 나은 제안을 만들 수 있는가

> (3) 차이가 어디에서 오는지 쓰세요.

**생각의 실마리.** 무작위 걸음은 **어디로 갈지 전혀 모릅니다.** 밀도가 낮은 쪽으로도 똑같이 제안하므로 대부분 기각됩니다.

| 무작위 걸음 | $0.3366$ | $0.4954$ | $302.62$ | $159$ |

**이 문제에서 배우는 것: 기울기를 쓰는 제안.**

> **메트로폴리스 조정 랑주뱅.** 제안에 기울기를 넣습니다.
> $$y=x+\frac{\varepsilon^{2}}{2}\nabla\log\pi(x)+\varepsilon\,Z$$
> 제안이 대칭이 아니므로 수용확률에 $q(x\mid y)/q(y\mid x)$를 넣습니다.

**156강 심화 6의 랑주뱅 확산을 이산화한 것**입니다. 그 확산의 정상분포가 정확히 $\pi$이며, 이산화 오차를 수용 판정이 고쳐 줍니다.

$$dX_{t}=\tfrac12\nabla\log\pi(X_{t})\,dt+dW_{t}$$

| 방법 | 쓰는 정보 | 차원 의존 |
|---|---|---|
| 무작위 걸음 | $\pi$의 비 | $d$ |
| 랑주뱅 | 기울기 | $d^{1/3}$ |
| 해밀토니안 | 기울기와 운동량 | $d^{1/4}$ |
| 깁스 | 조건부분포 | 문제마다 다릅니다 |

**셋째 줄이 오늘날의 표준**입니다. 위치에 운동량을 붙여 물리계처럼 굴리면 **멀리까지 이동하면서도 수용률이 높습니다.**

| 목표 수용률 | 방법 |
|---|---|
| $0.234$ | 무작위 걸음 |
| $0.574$ | 랑주뱅 |
| $0.65$ | 해밀토니안 |

**세 값이 모두 이론으로 유도됩니다.** 최적 스케일링 이론의 결과이며, 검산의 랑주뱅 수용률 $0.98$은 걸음을 조금 작게 잡은 것입니다.

**기울기를 쓸 수 있으면 언제나 쓰는 것이 낫습니다.** 그리고 **자동미분이 있으면 기울기가 공짜**이므로, 현대의 확률 프로그래밍 도구는 기본으로 해밀토니안 방법을 씁니다.

**261강의 확산모형이 같은 재료를 씁니다.** 점수함수 $\nabla\log p$를 학습해 역방향 확산을 돌리는 것이며, **이 강의의 랑주뱅과 뿌리가 같습니다.**

**바로 확인 5.**

**확인 5-1.** 랑주뱅 제안의 식을 쓰세요.

def act(x, K=200):
    x = x - x.mean()
    v = float((x * x).mean())
    if v <= 0.0:
        return float(len(x))   # 사슬이 한 번도 움직이지 않은 경우입니다
    s = 0.0
    for k in range(1, K):
        r = float((x[:-k] * x[k:]).mean()) / v
        if r <= 0.05:
            break
        s += r
    return 1 + 2 * s

def lp2(v):
    return np.logaddexp(-0.5 * (v + 4) ** 2, -0.5 * (v - 4) ** 2)


def run_mh(x0, n, s):
    x = x0
    lx = lp2(x)
    out = np.empty(n)
    Zp = rng.normal(0, s, n)
    Up = rng.random(n)
    for t in range(n):
        y = x + Zp[t]
        ly = lp2(y)
        if np.log(Up[t]) < ly - lx:
            x, lx = y, ly
        out[t] = x
    return out


def rhat(ch):
    m, n = ch.shape
    W = float(np.mean(ch.var(axis=1, ddof=1)))
    B = n * float(ch.mean(axis=1).var(ddof=1))
    V = (n - 1) / n * W + B / n
    return float(np.sqrt(V / W))


print("        제안 폭   사슬 길이    사슬별 평균                          R-hat     전체 평균")
