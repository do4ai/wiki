# 152강. 가설검정

151강의 신뢰구간은 **"모수가 어디쯤인가"**에 답합니다. 그런데 실무의 질문은 대개 다른 모양입니다.

$$\text{이 약이 효과가 있는가.}\qquad \text{새 모델이 더 나은가.}$$

**답이 예 또는 아니오여야 합니다.** 구간을 보고 사람이 눈으로 판단하는 것이 아니라, **미리 정한 규칙이 자동으로 결정을 내려야** 여러 사람이 같은 자료에서 같은 결론에 이릅니다.

$$H_{0}:\ \theta=\theta_{0}\qquad\text{대}\qquad H_{1}:\ \theta\ne\theta_{0}$$

**가설검정은 추정이 아니라 결정의 언어**입니다. 그리고 결정에는 두 가지 방식으로 틀릴 수 있습니다.

| 실제 | $H_{0}$을 기각 | $H_{0}$을 유지 |
|---|---|---|
| $H_{0}$이 참 | 1종 오류 $\alpha$ | 옳습니다 |
| $H_{0}$이 거짓 | 옳습니다(검정력) | 2종 오류 $\beta$ |

**두 오류를 동시에 줄일 수는 없습니다.** 이 강의는 그 거래를 정확히 다루고, **151강 심화 1에서 예고한 검정과 구간의 동치**를 확인하며, **$p$값이 무엇이고 무엇이 아닌지**를 분명히 합니다.

## 이 강의에서 할 수 있게 되는 것
- 두 종류의 오류를 구분하고 검정력을 계산할 수 있습니다.
- 네이만-피어슨 보조정리로 최강력 검정을 찾을 수 있습니다.
- $p$값을 정확히 정의하고 흔한 오해를 바로잡을 수 있습니다.
- 목표 검정력에 맞춰 표본 크기를 설계할 수 있습니다.
- 다중 검정에서 무엇을 통제할지 고르고 보정을 적용할 수 있습니다.

## 문제 1. 두 종류의 오류를 어떻게 나누는가

> **문제.** $H_{0}:\mu=0$을 단측 $5\%$로 검정합니다. $\sigma=1$을 안다고 둡니다.
> (1) 1종 오류가 효과크기에 의존하는지 확인하세요.
> (2) 검정력을 이론과 견주세요.
> (3) 표본을 늘릴 때 무엇이 달라지는지 쓰세요.

**생각의 실마리.** 기각역을 $\bar{X}>z_{0.95}\sigma/\sqrt{n}$으로 잡습니다. **이 경계는 $H_{0}$만 보고 정한 것**이라 대립가설이 무엇이든 상관없습니다.

**풀이.** (1)(2)(3) 검산 결과입니다. $z_{0.95}=1.644854$입니다.

| $n$ | 효과 $\delta$ | 1종 오류 | 2종 오류 | 검정력 | 검정력 이론 |
|---|---|---|---|---|---|
| $10$ | $0.00$ | $0.049550$ | $H_{0}$이 참입니다 | $0.050195$ | $0.050000$ |
| $10$ | $0.50$ | $0.050685$ | $0.526010$ | $0.473990$ | $0.474599$ |
| $10$ | $1.00$ | $0.050575$ | $0.064120$ | $0.935880$ | $0.935420$ |
| $40$ | $0.50$ | $0.050345$ | $0.064220$ | $0.935780$ | $0.935420$ |
| $160$ | $0.50$ | $0.050520$ | $0.000005$ | $0.999995$ | $0.999999$ |

**1종 오류가 어느 줄에서나 $5\%$**입니다. $\delta$를 바꿔도 $n$을 바꿔도 변하지 않으며, **우리가 정한 값이기 때문**입니다.

**2종 오류는 통제되지 않습니다.** $n=10$, $\delta=0.5$에서 $52.6\%$이며, **효과가 있는데도 절반 이상 놓칩니다.**

**둘째 줄과 넷째 줄이 짝입니다.** 같은 $\delta=0.5$에서 $n$을 네 배로 늘리자 검정력이 $0.474$에서 $0.936$으로 올라갔습니다.

**이 문제에서 배우는 것: 비대칭한 두 오류.**

> **검정의 요소.**

| 요소 | 뜻 |
|---|---|
| $H_{0}$ | 귀무가설, 기각할 대상 |
| $H_{1}$ | 대립가설 |
| 검정통계량 | 자료를 하나의 수로 요약합니다 |
| 유의수준 $\alpha$ | 허용하는 1종 오류 |
| 기각역 | $H_{0}$을 버리는 통계량의 범위 |
| 검정력 $1-\beta$ | $H_{1}$이 참일 때 기각할 확률 |

> **검정력 공식.** 단측 $z$검정에서
> $$1-\beta=1-\Phi\Bigl(z_{1-\alpha}-\frac{\delta\sqrt{n}}{\sigma}\Bigr)$$

**$\delta\sqrt{n}/\sigma$ 하나가 전부**입니다. 효과크기와 $\sqrt{n}$의 곱이며, **143강 심화 1의 비중심 모수 $\delta$가 바로 이것**입니다.

> **두 오류를 동시에 줄일 수 없습니다.** 기각역을 좁히면 $\alpha$가 줄고 $\beta$가 늘며, 넓히면 반대입니다. 둘 다 줄이려면 $n$을 늘려야 합니다.

**법정의 비유가 정확합니다.** 무죄추정이 $H_{0}$이고 유죄 판결이 기각입니다. **무고한 사람을 벌하는 것($\alpha$)을 더 무겁게 보기 때문에** 그쪽만 엄격히 통제하고, 진범을 놓치는 것($\beta$)은 감수합니다.

**"유의하지 않다"가 "효과가 없다"는 뜻이 아닙니다.** 둘째 줄에서 효과가 분명히 $0.5$인데 $52.6\%$의 경우에 기각하지 못했습니다. **검정력을 모르면 음성 결과를 해석할 수 없습니다.**

**바로 확인 1.**

**확인 1-1.** 두 종류의 오류를 쓰세요.

*답.* 참인 $H_{0}$을 기각하는 1종 오류와 거짓인 $H_{0}$을 유지하는 2종 오류입니다.

**확인 1-2.** 1종 오류가 효과크기에 의존하는지 쓰세요.

*답.* 의존하지 않으며 우리가 $\alpha$로 정합니다.

**확인 1-3.** 검정력을 정하는 하나의 양을 쓰세요.

*답.* $\delta\sqrt{n}/\sigma$입니다.

## 문제 2. 가장 강한 검정은 무엇인가

> **문제.** 단순가설 $\mathcal{N}(0,1)$ 대 $\mathcal{N}(1,1)$에서 $n=10$입니다.
> (1) 네 가지 검정통계량의 임계값을 $5\%$에 맞추세요.
> (2) 각각의 검정력을 재세요.
> (3) 가장 강한 것이 무엇이고 왜 그런지 쓰세요.

**생각의 실마리.** 유의수준을 같게 맞춰야 공정한 비교입니다. **$H_{0}$ 아래에서의 $95\%$ 분위수를 임계값으로 잡으면** 모두 정확히 $5\%$가 됩니다.

**풀이.** (1)(2) 검산 결과입니다.

| 검정통계량 | 임계값 | 실제 1종 오류 | 검정력 |
|---|---|---|---|
| 표본평균(우도비) | $0.520276$ | $0.050000$ | $0.935090$ |
| 절사평균 | $0.554461$ | $0.050000$ | $0.907320$ |
| 중앙값 | $0.611749$ | $0.050000$ | $0.852897$ |
| 첫 관측 | $1.645768$ | $0.050000$ | $0.259985$ |

(3) **표본평균이 가장 강합니다.** 절사평균 $0.9073$, 중앙값 $0.8529$, 첫 관측 $0.2600$으로 차례로 밀립니다.

**우연이 아닙니다.** 우도비를 계산하면 다음이 됩니다.

$$\log\frac{L_{1}}{L_{0}}=\sum_{i}\Bigl[-\frac{(x_{i}-1)^{2}}{2}+\frac{x_{i}^{2}}{2}\Bigr]=\sum_{i}x_{i}-\frac{n}{2}$$

**$\sum x_{i}$의 일차식**이므로 우도비가 크다는 것과 $\bar{X}$가 크다는 것이 같습니다.

**이 문제에서 배우는 것: 네이만-피어슨 보조정리.**

> **네이만-피어슨 보조정리.** 단순가설 $H_{0}:f_{0}$ 대 $H_{1}:f_{1}$에서, 우도비가 임계값을 넘을 때 기각하는 검정이 **주어진 $\alpha$에서 검정력이 가장 큽니다.**
> $$\Lambda(\mathbf{x})=\frac{f_{1}(\mathbf{x})}{f_{0}(\mathbf{x})}>k\ \Longrightarrow\ \text{기각}$$

**증명의 발상이 단순합니다.** 기각역에 넣을 자료 점을 고를 때 **"$H_{1}$ 아래 확률이 크고 $H_{0}$ 아래 확률이 작은" 점부터** 채우는 것이 이득이며, 그 순위가 곧 우도비입니다.

| 검정 | 왜 밀리는가 |
|---|---|
| 절사평균 | 양 끝 관측의 정보를 버립니다 |
| 중앙값 | 순서만 쓰고 크기를 덜 씁니다 |
| 첫 관측 | 관측 아홉 개를 버립니다 |

**148강 문제 5의 충분통계량과 이어집니다.** 정규분포에서 $\sum x_{i}$가 충분통계량이므로 **그것을 쓰는 검정이 정보를 하나도 버리지 않습니다.**

> **복합가설에서는 언제나 최강력 검정이 있지는 않습니다.** 단조 우도비를 갖는 족에서는 단측 검정에 대해 일양최강력 검정이 존재하지만, 양측이면 대개 없습니다.

**그럴 때 쓰는 것이 우도비 검정**입니다. 최강력이라는 보장은 없지만 **점근적으로 최적이며 어떤 모형에도 적용됩니다.** 그 통계량 $2\log\Lambda$가 카이제곱을 따르는 것이 145강 심화 6의 윌크스 정리입니다.

**바로 확인 2.**

**확인 2-1.** 네이만-피어슨 보조정리를 쓰세요.

*답.* 단순가설에서 우도비 검정이 주어진 $\alpha$에서 최강력입니다.

**확인 2-2.** 정규 평균 검정에서 우도비가 무엇의 함수인지 쓰세요.

*답.* $\sum x_{i}$의 일차식이므로 $\bar{X}$의 단조함수입니다.

**확인 2-3.** 검산에서 첫 관측만 쓴 검정의 검정력을 쓰세요.

*답.* $0.2600$입니다.

## 문제 3. $p$값은 무엇이고 무엇이 아닌가

> **문제.** $n=25$의 양측 $z$검정입니다.
> (1) $H_{0}$이 참일 때 $p$값의 분포를 확인하세요.
> (2) $H_{1}$에서는 어떻게 되는지 보세요.
> (3) $p=0.05$일 때 $H_{0}$이 참일 확률을 계산하세요.

**생각의 실마리.** $p$값은 **관측된 것만큼 또는 그보다 극단적인 결과가 $H_{0}$ 아래에서 나올 확률**입니다. 그 정의에서 분포가 바로 따라 나옵니다.

**풀이.** (1) 검산 결과입니다.

| 항목 | 값 |
|---|---|
| $p$값의 평균 | $0.498931$ |
| $0.05$ 이하 비율 | $0.049700$ |
| $0.5$ 이하 비율 | $0.502120$ |
| 균등분포와의 최대 거리 | $0.002475$ |

**$H_{0}$이 참이면 $p$값이 균등분포**입니다. 129강 문제 3의 확률적분변환이며, 연속인 통계량의 분포함수를 자기 자신에 씌운 결과입니다.

(2) $\delta=0.4$에서 **$0.05$ 이하 비율이 $0.515820$**으로 몰립니다. 이것이 그 상황에서의 검정력입니다.

(3) 사전 확률이 반반일 때 $H_{0}$의 사후확률 하한을 계산합니다.

| $p$값 | 최소 베이즈 인자 | $H_{0}$의 사후확률 하한 |
|---|---|---|
| $0.050$ | $0.407162$ | $0.289350$ |
| $0.010$ | $0.125182$ | $0.111254$ |
| $0.005$ | $0.072012$ | $0.067174$ |
| $0.001$ | $0.018777$ | $0.018431$ |

**$p=0.05$여도 $H_{0}$이 참일 확률이 $29\%$ 아래로 내려가지 않습니다.** 어떤 대립가설을 놓아도 그렇습니다.

**이 문제에서 배우는 것: $p$값의 정확한 뜻.**

> **$p$값.** $H_{0}$이 참이라고 가정할 때, 관측된 통계량만큼 또는 그보다 극단적인 값이 나올 확률입니다.

| 옳은 문장 | 틀린 문장 |
|---|---|
| $H_{0}$ 아래에서 이 정도 극단적일 확률 | $H_{0}$이 참일 확률 |
| 자료가 $H_{0}$과 얼마나 안 맞는가 | 효과의 크기 |
| $p<\alpha$이면 기각 | $p>\alpha$이면 $H_{0}$이 참 |
| $H_{0}$이 참이면 균등분포 | 작을수록 효과가 크다 |

**오른쪽 첫 줄이 가장 흔한 오해**입니다. $P(\text{자료}\mid H_{0})$와 $P(H_{0}\mid\text{자료})$는 전혀 다르며, **125강 베이즈 정리의 기본 구분**입니다.

$$P(H_{0}\mid\text{자료})=\frac{P(\text{자료}\mid H_{0})P(H_{0})}{P(\text{자료})}$$

**사전 확률과 대립가설 아래의 확률이 함께 있어야** 뒤집을 수 있습니다.

> **최소 베이즈 인자.** $p$값만 알 때 베이즈 인자는 $-e\,p\ln p$보다 작아질 수 없습니다.

**어떤 대립가설을 최대한 유리하게 잡아도** 그 이상 유리해지지 않는다는 뜻이며, $p=0.05$에서 $0.407$입니다. **증거로서 $p=0.05$는 생각보다 훨씬 약합니다.**

**둘째 줄도 중요합니다.** $n$이 크면 아주 작은 효과도 $p$값이 작아지므로, **$p$값이 작다고 효과가 크다는 뜻이 아닙니다.** 효과크기와 신뢰구간을 함께 보고해야 합니다.

**바로 확인 3.**

**확인 3-1.** $p$값의 정의를 쓰세요.

*답.* $H_{0}$ 아래에서 관측만큼 또는 그보다 극단적일 확률입니다.

**확인 3-2.** $H_{0}$이 참일 때 $p$값의 분포를 쓰세요.

*답.* 균등분포입니다.

**확인 3-3.** $p=0.05$에서 $H_{0}$의 사후확률 하한을 쓰세요.

*답.* 약 $0.289$입니다.

## 문제 4. 표본을 얼마나 모아야 하는가

> **문제.** 양측 $5\%$에서 검정력 $80\%$를 목표로 합니다.
> (1) 필요한 표본 크기 공식을 쓰세요.
> (2) 효과크기별로 계산하세요.
> (3) 실제 검정력을 확인하세요.

**생각의 실마리.** 문제 1에서 검정력이 $\delta\sqrt{n}/\sigma$ 하나로 정해졌습니다. **원하는 검정력을 넣고 $n$에 대해 풀면 됩니다.**

**풀이.** (1) $z_{0.975}=1.959964$, $z_{0.80}=0.841621$입니다.

$$n\ \ge\ \frac{(z_{1-\alpha/2}+z_{1-\beta})^{2}\sigma^{2}}{\delta^{2}}$$

(2)(3) 검산 결과입니다.

| 효과크기 $d$ | 필요한 $n$ | 그 $n$에서 검정력 수치 | 이론 검정력 |
|---|---|---|---|
| $0.2$ | $197$ | $0.802150$ | $0.801551$ |
| $0.5$ | $32$ | $0.808180$ | $0.807430$ |
| $0.8$ | $13$ | $0.820150$ | $0.822382$ |
| $1.2$ | $6$ | $0.837530$ | $0.836315$ |

**모두 $80\%$를 넘습니다.** 올림 때문에 조금씩 여유가 있습니다.

**필요한 표본이 효과크기의 제곱에 반비례**합니다. $d$가 절반이 되면 $n$이 네 배가 되며, **$d=0.2$에 $197$개, $d=1.2$에 $6$개**입니다.

**이 문제에서 배우는 것: 검정력 설계.**

> **설계에 필요한 네 가지.** $\alpha$, 목표 검정력, 효과크기, 산포 중 셋을 정하면 나머지 하나가 정해집니다.

| 정하는 것 | 근거 |
|---|---|
| $\alpha$ | 관행이나 규제, 대개 $0.05$ |
| 검정력 | 관행상 $0.8$ 또는 $0.9$ |
| 효과크기 | 실질적으로 의미 있는 최소 크기 |
| $\sigma$ | 예비 연구나 문헌 |

**셋째 줄이 가장 어렵고 가장 중요합니다.** "통계적으로 유의한 차이"가 아니라 **"실무에서 의미 있는 차이"**를 먼저 정해야 하며, 그것이 없으면 표본 크기를 정할 수 없습니다.

> **사후 검정력 계산은 하지 않습니다.** 실험이 끝난 뒤 관측된 효과크기로 검정력을 계산하면 $p$값의 함수가 될 뿐이라 새 정보가 없습니다.

**대신 신뢰구간을 봅니다.** 151강의 구간이 좁으면서 $0$을 포함하면 **효과가 작다는 증거**이고, 넓으면서 $0$을 포함하면 **표본이 부족하다는 증거**입니다. 두 상황은 전혀 다른데 $p$값은 둘을 구별해 주지 않습니다.

**검정력이 낮은 연구는 두 배로 위험합니다.** 효과를 놓치기 쉬울 뿐 아니라, **유의하게 나온 경우 효과크기가 크게 과대추정**됩니다. 우연히 큰 값이 나와야 문턱을 넘기 때문입니다.

**바로 확인 4.**

*답.* $n\ge(z_{1-\alpha/2}+z_{1-\beta})^{2}\sigma^{2}/\delta^{2}$입니다.

## 문제 5. 많이 검정하면 무엇이 무너지는가

> **문제.** 가설 $1000$개 중 $50$개에만 효과가 있습니다. $n=20$, $\delta=1.0$입니다.
> (1) 보정 없이 검정하면 어떻게 되는지 보세요.
> (2) 본페로니와 홀름을 적용하세요.
> (3) 벤야미니-호흐베르크와 비교하고 무엇을 통제하는지 쓰세요.

**생각의 실마리.** 효과가 없는 $950$개 각각이 $5\%$ 확률로 기각됩니다. **$950\times0.05=47.5$개**가 그냥 나옵니다.

**풀이.** (1)(2)(3) $400$번 시행한 평균입니다.

| 방법 | 평균 발견 수 | 평균 거짓 발견 | 거짓발견율 | 한 번이라도 틀릴 확률 |
|---|---|---|---|---|
| 보정 없음 | $96.760$ | $47.080$ | $0.4866$ | $1.0000$ |
| 본페로니 | $33.045$ | $0.050$ | $0.0015$ | $0.0500$ |
| 홀름 | $33.210$ | $0.052$ | $0.0016$ | $0.0525$ |
| 벤야미니-호흐베르크 | $48.550$ | $2.255$ | $0.0464$ | $0.9050$ |

**보정이 없으면 발견 $96.8$개 중 $47.1$개가 거짓**입니다. 거의 절반이 잡음이며, **한 번이라도 틀릴 확률이 $100\%$**입니다.

**본페로니와 홀름은 한 번이라도 틀릴 확률을 $5\%$로 누릅니다.** 대가는 발견이 $33$개로 줄어드는 것이며, 진짜 $50$개 중 $17$개를 놓칩니다.

**벤야미니-호흐베르크가 절충입니다.** 발견이 $48.6$개로 훨씬 많고 거짓발견율이 $0.0464$로 목표 아래입니다. 다만 **한 번이라도 틀릴 확률은 $90.5\%$**입니다.

**이 문제에서 배우는 것: 무엇을 통제할지 먼저 정합니다.**

| 통제 대상 | 정의 | 방법 |
|---|---|---|
| 개별 오류율 | 각 검정의 $\alpha$ | 보정 없음 |
| 집단별 오류율 | 하나라도 틀릴 확률 | 본페로니, 홀름 |
| 거짓발견율 | 발견 중 틀린 비율의 기댓값 | 벤야미니-호흐베르크 |

> **홀름 절차.** $p$값을 오름차순으로 놓고 $j$번째를 $\alpha/(m-j+1)$과 견줍니다. 처음 실패하는 곳에서 멈추고 그 앞을 모두 기각합니다.

**본페로니보다 언제나 강력하면서 같은 보장**을 줍니다. 검산에서 발견이 $33.045$에서 $33.210$으로 늘었습니다.

> **벤야미니-호흐베르크 절차.** $p$값을 오름차순으로 놓고 $p_{(j)}\le\alpha j/m$인 가장 큰 $j$를 찾아 그 앞을 모두 기각합니다.

**목표를 바꾼 것이 핵심입니다.** "틀린 것이 하나도 없어야 한다"에서 **"발견한 것 중 틀린 비율을 $5\%$로 유지한다"**로 낮추면 훨씬 많이 찾을 수 있습니다.

| 상황 | 권하는 통제 |
|---|---|
| 결론 하나가 중대함 | 집단별 오류율 |
| 규제 승인, 확증 연구 | 집단별 오류율 |
| 탐색적 선별, 유전체 | 거짓발견율 |
| 후속 검증이 뒤따름 | 거짓발견율 |

**$m$을 정직하게 세는 것이 전제**입니다. 151강 문제 5에서 본 대로 **들여다본 모든 것**이 $m$이며, 유의한 것만 골라 보고하면 어떤 보정도 소용없습니다.

**바로 확인 5.**

**확인 5-1.** 보정 없이 $1000$개를 검정할 때의 거짓 발견 수를 쓰세요.

*답.* 검산에서 평균 $47.1$개입니다.

**확인 5-2.** 세 가지 통제 대상을 쓰세요.

*답.* 개별 오류율, 집단별 오류율, 거짓발견율입니다.

**확인 5-3.** 벤야미니-호흐베르크가 통제하는 양을 쓰세요.

*답.* 거짓발견율이며 발견 중 틀린 비율의 기댓값입니다.

## 심화 문제

> **동치.** 유의수준 $\alpha$ 검정족에서 기각되지 않는 모수값을 모으면 신뢰수준 $1-\alpha$ 구간이 됩니다.

| 검정 | 대응하는 구간 |
|---|---|
| $t$검정 | $t$ 구간 |
| 점수 검정 | 윌슨 구간 |

| 검정 | 무엇을 재는가 |
|---|---|
| 발트 | 추정값이 $\theta_{0}$에서 얼마나 먼가 |
| 점수 | $\theta_{0}$에서 기울기가 얼마나 가파른가 |
| 우도비 | 로그 우도가 얼마나 떨어지는가 |

| 열등하지 않음을 보임 | 차이가 $-\Delta$ 이하 | 차이가 $-\Delta$ 초과 |

**둘째 줄이 등가성 검정**입니다. 가설을 뒤집어 **"같다"를 대립가설에 놓아야** 증명할 수 있습니다.

**실무에서 매우 자주 필요합니다.** 새 모델이 기존 모델과 "비슷한데 훨씬 빠르다"를 주장하려면 성능이 같다는 것을 보여야 하는데, **유의하지 않다는 사실만으로는 부족합니다.**

**두 단측 검정 절차가 표준입니다.** $[-\Delta,\Delta]$ 안에 있음을 보이려면 양쪽 경계를 각각 단측으로 검정하며, **신뢰구간이 $[-\Delta,\Delta]$에 완전히 들어가는 것과 같습니다.**

**$\Delta$를 정하는 일이 통계가 아니라 판단입니다.** 얼마나 차이 나면 실질적으로 다른 것인지는 도메인이 정합니다.

cdfg = (np.cumsum(phig) - 0.5 * phig) * 1e-4
cdfg = cdfg - cdfg[120000] + 0.5


def Phi(z):
    return np.interp(z, zg, cdfg)


def zq(q):
    return float(np.interp(q, cdfg, zg))


z95, z975, z80 = zq(0.95), zq(0.975), zq(0.80)

    b2 = "  H0 가 참입니다" if d == 0 else "%13.6f" % (1 - pw)

def stat(X, kind):
    if kind == "mean":
        return X.mean(1)
    if kind == "median":
        return np.median(X, axis=1)
    if kind == "trim":
        s = np.sort(X, axis=1)
        return s[:, 2:-2].mean(1)
    return X[:, 0]


print("      검정통계량        임계값        실제 1종 오류      검정력")
res = {}
for kind, name in [("mean", "표본평균(우도비)"), ("trim", "절사평균"),
                   ("median", "중앙값"), ("first", "첫 관측")]:
    s0 = stat(X0, kind)
    c = float(np.quantile(s0, 0.95))
    pw = float((stat(X1, kind) > c).mean())
    res[kind] = pw
    print("      %-16s %11.6f   %14.6f  %12.6f"
          % (name, c, float((s0 > c).mean()), pw))
print("  표본평균이 가장 강합니다. 우도비가 표본평균의 단조함수이기 때문입니다")

    for kname, rr in rej.items():
        tp = int(rr[:m1].sum())

        rows[kname][0] += tp
        rows[kname][1] += fp

print("      방법            평균 발견 수   평균 거짓 발견   거짓발견율   한 번이라도 틀릴 확률")

    fdr = fp / (tp + fp) if tp + fp > 0 else 0.0
    print("      %-20s %10.3f   %14.3f  %11.4f   %18.4f" % (name, tp + fp, fp, fdr, fw))
