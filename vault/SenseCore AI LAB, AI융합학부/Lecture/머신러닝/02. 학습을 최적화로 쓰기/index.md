---
title: "02. 학습을 최적화로 쓰기"
---
이 단원은 205강부터 209강까지를 맡습니다. **학습을 최적화 문제 하나로 적습니다.**

01단원이 답한 것은 **"무엇을 최소화할 것인가"**였습니다. 이 단원이 답하는 것은 다릅니다.

$$\text{어떻게 최소화할 것인가}$$

그리고 그 과정에서 **손실함수가 어디서 왔는지**를 유도하고, **왜 그렇게 계산해야 하는지**까지 갑니다.

# 이 단원의 흐름

| 강의 | 하는 일 |
|---|---|
| $205$ | 경험적 위험 최소화라는 틀을 세웁니다 |
| $206$ | 지수족에서 손실함수를 직접 꺼냅니다 |
| $207$ | 닫힌 해가 있는 문제를 안정적으로 풉니다 |
| $208$ | 닫힌 해가 없는 문제를 반복으로 풉니다 |
| $209$ | 갈래가 셋 이상인 문제로 넓힙니다 |

**다섯 강이 하나의 줄기입니다.** 틀을 세우고, 목적함수를 유도하고, 실제로 푸는 순서입니다.

# 하나의 문장이 단원 전체를 관통합니다

$$\text{넷을 정하면 알고리즘이 정해집니다}$$

| 무엇을 정하면 | 무엇이 정해지나 | 어디서 |
|---|---|---|
| 분포 가정 | 손실함수 | $206$강 |
| 손실과 모형 | 볼록한지 | $205$강 문제 $2$ |
| 볼록성과 크기 | 어떤 방법으로 풀지 | $207$~$208$강 |
| 갈래 수 | 분모 비용과 방법 | $209$강 |

**"학습 알고리즘"이라는 것이 이 넷을 정한 결과일 뿐입니다.** 새로운 문제를 만나도 이 순서로 물으면 됩니다.

# 못 재는 것을 잽니다

$$R(f)=\mathbb{E}[\ell(f(x),y)]\qquad\longrightarrow\qquad \hat{R}(f)=\frac{1}{n}\sum_{i}\ell(f(x_{i}),y_{i})$$

| 표본 크기 | 경험적 위험 | 참 위험 |
|---|---|---|
| $5$ | $0.395658$ | $4.985743$ |
| $100$ | $0.979893$ | $1.034883$ |
| $10000$ | $0.999596$ | $1.000667$ |

**표본 $5$에 계수 $3$개면 거의 완벽히 맞는데 참 위험은 열두 배입니다.** 같은 표본으로 고르고 같은 표본으로 점수를 매기므로 **구조적으로 낙관**되며, 그 간극을 다루는 것이 $03$단원입니다.

# 볼록성이 무엇을 보장하고 무엇을 안 하는가

| 무엇 | 볼록한가 | 무엇이 따라오나 |
|---|---|---|
| 제곱오차와 선형모형 | 예 | 닫힌 해가 있음 |
| 교차엔트로피와 선형 로짓 | 예 | 시작점에 안 걸림 |
| 제곱오차와 시그모이드 | 아니오 | 멀리서 시작하면 갇힘 |
| 교차엔트로피와 신경망 | 아니오 | S$10$의 주제 |

**$205$강 문제 $2$에서 제곱오차가 멀리서 시작해 $8.628575$ 떨어진 곳에 갇혔습니다.** 같은 자료에서 교차엔트로피는 두 시작점에서 소수점 여섯 자리까지 같은 자리에 왔습니다.

**그런데 볼록해도 어려운 자리가 있습니다.** $208$강 문제 $1$에서 계수를 $30$배로 키우니 곡률이 $0.000037$로 사라졌고, 그때는 갇히지는 않지만 **도달하지 못합니다.**

# 계산 경로가 정확도를 정합니다

| $X$의 조건수 | 정규방정식 오차 | QR 오차 |
|---|---|---|
| $1\text{e}{+}02$ | $8.1276\text{e}{-}13$ | $3.9464\text{e}{-}15$ |
| $1\text{e}{+}08$ | $1.4120\text{e}{-}01$ | $3.9244\text{e}{-}09$ |

**$X^{\top}X$를 만드는 순간 조건수가 제곱됩니다.** 수식이 맞다고 그대로 계산하면 안 된다는 것이 $92$강에서 배운 것이고, $207$강에서 실제 손해로 나타났습니다.

**반복법에서는 같은 문제가 수렴 속도로 나타납니다.** $208$강 문제 $5$에서 눈금이 $2000$배 차이 나는 자료에 경사하강을 $300$걸음 돌려도 기울기가 $27.6$이었고, 표준화하면 $3.5\text{e}{-}07$까지 갔습니다.

# 정보가 모자라면 자료가 답을 안 정합니다

| 어디서 | 무엇이 일어나나 |
|---|---|
| $205$강 문제 $4$ | 점 $12$개를 차수 $11$ 다항식이 다 지남 |
| $207$강 문제 $3$ | 잔차 $0$인 해가 무한히 많음 |
| $208$강 문제 $4$ | 라벨이 무작위인데 표본 $50$에 변수 $49$면 언제나 완전 분리 |

**셋이 같은 현상입니다.** "학습 위험이 $0$"이 좋은 소식이 아니라 **정보가 모자라다는 신호**이며, 그때 답을 정하는 것은 자료가 아니라 **우리가 넣은 가정**입니다.

# 앞에서 배운 것이 그대로 쓰입니다

| 이 단원의 개념 | 어디서 배웠는가 |
|---|---|
| 정사영 | $80$강, $207$강 문제 $1$ |
| 조건수와 수치 안정성 | $92$강, $207$강 문제 $2$ |
| 특이값 분해 | $84$~$89$강, $207$강 문제 $3$ |
| 라그랑주 승수 | $107$강, $206$강 문제 $1$ |
| 최대우도 | $149$강, $206$강 문제 $2$ |
| 피셔 정보 | $152$강, $208$강 문제 $3$ |
| 정규화와 사전분포 | $116$강과 $148$강, $206$강 문제 $4$ |
| 이분산과 가중 | $188$강, $206$강 문제 $2$ |
| IRLS | $190$강, $208$강 문제 $3$ |
| 더미변수 함정 | $186$강, $209$강 문제 $1$ |
| 자유도 | $163$강과 $180$강, $207$강 문제 $1$ |

**아홉째 줄이 눈에 띕니다.** $190$강에서 도구로 썼던 IRLS가 $208$강에서 **왜 그런지** 밝혀집니다. 가중치 $p(1-p)$가 곧 그 관측의 분산이고, 분산의 역수로 가중하는 것이 최대우도입니다.

# 다음 단계

**03단원은 답이 새 자료에서도 맞는지 묻습니다.**

$$\text{어떻게 최소화할 것인가} \;\longrightarrow\; \text{그 답이 새 자료에서도 맞는가}$$

$205$강 문제 $1$에서 본 경험적 위험과 참 위험의 간극이 **무엇으로 이루어져 있는지**가 $210$강의 주제이고, 그것을 줄이는 장치가 $211$강의 정규화와 $212$강의 교차검증입니다.
