title: "03. 일반화의 수학"

이 단원은 210강부터 214강까지를 맡습니다. **답이 새 자료에서도 맞는지를 다룹니다.**

02단원이 답한 것은 **"어떻게 최소화할 것인가"**였습니다. 이 단원이 묻는 것은 다릅니다.

$$\text{그 답이 새 자료에서도 맞는가}$$

**이 단원이 이 과목의 중심입니다.** 205강 문제 1에서 표본 $5$일 때 경험적 위험 $0.395658$과 참 위험 $4.985743$의 간극을 봤습니다. 그 간극이 **무엇으로 이루어져 있고, 무엇으로 줄이고, 무엇으로 재는지**를 다섯 강에 걸쳐 답합니다.

# 이 단원의 흐름

| 강의 | 하는 일 |
|---|---|
| $210$ | 오차를 잡음과 편향과 분산 셋으로 쪼갭니다 |
| $211$ | 벌점의 모양이 무엇을 바꾸는지 봅니다 |
| $212$ | $\lambda$를 고르는 법을 자료에게 묻습니다 |
| $213$ | 변수가 많으면 무엇이 어려워지는지 봅니다 |
| $214$ | 복잡도를 재는 눈금을 만듭니다 |

**다섯 강이 하나의 줄기입니다.** 간극을 분해하고, 줄이는 장치를 만들고, 그 장치의 손잡이를 고르고, 어려움의 근원을 보고, 마지막으로 어려움을 재는 자를 만듭니다.

# 하나의 문장이 단원 전체를 관통합니다

$$\text{복잡도는 세는 것이 아니라 재는 것입니다}$$

| 세려고 하면 | 실제로는 | 어디서 |
|---|---|---|
| 계수의 개수 | 유효 자유도가 $21$에서 $0.11$까지 움직임 | $214$강 문제 $1$ |
| 변수의 개수 | 내재 차원이 어려움을 정함 | $213$강 문제 $4$ |
| 모형의 크기 | 자료가 늘면 외울 힘이 줄어듦 | $214$강 문제 $4$ |
| VC 차원 | 표본이 $476$배여도 상계가 $0.34$ | $214$강 문제 $3$ |

**모형만 봐서는 복잡도를 알 수 없습니다.** 학습 방식과 자료가 함께 정합니다.

# 간극이 무엇으로 이루어져 있는가

$$\mathbb{E}[(y-\hat{f}(x))^{2}]=\underbrace{\sigma^{2}}_{\text{잡음}}+\underbrace{(\mathbb{E}[\hat{f}]-f)^{2}}_{\text{편향 제곱}}+\underbrace{\text{Var}[\hat{f}]}_{\text{분산}}$$

| 차수 | 편향 제곱 | 분산 |
|---|---|---|
| $0$ | $0.594691$ | $0.003745$ |
| $3$ | 합이 최소인 $0.103436$ | |
| $12$ | $0.000023$ | $0.049351$ |

**잡음은 줄일 수 없고 편향과 분산은 서로 밀고 당깁니다.** 210강에서 이 분해를 확인하고, 211강부터는 **분산 쪽을 누르는 장치**를 만듭니다.

# 벌점의 모양이 해의 질을 바꿉니다

| 방법 | $0$이 아닌 계수 수 | 검증 오차 |
|---|---|---|
| 릿지 $\lambda\,0.01$ | $200$ | $10.929741$ |
| 라소 $\lambda\,0.05$ | $38$ | $0.375322$ |

**표본 $80$에 변수 $200$이고 참 계수가 $8$개일 때 스물아홉 배 차이가 납니다.** 그런데 참 계수가 고르게 퍼져 있으면 릿지가 낫습니다. **어느 쪽이 좋은지는 참 구조가 정하고 참 구조는 미리 알 수 없으므로**, 212강의 교차검증으로 자료에게 묻습니다.

# 교차검증은 값을 맞히는 도구가 아닙니다

| 무엇으로 쟀나 | 평균 | 참 오차와의 차 | 표준편차 |
|---|---|---|---|
| 학습 자료 그대로 | $0.664301$ | $-0.849451$ | $0.138007$ |
| 따로 뗀 $20$개 | $2.059905$ | $0.546153$ | $0.765656$ |
| $5$겹 교차검증 | $1.749904$ | $0.236153$ | $0.428040$ |

**$5$겹은 따로 떼기보다 편향도 작고 분산도 절반입니다.** 그런데 교차검증 값 자체도 흔들립니다. 같은 자료에 나누기만 바꿔도 표준편차가 $0.207097$이고, **후보를 $100$개 두고 최소를 고르면 값이 $1.728606$에서 $1.060290$까지 내려갑니다.** 고르는 행위 자체가 값을 끌어내립니다.

# 저주는 겉보기 차원이 아니라 내재 차원에 걸립니다

| 자료 | 겉보기 차원 | 상관 차원 | 이웃 오차의 분산 대비 비율 |
|---|---|---|---|
| $60$차원인데 내재 $1$차원 | $60$ | $1.013144$ | $0.000270$ |
| 진짜 $60$차원 | $60$ | $15.754661$ | $1.236375$ |

**같은 $60$차원인데 한쪽은 이웃 방법이 완벽히 듣고 다른 쪽은 평균보다도 못합니다.** 213강이 이 차이를 설명하고, 대응 수단 다섯 가지를 정리합니다.

# 앞에서 배운 것이 그대로 쓰입니다

| 이 단원의 개념 | 어디서 배웠는가 |
|---|---|
| 편향과 분산 | $165$강, $210$강 문제 $1$ |
| 정규화와 사전분포 | $116$강과 $148$강, $211$강 문제 $1$ |
| 특이값 분해 | $84$~$89$강, $211$강 문제 $4$ |
| 공선성 | $187$강, $211$강 문제 $2$ |
| 변수 선택과 선택 후 추론 | $189$강, $211$강 문제 $5$ |
| 라그랑주 승수 | $107$강, $211$강 심화 $6$ |
| 유효 표본 크기 | $163$강, $212$강 문제 $2$ |
| 지렛대 | $180$강, $212$강 심화 $1$ |
| 시계열의 앞뒤 | $199$강, $212$강 문제 $4$ |
| 주성분 | $88$강, $213$강 문제 $4$ |
| 델타법 | $153$강, $213$강 심화 $2$ |
| 자유도 | $163$강과 $207$강, $214$강 문제 $1$ |
| 완전 분리 | $208$강, $214$강 문제 $2$ |
| 조기 종료 | $197$강, $214$강 문제 $4$ |

**마지막 줄이 눈에 띕니다.** $197$강에서 실무 요령으로 썼던 조기 종료가 $214$강에서 **왜 그런지** 밝혀집니다. 걸음 수가 계수 크기를 묶어 $\lambda$의 역수처럼 작동합니다.

# 이 단원이 남기는 세 가지 습관

| 습관 | 왜 |
|---|---|
| 학습 오차만 보고 판단하지 않기 | $214$강 문제 $4$에서 검증이 $74$배 나빠지는 동안 학습은 좋아짐 |
| 고르는 데 쓴 값을 성능으로 보고하지 않기 | $212$강 문제 $3$의 후보 수 효과 |
| 라벨을 섞어 학습시켜 보기 | $214$강 심화 $6$의 누출 탐지 |
