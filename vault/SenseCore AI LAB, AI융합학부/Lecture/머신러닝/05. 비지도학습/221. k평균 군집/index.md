# 221강. k평균 군집

$04$단원의 여섯 방법은 모두 **정답을 보고** 배웠습니다. 이제 정답이 없습니다.

$$\text{맞힐 것이 없을 때 무엇을 최소화합니까}$$

지도학습에서는 목적함수가 저절로 정해졌습니다. $205$강에서 "무엇을 최소화할 것인가"를 물었을 때 답이 **예측 오차**였습니다. 여기서는 그 답이 없습니다.

$$\text{우리가 정해야 합니다}$$

이 강의는 가장 널리 쓰이는 답 하나를 세웁니다. **비슷한 것끼리 뭉치게 하고, 뭉친 정도를 제곱합으로 잽니다.** 그리고 그 답이 **무엇을 못 찾는지**까지 봅니다.

## 이 강의에서 할 수 있게 되는 것
- 군집 안 제곱합이 무엇이고 왜 중심이 평균인지 유도할 수 있습니다.
- 번갈아 푸는 절차가 왜 반드시 멈추는지 설명할 수 있습니다.
- 군집 개수를 고르는 네 가지 방법과 그 한계를 말할 수 있습니다.
- 이 방법이 어떤 모양의 덩어리만 찾는지 수치로 보일 수 있습니다.
- 군집을 특성으로 써서 지도학습에 쓸 수 있습니다.

## 문제 1. 라벨이 없을 때 무엇을 최소화하는가

> **문제.** 목적함수를 정합니다.
> ($1$) 지도학습과 무엇이 다른지 정리하세요.
> ($2$) 제곱합이 어떻게 쪼개지는지 확인하세요.
> ($3$) 왜 중심이 평균인지 보이세요.

**생각의 실마리.** "비슷한 것끼리 묶는다"를 수식으로 적어야 합니다. **각 점이 자기 군집의 대표에서 얼마나 떨어졌는지**를 다 더하는 것이 가장 단순한 방식입니다.

**풀이.** ($1$) 정리합니다.

$$W(C)=\sum_{j=1}^{k}\sum_{i\in C_{j}}\|x_{i}-\mu_{j}\|^{2}$$

| 무엇 | 지도학습 | 군집 |
|---|---|---|
| 무엇이 주어지나 | $x$와 $y$ | $x$만 |
| 무엇을 최소화 | 예측 오차 | 군집 안 흩어짐 |
| 정답이 있나 | 예 | 없음 |
| 잘했는지 재기 | 검증 오차 | 어렵고 애매함 |
| 몇 개로 나눌지 | 정해져 있음 | 우리가 정함 |

($2$) 제곱합이 어떻게 쪼개지는지 확인합니다. 참 군집이 셋인 자료입니다.

| $k$ | 군집 안 제곱합 | 군집 사이 제곱합 | 둘의 합 |
|---|---|---|---|
| $1$ | $3955.631101$ | $0.000000$ | $3955.631101$ |
| $2$ | $2240.378888$ | $1715.252213$ | $3955.631101$ |
| $3$ | $729.442615$ | $3226.188486$ | $3955.631101$ |
| $5$ | $537.157943$ | $3418.473158$ | $3955.631101$ |
| $10$ | $282.961101$ | $3672.670000$ | $3955.631101$ |

**마지막 열이 $3955.631101$로 $k$와 무관하게 일정합니다.** $k$를 키우면 군집 안이 줄고 군집 사이가 **정확히 그만큼** 늡니다.

**$166$강의 분산분석에서 본 제곱합 분해와 같은 식입니다.** 거기서는 처리 효과와 오차로 나눴고 여기서는 군집 사이와 군집 안으로 나눕니다.

**그래서 군집 안을 최소화하는 것은 군집 사이를 최대화하는 것과 같습니다.**

($3$) 왜 중심이 평균인지 보입니다. 첫 군집 안에서 중심을 옮겨 봅니다.

| 어느 점을 중심으로 두나 | 제곱합 | 차 |
|---|---|---|
| 평균 | $35.526110$ | $0.000000$ |
| 중앙값 | $36.453969$ | $0.927859$ |
| 첫 점 | $70.124645$ | $34.598535$ |
| 평균에서 $0.3$ 옮김 | $48.486110$ | $12.960000$ |

**평균이 가장 작고 다른 어느 점으로 옮겨도 늘어납니다.**

$$\frac{\partial}{\partial c}\sum_{i}\|x_{i}-c\|^{2}=-2\sum_{i}(x_{i}-c)=0\quad\Longrightarrow\quad c=\bar{x}$$

**거리를 절댓값으로 바꾸면 중앙값이 나옵니다.** 그것이 $k$중앙값이고, $188$강에서 본 이상점 문제를 여기서도 그렇게 다룹니다.

**이 문제에서 배우는 것.** 군집의 목적함수는 **자연법칙이 아니라 선택**입니다. 제곱합을 고르면 평균이 따라오고, 절댓값을 고르면 중앙값이 따라옵니다. **무엇을 최소화할지 정하는 순간 나머지가 정해집니다.**

**확인 1-1.** 군집이 최소화하는 양을 쓰세요.

*답.* 각 점에서 자기 군집 중심까지의 거리 제곱의 합입니다.

**확인 1-2.** 검산에서 $k$가 $3$일 때 군집 안과 군집 사이 제곱합을 쓰세요.

*답.* $729.442615$와 $3226.188486$입니다.

**확인 1-3.** 검산에서 평균과 중앙값을 중심으로 뒀을 때의 제곱합을 쓰세요.

*답.* $35.526110$과 $36.453969$입니다.

## 문제 2. 번갈아 푸는 방법

> **문제.** 실제로 푸는 절차를 세웁니다.
> ($1$) 두 단계를 정리하세요.
> ($2$) 목적함수가 단조로 줄어드는지 보세요.
> ($3$) 시작점이 답을 바꾸는지 재세요.

**생각의 실마리.** 배정과 중심을 **동시에** 정하는 것은 어렵습니다. 그런데 **하나를 고정하면 다른 하나는 쉽습니다.**

**풀이.** ($1$) 정리합니다.

| 단계 | 무엇을 고정하고 | 무엇을 푸나 |
|---|---|---|
| 배정 | 중심을 고정 | 각 점을 가까운 중심에 |
| 갱신 | 배정을 고정 | 각 군집의 평균으로 |
| 반복 | 안 바뀔 때까지 | 유한 번에 멈춤 |

**두 단계 모두 목적함수를 줄이거나 그대로 둡니다.** 배정이 유한 가지뿐이고 같은 배정이 두 번 안 나오므로 **반드시 멈춥니다.** 다만 **가장 좋은 자리라는 보장은 없습니다.**

($2$) 목적함수가 단조로 줄어드는지 봅니다.

| 반복 | 배정 뒤 목적함수 | 갱신 뒤 목적함수 | 배정이 바뀐 점 수 |
|---|---|---|---|
| $1$ | $3623.932400$ | $2216.374605$ | $600$ |
| $2$ | $2216.374605$ | $1895.205842$ | $56$ |
| $3$ | $1895.205842$ | $1043.180625$ | $104$ |
| $4$ | $1043.180625$ | $735.748783$ | $96$ |
| $5$ | $735.748783$ | $729.599343$ | $15$ |
| $6$ | $729.599343$ | $729.442615$ | $2$ |
| $7$ | $729.442615$ | $729.442615$ | $0$ |
| $8$ | $729.442615$ | $729.442615$ | $0$ |

**두 열이 모두 줄어들고 배정이 바뀐 점 수가 $600$에서 $0$으로 갑니다.** 일곱 번째에 멈췄습니다.

**$107$강의 좌표하강과 같은 구조입니다.** 한 번에 한 쪽만 최적화하고, 그래서 국소 최소에 갇힐 수 있습니다.

($3$) 시작점이 답을 바꾸는지 잽니다. 덩어리 여덟 개를 원 위에 고르게 놓은 어려운 자료입니다.

| 시작 방법 | 목적함수 평균 | 가장 나쁜 값 | 가장 좋은 값 |
|---|---|---|---|
| 무작위 점 여덟 | $396.767838$ | $618.005467$ | $306.957075$ |
| $k$평균 플러스플러스 | $365.617196$ | $477.813702$ | $306.957075$ |

**둘 다 가장 좋은 값은 $306.957075$로 같은 자리에 닿습니다.** 그런데 **평균과 가장 나쁜 값이 다릅니다.**

**무작위 시작이 더 자주 갇힙니다.** 가장 나쁜 값이 $618.005467$로 최선의 두 배입니다.

$k$평균 플러스플러스는 **이미 고른 중심에서 멀수록 뽑힐 확률이 크게** 다음 중심을 고릅니다.

$$P(x)\propto \min_{j}\|x-c_{j}\|^{2}$$

나쁜 자리에서 무슨 일이 나는지 봅니다.

| 무엇 | 목적함수 | 빈 덩어리 수 | 가장 큰 군집 크기 |
|---|---|---|---|
| 가장 나쁜 자리 | $578.289362$ | $2$ | $135$ |
| 가장 좋은 자리 | $306.957075$ | $0$ | $90$ |

**나쁜 자리에서는 한 덩어리에 중심 둘이 들어가고 다른 덩어리 둘이 하나로 묶입니다.** 그래서 **아무 중심도 안 맡은 참 덩어리가 $2$개** 생기고, 가장 큰 군집이 $135$개로 부풉니다.

**목적함수 값만 보면 어느 쪽인지 알 수 있습니다.** 그래서 실무에서는 **여러 번 돌려 가장 좋은 것을 고릅니다.**

**이 문제에서 배우는 것.** 이 절차는 **반드시 멈추지만 어디서 멈출지는 시작점이 정합니다.** 그래서 한 번 돌린 결과를 그대로 쓰면 안 되고, **목적함수 값을 반드시 함께 봐야** 합니다.

**확인 2-1.** 이 절차가 왜 반드시 멈추는지 쓰세요.

*답.* 배정이 유한 가지이고 목적함수가 매번 줄거나 그대로이기 때문입니다.

**확인 2-2.** 검산에서 무작위 시작과 $k$평균 플러스플러스의 가장 나쁜 값을 쓰세요.

*답.* $618.005467$과 $477.813702$입니다.

**확인 2-3.** 검산에서 가장 나쁜 자리의 빈 덩어리 수를 쓰세요.

*답.* $2$개입니다.

## 문제 3. $k$를 어떻게 고르는가

> **문제.** 군집 개수를 정합니다.
> ($1$) 방법을 정리하세요.
> ($2$) 팔꿈치와 실루엣을 재세요.
> ($3$) 군집이 없는 자료에서 무엇이 나오는지 보세요.

**생각의 실마리.** $k$를 키우면 목적함수가 **언제나** 줄어듭니다. $k=n$이면 $0$입니다. 그러니 목적함수만 보고는 못 고릅니다.

**풀이.** ($1$) 정리합니다.

| 방법 | 무엇을 보나 | 무엇이 문제인가 |
|---|---|---|
| 팔꿈치 | 목적함수가 꺾이는 자리 | 눈으로 정함 |
| 실루엣 | 안과 밖의 거리 비 | 덩어리 모양에 딸림 |
| 간격 통계량 | 무작위 자료와 비교 | 계산이 비쌈 |
| 아는 것 쓰기 | 문제의 뜻 | 언제나 있지는 않음 |
| 다음 단계 성능 | 군집을 쓴 결과 | 가장 정직함 |

($2$) 팔꿈치와 실루엣을 잽니다. 참 군집이 셋인 자료입니다.

$$s(i)=\frac{b(i)-a(i)}{\max(a(i),b(i))}$$

| $k$ | 목적함수 | 앞 $k$ 대비 감소 | 실루엣 |
|---|---|---|---|
| $1$ | $3955.631101$ | $0.000000$ | $0.000000$ |
| $2$ | $2240.378888$ | $1715.252213$ | $0.445821$ |
| $3$ | $729.442615$ | $1510.936273$ | $0.622244$ |
| $4$ | $632.897259$ | $96.545356$ | $0.509223$ |
| $5$ | $537.137917$ | $95.759341$ | $0.418345$ |
| $6$ | $454.767344$ | $82.370573$ | $0.341601$ |
| $8$ | $354.201305$ | $100.566039$ | $0.350698$ |

**감소량이 $k=3$에서 $1510.936273$이었다가 $k=4$에서 $96.545356$으로 열다섯 배 작아집니다.** 그 자리가 팔꿈치입니다.

**실루엣도 $k=3$에서 $0.622244$로 가장 큽니다.** 둘이 같은 답을 주는 것은 **이 자료가 쉬운 경우**이기 때문입니다.

($3$) 군집이 없는 자료에서 무엇이 나오는지 봅니다. 균등분포에서 뽑았습니다.

| $k$ | 목적함수 | 앞 $k$ 대비 감소 | 실루엣 |
|---|---|---|---|
| $1$ | $82.484472$ | $0.000000$ | $0.000000$ |
| $2$ | $50.333585$ | $32.150887$ | $0.362161$ |
| $3$ | $32.163146$ | $18.170440$ | $0.380217$ |
| $4$ | $19.941817$ | $12.221328$ | $0.421717$ |
| $6$ | $13.944652$ | $5.997165$ | $0.370528$ |

**참 군집이 없는데도 목적함수는 계속 줄고 실루엣이 $0.421717$까지 올라갑니다.**

**군집을 찾으라고 하면 언제나 찾아 줍니다.** 있든 없든 상관없이 나눕니다. **그래서 실루엣 값 하나로 군집이 있다고 말하면 안 됩니다.**

무작위 자료와 견주는 것이 그래서 필요합니다.

| $k$ | 실제 자료 로그 목적함수 | 무작위 자료 평균 | 차 |
|---|---|---|---|
| $1$ | $8.282895$ | $8.762305$ | $0.479410$ |
| $2$ | $7.714400$ | $8.247500$ | $0.533100$ |
| $3$ | $6.592281$ | $7.794712$ | $1.202432$ |
| $4$ | $6.450517$ | $7.365142$ | $0.914625$ |
| $6$ | $6.119786$ | $6.986164$ | $0.866378$ |

**차가 $k=3$에서 $1.202432$로 가장 큽니다.** 간격 통계량이 고르는 $k$가 그것입니다.

**무작위 자료도 $k$를 키우면 목적함수가 줄어드는 것을 빼는 것입니다.** $212$강에서 후보를 많이 보면 최소값이 저절로 내려간다고 한 것과 **같은 종류의 보정**입니다.

**이 문제에서 배우는 것.** $k$를 고르는 **정답은 없습니다.** 목적함수는 언제나 줄고, 실루엣은 군집이 없어도 높게 나옵니다. **무엇에 쓸지가 정해져야 $k$가 정해집니다.**

**확인 3-1.** 목적함수만 보고 $k$를 못 고르는 이유를 쓰세요.

*답.* $k$를 키우면 언제나 줄어들기 때문입니다.

**확인 3-2.** 검산에서 참 군집이 셋인 자료의 $k=3$과 $k=4$의 감소량을 쓰세요.

*답.* $1510.936273$과 $96.545356$입니다.

**확인 3-3.** 검산에서 군집이 없는 자료의 실루엣 최대값을 쓰세요.

*답.* $k=4$에서 $0.421717$입니다.

## 문제 4. 무엇을 못 하는가

> **문제.** 한계를 봅니다.
> ($1$) 어떤 모양만 찾는지 정리하세요.
> ($2$) 세 가지 어려운 자료에서 재세요.
> ($3$) 눈금이 답을 바꾸는지 보세요.

**생각의 실마리.** 배정 규칙이 "가장 가까운 중심"이므로, **두 중심 사이의 경계는 언제나 수직이등분선**입니다. 그러면 각 군집이 **볼록한 조각**이 됩니다.

**풀이.** ($1$) 정리합니다.

| 자료 모양 | $k$평균이 찾나 | 왜 |
|---|---|---|
| 공 모양이고 크기 비슷 | 예 | 가정에 맞음 |
| 길쭉한 타원 | 아니오 | 거리가 등방성 |
| 크기가 아주 다름 | 아니오 | 큰 것을 쪼갬 |
| 겹친 고리 | 아니오 | 볼록한 조각만 |
| 밀도가 다름 | 아니오 | $222$강의 방법 |

($2$) 세 가지 어려운 자료에서 잽니다.

| 자료 | 순도 | 무엇이 문제인가 |
|---|---|---|
| 길쭉한 띠 둘 | $0.522000$ | 긴 쪽으로 잘림 |
| 큰 덩어리와 작은 덩어리 | $0.926667$ | 작은 쪽 군집 정밀도 $0.1254$ |

| 기호 | 읽는 법 | 뜻 |
|---|---|---|

def pw(s, n):
    k = n - sum(2 if ord(c) > 0x2FFF else 1 for c in str(s))
    return str(s) + " " * max(k, 0)


def rw(s, n):
    k = n - sum(2 if ord(c) > 0x2FFF else 1 for c in str(s))
    return " " * max(k, 0) + str(s)


def d2(A, B):
    return ((A[:, None, :] - B[None, :, :]) ** 2).sum(axis=2)


def kmeans(X, k, init=None, iters=200, r=None):
    n = len(X)
    if init is None:
        C = X[r.permutation(n)[:k]].copy()
    else:
        C = init.copy()
    lab = np.zeros(n, dtype=np.int64)
    for _ in range(iters):
        D = d2(X, C)
        new = np.argmin(D, axis=1)
        if np.array_equal(new, lab) and _ > 0:
            break
        lab = new
        for j in range(k):
            m = lab == j
            if m.any():
                C[j] = X[m].mean(axis=0)
    return C, lab, float(np.sum(np.min(d2(X, C), axis=1)))


def kpp_init(X, k, r):
    n = len(X)
    C = [X[r.integers(0, n)]]
    for _ in range(k - 1):
        D = np.min(d2(X, np.stack(C)), axis=1)
        p = D / max(D.sum(), 1e-300)
        C.append(X[r.choice(n, p=p)])
    return np.stack(C)

def silhouette(X, lab, k):
    n = len(X)
    D = np.sqrt(d2(X, X))
    s = np.zeros(n)
    for i in range(n):
        own = lab[i]
        m = lab == own
        m[i] = False
        a = D[i, m].mean() if m.any() else 0.0
        b = np.inf
        for j in range(k):
            if j == own:
                continue
            mj = lab == j
            if mj.any():
                b = min(b, D[i, mj].mean())
        s[i] = 0.0 if max(a, b) == 0 else (b - a) / max(a, b)
    return float(s.mean())

def purity(lab, z, k):
    tot = 0
    for j in range(k):
        m = lab == j
        if m.any():

    Aa = np.hstack([A, np.ones((len(A), 1))])
    w = np.zeros(Aa.shape[1])

    return float(np.mean(((Bb @ w) > 0) == yb))
