title: "05. 비지도학습"
---
이 단원은 221강부터 225강까지를 맡습니다. **라벨 없이 구조를 찾습니다.**

04단원의 여섯 방법은 모두 **정답을 보고** 배웠습니다. 이 단원이 묻는 것은 다릅니다.

$$\text{맞힐 것이 없을 때 무엇을 찾는가}$$

**목적함수가 저절로 안 정해집니다.** $205$강에서 "무엇을 최소화할 것인가"의 답이 예측 오차였는데, 여기서는 그 답이 없어 **우리가 정해야** 합니다.

# 이 단원의 흐름

| 강의 | 무엇을 정하는가 |
|---|---|
| $221$ | 군집 안 제곱합을 최소로 합니다 |
| $222$ | 개수도 모양도 안 정하고 연결이나 밀도로 정의합니다 |
| $223$ | 모양을 확률분포로 적고 우도를 최대로 합니다 |
| $224$ | 나누지 않고 축을 갈아탑니다 |
| $225$ | 정상을 배우고 벗어난 것을 찾습니다 |

**$221$강부터 $223$강이 하나의 줄기입니다.** 가정을 세게 하는 쪽에서 안 하는 쪽으로, 다시 확률로 적는 쪽으로 갑니다.

# 하나의 문장이 단원 전체를 관통합니다

$$\text{무엇을 정상이라 볼지가 답을 정합니다}$$

| 무엇을 가정하면 | 무엇이 나오나 | 어디서 |
|---|---|---|
| 덩어리가 공 모양 | 볼록한 조각으로 나뉨 | $221$강 문제 $4$ |
| 한 점만 가까우면 이음 | 초승달을 찾되 다리에 무너짐 | $222$강 문제 $2$ |
| 덩어리가 정규분포 | 타원과 소속 확률 | $223$강 문제 $3$ |
| 분산이 큰 방향이 중요 | 갈래 방향을 버릴 수 있음 | $224$강 문제 $2$ |
| 밀도가 낮으면 이상 | 덩어리 사이 빈 곳이 이상 | $225$강 문제 $2$ |

**라벨이 없으므로 가정이 맞는지 확인할 방법이 없습니다.** 그것이 이 단원 전체의 어려움입니다.

# 없는 것도 찾아 줍니다

| 자료 | $k$ | 목적함수 | 실루엣 |
|---|---|---|---|
| 균등분포 (군집 없음) | $2$ | $50.333585$ | $0.362161$ |
| 균등분포 (군집 없음) | $4$ | $19.941817$ | $0.421717$ |

**참 군집이 없는데도 실루엣이 $0.42$까지 오릅니다.** $224$강 문제 $5$에서는 $10$차원 표준정규 자료를 t-SNE로 그리니 **네 조각이 고르게 생겼습니다.**

**군집을 찾으라고 하면 언제나 찾아 줍니다.** 그래서 값 하나로 "군집이 있다"고 말하면 안 되고, $221$강의 간격 통계량처럼 **무작위 자료와 견줘야** 합니다.

# 같은 자료가 방법마다 다르게 보입니다

| 자료 | $k$평균 순도 | 워드 연결 순도 | 밀도 기반 순도 |
|---|---|---|---|
| 공 모양 둘 | $0.985000$ | $0.980000$ | $0.534031$ |
| 초승달 둘 | $0.726667$ | $0.850000$ | $1.000000$ |
| 밀도 다름 | $0.940000$ | $0.956667$ | $0.963768$ |

**공 모양에서 꼴찌인 밀도 기반이 초승달에서 유일한 승자입니다.** $222$강 문제 $2$에서 최단 연결도 정확히 같은 방향으로 뒤집혔습니다.

# 세 군집 방법이 서로를 포함합니다

| 무엇 | $k$평균 | 밀도 기반 | 혼합모형 |
|---|---|---|---|
| 배정 | 굳음 | 굳음 | 확률 |
| 모양 | 공 | 아무 모양 | 타원 |
| 개수 | 정함 | 안 정함 | 정보기준 |
| 잡음 | 다 넣음 | 따로 뺌 | 낮은 밀도 |
| 밀도를 주나 | 아니오 | 아니오 | 예 |

**$k$평균은 혼합모형에서 공분산을 묶고 굳힌 것입니다.** $223$강 문제 $3$에서 분산을 $0.30$으로 줄이니 배정이 $k$평균과 **완전히 같아졌습니다.**

# 앞에서 배운 것이 그대로 쓰입니다

| 이 단원의 개념 | 어디서 배웠는가 |
|---|---|
| 제곱합 분해 | $166$강, $221$강 문제 $1$ |
| 좌표하강 | $107$강, $221$강 문제 $2$ |
| 유효 표본 크기 | $163$강, $222$강 심화 $5$ |
| 젠센 부등식 | $132$강, $223$강 심화 $1$ |
| 최대우도 | $149$강, $223$강 문제 $1$ |
| 결측자료 | $156$강, $223$강 문제 $1$ |
| 정보기준 | $212$강 심화 $6$, $223$강 문제 $4$ |
| 특이값 분해 | $84$강, $224$강 문제 $1$ |
| 주성분 | $88$강, $224$강 전체 |
| KL 발산 | $203$강, $224$강 문제 $4$ |
| 거리 집중 | $213$강, $224$강 문제 $5$ |
| 마할라노비스 거리 | $137$강, $225$강 문제 $1$ |
| 커널 요령 | $220$강, $222$강과 $224$강 심화 |
| 앙상블 | $218$강, $225$강 문제 $5$ |

**$213$강이 이 단원 내내 따라다닙니다.** 거리가 뜻을 잃으면 군집도 밀도도 이상탐지도 함께 무너집니다.

# 이 단원이 남기는 세 가지 습관

| 습관 | 왜 |
|---|---|
| 결과를 무작위 자료와 견주기 | 없어도 나오기 때문 |
| 손잡이 값을 함께 보고하기 | $k$나 $\varepsilon$이 답을 정하기 때문 |
| 여러 방법을 함께 돌리기 | 어느 것이 맞는지 못 고르기 때문 |

# 다음 단계

**06단원부터는 다시 라벨이 있습니다.**

$$\text{맞힐 것이 없을 때 무엇을 찾는가} \;\longrightarrow\; \text{만든 것을 어떻게 재고 고치는가}$$

다만 이번에는 모형을 만드는 것이 아니라 **재고 고르고 해석하는 일**입니다. $225$강 문제 $5$의 문턱 맞바꿈이 $226$강의 ROC 곡선으로 이어집니다.
