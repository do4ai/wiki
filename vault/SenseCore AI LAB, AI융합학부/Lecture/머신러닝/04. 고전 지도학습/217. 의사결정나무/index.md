# 217강. 의사결정나무

$215$강은 **거리**로, $216$강은 **분포**로 답을 찾았습니다. 이번에는 셋째 방법입니다.

$$\text{예 아니오 질문을 이어 붙여 답을 찾습니다}$$

"소득이 $3000$만 원 이하입니까"라고 묻고, 그 답에 따라 다음 질문을 던집니다. **사람이 결정을 내리는 방식과 같아서** 규칙을 그대로 읽을 수 있습니다.

$$\text{어떤 질문을 어떤 순서로 던집니까}$$

이 강의는 그 질문을 고르는 자를 만들고, 언제 멈출지 정하고, 이 방법이 **무엇을 원리적으로 못 하는지**까지 봅니다. 마지막 못 하는 것이 $218$강과 $219$강을 낳습니다.

## 이 강의에서 할 수 있게 되는 것
- 지니와 엔트로피와 오분류율을 계산하고 왜 오분류율을 안 쓰는지 보일 수 있습니다.
- 나무를 키우고 비용 복잡도로 깎을 수 있습니다.
- 나무가 못 잡는 경계를 알아보고 그 비용을 셀 수 있습니다.
- 회귀 나무를 세우고 예측값의 가짓수 한계를 말할 수 있습니다.
- 변수 중요도의 두 가지 편향을 수치로 보일 수 있습니다.

## 문제 1. 질문을 하나씩 던져 나눕니다

> **문제.** 나눔의 자를 정합니다.
> ($1$) 이웃 방법과 무엇이 다른지 정리하세요.
> ($2$) 순도를 재는 자 셋을 계산하세요.
> ($3$) 오분류율을 왜 안 쓰는지 보이세요.

**생각의 실마리.** 좋은 질문은 **답을 갈라 주는 질문**입니다. 갈랐다는 것을 재려면 **한 마디가 얼마나 순수한지**를 재는 자가 필요합니다.

**풀이.** ($1$) 정리합니다.

| 무엇 | 이웃 방법 | 나무 |
|---|---|---|
| 공간을 어떻게 나누나 | 점 주위로 | 축에 나란한 상자로 |
| 예측 비용 | 표본에 비례 | 깊이에 비례 |
| 사람이 읽을 수 있나 | 어려움 | 규칙으로 읽힘 |
| 눈금에 민감한가 | 매우 | 전혀 |
| 결측값 | 곤란 | 따로 보낼 수 있음 |

**상자로 나누므로 변수의 눈금을 바꿔도 답이 안 바뀝니다.** $215$강 문제 $2$에서 배율 $100$이 정확도를 $0.955$에서 $0.728$로 떨어뜨렸는데, 나무는 그런 일이 없습니다. **$x_{j}\leq t$라는 질문은 단조 변환에 안 변하기 때문**입니다.

($2$) 순도를 재는 자 셋을 계산합니다.

$$\text{지니}=2p(1-p)\qquad\text{엔트로피}=-p\log_{2}p-(1-p)\log_{2}(1-p)\qquad\text{오분류율}=\min(p,1-p)$$

| 양성 비율 | 지니 | 엔트로피 | 오분류율 |
|---|---|---|---|
| $0.0$ | $0.000000$ | $0.000000$ | $0.000000$ |
| $0.1$ | $0.180000$ | $0.468996$ | $0.100000$ |
| $0.3$ | $0.420000$ | $0.881291$ | $0.300000$ |
| $0.5$ | $0.500000$ | $1.000000$ | $0.500000$ |
| $0.7$ | $0.420000$ | $0.881291$ | $0.300000$ |
| $0.9$ | $0.180000$ | $0.468996$ | $0.100000$ |
| $1.0$ | $0.000000$ | $0.000000$ | $0.000000$ |

**셋 다 $0.5$에서 가장 크고 $0$과 $1$에서 $0$입니다.** 그런데 **모양이 다릅니다.** 지니와 엔트로피는 굽어 있고 오분류율은 꺾인 직선 둘입니다.

($3$) 오분류율을 왜 안 쓰는지 보입니다. 부모 마디에 양성 $400$ 음성 $400$이 있고 두 나눔을 견줍니다.

| 나눔 | 왼쪽 (양성 음성) | 오른쪽 (양성 음성) |
|---|---|---|
| 가 나눔 | $300$ $100$ | $100$ $300$ |
| 나 나눔 | $200$ $400$ | $200$ $0$ |

| 자 | 가 나눔의 이득 | 나 나눔의 이득 | 어느 쪽을 고르나 |
|---|---|---|---|
| 지니 | $0.125000$ | $0.166667$ | 나 |
| 엔트로피 | $0.188722$ | $0.311278$ | 나 |
| 오분류율 | $0.250000$ | $0.250000$ | 고를 수 없음 |

**오분류율은 두 나눔의 이득이 정확히 같아 고를 수가 없습니다.** 둘 다 오분류 $200$개를 남기기 때문입니다.

**지니와 엔트로피는 나 나눔을 고릅니다.** 오른쪽이 **완전히 순수해지기 때문**이고, 그것은 그 뒤에 더 나눌 것이 없다는 뜻입니다.

**$132$강의 젠센 부등식에서 굽음이 이 차이를 만듭니다.** 굽은 함수는 **극단으로 쪼갤수록 가중평균이 더 많이 내려가고**, 직선은 그렇지 않습니다.

**이 문제에서 배우는 것.** 나눔의 자는 **지금의 오류율이 아니라 앞으로 나눌 여지**를 재야 합니다. 굽은 함수가 그 여지를 재고, 오분류율은 못 잽니다. **그래서 나무를 키울 때는 지니나 엔트로피를 쓰고, 깎을 때는 오분류율을 씁니다.**

**확인 1-1.** 나무가 눈금에 안 민감한 이유를 쓰세요.

*답.* 상자로 나누므로 단조 변환에 답이 안 변하기 때문입니다.

**확인 1-2.** 검산에서 양성 비율 $0.1$일 때 지니와 엔트로피를 쓰세요.

*답.* $0.180000$과 $0.468996$입니다.

**확인 1-3.** 검산에서 오분류율이 두 나눔에 준 이득을 쓰세요.

*답.* 둘 다 $0.250000$입니다.

## 문제 2. 나무를 키우고 깎습니다

> **문제.** 실제로 나무를 만듭니다.
> ($1$) 깊이를 바꿔 가며 재세요.
> ($2$) 멈추는 규칙 셋을 견주세요.
> ($3$) 비용 복잡도 가지치기를 하세요.

**생각의 실마리.** 나무는 **끝까지 키우면 모든 점을 외웁니다.** 잎마다 한 점씩 담으면 학습 오차가 $0$이 됩니다. 어디서 멈출지가 전부입니다.

**풀이.** ($1$) 참 경계가 원인 자료에서 잽니다. 베이즈 최적 정확도는 $0.878000$입니다.

| 깊이 | 잎 개수 | 학습 정확도 | 검증 정확도 | 최적과의 차 |
|---|---|---|---|---|
| $1$ | $2$ | $0.698333$ | $0.666000$ | $-0.212000$ |
| $2$ | $4$ | $0.698333$ | $0.666000$ | $-0.212000$ |
| $3$ | $7$ | $0.790000$ | $0.781000$ | $-0.097000$ |
| $5$ | $18$ | $0.881667$ | $0.844667$ | $-0.033333$ |
| $8$ | $42$ | $0.916667$ | $0.838667$ | $-0.039333$ |
| $15$ | $90$ | $0.991667$ | $0.815333$ | $-0.062667$ |

**깊이 $1$과 $2$가 같은 값입니다.** 원 경계를 축 하나로 자르면 어느 쪽으로 잘라도 판정이 안 바뀌기 때문입니다.

**깊이 $15$에서 학습 정확도가 $0.991667$이고 검증은 $0.815333$입니다.** 잎이 $90$개라 거의 외웠습니다.

**검증 정확도는 깊이 $5$에서 $0.844667$로 가장 좋고 그 뒤로 떨어집니다.** $214$강의 복잡도 손잡이가 여기서는 **깊이**입니다.

잎 개수가 곧 유효 자유도인지 확인합니다.

| 깊이 | 잎 개수 | 학습 오분류율 | 검증 빼기 학습 |
|---|---|---|---|
| $1$ | $2$ | $0.301667$ | $0.032333$ |
| $2$ | $4$ | $0.301667$ | $0.032333$ |
| $3$ | $7$ | $0.210000$ | $0.009000$ |
| $5$ | $18$ | $0.118333$ | $0.037000$ |
| $8$ | $42$ | $0.083333$ | $0.078000$ |
| $15$ | $90$ | $0.008333$ | $0.176333$ |

**잎이 늘수록 격차가 벌어집니다.** 잎 $2$개에서 $0.032333$이고 잎 $90$개에서 $0.176333$입니다. **잎 하나가 모수 하나 노릇을 하고**, $214$강 문제 $1$의 낙관이 잎 개수에 비례합니다.

($2$) 멈추는 규칙 셋을 견줍니다.

| 멈추는 규칙 | 잎 개수 | 검증 정확도 | 무엇이 문제인가 |
|---|---|---|---|
| 깊이 제한 $3$ | $7$ | $0.781000$ | 너무 얕을 수 있음 |
| 잎 최소 $30$개 | $13$ | $0.857000$ | 가지마다 다름 |
| 이득 문턱 $0.01$ | $67$ | $0.838667$ | 앞을 못 봄 |
| 제한 없음 | $95$ | $0.812667$ | 완전히 외움 |

**이득 문턱은 지금 나눔만 봅니다.** 한 번 나눠서는 이득이 없지만 **두 번 나눠야 좋아지는 자리**를 놓칩니다. 배타적 논리합이 정확히 그런 자리입니다.

**그래서 크게 키운 뒤 깎는 것이 표준입니다.**

($3$) 비용 복잡도 가지치기를 합니다. 잎 개수에 벌점을 겁니다.

$$C_{\alpha}(T)=\sum_{\text{잎}}\text{오차}+\alpha\,|T|$$

| $\alpha$ | 잎 개수 | 검증 정확도 | 최적과의 차 |
|---|---|---|---|
| $0.0$ | $95$ | $0.812667$ | $-0.065333$ |
| $0.5$ | $70$ | $0.822333$ | $-0.055667$ |
| $2.0$ | $9$ | $0.855333$ | $-0.022667$ |
| $8.0$ | $5$ | $0.857000$ | $-0.021000$ |
| $30.0$ | $1$ | $0.666000$ | $-0.212000$ |

**$\alpha$를 올리면 잎이 $95$에서 $1$까지 줄고 검증은 $\alpha=8$에서 가장 좋습니다.**

**$211$강의 벌점과 정확히 같은 꼴입니다.** 거기서는 계수 크기에 벌점을 걸었고 여기서는 잎 개수에 겁니다. **$\alpha$를 교차검증으로 고르는 것이 $212$강 그대로입니다.**

**이 문제에서 배우는 것.** 나무의 복잡도 손잡이는 **깊이가 아니라 잎 개수**입니다. 깊이는 거칠고, 가지마다 필요한 깊이가 다릅니다. **키운 뒤 깎으면 가지마다 알맞은 깊이가 자동으로 정해집니다.**

**확인 2-1.** 나무의 유효 자유도가 무엇인지 쓰세요.

*답.* 잎의 개수입니다.

**확인 2-2.** 검산에서 깊이 $5$와 $15$의 검증 정확도를 쓰세요.

*답.* $0.844667$과 $0.815333$입니다.

**확인 2-3.** 검산에서 $\alpha=8$일 때 잎 개수와 검증 정확도를 쓰세요.

*답.* $5$개와 $0.857000$입니다.

## 문제 3. 나무가 못 하는 것

> **문제.** 나무의 한계를 봅니다.
> ($1$) 잘하는 경계와 못하는 경계를 견주세요.
> ($2$) 기울어진 직선의 비용을 세세요.
> ($3$) 회전을 미리 해 주면 어떻게 되는지 보세요.

**생각의 실마리.** 나무는 **축에 나란한 자름만** 씁니다. $x_{1}+x_{2}>0$ 같은 경계는 **계단으로 근사**해야 하고, 계단은 대각선을 정확히 못 덮습니다.

**풀이.** ($1$) 세 경계에서 견줍니다.

| 참 경계 | 나무 정확도 | 로지스틱 정확도 |
|---|---|---|
| 배타적 논리합 | $0.945000$ | $0.573333$ |
| $45$도 기울어진 직선 | $0.867333$ | $0.889000$ |
| 원 | $0.870667$ | $0.685000$ |

**배타적 논리합에서 나무가 $0.945000$이고 로지스틱이 $0.573333$입니다.** 나무는 두 번 나눠 잡고 로지스틱은 직선 하나로 원리적으로 못 잡습니다.

**$45$도 기울어진 직선에서는 반대입니다.** 로지스틱이 $0.889000$이고 나무가 $0.867333$입니다.

**원에서는 나무가 크게 이깁니다.** $0.870667$ 대 $0.685000$입니다. 원은 계단으로 꽤 잘 덮이지만 직선 하나로는 전혀 안 됩니다.

($2$) 기울어진 직선의 비용을 셉니다. 잡음이 없는 $45$도 경계에서 깊이를 늘려 갑니다.

| 깊이 | 잎 개수 | 검증 정확도 | 남은 오류율 |
|---|---|---|---|
| $1$ | $2$ | $0.736800$ | $0.263200$ |
| $2$ | $4$ | $0.845600$ | $0.154400$ |
| $4$ | $16$ | $0.941200$ | $0.058800$ |
| $6$ | $40$ | $0.973400$ | $0.026600$ |
| $8$ | $45$ | $0.980200$ | $0.019800$ |
| $10$ | $45$ | $0.980200$ | $0.019800$ |

**잡음이 하나도 없는데도 오류율이 $0$이 안 됩니다.** 잎을 네 배로 늘려야 오류율이 겨우 절반쯤 됩니다.

**계단으로 대각선을 덮으려면 잎이 지수로 필요합니다.** 깊이 $8$부터 잎이 $45$에서 멈추는 것은 잎 최소 $5$개 제한 때문입니다.

($3$) 회전을 미리 해 주면 어떻게 되는지 봅니다.

| 자료를 어떻게 주나 | 깊이 $4$ 정확도 | 잎 개수 |
|---|---|---|
| 그대로 | $0.941200$ | $16$ |
| $45$도 돌려서 | $0.998800$ | $4$ |

**돌려 주면 잎 $4$개로 $0.998800$입니다.** 그대로 두면 잎 $16$개로 $0.941200$입니다.

**나무는 축을 못 만듭니다. 주어진 축으로만 자릅니다.** $228$강의 특성공학이 하는 일이 정확히 이 회전을 대신 해 주는 것입니다.

**이 문제에서 배우는 것.** 나무의 한계는 **표현력이 아니라 표현의 효율**입니다. 잎을 충분히 쓰면 어떤 경계든 덮을 수 있지만, **기울어진 경계에는 잎이 지수로 듭니다.** $215$강에서 거리가 모형이었듯 **여기서는 축이 모형입니다.**

**확인 3-1.** 나무가 기울어진 경계에 약한 이유를 쓰세요.

*답.* 축에 나란한 자름만 쓰므로 계단으로 근사해야 하기 때문입니다.

**확인 3-2.** 검산에서 배타적 논리합의 두 정확도를 쓰세요.

*답.* $0.945000$과 $0.573333$입니다.

**확인 3-3.** 검산에서 $45$도 자료를 그대로 줄 때와 돌려 줄 때의 잎 개수를 쓰세요.

*답.* $16$개와 $4$개입니다.

## 문제 4. 회귀 나무와 변수 중요도

> **문제.** 회귀로 넓히고 중요도를 잽니다.
> ($1$) 회귀 나무를 세우고 재세요.
> ($2$) 예측값의 가짓수를 세세요.
> ($3$) 변수 중요도의 편향 둘을 보이세요.

**생각의 실마리.** 자를 제곱오차로 바꾸면 그대로 회귀가 됩니다. 잎 안에서는 **평균 하나**를 냅니다.

**풀이.** ($1$) 회귀 나무를 세웁니다. 자는 잎 안 분산입니다.

$$\text{나눔의 이득}=\text{Var}(y)-\frac{n_{L}\text{Var}(y_{L})+n_{R}\text{Var}(y_{R})}{n}$$

| 깊이 | 잎 개수 | 학습 오차 | 검증 오차 |
|---|---|---|---|
| $1$ | $2$ | $0.849826$ | $0.834216$ |
| $2$ | $4$ | $0.372302$ | $0.390377$ |
| $4$ | $16$ | $0.135591$ | $0.196160$ |
| $6$ | $48$ | $0.079096$ | $0.154662$ |
| $10$ | $77$ | $0.062486$ | $0.145824$ |

검증 오차에는 줄일 수 없는 잡음 분산 $0.09$를 더해 눈금을 맞췄습니다.

**깊이 $10$에서도 검증 오차가 $0.145824$로 잡음 바닥 $0.09$에 못 미칩니다.** 매끄러운 함수를 계단으로 덮으므로 **편향이 남습니다.**

**$215$강의 이웃 방법과 같은 약점입니다.** $218$강의 평균이 이것을 고칩니다.

($2$) 예측값의 가짓수를 셉니다.

| 깊이 | 잎 개수 | 서로 다른 예측값 수 | 참 함수의 치역 폭 |
|---|---|---|---|
| $1$ | $2$ | $2$ | $4.980707$ |

> **심화 2.** 지니와 엔트로피의 관계를 정리하세요.

$$\text{엔트로피}=-p\log p-(1-p)\log(1-p)\approx 2p(1-p)+O((p-\tfrac12)^{4})$$

| 무엇 | 지니 | 엔트로피 |
|---|---|---|
| $p=0.5$ 근처 | 거의 같음 | 거의 같음 |

| 고르는 나눔 | 거의 같음 | 거의 같음 |

**$p=1/2$ 근처에서 테일러 전개하면 둘이 상수배로 같습니다.** 실제로 고르는 나눔이 거의 안 달라지므로 **어느 쪽을 써도 됩니다.** 지니가 로그를 안 쓰므로 조금 빠릅니다.

> **심화 4.** 나무가 왜 편향이 낮고 분산이 높은지 설명하세요.

| 기호 | 읽는 법 | 뜻 |
|---|---|---|
| 의사결정나무 | decision tree | 질문을 이어 붙여 답을 냅니다 |
| 마디 | node | 질문 하나가 붙는 자리입니다 |
| 잎 | leaf | 더 안 나누고 답을 내는 자리입니다 |
| 지니 불순도 | Gini impurity | $2p(1-p)$입니다 |

| 이득비 | gain ratio | 이득을 나눔의 가짓수로 나눕니다 |

import numpy as np

rng = np.random.default_rng(20261129)


def pw(s, n):
    k = n - sum(2 if ord(c) > 0x2FFF else 1 for c in str(s))
    return str(s) + " " * max(k, 0)


def rw(s, n):
    k = n - sum(2 if ord(c) > 0x2FFF else 1 for c in str(s))
    return " " * max(k, 0) + str(s)


def gini(y):
    if len(y) == 0:
        return 0.0
    p = y.mean()
    return float(2 * p * (1 - p))


def entropy(y):
    if len(y) == 0:
        return 0.0
    p = y.mean()
    if p <= 0 or p >= 1:
        return 0.0
    return float(-p * np.log2(p) - (1 - p) * np.log2(1 - p))


def mis(y):
    if len(y) == 0:
        return 0.0
    p = y.mean()
    return float(min(p, 1 - p))


def best_split(X, y, crit=gini, min_leaf=1):
    n, d = X.shape
    base = crit(y)
    best = (0.0, -1, 0.0)
    for j in range(d):
        v = X[:, j]
        cuts = np.unique(v)
        if len(cuts) > 40:
            cuts = np.quantile(v, np.linspace(0.02, 0.98, 40))
        for t in cuts:
            m = v <= t
            nl, nr = int(m.sum()), int((~m).sum())
            if nl < min_leaf or nr < min_leaf:
                continue
            g = base - (nl * crit(y[m]) + nr * crit(y[~m])) / n
            if g > best[0]:
                best = (g, j, float(t))
    return best


class Node:
    def __init__(self):
        self.j = -1
        self.t = 0.0
        self.left = None
        self.right = None
        self.val = 0.0
        self.n = 0


def grow(X, y, depth, crit=gini, min_leaf=1, min_gain=0.0):
    nd = Node()
    nd.val = float(y.mean())
    nd.n = len(y)
    if depth <= 0 or len(y) < 2 * min_leaf or y.min() == y.max():
        return nd
    g, j, t = best_split(X, y, crit, min_leaf)
    if j < 0 or g <= min_gain:
        return nd
    nd.j, nd.t = j, t
    m = X[:, j] <= t
    nd.left = grow(X[m], y[m], depth - 1, crit, min_leaf, min_gain)
    nd.right = grow(X[~m], y[~m], depth - 1, crit, min_leaf, min_gain)
    return nd


def predict(nd, X):
    out = np.zeros(len(X))
    for i in range(len(X)):
        c = nd
        while c.j >= 0:
            c = c.left if X[i, c.j] <= c.t else c.right
        out[i] = c.val
    return out


def leaves(nd):
    if nd.j < 0:
        return 1
    return leaves(nd.left) + leaves(nd.right)

def cc_prune(nd, alpha, X, y):
    if nd.j < 0:
        return nd, 1, float(np.sum((y - nd.val) ** 2))
    m = X[:, nd.j] <= nd.t
    lft, nl, el = cc_prune(nd.left, alpha, X[m], y[m])
    rgt, nr, er = cc_prune(nd.right, alpha, X[~m], y[~m])
    err_sub = el + er
    err_leaf = float(np.sum((y - y.mean()) ** 2))
    if err_leaf + alpha * 1 <= err_sub + alpha * (nl + nr):
        z = Node()
        z.val, z.n = float(y.mean()), len(y)
        return z, 1, err_leaf
    nd.left, nd.right = lft, rgt
    return nd, nl + nr, err_sub

def logit_acc(Xa, ya, Xb, yb, steps=4000, lr=0.3):
    A = np.hstack([Xa, np.ones((len(Xa), 1))])
    w = np.zeros(A.shape[1])
    for _ in range(steps):
        p = 1.0 / (1.0 + np.exp(-A @ w))
        w -= lr * (A.T @ (p - ya)) / len(ya)
    B = np.hstack([Xb, np.ones((len(Xb), 1))])
    return float(np.mean(((B @ w) > 0) == yb))

def imp(nd, X, y, d):
    out = np.zeros(d)

    def walk(c, Xa, ya):
        if c.j < 0:
            return
        m = Xa[:, c.j] <= c.t
        g = (gini(ya) - (m.sum() * gini(ya[m])
                         + (~m).sum() * gini(ya[~m])) / len(ya))
        out[c.j] += g * len(ya)
        walk(c.left, Xa[m], ya[m])
        walk(c.right, Xa[~m], ya[~m])
    walk(nd, X, y)
    return out / out.sum()
