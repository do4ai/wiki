# 219강. 그래디언트 부스팅

$218$강은 나무를 **나란히** 심고 평균을 냈습니다. 그래서 분산은 줄었지만 **편향은 그대로**였습니다. $45$도 경계에서 $200$그루를 심어도 오류율이 $0.025333$에서 멈췄습니다.

$$\text{나무를 줄지어 심어 앞 나무가 틀린 것을 뒤 나무가 고칩니다}$$

첫 나무가 남긴 잔차를 둘째 나무가 맞추고, 그 잔차를 셋째 나무가 맞춥니다. **얕은 나무를 이어 붙여 깊은 모형을 만듭니다.**

$$\text{이번에는 편향이 줄어듭니다}$$

그리고 이 절차가 **함수 공간에서의 경사하강**이라는 것을 봅니다. $107$강의 경사하강이 모수가 아니라 함수를 움직이는 꼴로 다시 나옵니다.

## 이 강의에서 할 수 있게 되는 것
- 잔차를 이어 맞추는 절차를 세우고 편향이 줄어드는 것을 확인할 수 있습니다.
- 이 절차가 왜 경사하강인지 손실의 미분으로 설명할 수 있습니다.
- 학습률과 그루 수가 어떻게 맞바뀌는지 수치로 보일 수 있습니다.
- 손실을 바꿔 끼워 이상점에 튼튼한 모형을 만들 수 있습니다.
- 조기 종료와 다섯 가지 정규화 손잡이를 쓸 수 있습니다.

## 문제 1. 잔차를 이어서 맞춥니다

> **문제.** 부스팅의 골격을 세웁니다.
> ($1$) 나란히 심기와 무엇이 다른지 정리하세요.
> ($2$) 잔차를 이어 맞춰 보세요.
> ($3$) 편향과 분산을 나란히 재세요.

**생각의 실마리.** 평균은 **같은 것을 여러 번 재는 일**입니다. 아무리 평균 내도 **재는 자가 틀렸으면** 못 고칩니다. 틀린 만큼을 다시 재야 합니다.

**풀이.** ($1$) 정리합니다.

| 무엇 | 나란히 심기 | 줄지어 심기 |
|---|---|---|
| 나무를 어떻게 만드나 | 서로 무관하게 | 앞의 잔차를 보고 |
| 무엇을 줄이나 | 분산 | 편향 |
| 개별 나무 | 깊게 | 얕게 |
| 그루를 늘리면 | 평평해짐 | 과적합할 수 있음 |
| 병렬로 되나 | 예 | 아니오 |

**둘째 줄이 핵심입니다.** 부스팅은 편향을 줄입니다.

($2$) 잔차를 이어 맞춰 봅니다. 깊이 $2$짜리 나무를 한 그루씩 더하고 학습률은 $0.3$입니다.

$$F_{m}(x)=F_{m-1}(x)+\eta\,T_{m}(x),\qquad T_{m}\approx y-F_{m-1}$$

| 그루 수 | 학습 오차 | 검증 오차 | 잔차의 표준편차 |
|---|---|---|---|
| $1$ | $0.493973$ | $0.432777$ | $0.702832$ |
| $2$ | $0.329616$ | $0.259716$ | $0.574122$ |
| $5$ | $0.151224$ | $0.071727$ | $0.388875$ |
| $20$ | $0.091072$ | $0.009224$ | $0.301781$ |
| $80$ | $0.081324$ | $0.010224$ | $0.285173$ |
| $200$ | $0.076966$ | $0.011971$ | $0.277427$ |

**한 그루로는 계단 넷뿐인데 $20$그루를 더하면 검증 오차가 $0.009224$가 됩니다.** $217$강에서 깊이 $2$ 나무 하나가 못 하던 일입니다.

**나무 하나하나는 얕은데 합이 깊은 모형이 됩니다.** $218$강의 평균은 이렇게 못 합니다. 평균은 **편향을 못 줄이기 때문**입니다.

($3$) 편향과 분산을 나란히 잽니다.

| 무엇 | 편향 제곱 | 분산 | 합 |
|---|---|---|---|
| 숲 깊이 $2$ $25$그루 | $0.062939$ | $0.007537$ | $0.070476$ |
| 숲 깊이 $8$ $25$그루 | $0.000457$ | $0.016809$ | $0.017266$ |
| 부스팅 깊이 $2$ $20$그루 | $0.003893$ | $0.006110$ | $0.010002$ |
| 부스팅 깊이 $2$ $200$그루 | $0.000930$ | $0.011096$ | $0.012026$ |

**숲은 깊이 $2$에서 편향이 $0.062939$입니다.** 깊이를 $8$로 키워야 $0.000457$이 되는데, 그때 분산이 $0.007537$에서 $0.016809$로 커집니다.

**부스팅은 같은 깊이 $2$로 편향을 $0.003893$까지 줄입니다.** 얕은 나무를 이어 붙였기 때문입니다.

**그루를 $200$까지 늘리면 편향이 $0.000930$으로 더 줄어듭니다.** 대신 분산이 $0.006110$에서 $0.011096$으로 커져 합은 오히려 늘었습니다.

**이 문제에서 배우는 것.** 앙상블의 두 방식은 **다른 것을 줄입니다.** 나란히 심으면 분산이, 줄지어 심으면 편향이 줄어듭니다. 그래서 **개별 나무의 깊이를 정하는 방향이 정반대**입니다.

**확인 1-1.** 부스팅이 편향과 분산 중 무엇을 줄이는지 쓰세요.

*답.* 편향을 줄입니다.

**확인 1-2.** 검산에서 그루 $1$개와 $20$개의 검증 오차를 쓰세요.

*답.* $0.432777$과 $0.009224$입니다.

**확인 1-3.** 검산에서 숲 깊이 $2$와 부스팅 깊이 $2$ $20$그루의 편향 제곱을 쓰세요.

*답.* $0.062939$와 $0.003893$입니다.

## 문제 2. 왜 이것이 경사하강인가

> **문제.** 절차의 정체를 밝힙니다.
> ($1$) 손실마다 무엇을 맞추는지 정리하세요.
> ($2$) 손실이 정말 줄어드는지 확인하세요.
> ($3$) 학습률과 그루 수의 관계를 재세요.

**생각의 실마리.** "잔차를 맞춘다"는 것이 우연이 아닙니다. **제곱오차의 예측값에 대한 미분이 정확히 예측 빼기 정답**입니다. 잔차는 **음의 기울기**입니다.

**풀이.** ($1$) 정리합니다.

$$-\frac{\partial L(y,F)}{\partial F}\;\text{을 나무로 근사합니다}$$

| 손실 | $F$에 대한 미분 | 무엇을 맞추나 | 어디서 봤나 |
|---|---|---|---|
| 제곱오차 | $F$ 빼기 $y$ | 잔차 | $205$강 |
| 절댓값 | 부호 | 부호만 | $188$강 |
| 로지스틱 | $p$ 빼기 $y$ | 확률 오차 | $208$강 |
| 지수 | 마이너스 $y\exp$ | 가중 부호 | $197$강 |

**나무는 그 미분의 마이너스 방향을 근사하는 걸음입니다.** 함수 공간에서 한 걸음씩 내려가는 것이라 **함수 경사하강**이라 합니다.

($2$) 손실이 정말 줄어드는지 확인합니다.

| 걸음 | 학습 손실 | 앞 걸음 대비 감소 | 기울기 노름 |
|---|---|---|---|
| $0$ | $0.794957$ | $0.000000$ | $0.044580$ |
| $1$ | $0.493973$ | $0.300985$ | $0.035142$ |
| $2$ | $0.329616$ | $0.164356$ | $0.028706$ |
| $5$ | $0.151224$ | $0.178392$ | $0.019444$ |
| $20$ | $0.091072$ | $0.060153$ | $0.015089$ |
| $60$ | $0.082176$ | $0.008896$ | $0.014333$ |

**손실이 걸음마다 줄고 기울기 노름도 $0.044580$에서 $0.014333$으로 함께 줄어듭니다.**

**$107$강의 경사하강과 같은 그림입니다.** 다만 모수가 아니라 **함수를 움직입니다.**

($3$) 학습률과 그루 수의 관계를 잽니다.

| 학습률 | 가장 좋은 그루 수 | 그때 검증 오차 | 학습률 곱하기 그루 |
|---|---|---|---|
| $0.02$ | $331$ | $0.008239$ | $6.620000$ |
| $0.05$ | $131$ | $0.008246$ | $6.550000$ |
| $0.20$ | $31$ | $0.008577$ | $6.200000$ |
| $0.50$ | $31$ | $0.010462$ | $15.500000$ |

**학습률을 $2.5$배 줄이니 그루 수가 $2.53$배 늘었습니다.** 앞의 세 줄은 마지막 열이 $6.2$에서 $6.6$ 사이로 비슷합니다.

**둘의 곱이 실질 손잡이입니다.** 그것이 **얼마나 멀리 가는지**를 정합니다. $0.50$은 격자의 최소 자리에 걸려 곱이 어긋났습니다.

**그리고 학습률이 작을수록 도달한 검증 오차가 조금씩 더 낮습니다.** 왜 그런지 봅니다.

| 학습률 | 그루 $20$ 검증 오차 | 가장 좋은 검증 오차 | 둘의 차 |
|---|---|---|---|
| $0.05$ | $0.166495$ | $0.008246$ | $0.158249$ |
| $0.20$ | $0.011825$ | $0.008577$ | $0.003248$ |
| $0.50$ | $0.011252$ | $0.010462$ | $0.000789$ |
| $1.00$ | $0.015800$ | $0.015275$ | $0.000525$ |

**학습률 $0.05$는 $20$그루로는 아직 멀지만 끝까지 가면 $0.008246$으로 가장 낮습니다.**

**학습률 $1.0$은 $20$그루로 이미 다 왔는데 그 자리가 $0.015275$로 가장 나쁩니다.** 한 걸음이 크면 빨리 가는 대신 **좋은 자리를 지나칩니다.**

**$211$강의 정규화와 같습니다.** 학습률이 곧 축소 계수이고, 작은 걸음이 곧 약한 벌점입니다.

**이 문제에서 배우는 것.** 부스팅은 **손실을 정하면 나머지가 따라오는 틀**입니다. $206$강에서 "넷을 정하면 알고리즘이 정해진다"고 한 그 구조가 여기서도 그대로입니다. 손실만 바꿔 끼우면 회귀도 분류도 순위 학습도 됩니다.

**확인 2-1.** 부스팅이 함수 공간의 경사하강인 이유를 쓰세요.

*답.* 나무가 손실의 음의 기울기를 근사하는 걸음이기 때문입니다.

**확인 2-2.** 검산에서 학습률 $0.05$와 $0.20$의 가장 좋은 그루 수를 쓰세요.

*답.* $131$과 $31$입니다.

**확인 2-3.** 검산에서 학습률 $0.05$와 $1.00$의 가장 좋은 검증 오차를 쓰세요.

*답.* $0.008246$과 $0.015275$입니다.

## 문제 3. 손실을 바꿔 끼웁니다

> **문제.** 다른 손실로 갈아 끼웁니다.
> ($1$) 분류에서 재세요.
> ($2$) 손실마다 이상점에 얼마나 끌리는지 보세요.
> ($3$) 이상점을 넣고 실제로 견주세요.

**생각의 실마리.** 손실을 바꾸면 **맞추는 대상이 바뀝니다.** 제곱오차는 잔차를, 로지스틱은 확률 오차를 맞춥니다. 나무를 키우는 코드는 그대로입니다.

**풀이.** ($1$) 분류에서 잽니다. 베이즈 최적 정확도는 $0.896400$입니다.

| 그루 수 | 학습 로그손실 | 검증 로그손실 | 검증 정확도 |
|---|---|---|---|
| $1$ | $0.560793$ | $0.550975$ | $0.737600$ |
| $10$ | $0.400221$ | $0.419030$ | $0.862400$ |
| $50$ | $0.211986$ | $0.283443$ | $0.878000$ |
| $150$ | $0.123285$ | $0.271255$ | $0.882800$ |
| $300$ | $0.073105$ | $0.292806$ | $0.886000$ |

**학습 로그손실은 계속 줄어드는데 검증은 $150$에서 $0.271255$로 최소를 찍고 돌아섭니다.**

**그런데 검증 정확도는 $300$까지 계속 올라갑니다.** $212$강 문제 $3$에서 본 대로 **어느 눈금으로 고르느냐가 답을 바꿉니다.**

**$218$강과 다릅니다.** 부스팅은 그루를 늘리면 과적합할 수 있습니다. 그래서 **조기 종료가 필요**하고, 그것이 $214$강 문제 $4$의 그 조기 종료입니다.

($2$) 손실마다 이상점에 얼마나 끌리는지 봅니다.

| 손실 | 잔차 $1$일 때 기울기 | 잔차 $5$일 때 기울기 | 이상점에 끌리나 |
|---|---|---|---|
| 제곱오차 | $1.000000$ | $5.000000$ | 매우 |
| 절댓값 | $1.000000$ | $1.000000$ | 적게 |
| 후버 $1.0$ | $1.000000$ | $1.000000$ | 적게 |

**제곱오차는 잔차가 다섯 배면 기울기도 다섯 배입니다.** 절댓값과 후버는 멀리 있는 점에 덜 끌립니다.

**$188$강에서 본 이상점 문제가 손실 고르기로 풀립니다.**

($3$) 이상점을 넣고 실제로 견줍니다. $400$개 중 $12$개를 $6$만큼 튀게 만들었습니다.

| 손실 | 검증 오차 | 이상점 없을 때 대비 |
|---|---|---|
| 제곱오차 | $0.093616$ | $0.082815$ |
| 절댓값 | $0.021622$ | $-0.002561$ |
| 후버 $1.0$ | $0.015227$ | $0.004451$ |

**제곱오차가 $0.082815$만큼 나빠져 가장 크게 흔들립니다.** 절댓값은 오히려 $0.002561$ 좋아지고 후버는 $0.004451$만 나빠집니다.

**다만 이상점이 없으면 제곱오차가 $0.010801$로 셋 중 가장 좋습니다.** 튼튼한 손실은 공짜가 아니고, **깨끗한 자료에서는 손해**입니다.

**이 문제에서 배우는 것.** 손실을 고르는 것이 곧 **무엇을 중요하게 볼지 정하는 것**입니다. 잔차가 큰 점을 고칠 것인지 무시할 것인지를 정하고, 그 결정이 기울기를 통해 나무에 전달됩니다.

**확인 3-1.** 부스팅에 조기 종료가 필요한 이유를 쓰세요.

*답.* 그루를 늘리면 과적합할 수 있기 때문입니다.

**확인 3-2.** 검산에서 검증 로그손실이 가장 낮은 그루 수와 그 값을 쓰세요.

*답.* $150$그루이고 $0.271255$입니다.

**확인 3-3.** 검산에서 이상점을 넣었을 때 제곱오차와 후버의 나빠진 정도를 쓰세요.

*답.* $0.082815$와 $0.004451$입니다.

## 문제 4. 벌점과 무작위를 넣습니다

> **문제.** 정규화를 겁니다.
> ($1$) 손잡이를 정리하세요.
> ($2$) 잎 값 벌점을 재세요.
> ($3$) 깊이와 무작위를 재세요.

**생각의 실마리.** 부스팅은 과적합할 수 있으므로 **막을 장치가 필요**합니다. $211$강의 벌점이 여기서는 **잎 값**에 걸립니다.

**풀이.** ($1$) 정리합니다.

| 무엇 | 무엇을 막나 | 어디서 봤나 |
|---|---|---|
| 학습률 | 한 걸음이 너무 큼 | 문제 $2$ |
| 나무 깊이 | 상호작용 차수 | 이 문제 |
| 잎 값에 벌점 | 잎 하나가 튐 | $211$강 |
| 표본 뽑기 | 같은 점에 매달림 | $218$강 |
| 변수 뽑기 | 같은 변수만 씀 | $218$강 |
| 조기 종료 | 그루가 너무 많음 | 문제 $3$ |

($2$) 잎 값 벌점을 잽니다. 이차 근사로 풀면 잎 값이 닫힌 꼴로 나옵니다.

$$w_{\text{잎}}=-\frac{\sum_{i\in\text{잎}}g_{i}}{\sum_{i\in\text{잎}}h_{i}+\lambda}$$

| $\lambda$ | 잎 값의 최대 절댓값 | 검증 로그손실 | 검증 정확도 |
|---|---|---|---|
| $0.0$ | $3.874030$ | $0.273973$ | $0.881600$ |
| $1.0$ | $1.626724$ | $0.271255$ | $0.882800$ |
| $10.0$ | $1.383697$ | $0.270479$ | $0.885200$ |
| $100.0$ | $0.550358$ | $0.324107$ | $0.877200$ |

**$\lambda$를 키우면 잎 값이 $3.874030$에서 $0.550358$로 작아집니다.** $211$강의 축소와 같습니다.

**$\lambda=10$에서 검증 로그손실이 $0.270479$로 가장 좋습니다.** 아주 크게 걸면 걸음이 너무 작아져 오히려 나빠집니다.

## 심화 문제

> **심화 1.** 이차 근사로 잎 값을 유도하세요.

손실을 현재 예측 근처에서 이차까지 전개합니다.

$$L(y,F+f)\approx L(y,F)+g\,f+\tfrac{1}{2}h\,f^{2},\qquad g=\frac{\partial L}{\partial F},\;h=\frac{\partial^{2}L}{\partial F^{2}}$$

한 잎 안에서 $f$가 상수 $w$이므로 잎마다 따로 최소화합니다.

| 단계 | 무엇 |
|---|---|
| 첫째 | 잎 안에서 $\sum(g_{i}w+\tfrac12 h_{i}w^{2})+\tfrac12\lambda w^{2}$ |
| 둘째 | $w$로 미분해 $0$ |
| 셋째 | $w=-\sum g/(\sum h+\lambda)$ |

**이 값을 대입하면 나눔의 이득 공식이 나옵니다.** 그 이득으로 나눌 자리를 고르는 것이 $217$강의 지니 대신 쓰는 자입니다. **손실이 자를 정합니다.**

> **심화 2.** 에이다부스트가 지수 손실의 부스팅임을 정리하세요.

$$L(y,F)=e^{-yF},\qquad y\in\{-1,+1\}$$

| 무엇 | 값 |
|---|---|
| 음의 기울기 | $y\,e^{-yF}$ |
| 가중치 해석 | 틀린 점의 무게가 커짐 |
| 최적 계수 | $\tfrac12\log\frac{1-\text{오류율}}{\text{오류율}}$ |
| 약한 학습기 | 대개 그루터기 |

**기울기가 "부호 곱하기 무게"이므로, 무게를 바꿔 가며 약한 분류기를 학습시키는 절차와 같아집니다.** 에이다부스트는 $1995$년에 나왔고 이것이 경사하강이라는 해석은 나중에 붙었습니다. **지수 손실은 이상점에 아주 약하고**, 그래서 요즘은 로지스틱 손실을 씁니다.

rng = np.random.default_rng(20261213)


def pw(s, n):
    k = n - sum(2 if ord(c) > 0x2FFF else 1 for c in str(s))
    return str(s) + " " * max(k, 0)


def rw(s, n):
    k = n - sum(2 if ord(c) > 0x2FFF else 1 for c in str(s))
    return " " * max(k, 0) + str(s)


class Node:
    __slots__ = ("j", "t", "left", "right", "val")

    def __init__(self):
        self.j = -1
        self.t = 0.0
        self.left = None
        self.right = None
        self.val = 0.0


def grow_reg(X, g, h, depth, min_leaf=1, lam=1.0, mtry=None, r=None):
    nd = Node()
    nd.val = -g.sum() / (h.sum() + lam)
    if depth <= 0 or len(g) < 2 * min_leaf:
        return nd
    d = X.shape[1]
    cols = np.arange(d) if mtry is None else r.choice(d, mtry, replace=False)
    base = -(g.sum() ** 2) / (h.sum() + lam)
    bg, bj, bt = 1e-12, -1, 0.0
    for j in cols:
        v = X[:, j]
        cuts = np.unique(v)
        if len(cuts) > 24:
            cuts = np.quantile(v, np.linspace(0.04, 0.96, 24))
        for t in cuts:
            m = v <= t
            nl = int(m.sum())
            if nl < min_leaf or len(g) - nl < min_leaf:
                continue
            sc = -(g[m].sum() ** 2) / (h[m].sum() + lam) \
                 - (g[~m].sum() ** 2) / (h[~m].sum() + lam)
            if base - sc > bg:
                bg, bj, bt = base - sc, int(j), float(t)
    if bj < 0:
        return nd
    nd.j, nd.t = bj, bt
    m = X[:, bj] <= bt
    nd.left = grow_reg(X[m], g[m], h[m], depth - 1, min_leaf, lam, mtry, r)
    nd.right = grow_reg(X[~m], g[~m], h[~m], depth - 1, min_leaf, lam, mtry, r)
    return nd


def predict(nd, X):
    out = np.zeros(len(X))
    for i in range(len(X)):
        c = nd
        while c.j >= 0:
            c = c.left if X[i, c.j] <= c.t else c.right
        out[i] = c.val
    return out


def gb_fit(X, y, M, eta=0.1, depth=3, loss="sq", lam=1.0, min_leaf=5,
           sub=1.0, mtry=None):
    n = len(y)
    if loss == "sq":
        F0 = float(y.mean())
    else:
        p = float(np.clip(y.mean(), 1e-6, 1 - 1e-6))
        F0 = float(np.log(p / (1 - p)))
    F = np.full(n, F0)
    trees = []
    for _ in range(M):
        if loss == "sq":
            g = F - y
            h = np.ones(n)
        else:
            p = 1.0 / (1.0 + np.exp(-F))
            g = p - y
            h = np.maximum(p * (1 - p), 1e-6)
        if sub < 1.0:
            idx = rng.permutation(n)[:max(int(n * sub), 2 * min_leaf)]
        else:
            idx = np.arange(n)
        t = grow_reg(X[idx], g[idx], h[idx], depth, min_leaf, lam, mtry, rng)
        F = F + eta * predict(t, X)
        trees.append(t)
    return F0, trees


def gb_pred(F0, trees, X, eta=0.1, M=None):
    out = np.full(len(X), F0)
    for t in trees[:M]:
        out = out + eta * predict(t, X)
    return out

def gb_fit_loss(X, y, M, eta, depth, kind, delta=1.0):
    F = np.full(len(y), float(np.median(y)))
    ts = []
    for _ in range(M):
        r = y - F
        if kind == "sq":
            g = -r
        elif kind == "abs":
            g = -np.sign(r)
        else:
            g = -np.clip(r, -delta, delta)
        h = np.ones(len(y))
        t = grow_reg(X, g, h, depth, 5, 1e-9, None, rng)
        F = F + eta * predict(t, X)
        ts.append(t)
    return float(np.median(y)), ts
