# 00. 학습 순서와 커리큘럼

이 문서는 SCAI LAB 수학 교본 전체의 학습 순서와 커리큘럼을 한자리에 모은 지도입니다. 어떤 과목을 어떤 순서로 읽어야 하는지, 각 과목이 몇 개의 단원과 몇 개의 강의로 이루어지는지, 각 강의가 어떤 문제 계층을 갖추는지를 규정합니다. 개별 과목의 index는 이 문서의 넘버링을 그대로 따릅니다.

# 이 커리큘럼이 지키는 세 가지 원칙

## 1. 개념보다 문제가 먼저 나옵니다
모든 강의는 정의와 공식을 먼저 나열하지 않습니다. 아직 배우지 않은 상황을 문제로 먼저 던지고, 그 문제를 푸는 과정에서 정의와 공식을 끌어냅니다. 공식은 외워야 할 대상이 아니라 방금 푼 풀이를 짧게 줄인 것입니다.

각 개념 단위는 다음 다섯 단계로 진행합니다.

1. **문제**: 아직 배우지 않은 상황이 문제로 먼저 나옵니다.
2. **생각의 실마리**: 바로 풀리지 않을 때 붙잡을 질문을 줍니다.
3. **풀이**: 답까지 가는 계산과 논리를 모두 적습니다.
4. **이 문제에서 배우는 것**: 방금 쓴 풀이를 일반화해 정의와 공식으로 정리합니다.
5. **바로 확인**: 같은 도구로 풀리는 변형 문제로 손에 붙입니다.

## 2. 한 강의는 네 겹의 문제로 이루어집니다
순서대로 따라가기만 해도 그 주제의 문제를 전부 익히도록, 각 강의는 난이도가 다른 네 겹의 문제를 갖춥니다. 어느 한 겹도 생략하지 않습니다.

| 계층 | 위치 | 분량 | 역할 |
| --- | --- | --- | --- |
| 개념 문제 | 강의 본문 | 5~6문항 + 문항당 확인 2~3개 | 개념을 끌어냅니다. |
| 종합 문제 드릴 | 강의 본문 | 10~13문항 (기초·표준) | 배운 도구를 섞어 씁니다. |
| 심화 문제 | 강의 본문 | 4~6문항 | 도구를 조합하거나 한 단계 비틀어 씁니다. |
| 단원 문제집 | 단원 폴더 | 40~48문항 (기초·표준·심화) | 단원 전체를 통합 훈련합니다. |

문제는 모두 `문제 → 답 → 풀이` 세 줄로 적고, 풀이는 중간 계산을 전부 드러냅니다. 답만 적고 넘어가는 문제는 두지 않습니다.

## 3. 앞에서 끌어낸 도구만으로 뒤가 풀립니다
강의 $n$의 문제는 강의 $1$부터 $n-1$까지에서 끌어낸 도구만으로 풀립니다. 아직 나오지 않은 개념을 미리 쓰지 않으며, 부득이하게 뒤 강의를 참조할 때는 어느 강의에서 다루는지 본문에 명시합니다. 과목 사이에도 같은 규칙이 적용되며, 선수 과목이 필요한 단원은 아래 표에 따로 표시합니다.

# 넘버링 규칙

- **과목 번호**는 `M1`~`M7`이며 학습 순서를 뜻합니다. 폴더 이름에는 넣지 않고 이 문서와 각 과목 index에서만 씁니다.
- **단원 번호**는 과목 안에서 `01`부터 두 자리로 매기며 폴더 이름 앞에 붙입니다. 예를 들어 `03. 기대와 적률`입니다.
- **강의 번호**는 과목 안에서 `1`부터 연속으로 매기며 단원이 바뀌어도 번호가 이어집니다. 폴더 이름 앞에 붙이며 자릿수를 채우지 않습니다. 예를 들어 `10. 기대값과 분산`입니다.
- **강의 번호는 결번을 두지 않습니다.** 강의를 추가하면 뒤 번호를 모두 밀어 다시 매기는 대신, 설계 단계에서 번호를 확정하고 그대로 씁니다.
- **문제 번호**는 강의 안에서 `문제 1`부터 연속으로 매깁니다. 개념 문제가 `문제 1`부터 `문제 K`까지이면 종합 문제 드릴은 `문제 K+1`부터 이어받고, 심화 문제가 그 뒤를 다시 이어받습니다.
- **바로 확인 번호**는 부모 문제 번호를 물려받아 `확인 K-1`, `확인 K-2` 형태로 매깁니다.
- **단원 문제집**은 `문제집 - {단원번호}. {단원명}` 폴더에 두며 단원마다 하나씩 반드시 둡니다.
