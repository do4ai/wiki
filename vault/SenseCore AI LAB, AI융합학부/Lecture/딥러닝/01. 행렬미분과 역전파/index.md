title: "01. 행렬미분과 역전파"
---
이 단원은 231강부터 234강까지를 맡습니다. **그래디언트를 정확하고 빠르게 얻는 법**을 세웁니다.

$209$강에서 경사하강을 배웠습니다. 그런데 거기서 미분한 것은 **계수 벡터 하나**였습니다.

$$\text{층이 쌓이면 미분해야 할 것이 행렬입니다}$$

그리고 층이 백 개면 **손으로 백 번 유도할 수 없습니다.** 이 단원은 그 일을 **규칙과 자료구조**로 넘깁니다.

# 이 단원의 흐름

| 강의 | 무엇을 묻는가 |
|---|---|
| $231$ | 행렬로 미분한다는 것이 무슨 뜻인지 정합니다 |
| $232$ | 연결을 자료구조가 알게 만듭니다 |
| $233$ | 층 위에서 그 훑기를 알고리즘으로 적습니다 |
| $234$ | 반복문을 행렬 연산으로 접습니다 |

**$231$강이 문법이고 $232$강이 구조입니다.** $233$강이 둘을 합치고 $234$강이 그것을 빠르게 만듭니다.

# 하나의 규칙이 단원 전체를 관통합니다

$$\text{결과의 모양은 분자의 모양 곱하기 분모의 모양입니다}$$

| 무엇을 무엇으로 | 결과의 모양 | 어디서 |
|---|---|---|
| 스칼라를 벡터로 | 벡터 | $231$강 문제 $1$ |
| 스칼라를 행렬로 | 같은 모양 행렬 | $231$강 문제 $1$ |
| 벡터를 벡터로 | 야코비 | $231$강 문제 $2$ |
| 층 하나의 가중치 | 바깥곱 | $231$강 문제 $2$ |
| 배치까지 | 전치 곱하기 신호 | $234$강 문제 $2$ |

**손실이 언제나 스칼라이므로 그래디언트는 언제나 입력과 같은 모양입니다.** 그것 하나로 전치 위치가 정해집니다.

# 두 줄이면 층 하나가 끝납니다

$$\nabla W=H^{\top}\Delta,\qquad \Delta_{\text{앞}}=(\Delta W^{\top})\odot\sigma'$$

| 무엇 | 모양 | 무엇을 뜻하나 |
|---|---|---|
| 위쪽 신호 | 배치 곱하기 출력차원 | 뒤에서 온 것 |
| 가중치 그래디언트 | 입력차원 곱하기 출력차원 | 표본을 다 더함 |
| 아래쪽 신호 | 배치 곱하기 입력차원 | 앞으로 넘길 것 |

**층이 몇 개든 이 두 줄을 되풀이할 뿐입니다.** $233$강 문제 $1$에서 세 층 신경망의 여섯 파라미터가 모두 수치 미분과 일치했습니다.

# 정확한 알고리즘이 정확한 학습을 뜻하지 않습니다

| 깊이 | 첫 층 그래디언트 크기 | 마지막 층 크기 |
|---|---|---|
| $4$ | $1.8558e-03$ | $3.7242e-03$ |
| $32$ | $6.0076e-12$ | $6.4458e-12$ |

**$233$강 문제 $2$입니다.** 역전파 식은 완벽히 맞는데 **첫 층에 신호가 안 닿습니다.**

**초기화 표준편차를 $0.5$로 키우면 반대로 터집니다.** 깊이 $32$에서 첫 층 크기가 $10^5$을 넘습니다.

# 조용히 틀리는 것들

| 무엇을 했나 | 상대 오차 | 예외가 나나 |
|---|---|---|
| 소프트맥스를 열 방향으로 | $7.8532e-01$ | 안 남 |
| 정사각에서 전치를 틀림 | $1.0000e+00$ | 안 남 |
| 배치로 안 나눔 | 크기가 표본 수 배 | 안 남 |
| 잔차 연결을 빠뜨림 | $1.0000e+00$ | 안 남 |

**넷 다 예외가 안 납니다.** 그래서 이 단원은 **유도한 식을 언제나 수치 미분과 견줍니다.**

# 앞에서 배운 것이 그대로 쓰입니다

| 이 단원의 개념 | 어디서 배웠는가 |
|---|---|
| 바깥곱 | $66$강, $231$강 문제 $2$ |
| 행렬 곱은 바깥곱의 합 | $90$강, $234$강 문제 $1$ |
| 특이값 분해 | $84$강, $231$강 심화 $3$ |
| 다변수 연쇄법칙 | $95$강, $231$강 문제 $2$ |
| 헤세 | $114$강, $231$강 심화 $3$ |
| 위상 정렬 | $232$강 문제 $1$ |
| 교차엔트로피 | $203$강, $231$강 문제 $3$ |
| 사전확률 보정 | $216$강, $233$강 문제 $4$ |
| 정규방정식 | $207$강, $232$강 문제 $3$ |
| 과적합 | $210$강, $233$강 문제 $4$ |

**$203$강의 교차엔트로피가 $231$강에서 예측 빼기 정답으로 접힙니다.** 그 한 줄이 딥러닝 분류의 출발점입니다.

# 이 단원이 남기는 네 가지 습관

| 습관 | 왜 |
|---|---|
| 모양표를 먼저 그리기 | 식을 외울 필요가 없기 때문 |
| 갈래를 반드시 더하기 | 안 더하면 조용히 틀리기 때문 |
| 수치 미분으로 검산하기 | 예외가 안 나기 때문 |
| 첫 손실을 확인하기 | 로그 갈래 수여야 하기 때문 |

# 다음 단계

**02단원은 이렇게 얻은 그래디언트를 어떻게 쓸지 봅니다.**

$$\text{그래디언트를 어떻게 얻는가} \;\longrightarrow\; \text{일부만 보고 딛는 걸음이 왜 되는가}$$

지금까지는 **자료 전체**의 그래디언트를 계산했습니다. 실제로는 몇십 개만 보고 한 걸음 딛습니다. **그것이 왜 되는지**가 $235$강의 물음입니다.
