# 237강. 배치 크기와 학습률의 관계

$236$강에서 떨림의 크기가 **$\eta/B$로 정해진다**는 것을 봤습니다. 그러면 둘을 같은 배수로 키우면 떨림이 그대로입니다.

$$\text{배치를 }k\text{배 하면 학습률도 }k\text{배}$$

$235$강 문제 $3$에서 이 규칙이 실제로 들었습니다. 그런데 배치 $256$에서 깨졌습니다.

$$\text{학습률에는 상한이 있어 끝없이 못 키웁니다}$$

이 강의는 **그 상한이 어디서 오는지**, **어디까지 배치를 키울 값이 있는지**, 그리고 **배치로 못 고치는 것은 무엇인지**를 봅니다.

## 이 강의에서 할 수 있게 되는 것
- 학습률 상한이 $2/L$임을 확인할 수 있습니다.
- 선형 스케일링이 언제 깨지는지 수치로 보일 수 있습니다.
- 임계 배치 크기를 잡음 대 신호 비로 예측할 수 있습니다.
- 조건수가 배치로 못 고치는 문제임을 보일 수 있습니다.
- 학습률 훑기로 실무 값을 고를 수 있습니다.

## 문제 1. 학습률의 상한

> **문제.** 상한을 찾습니다.
> ($1$) 어디서 상한이 오는지 정리하세요.
> ($2$) 전체 배치에서 확인하세요.
> ($3$) 미니배치에서 얼마나 낮아지는지 보세요.

**생각의 실마리.** 이차형식에서 한 걸음은 오차에 $(1-\eta\lambda)$를 곱합니다. **절댓값이 $1$보다 커지면** 오차가 늘어납니다.

**풀이.** ($1$) 정리합니다.

| 무엇 | 무엇이 정하나 | 조건 |
|---|---|---|
| 이차형식 | $1-\eta\lambda$ | 절댓값이 $1$보다 작아야 함 |
| 가장 큰 고윳값 | 가장 먼저 터짐 | 그 방향이 상한을 정함 |
| 상한 | $2/L$ | 전체 배치 기준 |
| 잡음이 있으면 | 상한이 더 낮아짐 | 미니배치는 더 조심 |

**이 자료의 헤세 고윳값은 최소 $0.957383$ 최대 $254.109580$입니다.** 전체 배치의 이론 상한은 $0.007871$입니다.

($2$) 전체 배치에서 확인합니다.

| 학습률 | 이론 상한 대비 | $200$걸음 뒤 손실 | 어떻게 되나 |
|---|---|---|---|
| $0.003935$ | $0.500000$ | $0.3475112630$ | 수렴 |
| $0.007084$ | $0.900000$ | $0.0973351758$ | 수렴 |
| $0.007713$ | $0.980000$ | $0.0758995624$ | 수렴 |
| $0.008028$ | $1.020000$ | 발산 | 발산 |
| $0.008658$ | $1.100000$ | 발산 | 발산 |

**상한 대비 $0.98$까지는 수렴하고 $1.02$부터 발산합니다.**

$$\eta<\frac{2}{L}$$

**경계가 이론이 말한 자리와 정확히 맞습니다.** $236$강 심화 $4$에서 예고한 상한이 여기서 확인됩니다.

($3$) 미니배치에서 얼마나 낮아지는지 봅니다.

| 배치 크기 | 발산 안 한 최대 학습률 | 전체 배치 상한 대비 |
|---|---|---|
| $4$ | $0.005509$ | $0.700000$ |
| $16$ | $0.007713$ | $0.980000$ |
| $64$ | $0.007713$ | $0.980000$ |
| $256$ | $0.007713$ | $0.980000$ |
| $4000$ | $0.007713$ | $0.980000$ |

**배치 $4$만 상한의 $0.7$배에서 이미 터집니다.** $16$부터는 격자 끝인 $0.98$배까지 견딥니다.

**잡음이 상한을 낮추는 효과는 아주 작은 배치에서만 뚜렷합니다.** $235$강 문제 $5$에서 본 것이 여기서 **더 좁은 구간의 이야기**로 드러납니다.

**이 문제에서 배우는 것.** 학습률 상한은 **잡음이 아니라 손실면의 곡률**이 정합니다. 미니배치의 잡음은 그 상한을 조금 더 낮출 뿐이고, **근본은 $2/L$입니다.**

**확인 1-1.** 학습률 상한을 정하는 것이 무엇인지 쓰세요.

*답.* 헤세의 가장 큰 고윳값이고 상한은 그 역수의 두 배입니다.

**확인 1-2.** 검산에서 상한 대비 $0.98$과 $1.02$일 때 어떻게 되는지 쓰세요.

*답.* $0.98$은 수렴하고 $1.02$는 발산합니다.

**확인 1-3.** 검산에서 배치 $4$가 견딘 최대 학습률의 상한 대비를 쓰세요.

*답.* $0.700000$입니다.

## 문제 2. 선형 스케일링이 어디까지 되는가

> **문제.** 규칙의 한계를 봅니다.
> ($1$) 규칙을 적으세요.
> ($2$) 같은 표본 예산에서 적용하세요.
> ($3$) 상한에서 자르면 어떤지 보세요.
> ($4$) 제곱근 규칙과 견주세요.

**생각의 실마리.** 떨림이 $\eta/B$이므로 둘을 같이 키우면 떨림이 그대로입니다. 그런데 **$\eta$에는 천장이 있습니다.**

**풀이.** ($1$) 규칙을 적습니다.

| 무엇 | 무엇인가 | 어디서 |
|---|---|---|
| 무엇을 하나 | 배치를 $k$배 하면 학습률도 $k$배 | 떨림 비를 지킴 |
| 왜 되나 | 떨림이 $\eta/B$ | $236$강 문제 $1$ |
| 언제 깨지나 | 학습률이 상한에 닿을 때 | 문제 $1$의 상한 |
| 그 지점 | 임계 배치 크기 | 더 키워도 안 빨라짐 |

($2$) 같은 표본 예산에서 적용합니다. 기준은 배치 $4$에 학습률 $0.000394$입니다.

| 배치 크기 | 규칙이 말하는 학습률 | 걸음 수 | 초과손실 |
|---|---|---|---|
| $4$ | $0.000394$ | $64000$ | $0.0167824285$ |
| $16$ | $0.001574$ | $16000$ | $0.0159915203$ |
| $64$ | $0.006296$ | $4000$ | $0.0518736672$ |
| $256$ | $0.025186$ | $1000$ | 발산 |
| $1024$ | $0.100744$ | $250$ | 발산 |

**배치 $4$와 $16$은 초과손실이 $0.016$ 근처로 거의 같습니다.** 규칙이 듣습니다.

**$64$에서 이미 세 배 나빠지고 $256$부터는 발산합니다.** 학습률이 상한의 $0.8$배를 넘어서면서 규칙이 깨집니다.

**임계 배치 크기가 $16$과 $64$ 사이에 있습니다.**

($3$) 상한에서 자르면 어떤지 봅니다. 상한의 $90$퍼센트인 $0.007084$에서 자릅니다.

| 배치 크기 | 자르기 전 학습률 | 실제 쓴 학습률 | 초과손실 |
|---|---|---|---|
| $4$ | $0.000394$ | $0.000394$ | $0.0150343806$ |
| $16$ | $0.001574$ | $0.001574$ | $0.0162287868$ |
| $64$ | $0.006296$ | $0.006296$ | $0.0414117260$ |
| $256$ | $0.025186$ | $0.007084$ | $0.0231293304$ |
| $1024$ | $0.100744$ | $0.007084$ | $1.1196292033$ |

**자르면 발산이 사라집니다.** $256$은 오히려 $64$보다 낫습니다.

**그런데 $1024$에서는 걸음이 $250$번뿐이라 도착을 못 합니다.**

**학습률이 상한에 눌린 뒤로는 배치를 키우면 걸음 수만 줄어듭니다.** 계산은 그대로인데 얻는 것이 없습니다.

($4$) 제곱근 규칙과 견줍니다.

| 배치 크기 | 선형 규칙 학습률 | 선형 초과손실 | 제곱근 규칙 학습률 | 제곱근 초과손실 |
|---|---|---|---|---|
| $4$ | $0.000394$ | $0.01266021$ | $0.000394$ | $0.01266021$ |
| $16$ | $0.001574$ | $0.01801023$ | $0.000787$ | $0.00812006$ |
| $64$ | $0.006296$ | $0.04800289$ | $0.001574$ | $0.00432672$ |
| $256$ | $0.025186$ | 발산 | $0.003148$ | $0.02500983$ |
| $1024$ | $0.100744$ | 발산 | $0.006296$ | $0.88608866$ |

**이 자료에서는 제곱근 규칙이 배치 $16$부터 $256$까지 모두 낫습니다.**

**조건수가 $265.4$라 선형 규칙이 금방 상한에 닿기 때문입니다.**

**$1024$에서는 제곱근 규칙도 무너집니다.** 걸음이 $250$번뿐이기 때문입니다.

**어느 규칙이 옳은가가 아니라 상한에 닿았는지가 문제입니다.** 상한에서 먼 구간에서는 선형이 맞고, 가까워지면 어떤 규칙도 안 됩니다.

**이 문제에서 배우는 것.** 선형 스케일링은 **떨림에 대한 규칙**이지 **안정성에 대한 규칙이 아닙니다.** 상한이라는 다른 제약이 먼저 걸리면 규칙 자체가 무의미해집니다.

**확인 2-1.** 선형 스케일링이 깨지는 조건을 쓰세요.

*답.* 학습률이 상한에 닿을 때입니다.

**확인 2-2.** 검산에서 배치 $16$과 $64$의 선형 규칙 초과손실을 쓰세요.

*답.* $0.0159915203$과 $0.0518736672$입니다.

**확인 2-3.** 검산에서 배치 $64$의 선형과 제곱근 초과손실을 쓰세요.

*답.* $0.04800289$와 $0.00432672$입니다.

## 문제 3. 임계 배치 크기

> **문제.** 어디까지 키울지 정합니다.
> ($1$) 무엇을 뜻하는지 정리하세요.
> ($2$) 목표에 닿는 걸음 수를 세세요.
> ($3$) 걸음 수가 얼마나 줄었는지 보세요.
> ($4$) 잡음 대 신호 비로 예측하세요.

**생각의 실마리.** 배치를 키우면 **한 걸음이 정확해집니다.** 그런데 이미 충분히 정확하면 **더 키워도 얻는 것이 없습니다.**

**풀이.** ($1$) 정리합니다.

| 구간 | 무슨 일 | 뜻 |
|---|---|---|
| 작은 배치 구간 | 배치를 키우면 걸음이 줄음 | 계산에 비례해 이득 |
| 임계 배치 크기 | 이득이 꺾이는 자리 | 잡음과 신호가 같아짐 |
| 큰 배치 구간 | 키워도 걸음이 안 줄음 | 계산만 낭비 |
| 무엇이 정하나 | 잡음 나누기 신호 | $235$강 문제 $5$ |

($2$) 초과손실 $0.05$에 처음 닿는 걸음 수를 셉니다. 학습률은 배치마다 최적을 고릅니다.

| 배치 크기 | 고른 학습률 | 걸음 수 | 본 표본 수 |
|---|---|---|---|
| $2$ | $0.003148$ | $831$ | $1662$ |
| $8$ | $0.006296$ | $431$ | $3448$ |
| $32$ | $0.007477$ | $302$ | $9664$ |
| $128$ | $0.007477$ | $250$ | $32000$ |
| $512$ | $0.007477$ | $242$ | $123904$ |
| $2048$ | $0.007477$ | $240$ | $491520$ |

**배치를 $2$에서 $2048$로 천 배 키우는 사이 걸음 수는 $831$에서 $240$으로 세 배 남짓만 줄었습니다.**

**본 표본 수는 $1662$에서 $491520$으로 삼백 배 늘었습니다.**

($3$) 걸음 수가 얼마나 줄었는지 봅니다.

| 배치 크기 | 걸음 수 | 앞 배치 대비 줄어든 비 | 이상적이면 |
|---|---|---|---|
| $2$ | $831$ | 기준 | 기준 |
| $8$ | $431$ | $0.518652$ | $0.250000$ |
| $32$ | $302$ | $0.700696$ | $0.250000$ |
| $128$ | $250$ | $0.827815$ | $0.250000$ |
| $512$ | $242$ | $0.968000$ | $0.250000$ |
| $2048$ | $240$ | $0.991736$ | $0.250000$ |

**셋째 열이 $0.52$에서 $0.99$로 계속 올라갑니다.**

**배치 $512$에서 $2048$로 네 배 키우면 걸음이 $0.991736$배가 됩니다.** 사실상 안 줄었고 **계산만 네 배** 쓴 것입니다.

($4$) 잡음 대 신호 비로 예측합니다.

**한 표본 그래디언트의 분산 합은 $12719.501994$이고 전체 그래디언트 노름 제곱은 $1261.885791$입니다.**

$$B_{\text{임계}}\approx\frac{\mathrm{tr}\,\Sigma}{\|g\|^2}=10.079757$$

| 배치 크기 | 잡음 나누기 신호 | 어느 구간인가 |
|---|---|---|
| $2$ | $5.039878$ | 잡음이 큼 |
| $8$ | $1.259970$ | 잡음이 큼 |
| $32$ | $0.314992$ | 신호가 큼 |
| $128$ | $0.078748$ | 신호가 큼 |
| $512$ | $0.019687$ | 신호가 큼 |
| $2048$ | $0.004922$ | 신호가 큼 |

**예측한 임계 배치 크기가 $10.08$입니다.** ($3$)에서 $8$에서 $32$ 사이에 꺾임이 있었으니 **예측과 관측이 맞습니다.**

**비가 $1$을 넘는 구간에서는 배치를 키우는 것이 곧바로 이득입니다.** $1$ 아래로 내려가면 **이미 그래디언트가 충분히 정확해** 더 키울 값이 줄어듭니다.

**이 문제에서 배우는 것.** 임계 배치 크기는 **자료가 정하는 값**입니다. 그래디언트의 잡음과 신호를 재면 **학습을 돌려 보기 전에** 대략 알 수 있고, 그 위로는 계산을 늘려도 시간이 안 줄어듭니다.

**확인 3-1.** 임계 배치 크기가 무엇인지 쓰세요.

*답.* 배치를 키워도 걸음 수가 더 안 줄기 시작하는 크기입니다.

**확인 3-2.** 검산에서 배치 $512$에서 $2048$로 갈 때 걸음이 줄어든 비를 쓰세요.

*답.* $0.991736$입니다.

**확인 3-3.** 검산에서 예측한 임계 배치 크기를 쓰세요.

*답.* $10.079757$입니다.

## 문제 4. 조건수와 방향별 차이

> **문제.** 배치로 못 고치는 것을 봅니다.
> ($1$) 무엇이 문제인지 정리하세요.
> ($2$) 방향마다 얼마나 빨리 줄어드는지 보세요.
> ($3$) 조건수를 바꿔 걸음 수를 세세요.
> ($4$) 배치와 조건수 중 무엇이 병목인지 가리세요.

**생각의 실마리.** 학습률은 **하나**인데 방향마다 곡률이 다릅니다. 가장 가파른 방향이 상한을 정하면 **완만한 방향은 아주 느립니다.**

**풀이.** ($1$) 정리합니다.

| 무엇 | 무엇인가 | 결과 |
|---|---|---|
| 방향마다 곡률이 다름 | 고윳값이 다름 | 조건수가 큼 |
| 학습률은 하나 | 가장 가파른 방향이 정함 | 완만한 방향은 느림 |
| 걸음 수 | 조건수에 비례 | 느린 방향을 기다림 |
| 해결 | 좌표마다 다른 학습률 | $247$강 아담 |

**이 자료의 조건수는 $265.420979$입니다.**

($2$) 방향마다 얼마나 빨리 줄어드는지 봅니다. 값은 **처음 오차 대비 남은 비율**입니다.

| 고윳값 | $10$걸음 | $50$걸음 | $200$걸음 | $600$걸음 |
|---|---|---|---|---|
| $0.957383$ | $0.93421582$ | $0.71160025$ | $0.25641555$ | $0.01685905$ |
| $1.834254$ | $0.87740906$ | $0.52000866$ | $0.07312103$ | $0.00039096$ |
| $21.739062$ | $0.18782588$ | $0.00023376$ | $0.00000000$ | $0.00000000$ |
| $254.109580$ | $0.10737418$ | $0.00001427$ | $0.00000000$ | $0.00000000$ |

**가장 가파른 방향은 $50$걸음에 $0.00001427$까지 사라집니다.**

**가장 완만한 방향은 $600$걸음 뒤에도 $0.01685905$가 남아 있습니다.**

**같은 걸음 수에서 천 배 넘게 차이 납니다.** 학습률이 가파른 방향에 맞춰져 있기 때문입니다.

($3$) 조건수를 바꿔 걸음 수를 셉니다.

| 퍼짐 지수 | 조건수 | 초과손실 $0.01$까지 걸음 | 조건수 대비 |
|---|---|---|---|

## 심화 문제

> **심화 1.** 상한 $2/L$을 유도하세요.

이차형식에서 오차의 갱신은 이렇습니다.

$$e_{t+1}=(I-\eta H)e_t$$

| 단계 | 무엇 |
|---|---|
| 첫째 | 고유분해하면 방향마다 $1-\eta\lambda$가 곱해짐 |
| 둘째 | 모든 방향에서 절댓값이 $1$보다 작아야 함 |
| 셋째 | 가장 큰 $\lambda$가 가장 먼저 어김 |
| 넷째 | $\lvert 1-\eta L\rvert<1$에서 $0<\eta<2/L$ |

**문제 $1$의 관측이 이 유도의 확인입니다.** $0.98$배와 $1.02$배에서 갈렸습니다.

**최적 학습률은 $2/(L+\mu)$이고 그때 수렴률이 $(L-\mu)/(L+\mu)$입니다.** 조건수가 크면 이 값이 $1$에 가까워져 느려집니다.

> **심화 2.** 임계 배치 크기 공식을 유도하세요.

한 걸음의 기대 감소량을 최대로 하는 학습률을 씁니다.

$$\mathbb{E}[\Delta L]\approx-\eta\|g\|^2+\frac{\eta^2 L}{2}\left(\|g\|^2+\frac{\mathrm{tr}\,\Sigma}{B}\right)$$

| 단계 | 무엇 |
|---|---|
| 첫째 | $\eta$에 대해 최소화 |
| 둘째 | 최적 감소량이 $B$에 대해 포화 |
| 셋째 | 포화 지점이 $\mathrm{tr}\,\Sigma/\|g\|^2$ |

**둘째 줄이 문제 $3$의 관측입니다.** $B$가 그 값을 넘으면 괄호 안이 $\|g\|^2$에 수렴해 **더 안 좋아집니다.**

> **심화 3.** 큰 배치 학습의 실무 기법을 정리하세요.

| 기법 | 무엇을 하나 |
|---|---|
| 준비 구간 | 처음에 학습률을 천천히 올립니다 |
| 층별 학습률 | 층마다 노름에 맞춰 조절합니다 |
| 라스 최적화기 | 가중치 노름 대비 갱신 노름을 맞춥니다 |
| 배치를 키워 감 | 처음에 작게 나중에 크게 |

**넷째 줄이 임계 배치 크기의 직접적 응용입니다.** 학습 초기에는 **그래디언트가 크고 잡음 비가 낮아** 작은 배치로 충분하고, 최적점에 가까워지면 신호가 작아져 **큰 배치가 필요해집니다.**

> **심화 4.** 실제 신경망에서 임계 배치 크기를 재는 법을 정리하세요.

$$\hat{\mathcal{B}}=\frac{\mathrm{tr}\,\Sigma}{\|g\|^2}$$

| 무엇 | 어떻게 |
|---|---|
| 두 배치로 추정 | 작은 배치와 큰 배치의 그래디언트 |
| 노름 제곱의 차 | 잡음 흔적을 뺌 |
| 학습 중에 잼 | 값이 계속 변함 |

**셋째 줄이 중요합니다.** 임계 배치 크기는 **고정된 값이 아니라 학습이 진행되며 커집니다.** 문제 $3$은 한 지점에서 잰 값입니다.

**둘째 줄과 셋째 줄이 신경망의 답입니다.** 층을 지나며 조건수가 나빠지는 것을 **층마다 되돌립니다.**

## 부록. 기호 정리

| 기호 | 읽는 법 | 뜻 |
|---|---|---|
| 학습률 상한 | learning rate bound | 넘으면 발산하는 값입니다 |
| 조건수 | condition number | 최대 고윳값 나누기 최소 고윳값입니다 |
| 선형 스케일링 | linear scaling rule | 배치를 $k$배 하면 학습률도 $k$배 합니다 |
| 제곱근 스케일링 | square-root scaling | 배치를 $k$배 하면 학습률을 $\sqrt{k}$배 합니다 |
| 임계 배치 크기 | critical batch size | 더 키워도 걸음이 안 줄어드는 크기입니다 |
| 잡음 대 신호 비 | noise-to-signal ratio | 그래디언트 분산을 노름 제곱으로 나눈 값입니다 |
| 학습률 훑기 | learning rate range test | 짧게 돌려 상한을 찾습니다 |
| 라스 | LARS | 층마다 갱신 크기를 맞추는 최적화기입니다 |
| 준비 구간 | warmup | 처음에 학습률을 올립니다 |
| 고유분해 | eigendecomposition | 대칭행렬을 방향과 곡률로 나눕니다 |

def pw(s):
    return sum(2 if ord(c) > 0x1100 else 1 for c in str(s))

def rw(s, w):
    return str(s) + ' ' * max(0, w - pw(s))

def rl(s, w):
    return ' ' * max(0, w - pw(s)) + str(s)

rng = np.random.default_rng(20237)
n, p = 4000, 10
X = rng.normal(0, 1, (n, p))
for j in range(p):
    X[:, j] *= 10.0 ** (1.2 * j / (p - 1))
beta = rng.normal(0, 1, p)
y = X @ beta + rng.normal(0, 1.0, n)
H = X.T @ X / n
bstar = np.linalg.solve(H, X.T @ y / n)
ev = np.linalg.eigvalsh(H)
Lsm, mu = float(ev.max()), float(ev.min())

def loss(b):
    r = X @ b - y
    return float((r ** 2).mean() / 2)

opt = loss(bstar)

def gmb(b, idx):
    Xi = X[idx]
    return Xi.T @ (Xi @ b - y[idx]) / len(idx)

def run(B, lr, steps, seed, tail=1000):
    rr = np.random.default_rng(seed)
    b = np.zeros(p)
    acc = []
    for t in range(steps):
        idx = rr.integers(0, n, B)
        b -= lr * gmb(b, idx)
        if not np.all(np.isfinite(b)):
            return float('inf')
        if t >= steps - tail:
            acc.append(loss(b) - opt)
    v = float(np.mean(acc))
    return v if np.isfinite(v) else float('inf')
