# 238강. 그래디언트 잡음과 분산 감소

$237$강에서 **배치를 키워도 안 되는 자리**가 있다는 것을 봤습니다. 임계 배치 크기를 넘으면 계산만 늘고 걸음은 안 줄어듭니다.

$$\text{배치를 안 키우고 잡음을 줄일 수 있습니까}$$

있습니다. 그리고 그중 하나는 **거의 공짜**입니다. 과거 걸음을 섞어 두면 그것 자체가 **평균을 내는 일**입니다.

$$\text{모멘텀은 그래디언트를 평균 내고 폴략 평균은 파라미터를 평균 냅니다}$$

이 강의는 **모멘텀·기준점 보정·평균** 셋을 보고, 마지막에 **잡음을 줄이는 것이 언제나 좋지는 않다**는 것을 확인합니다.

## 이 강의에서 할 수 있게 되는 것
- 모멘텀이 그래디언트의 가중 평균임을 수치로 보일 수 있습니다.
- 모멘텀이 잡음이 없어도 도움이 되는 이유를 설명할 수 있습니다.
- 기준점 보정이 편향 없이 분산을 줄이는 것을 확인할 수 있습니다.
- 폴략 평균과 지수이동평균을 견줄 수 있습니다.
- 잡음이 필요한 경우를 가릴 수 있습니다.

## 문제 1. 잡음을 줄이는 세 가지 길

> **문제.** 방법들을 봅니다.
> ($1$) 정리하세요.
> ($2$) 모멘텀이 무엇을 하는지 보세요.
> ($3$) 모멘텀이 평균을 내는 것임을 확인하세요.

**생각의 실마리.** 분산을 줄이려면 **더 많은 표본을 평균 내면** 됩니다. 그런데 표본을 새로 볼 필요는 없습니다. **이미 본 것을 다시 쓰면** 됩니다.

**풀이.** ($1$) 정리합니다.

| 방법 | 무엇을 하나 | 비용 |
|---|---|---|
| 배치를 키움 | 표본을 더 봄 | 계산이 비례해 늘음 |
| 과거를 섞음 | 모멘텀 | 공짜에 가까움 |
| 기준점을 씀 | 분산 감소 방법 | 가끔 전체를 봄 |
| 평균을 냄 | 폴략 평균 | 걸음은 그대로 |

**$237$강에서 첫 줄이 임계 배치 크기에서 막히는 것을 봤습니다.** 이 강의는 나머지 셋을 봅니다.

($2$) 모멘텀이 무엇을 하는지 봅니다.

$$v_{t+1}=\beta v_t+g_t,\qquad b_{t+1}=b_t-\eta v_{t+1}$$

| 모멘텀 계수 | 실효 걸음 배수 | 같은 학습률에서 | 학습률을 나눠 맞추면 |
|---|---|---|---|
| $0.0000$ | $1.000000$ | $0.00359812$ | $0.00359812$ |
| $0.5000$ | $2.000000$ | $0.00731684$ | $0.00358368$ |
| $0.9000$ | $10.000000$ | $0.04446094$ | $0.00358980$ |
| $0.9900$ | $100.000000$ | $1.45198881$ | $0.00348313$ |

**같은 학습률로 두면 계수를 키울수록 나빠집니다.** $0.99$에서 $1.45$까지 갑니다.

**모멘텀이 걸음을 $1/(1-\beta)$만큼 키우기 때문입니다.** 그래서 학습률을 그만큼 나눠야 같은 조건이 됩니다.

**맞춰 주면 넷째 열이 $0.00359$에서 $0.00348$로 조금씩 좋아집니다.**

($3$) 모멘텀이 평균을 내는 것임을 확인합니다. 모멘텀 벡터에 $(1-\beta)$를 곱한 값의 분산을 잽니다.

| 모멘텀 계수 | 유효 표본 수 | 모멘텀 벡터의 분산 | 한 걸음 분산 대비 |
|---|---|---|---|
| $0.0000$ | $1.000000$ | $2.365110$ | $1.000000$ |
| $0.5000$ | $3.000000$ | $0.792058$ | $0.334892$ |
| $0.9000$ | $19.000000$ | $0.127709$ | $0.053997$ |
| $0.9900$ | $199.000000$ | $0.012285$ | $0.005194$ |

**셋째 열과 넷째 열이 유효 표본 수의 역수와 맞습니다.** $\beta=0.9$에서 유효 표본 수가 $19.000000$이고 분산 비 관측이 $0.053997$이므로 그 역수와 맞습니다.

$$\text{유효 표본 수}=\frac{1+\beta}{1-\beta}$$

**계수 $0.9$면 대략 열아홉 걸음을 평균 낸 셈입니다.** 배치를 열아홉 배 키운 것과 **분산 면에서 같은데 계산은 그대로**입니다.

**이 문제에서 배우는 것.** 모멘텀은 **가속 장치이기 전에 평균 장치**입니다. 과거 그래디언트를 지수 가중으로 평균 내므로, **표본을 새로 안 보고도** 분산이 줄어듭니다.

**확인 1-1.** 모멘텀이 걸음 크기를 몇 배로 키우는지 쓰세요.

*답.* $1$ 나누기 $1$ 빼기 계수만큼입니다.

**확인 1-2.** 검산에서 계수 $0.99$일 때 같은 학습률과 나눠 맞춘 초과손실을 쓰세요.

*답.* $1.45198881$과 $0.00348313$입니다.

**확인 1-3.** 검산에서 계수 $0.9$의 유효 표본 수와 분산 비를 쓰세요.

*답.* $19.000000$과 $0.053997$입니다.

## 문제 2. 모멘텀이 실제로 무엇을 바꾸는가

> **문제.** 두 효과를 가릅니다.
> ($1$) 정리하세요.
> ($2$) 잡음이 없을 때도 도움이 되는지 보세요.
> ($3$) 방향별로 무엇이 달라지는지 보세요.
> ($4$) 계수를 너무 키우면 어떻게 되는지 보세요.

**생각의 실마리.** 문제 $1$은 **잡음을 평균 낸다**는 이야기였습니다. 그러면 **잡음이 아예 없으면** 모멘텀이 쓸모없을까요.

**풀이.** ($1$) 가릅니다.

| 효과 | 무엇인가 | 언제 |
|---|---|---|
| 잡음 평균 | 과거를 섞어 분산이 줄음 | 확률적일 때 |
| 골짜기 가속 | 같은 방향이 쌓임 | 잡음이 없어도 |
| 어느 쪽이 큰가 | 문제에 달림 | 아래에서 확인 |

($2$) 전체 배치로만 돌립니다. 잡음이 아예 없고 조건수는 $104.933200$입니다.

| 모멘텀 계수 | 고른 학습률 | 초과손실 $0.01$까지 걸음 |
|---|---|---|
| $0.0000$ | $0.018954$ | $65$ |
| $0.5000$ | $0.024940$ | $22$ |
| $0.9000$ | $0.002993$ | $69$ |
| $0.9900$ | $0.000299$ | $604$ |

**잡음이 하나도 없는데 계수 $0.5$에서 걸음이 $65$에서 $22$로 세 배 줄어듭니다.**

**골짜기에서 같은 방향의 그래디언트가 쌓이기** 때문입니다.

**그런데 $0.9$와 $0.99$에서는 다시 느려집니다.** 최적을 지나쳤기 때문입니다.

$$\beta^\star=\left(\frac{\sqrt{L}-\sqrt{\mu}}{\sqrt{L}+\sqrt{\mu}}\right)^2=0.675885$$

**표에서 $0.5$가 그 값에 가장 가깝습니다.** $237$강 문제 $4$의 조건수 문제를 모멘텀이 어느 정도 풉니다.

($3$) 방향별로 무엇이 달라지는지 봅니다. 값은 **처음 오차 대비 남은 비율**입니다.

| 고윳값 | 모멘텀 없이 $300$걸음 | 모멘텀 $0.9$로 $300$걸음 |
|---|---|---|
| $0.955281$ | $0.00556766$ | $0.00205989$ |
| $12.154193$ | $0.00000000$ | $0.00000000$ |
| $100.240679$ | $0.00000000$ | $0.00000006$ |

**가장 완만한 방향에서만 차이가 납니다.** $0.00556766$이 $0.00205989$로 두 배 넘게 줄었습니다.

**가파른 방향은 어차피 둘 다 $0$입니다.** 모멘텀이 **느린 방향을 밀어 주는** 장치임이 여기서 보입니다.

($4$) 계수를 너무 키우면 어떻게 되는지 봅니다. 학습률을 $(1-\beta)$로 맞춘 뒤 계수만 올립니다.

| 모멘텀 계수 | 맞춘 학습률 | 초과손실 | 어떻게 되나 |
|---|---|---|---|
| $0.9000$ | $0.00200000$ | $0.00422664$ | 수렴 |
| $0.9900$ | $0.00020000$ | $0.00364416$ | 수렴 |
| $0.9990$ | $0.00002000$ | $0.00949118$ | 수렴 |
| $0.9999$ | $0.00000200$ | $0.16381115$ | 수렴 |

**$0.99$까지는 좋아지다가 $0.999$부터 나빠집니다.** $0.9999$에서는 초과손실이 마흔 배 넘게 커집니다.

**평균 낼 과거가 걸음 수에 가까워지면 앞쪽 걸음이 계속 발목을 잡습니다.** 유효 표본 수가 $20000$인데 걸음이 $6000$번뿐입니다.

**실무에서 $0.9$나 $0.99$를 쓰는 이유입니다.**

**이 문제에서 배우는 것.** 모멘텀에는 **두 얼굴**이 있습니다. 잡음을 평균 내는 얼굴과 골짜기를 가속하는 얼굴입니다. 그리고 **둘 다 최적값이 있어** 무작정 키우면 안 됩니다.

**확인 2-1.** 잡음이 없어도 모멘텀이 도움이 되는 이유를 쓰세요.

*답.* 골짜기에서 같은 방향의 그래디언트가 쌓이기 때문입니다.

**확인 2-2.** 검산에서 계수 $0$과 $0.5$의 걸음 수를 쓰세요.

*답.* $65$와 $22$입니다.

**확인 2-3.** 검산에서 계수 $0.9999$의 초과손실을 쓰세요.

*답.* $0.16381115$입니다.

## 문제 3. 기준점을 쓰는 방법

> **문제.** 분산 감소 방법을 봅니다.
> ($1$) 생각을 정리하세요.
> ($2$) 편향이 없고 분산이 주는 것을 확인하세요.
> ($3$) 실제로 학습시켜 견주세요.
> ($4$) 왜 딥러닝에서 잘 안 쓰는지 보세요.

**생각의 실마리.** 표본 $i$의 그래디언트가 흔들립니다. 그런데 **가까운 두 점에서의 그래디언트는 비슷하게 흔들립니다.** 그 공통 부분을 빼면 됩니다.

**풀이.** ($1$) 정리합니다.

| 무엇 | 무엇인가 | 덧붙임 |
|---|---|---|
| 문제 | 미니배치 그래디언트가 흔들림 | 분산이 큼 |
| 생각 | 가끔 전체를 계산해 기준으로 둠 | 기준점 |
| 보정 | 지금 표본과 기준점의 차이만 씀 | 차이는 작음 |
| 결과 | 편향 없이 분산이 줄음 | SVRG |

$$\tilde g_i=g_i(b)-g_i(\tilde b)+\nabla F(\tilde b)$$

**기댓값을 취하면 뒤 둘이 지워져 편향이 없습니다.**

($2$) 편향이 없고 분산이 주는 것을 확인합니다.

| 기준점과의 거리 | 보통 편향 | 보정 편향 | 보통 분산 | 보정 분산 |
|---|---|---|---|---|
| $0.0326$ | $0.060208$ | $0.000928$ | $26.724278$ | $0.014912$ |
| $0.1282$ | $0.039070$ | $0.004305$ | $27.412148$ | $0.207312$ |
| $0.9672$ | $0.047776$ | $0.042875$ | $25.951244$ | $11.823412$ |

**두 편향이 모두 $0$에 가깝습니다.** 표집 오차 수준이고, **보정이 편향을 안 만듭니다.**

**기준점이 $0.0326$만큼 가까우면 분산이 $26.72$에서 $0.0149$로 $1800$배 줄어듭니다.**

**멀어지면 이득이 사라집니다.** 거리 $0.9672$에서는 $25.95$가 $11.82$로 절반만 줍니다. 그래서 **기준점을 주기적으로 갱신**합니다.

($3$) 실제로 학습시켜 견줍니다.

| 갱신 주기 | 초과손실 | 자료 통과 횟수 |
|---|---|---|
| 보통 미니배치 | $0.0030744857$ | $48.0000$ |
| $125$ | $0.0000000000$ | $144.0000$ |
| $500$ | $0.0000000000$ | $108.0000$ |
| $2000$ | $0.0000012171$ | $99.0000$ |

**보정하면 초과손실이 $0.00307$에서 사실상 $0$이 됩니다.**

**대신 기준점 계산 때문에 자료 통과 횟수가 $48$에서 $144$로 세 배 늘어납니다.**

**갱신을 자주 하면 분산은 더 줄지만 비용이 커집니다.** 주기 $2000$에서는 통과가 $99$번으로 줄지만 초과손실이 $0.0000012171$로 조금 커집니다.

($4$) 왜 딥러닝에서 잘 안 쓰는지 봅니다.

| 무엇 | 무엇이 문제 | 덧붙임 |
|---|---|---|
| 가정 | 손실면이 볼록하고 매끄러움 | 신경망은 아님 |
| 기준점 | 전체 그래디언트를 계산 | 자료가 크면 비쌈 |
| 저장 | 기준점 파라미터 한 벌 더 | 메모리 두 배 |
| 실효 | 잡음이 정규화 노릇도 함 | 줄이면 손해일 수도 |

**마지막 줄이 가장 큰 이유입니다.** $236$강 문제 $3$에서 잡음이 골을 넘게 해 줬습니다.

**볼록한 문제에서는 잡음이 순수한 손해**라 줄이는 것이 언제나 이득입니다. 신경망은 다릅니다.

**이 문제에서 배우는 것.** 기준점 보정은 **이론적으로 아름답고 볼록한 문제에서 강력**합니다. 그런데 딥러닝에서 안 쓰이는 이유는 성능이 아니라 **가정과 목적이 다르기** 때문입니다.

**확인 3-1.** 기준점 보정이 편향을 안 만드는 이유를 쓰세요.

*답.* 기댓값을 취하면 보정 항 둘이 서로 지워지기 때문입니다.

**확인 3-2.** 검산에서 기준점 거리 $0.0326$일 때 보통 분산과 보정 분산을 쓰세요.

*답.* $26.724278$과 $0.014912$입니다.

**확인 3-3.** 검산에서 갱신 주기 $125$의 자료 통과 횟수를 쓰세요.

*답.* $144.0000$입니다.

## 문제 4. 평균을 내는 방법

> **문제.** 파라미터를 평균 냅니다.
> ($1$) 두 평균을 가르세요.
> ($2$) 폴략 평균을 쓰세요.
> ($3$) 지수이동평균과 견주세요.
> ($4$) 학습률을 줄이는 것과 견주세요.

**생각의 실마리.** $236$강에서 **최적점 둘레를 맴돈다**고 했습니다. 맴도는 것이라면 **가운데가 최적점**입니다.

**풀이.** ($1$) 가릅니다.

| 무엇 | 무엇을 하나 | 덧붙임 |
|---|---|---|
| 폴략 평균 | 걸음들의 평균을 답으로 | 학습에는 안 씀 |
| 지수이동평균 | 최근에 무게를 더 | 실무의 기본 |
| 모멘텀과의 차이 | 모멘텀은 그래디언트를 평균 | 이쪽은 파라미터를 평균 |

($2$) 폴략 평균을 씁니다. 뒤 절반을 평균 냅니다.

| 학습률 | 마지막 걸음 | 뒤 절반 평균 | 몇 배 좋아졌나 |
|---|---|---|---|
| $0.0500$ | $0.00316382$ | $0.00005312$ | $59.5578$ |
| $0.0200$ | $0.00131473$ | $0.00005049$ | $26.0418$ |
| $0.0100$ | $0.00106724$ | $0.00004360$ | $24.4754$ |

**평균을 내면 스물네 배에서 예순 배까지 좋아집니다. 걸음은 하나도 더 안 갔습니다.**

**떨림이 최적점 둘레를 도는 것이라 평균이 가운데를 찾습니다.**

**학습률이 클수록 이득이 큽니다.** $0.05$에서 $59.5578$배입니다. 떨림이 클수록 평균이 지울 것이 많기 때문입니다.

**$236$강 심화 $3$의 폴략 평균이 여기서 확인됩니다.**

## 심화 문제

> **심화 1.** 모멘텀의 유효 표본 수를 유도하세요.

$v_t=\sum_{k}\beta^k g_{t-k}$이고 $g$들이 독립이면 이렇습니다.

$$\mathrm{Var}[(1-\beta)v_t]=(1-\beta)^2\sum_k\beta^{2k}\sigma^2=\frac{1-\beta}{1+\beta}\sigma^2$$

| 무엇 | 값 |
|---|---|
| 분산 비 | $(1-\beta)/(1+\beta)$ |
| 유효 표본 수 | 그 역수 |
| $\beta=0.9$ | $19$ |

**문제 $1$의 표가 이 식의 확인입니다.** 유효 표본 수 $19.000000$의 역수가 분산 비 $0.053997$과 맞습니다.

**독립 가정이 깨지면 달라집니다.** 실제 학습에서는 연속한 걸음의 그래디언트가 상관이 있어 **유효 표본 수가 이보다 작습니다.**

> **심화 2.** 네스테로프 가속을 정리하세요.

$$v_{t+1}=\beta v_t+\nabla F(b_t-\eta\beta v_t),\qquad b_{t+1}=b_t-\eta v_{t+1}$$

| 무엇이 다른가 | 왜 |
|---|---|
| 미리 가 본 자리에서 잼 | 관성으로 갈 곳을 먼저 봄 |
| 볼록에서 속도가 최적 | $1/t^2$ |
| 확률적일 때 이득이 작음 | 잡음이 미리 보기를 흐림 |

**둘째 줄이 이론의 자랑입니다.** 보통 경사하강의 $1/t$보다 빠릅니다.

**셋째 줄이 실무의 관찰입니다.** 신경망에서 네스테로프와 보통 모멘텀의 차이는 대개 작습니다.

def run_svrg(B, lr, steps, inner, seed, tail=500):
    rr = np.random.default_rng(seed)
    b = np.zeros(p)
    acc = []
    t = 0
    while t < steps:
        b_ref = b.copy()
        g_ref = X.T @ (X @ b_ref - y) / n
        for _ in range(inner):
            if t >= steps:
                break
            idx = rr.integers(0, n, B)
            g = gmb(b, idx) - gmb(b_ref, idx) + g_ref
            b -= lr * g
            t += 1
            if not np.all(np.isfinite(b)):
                return float('inf'), 0
            if t >= steps - tail:
                acc.append(loss(b) - opt)
    passes = (steps // inner) * 1.0 + steps * 2.0 * B / n
    return float(np.mean(acc)), passes

def run_avg(B, lr, steps, seed, avg_from=0.5, ema=None):
    rr = np.random.default_rng(seed)
    b = np.zeros(p)
    s = np.zeros(p)
    cnt = 0
    e = None
    start = int(steps * avg_from)
    for t in range(steps):
        idx = rr.integers(0, n, B)
        b -= lr * gmb(b, idx)
        if t >= start:
            s += b
            cnt += 1
        if ema is not None:
            e = b.copy() if e is None else ema * e + (1 - ema) * b
    out = {"마지막": loss(b) - opt, "폴략 평균": loss(s / cnt) - opt}
    if ema is not None:
        out["지수이동평균"] = loss(e) - opt
    return out

def run_all(B, lr0, mom, T, seed, use_cos, use_ema):
    rr = np.random.default_rng(seed)
    b = np.zeros(p)
    v = np.zeros(p)
    e = None
    for t in range(1, T + 1):
        lr = lr0 * (0.5 * (1 + np.cos(np.pi * t / T)) if use_cos else 1.0)
        idx = rr.integers(0, n, B)
        v = mom * v + gmb(b, idx)
        b -= lr * v
        if not np.all(np.isfinite(b)):
            return float('inf')
        if use_ema:
            e = b.copy() if e is None else 0.999 * e + 0.001 * b
    return loss(e if use_ema else b) - opt
