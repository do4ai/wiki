# 240강. 활성함수의 수학

$239$강에서 **활성함수가 표현력을 준다**는 것을 봤습니다. 없으면 층을 쌓아도 선형 하나로 접혔습니다.

$$\text{그러면 어느 함수를 써야 합니까}$$

아무 비선형 함수나 되는 것이 아닙니다. **역전파가 지나가야** 하고, 그러려면 **도함수가 살아 있어야** 합니다.

$$\text{도함수가 } 0 \text{이면 그 단위는 영원히 안 배웁니다}$$

이 강의는 여섯 함수를 나란히 놓고 **값과 도함수를 재고**, 깊은 신경망에서 **무엇이 무너지는지** 확인합니다.

## 이 강의에서 할 수 있게 되는 것
- 활성함수가 갖춰야 할 조건을 정리할 수 있습니다.
- 포화가 왜 깊은 신경망을 막는지 수치로 보일 수 있습니다.
- 정류 선형의 죽은 단위를 세고 원인을 설명할 수 있습니다.
- 새는 정류 선형의 기울기를 어떻게 정할지 판단할 수 있습니다.
- 활성함수보다 구조가 크게 드는 자리를 확인할 수 있습니다.

## 문제 1. 활성함수가 갖춰야 할 것

> **문제.** 조건을 정합니다.
> ($1$) 요구 조건을 정리하세요.
> ($2$) 여섯 함수의 값과 도함수를 보세요.
> ($3$) 도함수를 수치 미분으로 확인하세요.
> ($4$) 계산 비용을 세세요.

**생각의 실마리.** 활성함수는 **원소마다 한 번씩** 불립니다. 층이 백 개이고 너비가 천이면 **십만 번**이므로, 함수 하나의 비용이 그대로 곱해집니다.

**풀이.** ($1$) 정리합니다.

| 무엇 | 왜 필요한가 | 어디서 |
|---|---|---|
| 비선형 | 선형이면 층이 접힘 | $239$강 문제 $2$ |
| 미분 가능 | 역전파가 지나가야 함 | 거의 모든 곳에서 |
| 도함수가 살아 있음 | $0$이면 신호가 막힘 | $233$강 문제 $2$ |
| 계산이 쌈 | 원소마다 부르므로 | 지수 하나도 비쌈 |
| 출력 범위 | 너무 커지면 안 됨 | 다음 층의 입력 |

**셋째 줄이 실무에서 가장 크게 듭니다.**

($2$) 여섯 함수의 값을 봅니다.

| 함수 | $-4.0$에서 | $-1.0$에서 | $0.0$에서 | $1.0$에서 | $4.0$에서 |
|---|---|---|---|---|---|
| 로지스틱 | $0.017986$ | $0.268941$ | $0.500000$ | $0.731059$ | $0.982014$ |
| 하이퍼볼릭 탄젠트 | $-0.999329$ | $-0.761594$ | $0.000000$ | $0.761594$ | $0.999329$ |
| 정류 선형 | $0.000000$ | $0.000000$ | $0.000000$ | $1.000000$ | $4.000000$ |
| 새는 정류 선형 | $-0.040000$ | $-0.010000$ | $0.000000$ | $1.000000$ | $4.000000$ |
| 지수 선형 | $-0.981684$ | $-0.632121$ | $0.000000$ | $1.000000$ | $4.000000$ |
| 가우스 오차 선형 | $-0.004415$ | $-0.154204$ | $0.000000$ | $0.845796$ | $3.995585$ |

도함수입니다.

| 함수 | $-4.0$에서 | $-1.0$에서 | $0.0$에서 | $1.0$에서 | $4.0$에서 |
|---|---|---|---|---|---|
| 로지스틱 | $0.017663$ | $0.196612$ | $0.250000$ | $0.196612$ | $0.017663$ |
| 하이퍼볼릭 탄젠트 | $0.001341$ | $0.419974$ | $1.000000$ | $0.419974$ | $0.001341$ |
| 정류 선형 | $0.000000$ | $0.000000$ | $0.000000$ | $1.000000$ | $1.000000$ |
| 새는 정류 선형 | $0.010000$ | $0.010000$ | $0.010000$ | $1.000000$ | $1.000000$ |
| 지수 선형 | $0.018316$ | $0.367879$ | $1.000000$ | $1.000000$ | $1.000000$ |
| 가우스 오차 선형 | $-0.006402$ | $-0.067780$ | $0.500000$ | $1.067780$ | $1.006402$ |

**로지스틱과 탄젠트는 양끝에서 도함수가 $0$에 붙습니다.** $\pm4$에서 $0.017663$과 $0.001341$입니다.

**정류 선형은 음수 쪽에서 정확히 $0$입니다.**

**가우스 오차 선형은 도함수가 음수가 되기도 합니다.** $-1$에서 $-0.067780$이고, **비단조 함수**이기 때문입니다.

($3$) 도함수를 수치 미분으로 확인합니다.

| 함수 | 최대 상대 오차 | 어디서 큰가 |
|---|---|---|
| 로지스틱 | $7.7371e-09$ | 일반 자리 |
| 하이퍼볼릭 탄젠트 | $1.2648e-06$ | 일반 자리 |
| 정류 선형 | $1.0000e+00$ | $0$ 근처 |
| 새는 정류 선형 | $7.4694e-01$ | $0$ 근처 |
| 지수 선형 | $1.0997e-07$ | $0$ 근처 |
| 가우스 오차 선형 | $3.6934e-10$ | 일반 자리 |

**정류 선형은 $0$ 근처에서 상대 오차가 $1$입니다.** 미분 불가능한 점이 하나 있기 때문입니다.

**$231$강 심화 $4$에서 본 대로 측도 $0$인 점이라 실전에서는 거의 안 부딪힙니다.** 다만 그래디언트 검사에서 몇 개 원소만 실패하면 **이것을 의심해야** 합니다.

($4$) 계산 비용을 셉니다.

| 함수 | 무엇이 필요한가 | 값 |
|---|---|---|
| 정류 선형 | 비교 하나 | 가장 쌈 |
| 새는 정류 선형 | 비교 하나와 곱 하나 | 거의 같음 |
| 하이퍼볼릭 탄젠트 | 지수 둘 | 비쌈 |
| 로지스틱 | 지수 하나 | 비쌈 |
| 지수 선형 | 음수에서만 지수 | 가운데 |
| 가우스 오차 선형 | 지수 하나와 곱 여럿 | 가장 비쌈 |

**정류 선형이 표준이 된 첫째 이유가 이것입니다.** 비교 한 번이면 끝입니다.

**이 문제에서 배우는 것.** 활성함수는 **수학적 성질과 계산 비용을 함께** 봐야 합니다. 그리고 **미분 불가능한 점 하나는 실전에서 문제가 안 됩니다.**

**확인 1-1.** 활성함수의 도함수가 $0$이면 무엇이 일어나는지 쓰세요.

*답.* 그 단위는 신호가 막혀 영원히 안 배웁니다.

**확인 1-2.** 검산에서 탄젠트의 $\pm4$에서의 도함수를 쓰세요.

*답.* $0.001341$입니다.

**확인 1-3.** 검산에서 정류 선형의 최대 상대 오차와 그 자리를 쓰세요.

*답.* $1.0000e+00$이고 $0$ 근처입니다.

## 문제 2. 포화가 무엇을 막는가

> **문제.** 포화를 봅니다.
> ($1$) 뜻을 정리하세요.
> ($2$) 도함수의 최댓값을 보세요.
> ($3$) 층을 지나며 신호가 얼마나 주는지 보세요.
> ($4$) 실제로 학습이 되는지 견주세요.

**생각의 실마리.** 역전파는 층마다 **도함수를 곱합니다.** 그 값이 $1$보다 작으면 **거듭제곱으로 줄어듭니다.**

**풀이.** ($1$) 정리합니다.

| 무엇 | 무엇인가 | 덧붙임 |
|---|---|---|
| 포화 | 입력이 크면 도함수가 $0$에 붙음 | 로지스틱과 탄젠트 |
| 무슨 일 | 역전파 신호가 막힘 | $233$강 문제 $2$ |
| 층이 깊으면 | 곱이 쌓여 지수로 줄음 | 그래디언트 소실 |
| 정류 선형 | 양수 쪽 도함수가 $1$ | 곱해도 안 줄음 |

($2$) 도함수의 최댓값을 봅니다.

| 함수 | 도함수 최댓값 | 절댓값 $3$에서 | 절댓값 $6$에서 |
|---|---|---|---|
| 로지스틱 | $0.250000$ | $0.045177$ | $0.002467$ |
| 하이퍼볼릭 탄젠트 | $1.000000$ | $0.009866$ | $0.000025$ |
| 정류 선형 | $1.000000$ | $1.000000$ | $1.000000$ |
| 새는 정류 선형 | $1.000000$ | $1.000000$ | $1.000000$ |
| 지수 선형 | $1.000000$ | $1.000000$ | $1.000000$ |
| 가우스 오차 선형 | $1.099839$ | $1.024548$ | $1.000338$ |

**로지스틱은 최댓값이 $0.250000$뿐입니다.** 입력이 어디에 있든 층을 지날 때마다 **최소 네 배씩 줄어듭니다.**

**탄젠트는 최댓값이 $1$이지만 $\pm3$에서 이미 $0.009866$입니다.** 입력이 $0$ 근처에 머물러야만 버팁니다.

**정류 선형 계열은 양수 쪽에서 정확히 $1$이라 안 줄어듭니다.**

($3$) 깊이 $20$인 신경망에서 첫 층과 마지막 층 그래디언트 크기를 봅니다.

| 함수 | 첫 층 크기 | 마지막 층 크기 | 첫 층 나누기 마지막 |
|---|---|---|---|
| 로지스틱 | $1.7702e-13$ | $1.1119e-02$ | $1.5920e-11$ |
| 하이퍼볼릭 탄젠트 | $1.8439e-03$ | $2.5276e-02$ | $7.2952e-02$ |
| 정류 선형 | $2.7182e-04$ | $5.3896e-03$ | $5.0434e-02$ |
| 새는 정류 선형 | $2.7735e-04$ | $5.5778e-03$ | $4.9724e-02$ |
| 지수 선형 | $3.0969e-03$ | $7.3694e-02$ | $4.2024e-02$ |
| 가우스 오차 선형 | $6.3732e-05$ | $1.1894e-03$ | $5.3585e-02$ |

**로지스틱만 비가 $10^{-11}$입니다.** 나머지 다섯은 모두 $10^{-2}$대입니다.

**최댓값이 $0.25$인 것과 $1$인 것의 차이가 $20$층을 지나며 아홉 자릿수로 벌어집니다.**

($4$) 실제로 학습이 되는지 견줍니다. 깊이 $8$입니다.

| 함수 | 학습 정확도 | 따로 뗀 정확도 |
|---|---|---|
| 로지스틱 | $0.506818$ | $0.492500$ |
| 하이퍼볼릭 탄젠트 | $0.958182$ | $0.943750$ |
| 정류 선형 | $0.939545$ | $0.920000$ |
| 새는 정류 선형 | $0.917273$ | $0.882500$ |
| 지수 선형 | $0.956364$ | $0.943750$ |

**확인 2-1.** 로지스틱의 도함수 최댓값과 그 결과를 쓰세요.

*답.* $0.250000$이고 층마다 최소 네 배씩 줄어듭니다.

**확인 2-2.** 검산에서 깊이 $20$일 때 로지스틱과 탄젠트의 첫 층 나누기 마지막을 쓰세요.

*답.* $1.5920e-11$과 $7.2952e-02$입니다.

**확인 2-3.** 검산에서 깊이 $8$일 때 로지스틱과 탄젠트의 따로 뗀 정확도를 쓰세요.

*답.* $0.492500$과 $0.943750$입니다.

## 문제 3. 정류 선형의 문제

> **문제.** 약점을 봅니다.
> ($1$) 무엇이 문제인지 정리하세요.
> ($2$) 죽은 단위를 세세요.
> ($3$) 학습률을 키워 보세요.
> ($4$) 출력 평균을 보세요.

**생각의 실마리.** 정류 선형은 음수 쪽에서 도함수가 **정확히 $0$**입니다. 한 단위가 모든 입력에서 음수가 되면 **되돌아올 길이 없습니다.**

**풀이.** ($1$) 정리합니다.

| 무엇 | 무엇인가 | 덧붙임 |
|---|---|---|
| 죽은 단위 | 모든 입력에서 음수 | 영원히 안 배움 |
| $0$에서 안 매끄러움 | 도함수가 튐 | 실전에서는 큰 문제 아님 |
| 출력 평균이 양수 | $0$ 중심이 아님 | 다음 층에 치우침 |
| 위로 안 막힘 | 출력이 커질 수 있음 | 정규화로 다룸 |

($2$) 죽은 단위를 셉니다. 학습이 끝난 뒤 **모든 표본에서 도함수가 $0$인 단위**를 셉니다.

| 함수 | 전체 은닉 단위 | 죽은 단위 수 | 죽은 비율 |
|---|---|---|---|
| 로지스틱 | $96$ | $0$ | $0.000000$ |
| 하이퍼볼릭 탄젠트 | $96$ | $0$ | $0.000000$ |
| 정류 선형 | $96$ | $2$ | $0.020833$ |
| 새는 정류 선형 | $96$ | $0$ | $0.000000$ |
| 지수 선형 | $96$ | $0$ | $0.000000$ |
| 가우스 오차 선형 | $96$ | $0$ | $0.000000$ |

**정류 선형에서만 죽은 단위가 생깁니다.** 다른 다섯은 도함수가 **어디서도 정확히 $0$이 아니기** 때문입니다.

($3$) 학습률을 키워 봅니다. 정류 선형으로 학습률만 바꿉니다.

| 학습률 | 죽은 단위 수 | 죽은 비율 | 따로 뗀 정확도 |
|---|---|---|---|
| $0.0100$ | $4$ | $0.041667$ | $0.932500$ |
| $0.0500$ | $8$ | $0.083333$ | $0.897500$ |
| $0.2000$ | $63$ | $0.656250$ | $0.492500$ |
| $0.5000$ | $55$ | $0.572917$ | $0.492500$ |

**학습률 $0.2$에서 $65$퍼센트가 죽고 정확도가 $0.492500$으로 무너집니다.**

**큰 걸음 한 번에 단위가 음수 쪽으로 밀립니다.** 한 번 밀리면 그래디언트가 $0$이라 **되돌아올 길이 없습니다.**

**$237$강에서 학습률 상한을 곡률로 설명했는데**, 정류 선형에서는 **죽은 단위**라는 다른 경로로도 무너집니다.

($4$) 출력 평균을 봅니다. 표준정규 입력을 넣습니다.

| 함수 | 출력 평균 | 출력 표준편차 | 입력 대비 분산 비 |
|---|---|---|---|
| 로지스틱 | $0.500190$ | $0.208899$ | $0.043639$ |
| 하이퍼볼릭 탄젠트 | $0.000525$ | $0.629920$ | $0.396800$ |
| 정류 선형 | $0.400732$ | $0.582805$ | $0.339662$ |
| 새는 정류 선형 | $0.396729$ | $0.585581$ | $0.342905$ |
| 지수 선형 | $0.161658$ | $0.787224$ | $0.619721$ |
| 가우스 오차 선형 | $0.284046$ | $0.583831$ | $0.340859$ |

**정류 선형은 평균이 $0.400732$로 치우칩니다.** 음수를 다 자르기 때문입니다.

**탄젠트만 평균이 $0.000525$로 $0$에 가깝습니다.**

**분산이 $0.339662$로 대략 삼분의 일이 됩니다.** 층을 지날 때마다 이만큼 줄어들고, 그것을 되돌리는 것이 **$243$강 정착 초기화**입니다.

import numpy as np

def pw(s):
    return sum(2 if ord(c) > 0x1100 else 1 for c in str(s))

def rw(s, w):
    return str(s) + ' ' * max(0, w - pw(s))

def rl(s, w):
    return ' ' * max(0, w - pw(s)) + str(s)

def sig(z):
    return 1.0 / (1.0 + np.exp(-np.clip(z, -500, 500)))

ACTS = {
    "로지스틱": (lambda z: sig(z), lambda z: sig(z) * (1 - sig(z))),
    "하이퍼볼릭 탄젠트": (lambda z: np.tanh(z), lambda z: 1 - np.tanh(z) ** 2),
    "정류 선형": (lambda z: np.maximum(z, 0.0), lambda z: (z > 0).astype(float)),
    "새는 정류 선형": (lambda z: np.where(z > 0, z, 0.01 * z), lambda z: np.where(z > 0, 1.0, 0.01)),
    "지수 선형": (lambda z: np.where(z > 0, z, np.exp(np.clip(z, -500, 0)) - 1),
                  lambda z: np.where(z > 0, 1.0, np.exp(np.clip(z, -500, 0)))),
    "가우스 오차 선형": (lambda z: z * sig(1.702 * z),
                         lambda z: sig(1.702 * z) + z * 1.702 * sig(1.702 * z) * (1 - sig(1.702 * z))),
}

def softmax(Z):
    E = np.exp(Z - Z.max(axis=1, keepdims=True))
    return E / E.sum(axis=1, keepdims=True)

def ce(Z, Y):
    mx = Z.max(axis=1, keepdims=True)
    lse = mx[:, 0] + np.log(np.exp(Z - mx).sum(axis=1))
    return float(np.mean(lse - (Z * Y).sum(axis=1)))

def onehot(lab, K):
    Y = np.zeros((len(lab), K))
    Y[np.arange(len(lab)), lab] = 1.0
    return Y

def init(sizes, rr, gain=2.0):
    Ws, bs = [], []
    for i in range(len(sizes) - 1):
        s = np.sqrt(gain / sizes[i])
        W = rr.normal(0, s, (sizes[i], sizes[i + 1]))
        if i == len(sizes) - 2:
            W = W * 0.05
        Ws.append(W)
        bs.append(np.zeros(sizes[i + 1]))
    return Ws, bs

def fwd(Ws, bs, X, f):
    pre, acts = [], [X]
    H = X
    for i in range(len(Ws)):
        Z = H @ Ws[i] + bs[i]
        pre.append(Z)
        H = f(Z) if i < len(Ws) - 1 else Z
        acts.append(H)
    return pre, acts

def bwd(Ws, bs, X, Y, f, df):
    m = len(X)
    pre, acts = fwd(Ws, bs, X, f)
    D = (softmax(pre[-1]) - Y) / m
    gW = [None] * len(Ws)
    gb = [None] * len(Ws)
    for i in range(len(Ws) - 1, -1, -1):
        gW[i] = acts[i].T @ D
        gb[i] = D.sum(axis=0)
        if i > 0:
            D = (D @ Ws[i].T) * df(pre[i - 1])
    return gW, gb, ce(pre[-1], Y)

def train(Ws, bs, X, Y, f, df, lr, steps, B, rr, mom=0.9):
    vW = [np.zeros_like(w) for w in Ws]
    vb = [np.zeros_like(b) for b in bs]
    m = len(X)
    for t in range(steps):
        idx = rr.integers(0, m, min(B, m))
        gW, gb, _ = bwd(Ws, bs, X[idx], Y[idx], f, df)
        for i in range(len(Ws)):
            vW[i] = mom * vW[i] + gW[i]
            vb[i] = mom * vb[i] + gb[i]
            Ws[i] -= lr * vW[i]
            bs[i] -= lr * vb[i]
    return Ws, bs

def acc(Ws, bs, X, lab, f):
    _, a = fwd(Ws, bs, X, f)
    return float((a[-1].argmax(axis=1) == lab).mean())

def bwd_mixed(Ws, bs, X, Y, fs, dfs):

    pre, acts = fwd_mixed(Ws, bs, X, fs)

        gb[i] = D.sum(axis=0)
        if i > 0:
            D = (D @ Ws[i].T) * dfs[i - 1](pre[i - 1])
    return gW, gb

def fwd_res(Ws, bs, X, f):
    pre, ins, outs = [], [], [X]
    H = X
    for i in range(len(Ws)):
        Z = H @ Ws[i] + bs[i]
        pre.append(Z)
        ins.append(H)
        if i < len(Ws) - 1:
            A = f(Z)
            H = A + H if A.shape == H.shape else A
        else:
            H = Z
        outs.append(H)
    return pre, ins, outs

def bwd_res(Ws, bs, X, Y, f, df):
    m = len(X)
    pre, ins, outs = fwd_res(Ws, bs, X, f)
    L = len(Ws)
    D = (softmax(pre[-1]) - Y) / m
    gW = [None] * L
    gb = [None] * L
    for i in range(L - 1, -1, -1):
        Dz = D if i == L - 1 else D * df(pre[i])
        gW[i] = ins[i].T @ Dz
        gb[i] = Dz.sum(axis=0)
        Dnext = Dz @ Ws[i].T
        if i < L - 1 and ins[i].shape == outs[i + 1].shape:
            Dnext = Dnext + D
        D = Dnext
    return gW, gb
