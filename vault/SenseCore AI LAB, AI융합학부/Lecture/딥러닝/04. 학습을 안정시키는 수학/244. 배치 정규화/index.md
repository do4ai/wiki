# 244강. 배치 정규화

$243$강은 **시작점 하나**를 맞추는 방법이었습니다. 그런데 시작점은 한 번뿐입니다.

$$\text{학습이 진행되면 그 시작점이 어긋납니다}$$

가중치가 움직이면 $243$강의 분산 재귀식이 더 이상 성립하지 않습니다. 층마다 활성값의 크기가 다시 벌어지고, 그러면 **다시 초기화를 고쳐야 하는데 학습 중에는 그럴 수가 없습니다.**

$$\text{그러면 매 걸음 다시 맞추면 됩니다}$$

이 강의는 그 생각을 식으로 만듭니다. 배치 안에서 평균과 분산을 재서 **층 출력을 그때그때 표준화**합니다. 얻는 것과 잃는 것을 모두 재 봅니다.

## 이 강의에서 할 수 있게 되는 것
- 배치 정규화의 순전파를 네 단계로 쓸 수 있습니다.
- 정규화를 지나는 그래디언트를 유도하고 수치로 검증할 수 있습니다.
- 가중치 스케일 불변성과 유효 학습률을 계산할 수 있습니다.
- 배치 정규화가 무엇을 실제로 개선하는지 측정으로 가릴 수 있습니다.
- 배치 크기와 학습 추론 불일치가 어디서 오는지 설명할 수 있습니다.

## 문제 1. 배치 정규화가 무엇을 하는가

> **문제.** 정의부터 봅니다.
> ($1$) 네 단계로 정의하세요.
> ($2$) 표준화 뒤의 통계를 확인하세요.
> ($3$) 표현력이 줄지 않는지 보세요.
> ($4$) $243$강의 실험을 다시 하세요.

**생각의 실마리.** $243$강 문제 $1$의 재귀식은 **가중치 분산**을 손잡이로 삼아 활성 분산을 조절했습니다. 그런데 활성 분산을 직접 재서 나눠 버리면 **가중치가 무엇이든 상관없어집니다.**

**풀이.** ($1$) 네 단계로 정의합니다. 배치 $\mathcal{B}$의 한 열에 대해 다음과 같습니다.

$$\mu=\frac1m\sum_i x_i,\qquad \sigma^2=\frac1m\sum_i (x_i-\mu)^2$$

$$\hat{x}_i=\frac{x_i-\mu}{\sqrt{\sigma^2+\varepsilon}},\qquad y_i=\gamma\hat{x}_i+\beta$$

| 단계 | 식 | 무엇을 하나 |
|---|---|---|
| 평균 | $\mu$는 열평균 | 가운데로 옮김 |
| 분산 | $\sigma^2$은 열분산 | 퍼짐을 잼 |
| 표준화 | $\hat{x}=(x-\mu)/\sqrt{\sigma^2+\varepsilon}$ | 평균 $0$ 분산 $1$로 |
| 되돌리기 | $y=\gamma\hat{x}+\beta$ | 표현력을 돌려줌 |

**앞의 세 단계는 배치 안에서 계산합니다.** 그래서 **한 표본의 출력이 같은 배치의 다른 표본에 딸리게 됩니다.** 이것이 뒤에 나오는 모든 부작용의 뿌리입니다.

($2$) 표준화 뒤의 통계를 확인합니다. 평균 $3$이고 표준편차 $5$인 자료를 넣습니다.

| 무엇 | 처리 전 | 처리 후 |
|---|---|---|
| 열평균의 최대 절댓값 | $3.358884$ | $4.024558e-16$ |
| 열표준편차 최솟값 | $4.617018$ | $1.000000$ |
| 열표준편차 최댓값 | $5.467744$ | $1.000000$ |
| $1$에서 모자란 양 | | $2.345561e-07$ |

**처리 후 평균은 $10^{-16}$ 규모입니다.** 부동소수점이 낼 수 있는 만큼 $0$입니다.

**표준편차는 정확히 $1$이 아니라 $2.345561e-07$만큼 모자랍니다.** $\varepsilon$을 더했기 때문입니다. $\varepsilon$은 분산이 $0$인 열에서 나눗셈이 터지는 것을 막는 장치이고, 그 대가로 **표준화가 아주 조금 덜 됩니다.**

($3$) 표현력이 줄지 않는지 봅니다. $\gamma$와 $\beta$를 잘 고르면 원래 값이 그대로 나와야 합니다.

$$\gamma=\sqrt{\sigma^2+\varepsilon},\qquad \beta=\mu\quad\Longrightarrow\quad y=x$$

| 무엇 | 값 |
|---|---|
| 원본과의 최대 차이 | $3.552714e-15$ |

**표현할 수 있는 함수의 집합이 줄지 않습니다.** 배치 정규화를 넣는 것은 **제약을 거는 일이 아니라 좌표를 바꾸는 일**입니다.

($4$) $243$강의 실험을 다시 합니다. 폭 $256$이고 깊이 $10$입니다.

| 층 | $g=1$ 없이 | $g=1$ 있음 | $g=4$ 없이 | $g=4$ 있음 |
|---|---|---|---|---|
| $1$ | $0.582073$ | $0.583331$ | $1.164145$ | $0.583333$ |
| $5$ | $0.142975$ | $0.585587$ | $4.575186$ | $0.585594$ |
| $10$ | $0.023300$ | $0.584830$ | $23.858894$ | $0.584836$ |

**없는 쪽은 $0.023300$으로 꺼지거나 $23.858894$로 부풀어 오릅니다.** $243$강에서 본 그대로입니다.

**있는 쪽은 $g$가 네 배 달라져도 열째 층 값이 소수점 다섯째 자리까지 같습니다.**

**정규화가 가중치 스케일을 지워 버리기 때문입니다.** 왜 그런지는 문제 $3$에서 정확히 계산합니다.

**확인 1-1.** 배치 정규화의 네 단계를 순서대로 쓰세요.

*답.* 평균과 분산을 재고 표준화한 뒤 감마와 베타로 되돌립니다.

**확인 1-2.** 검산에서 표준화 뒤 표준편차가 $1$에서 모자란 양을 쓰세요.

*답.* $2.345561e-07$입니다.

**확인 1-3.** 검산에서 $g=1$과 $g=4$의 열째 층 값을 정규화 있을 때로 쓰세요.

*답.* $0.584830$과 $0.584836$입니다.

## 문제 2. 정규화를 지나는 그래디언트

> **문제.** 역전파를 유도합니다.
> ($1$) 무엇이 어려운지 보세요.
> ($2$) 정리한 식을 적으세요.
> ($3$) 수치 그래디언트와 맞추세요.
> ($4$) 틀린 구현이 무엇을 하는지 보세요.

**생각의 실마리.** 보통 층에서는 $x_i$가 $y_i$에만 영향을 줍니다. 그런데 여기서는 $x_i$가 $\mu$와 $\sigma^2$에도 들어갑니다. 그러면 $x_i$가 **배치의 모든 출력**에 영향을 줍니다. $231$강의 연쇄법칙을 쓸 때 **경로를 빠뜨리지 않는 것**이 전부입니다.

**풀이.** ($1$) 무엇이 어려운지 봅니다.

| 무엇 | 왜 어려운가 |
|---|---|
| 보통 층 | 한 표본이 한 표본에만 영향 |
| 정규화 층 | $\mu$와 $\sigma^2$이 배치 전체에 딸림 |
| 따라서 | 한 표본이 배치 전부에 영향 |
| 연쇄법칙에서 | 경로가 세 개로 갈라짐 |

**$x_i$는 직접 경로와 $\mu$를 통한 경로와 $\sigma^2$을 통한 경로로 세 번 나타납니다.**

($2$) 정리한 식을 적습니다. $s=\sqrt{\sigma^2+\varepsilon}$이고 $g_i=\partial L/\partial \hat{x}_i$입니다.

$$\frac{\partial L}{\partial x_i}=\frac{1}{m\,s}\left(m\,g_i-\sum_j g_j-\hat{x}_i\sum_j g_j\hat{x}_j\right)$$

| 항 | 어느 경로인가 |
|---|---|
| $m\,g_i$ | 직접 경로 |
| $-\sum_j g_j$ | $\mu$ 경로 |
| $-\hat{x}_i\sum_j g_j\hat{x}_j$ | $\sigma^2$ 경로 |

$\gamma$와 $\beta$의 그래디언트는 훨씬 쉽습니다.

$$\frac{\partial L}{\partial \gamma}=\sum_i \frac{\partial L}{\partial y_i}\hat{x}_i,\qquad \frac{\partial L}{\partial \beta}=\sum_i \frac{\partial L}{\partial y_i}$$

**두 번째와 세 번째 항이 없으면 그것이 곧 흔한 구현 실수입니다.** $\mu$와 $\sigma^2$을 **상수로 취급**한 것과 같습니다.

($3$) 수치 그래디언트와 맞춥니다. 배치 $16$에 열 $5$개입니다.

| 무엇 | 최대 절대오차 | 상대오차 |
|---|---|---|
| 정리한 식 | $1.919608e-09$ | $4.379636e-09$ |
| $\mu$와 $\sigma^2$을 상수 취급 | $1.889135e-01$ | $4.310111e-01$ |

**정리한 식은 중심차분과 $10^{-9}$까지 맞습니다.** 차분 폭이 $10^{-6}$이므로 이것이 도달할 수 있는 정확도입니다.

**상수 취급한 쪽은 상대오차가 $0.43$입니다.** 크기가 절반쯤 틀린 벡터입니다.

($4$) 틀린 구현이 무엇을 하는지 봅니다.

| 무엇 | 값 |
|---|---|
| 상수 취급과 참값의 코사인 | $0.892938$ |
| 정리한 식과 참값의 코사인 | $1.000000$ |

**코사인이 $0.892938$입니다.** 방향이 크게 어긋났는데도 **참값과 같은 반구 안에** 있습니다. 내림 방향인 것은 맞다는 뜻입니다.

**그래서 처음에는 손실이 내려갑니다.** 학습이 되는 것처럼 보이다가 나중에 수렴이 멈추거나 엉뚱한 곳에 갑니다. **구현 실수 중에 가장 늦게 드러나는 종류**이고, 그래서 수치 그래디언트 검사가 필요합니다.

**확인 2-1.** 정규화 역전파에서 경로가 몇 개로 갈라지는지 쓰세요.

*답.* 직접 경로와 평균 경로와 분산 경로로 세 개입니다.

**확인 2-2.** 검산에서 정리한 식과 상수 취급의 상대오차를 쓰세요.

*답.* $4.379636e-09$와 $4.310111e-01$입니다.

**확인 2-3.** 검산에서 상수 취급한 그래디언트와 참값의 코사인을 쓰세요.

*답.* $0.892938$입니다.

## 문제 3. 가중치 스케일이 사라집니다

> **문제.** 스케일을 바꿔 봅니다.
> ($1$) 가중치를 $c$배 하면 출력이 어떻게 되는지 보세요.
> ($2$) 그래디언트가 어떻게 되는지 보세요.
> ($3$) 유효 학습률을 계산하세요.
> ($4$) 무엇이 따라오는지 정리하세요.

**생각의 실마리.** 표준화는 **평균을 빼고 표준편차로 나눕니다.** 입력 전체에 $c$를 곱하면 평균도 $c$배, 표준편차도 $c$배가 되므로 **비율이 그대로**입니다.

**풀이.** ($1$)($2$) 가중치를 $c$배 하고 출력과 그래디언트를 함께 잽니다.

$$\mathrm{BN}(cz)=\mathrm{BN}(z),\qquad \frac{\partial L}{\partial (cW)}=\frac1c\frac{\partial L}{\partial W}$$

| $c$ | 출력 최대 차이 | 그래디언트 노름 비 | $1/c$ |
|---|---|---|---|
| $0.1$ | $1.544523e-03$ | $9.995644$ | $10.000000$ |
| $1.0$ | $0.000000e+00$ | $1.000000$ | $1.000000$ |
| $10.0$ | $1.545838e-05$ | $0.100000$ | $0.100000$ |
| $100.0$ | $1.561297e-05$ | $0.010000$ | $0.010000$ |

**$c$가 $10$과 $100$이면 그래디언트 노름 비가 $1/c$와 소수점 여섯 자리까지 맞습니다.**

**$c=0.1$에서만 $9.995644$로 조금 어긋납니다.** 분산이 $100$분의 $1$이 되어 **$\varepsilon$이 더 이상 무시되지 않기** 때문입니다. 스케일 불변성은 $\sigma^2\gg\varepsilon$일 때만 성립합니다.

($3$) 유효 학습률을 계산합니다. 출력이 $W$의 **방향에만** 딸리므로 의미 있는 갱신은 방향의 변화뿐입니다.

$$\lVert\Delta W\rVert\propto\frac{\eta}{\lVert W\rVert},\qquad \Big\lVert\Delta\frac{W}{\lVert W\rVert}\Big\rVert\propto\frac{\eta}{\lVert W\rVert^{2}}$$

| 가중치 노름 | 절대 갱신 | 방향 변화 |
|---|---|---|
| $0.5$ | $0.020770$ | $0.041513$ |
| $1.0$ | $0.010388$ | $0.010387$ |
| $2.0$ | $0.005194$ | $0.002597$ |
| $4.0$ | $0.002597$ | $0.000649$ |

**노름이 여덟 배 되는 동안 절대 갱신은 여덟 분의 $1$이 됩니다.** $0.020770$에서 $0.002597$이고 정확히 $8.00$배입니다.

**방향 변화는 $64$분의 $1$이 됩니다.** $0.041513$에서 $0.000649$이고 $63.96$배입니다. 제곱으로 줄어든다는 예측과 맞습니다.

($4$) 무엇이 따라오는지 정리합니다.

| 무엇 | 왜 |
|---|---|
| 초기화 스케일이 무의미 | 출력이 같음 |
| 가중치 감쇠가 다르게 작동 | 노름만 줄임 |
| 학습이 진행되면 노름이 커짐 | 유효 학습률이 저절로 내려감 |
| 학습률 감쇠를 덜 써도 됨 | 위 줄의 효과 |

**셋째 줄이 배치 정규화가 학습률에 덜 민감한 첫째 이유입니다.** 노름이 커지면서 **학습률 일정 계획이 저절로 생깁니다.**

**둘째 줄은 주의할 점입니다.** 가중치 감쇠는 원래 큰 가중치에 벌점을 주는 장치인데, 배치 정규화 뒤에서는 출력이 노름과 무관하므로 **벌점이 유효 학습률을 올리는 장치로 바뀝니다.**

**확인 3-1.** 배치 정규화 뒤 층에서 가중치를 $c$배 하면 출력이 어떻게 되는지 쓰세요.

*답.* 그대로입니다.

**확인 3-2.** 검산에서 $c=10$일 때 그래디언트 노름 비를 쓰세요.

*답.* $0.100000$입니다.

**확인 3-3.** 검산에서 노름 $0.5$와 $4.0$의 방향 변화를 쓰세요.

*답.* $0.041513$과 $0.000649$입니다.

## 문제 4. 무엇이 실제로 좋아지는가

> **문제.** 재 봅니다.
> ($1$) 학습률 구간이 넓어지는지 보세요.
> ($2$) 초기화 구간이 넓어지는지 보세요.
> ($3$) 손실면이 평평해지는지 재세요.
> ($4$) 분포 이동이 줄어드는지 재세요.

**생각의 실마리.** "배치 정규화가 좋다"는 말은 **무엇이 얼마나 좋아지는지**를 정하지 않으면 검증할 수 없습니다. 네 가지 후보를 각각 숫자로 잽니다.

**풀이.** ($1$) 학습률 구간을 봅니다. 깊이 $12$에 폭 $64$이고 $g=2$이며 걸음 $3000$입니다.

| 학습률 | 정규화 없이 | 정규화 있음 |
|---|---|---|
| $0.003$ | $0.580000$ | $0.532667$ |
| $0.010$ | $0.614000$ | $0.615333$ |
| $0.030$ | $0.662667$ | $0.706667$ |
| $0.100$ | $0.795333$ | $0.790000$ |
| $0.300$ | $0.873333$ | $0.785333$ |
| $1.000$ | 발산 | $0.809333$ |
| $3.000$ | 발산 | $0.839333$ |
| $0.7$ 넘는 칸 수 | $2$ | $5$ |

**없는 쪽은 학습률 $1.0$에서 이미 발산합니다.** 있는 쪽은 $3.0$까지 버팁니다.

**$0.7$을 넘는 칸이 $2$개에서 $5$개로 늘었습니다.** 쓸 만한 학습률의 구간 자체가 넓어진 것입니다.

**최고점은 오히려 없는 쪽이 높습니다.** $0.873333$과 $0.839333$입니다. 이 차이를 그대로 적어 둡니다.

($2$) 초기화 구간을 봅니다. $243$강 문제 $4$를 정규화를 켜고 다시 합니다.

| $g$ | 정규화 없이 | 정규화 있음 |
|---|---|---|
| $0.25$ | $0.333333$ | $0.860000$ |
| $1.00$ | $0.884667$ | $0.841333$ |
| $4.00$ | $0.420667$ | $0.824000$ |
| $16.00$ | 발산 | $0.848667$ |

**없는 쪽은 $g$가 $0.25$이거나 $16$이면 무너집니다.** 찍기와 같거나 발산합니다.

## 심화 문제

> **심화 1.** 세 경로 그래디언트를 처음부터 유도하세요.

$\hat{x}_i=(x_i-\mu)/s$이고 $s=\sqrt{\sigma^2+\varepsilon}$입니다.

$$\frac{\partial L}{\partial \sigma^2}=\sum_i g_i(x_i-\mu)\cdot\left(-\frac{1}{2}\right)(\sigma^2+\varepsilon)^{-3/2}=-\frac{1}{2s}\sum_i g_i\hat{x}_i$$

$$\frac{\partial L}{\partial \mu}=-\frac1s\sum_i g_i$$

| 단계 | 무엇을 씀 |
|---|---|
| 분산 경로 | $\partial s/\partial\sigma^2$ |
| 평균 경로 | $\sigma^2$이 $\mu$에 딸림 |
| 셋을 합침 | 연쇄법칙 |

세 항을 모으면 문제 $2$의 식이 나옵니다. **평균 경로 안에도 분산이 들어 있어** 실제로는 항이 하나 더 있는데, $\sum_i(x_i-\mu)=0$이라 사라집니다.

**그 소거가 식이 짧아 보이는 이유입니다.**

def bn_fwd(X, gam, bet):
    mu = X.mean(axis=0)

    Xh = (X - mu) / sd

def bn_bwd(dY, cache):
    Xh, sd, gam = cache

    dX = (m * dXh - dXh.sum(axis=0) - Xh * (dXh * Xh).sum(axis=0)) / (m * sd)
    return dX, dg, db


def bn_bwd_naive(dY, cache):
    Xh, sd, gam = cache
    return dY * gam / sd, (dY * Xh).sum(axis=0), dY.sum(axis=0)

    ins, pre, cs, raw = [], [], [], []
    H = X
    for i in range(len(Ws)):
        ins.append(H)
        Z = H @ Ws[i] + bs[i]
        raw.append(Z)
        if use_bn and i < len(Ws) - 1:
            Z, c = bn_fwd(Z, gm[i], bt[i])
            cs.append(c)
        else:
            cs.append(None)
        pre.append(Z)
        H = relu(Z) if i < len(Ws) - 1 else Z
    return ins, pre, cs, raw


def net_step(P, X, Y, lr, use_bn):
    Ws, bs, gm, bt = P
    m = len(X)
    ins, pre, cs, _ = net_fwd(P, X, use_bn)
    if not np.isfinite(pre[-1]).all():
        return False
    D = (softmax(pre[-1]) - Y) / m
    for i in range(len(Ws) - 1, -1, -1):
        Dz = D if i == len(Ws) - 1 else D * drelu(pre[i])
        if use_bn and i < len(Ws) - 1:
            Dz, dg, db = bn_bwd(Dz, cs[i])
            gm[i] -= lr * dg
            bt[i] -= lr * db
        gW = ins[i].T @ Dz
        gb = Dz.sum(axis=0)
        D = Dz @ Ws[i].T
        Ws[i] -= lr * gW
        bs[i] -= lr * gb
    return True


def run(g, use_bn, lr, depth=12, width=64, steps=3000, seed=7):
    P = build(g, depth, width, seed)
    r = np.random.default_rng(21)
    for t in range(steps):
        idx = r.integers(0, len(Xtr), 64)
        if not net_step(P, Xtr[idx], Ytr[idx], lr, use_bn):
            return -1.0
    _, pre, _, _ = net_fwd(P, Xte, use_bn)
    if not np.isfinite(pre[-1]).all():
        return -1.0
    return float((pre[-1].argmax(axis=1) == yte).mean())

def probe(use_bn, seed=7):
    P = build(2.0, 8, 64, seed)
    r = np.random.default_rng(21)
    for t in range(300):
        idx = r.integers(0, len(Xtr), 64)
        net_step(P, Xtr[idx], Ytr[idx], 0.03, use_bn)
    Ws, bs, gm, bt = P
    idx = r.integers(0, len(Xtr), 256)
    xb, yb = Xtr[idx], Ytr[idx]

    def Lof(Wl):
        Q = (Wl, bs, gm, bt)
        _, pre, _, _ = net_fwd(Q, xb, use_bn)
        P2 = softmax(pre[-1])
        return float(-np.log(np.clip((P2 * yb).sum(axis=1), 1e-12, None)).mean())

    W0 = [w.copy() for w in Ws]
    base = Lof(W0)
    G = []
    ins, pre, cs, _ = net_fwd(P, xb, use_bn)
    D = (softmax(pre[-1]) - yb) / len(xb)
    for i in range(len(Ws) - 1, -1, -1):
        Dz = D if i == len(Ws) - 1 else D * drelu(pre[i])
        if use_bn and i < len(Ws) - 1:
            Dz, _, _ = bn_bwd(Dz, cs[i])
        G.append(ins[i].T @ Dz)
        D = Dz @ Ws[i].T
    G = G[::-1]
    gn = np.sqrt(sum((g ** 2).sum() for g in G))
    out = []
    for t in (0.01, 0.1, 0.3, 1.0):
        Wt = [W0[i] - t * G[i] / gn for i in range(len(W0))]
        out.append(Lof(Wt) - base)
    return base, gn, out
