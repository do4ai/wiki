# 245강. 층 정규화와 잔차 연결

$244$강은 층 출력의 크기를 매 걸음 되돌리는 방법이었습니다. 그런데 그 방법은 통계를 **배치 안에서** 냈습니다.

$$\text{한 표본의 출력이 같은 배치의 다른 표본에 딸립니다}$$

이 한 문장에서 작은 배치의 흔들림과 학습 추론 불일치와 순환 신경망에서의 곤란이 모두 나왔습니다. 파라미터를 손봐서 풀리는 문제가 아닙니다.

$$\text{통계를 재는 축을 바꾸면 됩니다}$$

이 강의는 배치 축 대신 **특징 축**에서 평균과 분산을 냅니다. 그리고 그것이 $242$강의 잔차 연결과 어떻게 맞물리는지, 정규화를 잔차 블록의 **어디에** 두어야 하는지를 봅니다.

## 이 강의에서 할 수 있게 되는 것
- 층 정규화와 배치 정규화의 차이를 축으로 설명할 수 있습니다.
- 층 정규화의 그래디언트를 유도하고 수치로 검증할 수 있습니다.
- 각 정규화가 어떤 변환에 대해 불변인지 가릴 수 있습니다.
- 잔차 블록에서 정규화를 앞에 둘지 뒤에 둘지 근거를 대고 정할 수 있습니다.
- 제곱평균 정규화가 무엇을 생략하고 무엇을 아끼는지 설명할 수 있습니다.

## 문제 1. 축을 바꾸면 무엇이 달라지는가

> **문제.** 축을 바꿔 봅니다.
> ($1$) 두 정규화가 어느 축에서 통계를 내는지 정리하세요.
> ($2$) 정규화 뒤 통계를 확인하세요.
> ($3$) 한 표본을 바꾸면 다른 표본이 흔들리는지 보세요.
> ($4$) 각 정규화가 무엇에 대해 불변인지 보세요.

**생각의 실마리.** 자료는 표본이 행이고 특징이 열인 행렬입니다. 평균을 낼 때 **열마다 낼 수도 있고 행마다 낼 수도 있습니다.** $244$강은 열마다 냈습니다. 이 강의는 행마다 냅니다.

**풀이.** ($1$) 두 정규화를 나란히 둡니다.

$$\mu_{\text{배치}}=\frac1m\sum_{i=1}^{m}x_{ij},\qquad \mu_{\text{층}}=\frac1n\sum_{j=1}^{n}x_{ij}$$

| 무엇 | 배치 정규화 | 층 정규화 |
|---|---|---|
| 평균을 내는 축 | 표본 방향이며 열마다 냅니다 | 특징 방향이며 행마다 냅니다 |
| 통계의 개수 | 특징 수만큼 | 표본 수만큼 |
| 배치 크기 영향 | 있습니다 | 없습니다 |
| 학습과 추론 | 다른 함수입니다 | 같은 함수입니다 |

**같은 행렬을 가로로 자르느냐 세로로 자르느냐의 차이뿐입니다.** 그런데 그 하나에서 **배치 의존과 모드 불일치가 통째로 사라집니다.**

($2$) 정규화 뒤 통계를 확인합니다. 평균 $3$이고 표준편차 $5$인 자료를 넣었습니다.

| 무엇 | 열평균 최대 | 행평균 최대 |
|---|---|---|
| 배치 정규화 | $2.793e-16$ | $6.098e-01$ |
| 층 정규화 | $3.298e-01$ | $1.665e-16$ |

**두 줄이 정확히 반대입니다.** 배치 정규화는 열평균만 $0$이고 행평균은 $0.6$가량 남습니다. 층 정규화는 행평균만 $0$입니다.

($3$) 한 표본을 바꾸면 다른 표본이 흔들리는지 봅니다. 첫 표본에만 $20$을 더했습니다.

| 무엇 | 바꾼 표본의 변화 | 나머지 표본의 변화 |
|---|---|---|
| 배치 정규화 | $4.490163$ | $5.979545e-01$ |
| 층 정규화 | $0.000000$ | $0.000000e+00$ |

**배치 정규화에서는 한 표본을 건드리면 나머지 $63$개가 모두 흔들립니다.** 변화량이 $0.6$에 가깝습니다.

**층 정규화에서는 나머지가 정확히 $0$만큼 흔들립니다.** 부동소수점 오차조차 없습니다. 각 행이 자기 행의 통계만 쓰기 때문입니다.

**배치 안 표본들이 서로 독립인 것이 층 정규화의 정의상 성질입니다.** $244$강 문제 $5$의 부작용 목록이 여기서 한꺼번에 사라집니다.

($4$) 각 정규화가 무엇에 대해 불변인지 봅니다. 제곱평균 정규화는 평균 빼기를 생략한 변형입니다.

| 변환 | 배치 정규화 | 층 정규화 | 제곱평균 정규화 |
|---|---|---|---|
| 모든 원소에 $c$ 곱하기 | $1.848e-05$ | $2.856e-05$ | $2.815e-05$ |
| 모든 원소에 $b$ 더하기 | $9.992e-16$ | $8.882e-16$ | $2.257e+00$ |
| 한 행에만 $c$ 곱하기 | $2.144e+00$ | $7.158e-06$ | $7.378e-06$ |
| 한 열에만 $c$ 곱하기 | $7.005e-06$ | $1.825e+00$ | $1.587e+00$ |

**전체 곱하기 열은 셋 다 $10^{-5}$ 규모입니다.** $\varepsilon$ 때문에 정확히 $0$은 아닙니다.

**전체 더하기에는 제곱평균 정규화만 불변이 아닙니다.** $2.257e+00$입니다. 평균을 빼지 않기 때문입니다.

**셋째 줄과 넷째 줄이 이 표의 핵심입니다.** 한 행에만 곱한 것은 **층 정규화가 흡수**하고, 한 열에만 곱한 것은 **배치 정규화가 흡수**합니다. 어느 방향의 스케일 변동을 지울 것인지가 축 선택의 실질입니다.

**확인 1-1.** 자리표시입니다.

*답.* 자리표시입니다.

**확인 1-2.** 자리표시입니다.

*답.* 자리표시입니다.

## 문제 2. 층 정규화의 그래디언트

> **문제.** 역전파를 옮깁니다.
> ($1$) $244$강 식에서 무엇만 바뀌는지 보세요.
> ($2$) 세 정규화를 수치 그래디언트와 맞추세요.
> ($3$) 야코비가 무엇을 지우는지 보세요.
> ($4$) $\varepsilon$이 무엇을 바꾸는지 보세요.

**생각의 실마리.** $244$강 문제 $2$의 유도에서 배치라는 말을 **특징**으로, 열이라는 말을 **행**으로 바꾸면 그대로입니다. 유도가 쓴 것은 축의 이름이 아니라 **합해지는 방향** 하나뿐이었기 때문입니다.

**풀이.** ($1$) 무엇만 바뀌는지 봅니다. $m$을 특징 수 $n$으로 바꾸고 합을 행 방향으로 바꿉니다.

$$\frac{\partial L}{\partial x_{ij}}=\frac{1}{n\,s_i}\left(n\,g_{ij}-\sum_{k} g_{ik}-\hat{x}_{ij}\sum_{k} g_{ik}\hat{x}_{ik}\right)$$

| 무엇 | 배치 정규화 | 층 정규화 |
|---|---|---|
| 나누는 수 | 배치 크기 $m$ | 특징 수 $n$ |
| 합의 방향 | 열 방향 | 행 방향 |
| $s$의 개수 | 특징마다 하나 | 표본마다 하나 |

**제곱평균 정규화는 평균을 안 빼므로 가운데 항이 사라집니다.** 경로가 세 개에서 두 개로 줄어듭니다.

($2$) 세 정규화를 수치 그래디언트와 맞춥니다.

| 정규화 | 최대 절대오차 | 상대오차 |
|---|---|---|
| 배치 정규화 | $1.854184e-09$ | $8.940596e-10$ |
| 층 정규화 | $1.201732e-09$ | $4.708739e-10$ |
| 제곱평균 정규화 | $9.412583e-10$ | $4.803379e-10$ |

**세 식 모두 중심차분과 $10^{-9}$ 규모까지 맞습니다.** 차분 폭이 $10^{-6}$이므로 이것이 검사가 도달할 수 있는 한계입니다.

($3$)($4$) 야코비가 무엇을 지우는지 봅니다. 한 행의 야코비를 직접 만들어 특이값을 봤습니다.

$$\frac{\partial \hat{x}}{\partial x}=\frac{1}{s}\left(I-\frac1n\mathbf{1}\mathbf{1}^{\top}-\frac1n\hat{x}\hat{x}^{\top}\right)$$

| 정규화 | $\varepsilon$ | 계수 | 가장 작은 특이값 | 둘째로 작은 특이값 |
|---|---|---|---|---|
| 층 정규화 | $10^{-5}$ | $11$ | $1.353e-10$ | $9.634e-06$ |
| 층 정규화 | $0$ | $10$ | $1.040e-10$ | $2.401e-10$ |
| 제곱평균 정규화 | $10^{-5}$ | $12$ | $9.230e-06$ | $9.737e-01$ |
| 제곱평균 정규화 | $0$ | $11$ | $6.850e-11$ | $9.737e-01$ |

**$\varepsilon$을 끄면 층 정규화의 계수가 $10$이고 제곱평균 정규화는 $11$입니다.** 차원이 $12$였으므로 각각 두 방향과 한 방향이 지워진 것입니다.

**층 정규화는 상수 방향과 스케일 방향 두 개를 지우고 제곱평균 정규화는 스케일 방향 하나만 지웁니다.** 평균을 빼지 않으니 상수 방향이 살아남습니다.

**$\varepsilon$을 켜면 스케일 방향이 완전히 지워지지 않고 $10^{-5}$ 규모의 특이값으로 남습니다.** 그래서 실제 구현의 계수는 각각 $11$과 $12$로 하나씩 늘어납니다.

**층 정규화의 가장 작은 특이값은 두 경우 모두 $0$에 붙습니다.** $1.353e-10$과 $1.040e-10$입니다. 평균 빼기는 $\varepsilon$과 무관하게 정확하기 때문입니다.

**확인 2-1.** 자리표시입니다.

*답.* 자리표시입니다.

**확인 2-2.** 자리표시입니다.

*답.* 자리표시입니다.

## 문제 3. 배치 크기에 대한 의존

> **문제.** 배치를 흔들어 봅니다.
> ($1$) 배치 크기만 바꿔 셋을 견주세요.
> ($2$) 학습과 추론이 같은 함수인지 확인하세요.
> ($3$) 무엇이 사라졌는지 정리하세요.
> ($4$) 무엇을 잃었는지도 정리하세요.

**생각의 실마리.** $244$강 문제 $5$의 ($1$)에서 배치 통계의 추정 오차가 $1/\sqrt{m}$로 줄어드는 것을 봤습니다. 층 정규화의 통계는 배치가 아니라 **특징 수**로 나눈 것이므로, 배치를 줄여도 그 오차가 커지지 않아야 합니다.

**풀이.** ($1$) 배치 크기만 바꿔 견줍니다. 깊이 $8$에 폭 $64$이고 걸음 수는 $2000$으로 같습니다. 학습률은 각자 최선을 씁니다.

| 배치 크기 | 정규화 없음 | 배치 정규화 | 층 정규화 |
|---|---|---|---|
| $2$ | $0.772000$ | $0.346667$ | $0.732000$ |
| $4$ | $0.803333$ | $0.590000$ | $0.780667$ |
| $16$ | $0.850000$ | $0.815333$ | $0.851333$ |
| $64$ | $0.870000$ | $0.770000$ | $0.861333$ |
| $256$ | $0.852000$ | $0.684667$ | $0.816667$ |

**배치 $2$에서 배치 정규화만 $0.346667$로 무너집니다.** 세 부류이므로 찍기와 다름없습니다.

**층 정규화는 같은 자리에서 $0.732000$입니다.** 배치를 키워도 $0.72$와 $0.86$ 사이에 머뭅니다.

**이 문제는 깊이 $8$이라 정규화 없이도 잘 되므로 정규화 없음 열이 대체로 가장 높습니다.** 이 표가 말하는 것은 **정규화의 이득이 아니라 배치 의존의 유무**입니다. $244$강의 결론이 여기서도 그대로입니다.

($2$) 학습과 추론이 같은 함수인지 확인합니다. 같은 표본을 서로 다른 배치에 섞어 넣었습니다.

| 무엇 | 다른 배치와 섞을 때 | 혼자 넣을 때와의 차 |
|---|---|---|
| 배치 정규화 | $8.761193e-01$ | $1.810627e+00$ |
| 층 정규화 | $0.000000e+00$ | $0.000000e+00$ |

**층 정규화는 배치 구성이 무엇이든 출력이 완전히 같습니다.** 그래서 **학습 모드와 추론 모드를 나눌 필요 자체가 없습니다.** 이동평균을 들고 다닐 이유도, 모드를 바꾸는 것을 잊어버릴 위험도 사라집니다.

($3$) 무엇이 사라졌는지 정리합니다.

| $244$강의 문제 | 층 정규화에서 |
|---|---|
| 작은 배치에서 흔들림 | 사라집니다 |
| 학습과 추론이 다른 함수 | 사라집니다 |
| 배치 방향 계수가 $m-2$ | 사라집니다 |
| 순환 신경망에서 못 씀 | 사라집니다 |
| 장치를 나누면 통계를 모아야 함 | 사라집니다 |

**다섯 가지가 한꺼번에 사라집니다.** 하나의 선택에서 나온 결과들이었기 때문입니다.

($4$) 무엇을 잃었는지도 정리합니다.

| 무엇 | 왜 |
|---|---|
| 배치 잡음에 의한 정칙화 | 잡음의 출처가 없어짐 |
| 특징마다 다른 스케일 정보 | 행 안에서 모두 표준화됨 |
| 열 방향 스케일 변동 흡수 | 문제 $1$의 넷째 줄 |

**첫 줄은 $244$강 심화 $2$에서 본 부수효과입니다.** 공짜로 얻던 것이었으므로 잃어도 티가 크게 나지는 않지만, 정칙화를 다른 데서 보충해야 할 수는 있습니다.

**둘째 줄이 더 중요합니다.** 특징마다 단위가 다른 표 형태 자료에서는 행 안에서 섞어 표준화하는 것이 어색합니다. 층 정규화가 언어모형에서 잘 듣고 표 자료에서 덜 쓰이는 이유입니다.

**확인 3-1.** 자리표시입니다.

*답.* 자리표시입니다.

**확인 3-2.** 자리표시입니다.

*답.* 자리표시입니다.

## 문제 4. 잔차 연결과 정규화를 어디에 두는가

> **문제.** 자리를 정합니다.
> ($1$) 두 배치를 정의하세요.
> ($2$) 깊이를 늘려 가며 견주세요.
> ($3$) 학습률을 바꿔 가며 견주세요.
> ($4$) 순전파 크기를 재세요.

**생각의 실마리.** $242$강 심화 $2$에서 잔차 연결의 야코비를 전개해 **항등 경로**가 항상 남는다는 것을 봤습니다. 그런데 그 경로 위에 정규화를 놓으면 항등이 아니게 됩니다. 어디에 놓느냐가 그래서 문제가 됩니다.

**풀이.** ($1$) 두 배치를 정의합니다.

$$\text{나중 정규화: } \mathrm{Norm}\big(x+F(x)\big),\qquad \text{먼저 정규화: } x+F\big(\mathrm{Norm}(x)\big)$$

| 이름 | 한 블록의 식 | 항등 경로 |
|---|---|---|
| 나중 정규화 | 더한 뒤 정규화합니다 | 정규화를 거칩니다 |
| 먼저 정규화 | 가지 안에서만 정규화합니다 | 그대로 남습니다 |

**나중 정규화는 원 논문 방식이고 먼저 정규화는 나중에 널리 쓰이게 된 방식입니다.**

**먼저 정규화에서는 입력에서 출력까지 정규화를 한 번도 거치지 않는 길이 있습니다.**

($2$) 깊이를 늘려 가며 견줍니다. 폭 $64$이고 걸음 $2000$이며 학습률은 각자 최선을 씁니다.

**핵심 식을 한자리에 모읍니다.**

$$\hat{x}_{ij}=\frac{x_{ij}-\mu_i}{\sqrt{\sigma_i^2+\varepsilon}},\qquad \mu_i=\frac1n\sum_j x_{ij},\qquad \text{먼저 정규화: } x+\frac{1}{\sqrt{L}}F\big(\mathrm{Norm}(x)\big)$$

| 무엇을 얻나 | 무엇을 치르나 |
|---|---|
| 배치 크기와 무관 | 배치 잡음 정칙화를 잃음 |
| 학습과 추론이 같은 함수 | 특징 사이 스케일 정보를 잃음 |
| 순차열과 순환 구조에 쓸 수 있음 | 열 방향 변동을 못 흡수함 |
| 깊은 잔차망을 감당함 | 항등 경로가 깊이에 따라 자람 |

| 기호 | 읽는 법 | 뜻 |
|---|---|---|

def jac_of(f, x, n=12):
    J = np.zeros((n, n))
    h = 1e-6
    for j in range(n):
        xp = x.copy(); xp[j] += h
        xm = x.copy(); xm[j] -= h
        yp, _ = f(xp[None, :], np.ones(n), np.zeros(n))
        ym, _ = f(xm[None, :], np.ones(n), np.zeros(n))
        J[:, j] = (yp[0] - ym[0]) / (2 * h)
    return J

def make_data(n, seed):

    X = r.normal(0, 1, (n, 20))
    s = X[:, 0] + 0.8 * X[:, 1] ** 2 - 0.6 * X[:, 2] * X[:, 3] + 0.5 * X[:, 4]
    q = np.quantile(s, [1 / 3, 2 / 3])
    y = (s > q[0]).astype(int) + (s > q[1]).astype(int)
    Y = np.zeros((n, 3))
    Y[np.arange(n), y] = 1.0
    return X, Y, y

def build(g, depth, width, seed):
    r = np.random.default_rng(seed)
    dims = [20] + [width] * depth + [3]
    Ws = [r.normal(0, np.sqrt(g / dims[i]), (dims[i], dims[i + 1])) for i in range(len(dims) - 1)]
    bs = [np.zeros(dims[i + 1]) for i in range(len(dims) - 1)]
    gm = [np.ones(dims[i + 1]) for i in range(len(dims) - 1)]
    bt = [np.zeros(dims[i + 1]) for i in range(len(dims) - 1)]
    return Ws, bs, gm, bt


def net_fwd(P, X, norm, res=False, scale=1.0):
    Ws, bs, gm, bt = P
    ins, pre, cs, outs = [], [], [], []
    H = X
    f = NORMS[norm]
    for i in range(len(Ws)):
        ins.append(H)
        Z = H @ Ws[i] + bs[i]
        if f is not None and i < len(Ws) - 1:
            Z, c = f(Z, gm[i], bt[i])
            cs.append(c)
        else:
            cs.append(None)
        pre.append(Z)
        if i < len(Ws) - 1:
            H = relu(Z) * scale
            if res and ins[i].shape == H.shape:
                H = H + ins[i]
        else:
            H = Z
        outs.append(H)
    return ins, pre, cs, outs


def net_step(P, X, Y, lr, norm, res=False, scale=1.0):
    Ws, bs, gm, bt = P
    m = len(X)
    ins, pre, cs, outs = net_fwd(P, X, norm, res, scale)
    if not np.isfinite(pre[-1]).all():
        return False
    D = (softmax(pre[-1]) - Y) / m
    Lw = len(Ws)
    for i in range(Lw - 1, -1, -1):
        if i == Lw - 1:
            Dz = D
        else:
            Dz = D * drelu(pre[i]) * scale
        if cs[i] is not None:
            Dz, dg, db = norm_bwd(Dz, cs[i])
            gm[i] -= lr * dg
            bt[i] -= lr * db
        gW = ins[i].T @ Dz
        gb = Dz.sum(axis=0)
        Dnext = Dz @ Ws[i].T
        if res and i < Lw - 1 and ins[i].shape == outs[i].shape:
            Dnext = Dnext + D
        D = Dnext
        Ws[i] -= lr * gW
        bs[i] -= lr * gb
    return True


def run(norm, lr, bsz=64, depth=8, width=64, steps=2000, g=2.0, seed=7, res=False, scale=1.0):

    return float((pre[-1].argmax(axis=1) == yte).mean())

def rbuild(depth, width, seed, g=2.0):
    r = np.random.default_rng(seed)
    Win = r.normal(0, np.sqrt(g / 20), (20, width))
    Wb = [r.normal(0, np.sqrt(g / width), (width, width)) for _ in range(depth)]
    Wout = r.normal(0, np.sqrt(g / width), (width, 3))
    gm = [np.ones(width) for _ in range(depth)]
    bt = [np.zeros(width) for _ in range(depth)]
    return [Win, Wb, Wout, gm, bt]


def rfwd(P, X, mode, scale=1.0):
    Win, Wb, Wout, gm, bt = P
    H = X @ Win
    tape = []
    for i in range(len(Wb)):
        if mode == 'pre':
            N, c = ln_fwd(H, gm[i], bt[i])
            A = N @ Wb[i]
            U = relu(A) * scale
            out = H + U
            tape.append((H, c, N, A, None))
        elif mode == 'post':
            A = H @ Wb[i]
            U = relu(A) * scale
            Sm = H + U
            out, c = ln_fwd(Sm, gm[i], bt[i])
            tape.append((H, c, None, A, Sm))
        else:
            A = H @ Wb[i]
            U = relu(A) * scale
            out = H + U
            tape.append((H, None, None, A, None))
        H = out
    return H @ Wout, H, tape


def rstep(P, X, Y, lr, mode, scale=1.0):
    Win, Wb, Wout, gm, bt = P
    m = len(X)
    Z, Hlast, tape = rfwd(P, X, mode, scale)
    if not np.isfinite(Z).all():
        return False
    D = (softmax(Z) - Y) / m
    gWout = Hlast.T @ D
    dH = D @ Wout.T
    for i in range(len(Wb) - 1, -1, -1):
        Hin, c, N, A, Sm = tape[i]
        if mode == 'post':
            dS, dg, db = norm_bwd(dH, c)
            gm[i] -= lr * dg
            bt[i] -= lr * db
            dU = dS
            dskip = dS
        else:
            dU = dH
            dskip = dH
        dA = dU * drelu(A) * scale
        if mode == 'pre':
            gW = N.T @ dA
            dN = dA @ Wb[i].T
            dHin, dg, db = norm_bwd(dN, c)
            gm[i] -= lr * dg
            bt[i] -= lr * db
            dH = dHin + dskip
        else:
            gW = Hin.T @ dA
            dH = dA @ Wb[i].T + dskip
        Wb[i] -= lr * gW
    Win -= lr * (X.T @ dH)
    Wout -= lr * gWout
    return True


def rrun(depth, mode, lr, scale=1.0, width=64, steps=2000, seed=7):
    P = rbuild(depth, width, seed)
    r = np.random.default_rng(21)
    for t in range(steps):
        idx = r.integers(0, len(Xtr), 64)
        if not rstep(P, Xtr[idx], Ytr[idx], lr, mode, scale):
            return -1.0
    Z, _, _ = rfwd(P, Xte, mode, scale)
    if not np.isfinite(Z).all():
        return -1.0
    return float((Z.argmax(axis=1) == yte).mean())
