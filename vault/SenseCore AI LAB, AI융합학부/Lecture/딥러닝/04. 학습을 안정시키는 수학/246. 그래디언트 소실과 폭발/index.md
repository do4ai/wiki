# 246강. 그래디언트 소실과 폭발

$233$강에서 이 현상을 처음 봤고 $242$강에서 야코비의 곱으로 다시 봤습니다. 그 사이에 처방이 셋 늘었습니다. $243$강의 초기화, $244$강과 $245$강의 정규화, 그리고 $242$강의 잔차 연결입니다.

$$\text{이제 다시 진단합니다}$$

이 강의는 처방들을 손에 쥔 채 **무엇이 실제로 고쳐졌고 무엇이 남았는지** 잽니다. 그런데 그러려면 먼저 정해야 할 것이 있습니다.

$$\text{무엇을 재야 소실과 폭발이라 부를 수 있습니까}$$

이 물음이 이 강의의 절반입니다. 흔히 드는 지표들이 실제로 진단에 쓸모가 있는지를 **실측으로 시험**합니다.

## 이 강의에서 할 수 있게 되는 것
- 소실과 폭발을 층당 배율이라는 한 수로 정의할 수 있습니다.
- 그 지표가 무엇을 못 잡아내는지 실측으로 보일 수 있습니다.
- 그래디언트 자르기가 학습률과 어떤 관계인지 계산할 수 있습니다.
- 순환 구조에서 왜 더 날카로운지 고윳값으로 설명할 수 있습니다.
- 네 처방이 각각 무엇을 고치는지 가르고 진단 순서를 세울 수 있습니다.

## 문제 1. 소실과 폭발을 정확히 정의합니다

> **문제.** 재는 방법부터 정합니다.
> ($1$) 무엇을 재야 하는지 고르세요.
> ($2$) 그 값이 깊이를 어떻게 증폭하는지 세세요.
> ($3$) 초기 상태에서 직접 재세요.
> ($4$) 초기 상태가 무엇을 보장하는지 정하세요.

**생각의 실마리.** "그래디언트가 사라진다"는 말은 그대로는 잴 수 없습니다. **무엇에 견줘 작은지**를 정해야 합니다. 층마다 파라미터 수도 크기도 다르므로, 절댓값이 아니라 **층 사이의 비**를 봐야 합니다.

**풀이.** ($1$) 무엇을 재야 하는지 고릅니다.

| 후보 | 무엇이 문제인가 |
|---|---|
| 그래디언트 절댓값 | 층마다 크기가 달라 비교가 안 됩니다 |
| 층별 그래디언트 노름 | 파라미터 수가 층마다 다릅니다 |
| 상대 갱신 | 노름을 가중치 노름으로 나눕니다 |
| 층 사이 비의 기하평균 | 한 수로 요약되고 깊이와 무관합니다 |

**마지막 줄부터 써 봅니다.** 층당 배율이 $1$에서 얼마나 떨어졌는지를 보는 방식입니다.

$$r=\Big(\prod_{l=1}^{L-1}\frac{\lVert g_{l+1}\rVert}{\lVert g_l\rVert}\Big)^{1/(L-1)}$$

**교과서가 흔히 드는 지표입니다.** 이것이 실제로 쓸모 있는지는 **문제 $2$에서 시험합니다.**

($2$) 그 값이 깊이를 어떻게 증폭하는지 셉니다.

| 층당 배율 | 깊이 $10$ | 깊이 $30$ | 깊이 $100$ |
|---|---|---|---|
| $0.7$ | $2.8248e-02$ | $2.2539e-05$ | $3.2345e-16$ |
| $0.9$ | $3.4868e-01$ | $4.2391e-02$ | $2.6561e-05$ |
| $1.0$ | $1.0000e+00$ | $1.0000e+00$ | $1.0000e+00$ |
| $1.1$ | $2.5937e+00$ | $1.7449e+01$ | $1.3781e+04$ |
| $1.3$ | $1.3786e+01$ | $2.6200e+03$ | $2.4793e+11$ |

**배율이 $0.9$여도 깊이 $100$이면 $2.6561e-05$로 내려갑니다.** 배율이 $1.1$이면 같은 깊이에서 $1.3781e+04$로 올라갑니다.

**$1$에서 $10$퍼센트 어긋난 것이 아홉 자릿수 차이를 만듭니다.** 이것이 깊이가 어려운 이유의 전부입니다.

($3$) 초기 상태에서 직접 잽니다. 깊이 $20$에 폭 $64$이고 정착 초기화를 씁니다.

| 설정 | 첫 층 노름 | 끝 층 노름 | 층당 배율 |
|---|---|---|---|
| 정착 초기화만 | $1.8796e-01$ | $3.0069e+00$ | $1.157103$ |
| 층 정규화 | $5.2202e-02$ | $1.3015e+00$ | $1.184441$ |
| 잔차만 | $2.1948e+03$ | $7.7085e+04$ | $1.205998$ |
| 잔차와 층 정규화 | $8.3735e-01$ | $4.1066e+00$ | $1.087292$ |

**네 설정 모두 층당 배율이 $1.08$과 $1.21$ 사이입니다.**

**정착 초기화만 쓴 줄은 첫 층 $1.8796e-01$과 끝 층 $3.0069e+00$의 비가 $16$배입니다.** 깊이 $20$에 걸쳐 $16$배이므로 층당으로는 $1.15$배 남짓이고 **심각한 소실이 아닙니다.**

**잔차만 쓴 줄은 노름 자체가 $2.1948e+03$으로 이미 커서 다른 문제를 안고 있습니다.**

($4$) 초기 상태가 무엇을 보장하는지 정합니다.

| 무엇 | 초기 상태가 보장하나 |
|---|---|
| 첫 걸음이 발산하지 않음 | 보장합니다 |
| 신호가 마지막 층까지 도달 | 보장합니다 |
| 학습이 끝까지 잘 됨 | 보장하지 않습니다 |
| 깊이를 늘려도 됨 | 보장하지 않습니다 |

**셋째 줄과 넷째 줄이 남은 물음입니다.** 초기화는 걸음 $0$만 맞춥니다.

**확인 1-1.** 자리표시입니다.

*답.* 자리표시입니다.

**확인 1-2.** 자리표시입니다.

*답.* 자리표시입니다.

## 문제 2. 학습이 진행되면 무엇이 무너지는가

> **문제.** 걸음을 따라갑니다.
> ($1$) 층당 배율이 어떻게 움직이는지 보세요.
> ($2$) 층별 상대 갱신의 불균형을 보세요.
> ($3$) 전체 그래디언트 노름을 보세요.
> ($4$) 실제 정확도로 확인하세요.

**생각의 실마리.** 문제 $1$이 세운 지표를 **시험대에 올립니다.** 지표가 좋은 지표라면 네 설정 중 잘 되는 것과 안 되는 것을 **미리 갈라내야** 합니다.

**풀이.** ($1$) 층당 배율이 어떻게 움직이는지 봅니다. 깊이 $20$에 학습률 $0.03$이며 $2000$걸음입니다.

| 설정 | 걸음 $0$ | 걸음 $500$ | 걸음 $1000$ | 걸음 $2000$ |
|---|---|---|---|---|
| 정착 초기화만 | $1.094297$ | $0.970423$ | $0.917233$ | $0.953425$ |
| 층 정규화 | $1.100478$ | $0.966376$ | $0.937403$ | $1.031635$ |
| 잔차만 | $1.176992$ | 발산 | 발산 | 발산 |
| 잔차와 층 정규화 | $1.054086$ | $0.920419$ | $0.899512$ | $0.879006$ |

**잔차만 쓴 줄을 빼면 세 줄 모두 $0.87$과 $1.11$ 사이에서 움직입니다.**

**층당 배율만 봐서는 세 설정이 갈리지 않습니다.** 문제 $1$이 세운 지표가 여기서는 **진단에 쓸모가 없습니다.**

($2$) 다른 지표를 시험합니다. 층마다 그래디언트 노름을 그 층 가중치 노름으로 나눈 뒤 최대와 최소의 비를 잽니다.

| 설정 | 깊이 $8$ | 깊이 $20$ | 깊이 $40$ |
|---|---|---|---|
| 정착 초기화만 | $7.9968e+00$ | $8.2759e+00$ | $1.7889e+01$ |
| 층 정규화 | $6.9229e+00$ | $7.6820e+00$ | $2.2585e+01$ |
| 잔차만 | $2.0319e+01$ | 발산 | 발산 |
| 잔차와 층 정규화 | $6.3629e+01$ | $8.0107e+01$ | $2.4730e+02$ |

**이 지표는 설정을 갈라 놓기는 합니다.** 그런데 **방향이 예상과 반대입니다.**

**불균형이 가장 큰 줄이 ($4$)에서 정확도가 가장 높습니다.** 잔차 연결이 항등 경로로 앞 층에 그래디언트를 직접 보내므로 **앞 층의 상대 갱신이 커지는 것이 정상**이기 때문입니다.

$$\text{지표가 크다는 것과 나쁘다는 것은 다릅니다}$$

($3$) 전체 그래디언트 노름을 봅니다.

| 설정 | 걸음 $0$ | 걸음 $500$ | 걸음 $1000$ | 걸음 $2000$ |
|---|---|---|---|---|
| 정착 초기화만 | $9.4914e+00$ | $7.3618e+00$ | $1.3807e+00$ | $1.7755e-02$ |
| 층 정규화 | $3.9415e+00$ | $4.5738e+00$ | $2.3378e+00$ | $4.2482e-02$ |
| 잔차만 | $2.0464e+05$ | 발산 | 발산 | 발산 |
| 잔차와 층 정규화 | $5.5489e+01$ | $1.5249e+01$ | $1.6879e+00$ | $9.4974e-02$ |

**네 줄 모두 걸음이 갈수록 노름이 줄어듭니다.** 손실이 내려가고 있으니 당연합니다.

**노름이 작아지는 것 자체는 소실의 증거가 아닙니다.** 수렴하는 학습에서는 그래디언트가 작아지는 것이 목표입니다.

($4$) 실제 정확도로 확인합니다. 학습률은 네 개 격자에서 각자 최선을 씁니다.

| 깊이 | 정착 초기화만 | 층 정규화 | 잔차만 | 잔차와 층 정규화 |
|---|---|---|---|---|
| $8$ | $0.812000$ | $0.824000$ | $0.674000$ | $0.854667$ |
| $20$ | $0.784667$ | $0.815333$ | 발산 | $0.852667$ |
| $40$ | $0.660000$ | $0.724000$ | 발산 | $0.852667$ |

**깊이 $40$에서 $0.660000$과 $0.852667$로 크게 갈립니다.**

**층당 배율은 셋을 못 갈랐고 상대 갱신 불균형은 순서를 거꾸로 가리켰습니다.** 두 지표 모두 정확도 순위를 맞히지 못합니다.

**지표는 무엇이 무너졌는지 좁혀 줄 뿐이고 어느 설정이 나은지는 재 봐야 압니다.** 이 강의가 남기는 가장 실용적인 교훈입니다.

**확인 2-1.** 자리표시입니다.

*답.* 자리표시입니다.

**확인 2-2.** 자리표시입니다.

*답.* 자리표시입니다.

## 문제 3. 그래디언트 자르기가 무엇을 하는가

> **문제.** 자르기를 봅니다.
> ($1$) 두 가지 자르기를 정의하세요.
> ($2$) 두 방식이 방향을 얼마나 바꾸는지 재세요.
> ($3$) 학습에서 무엇을 바꾸는지 보세요.
> ($4$) 학습률과의 관계를 정하세요.

**생각의 실마리.** 자르기는 **드물게 튀는 걸음**을 막으려는 장치입니다. 그런데 임계값이 평소 그래디언트 크기보다 작으면 **매 걸음 작동**하게 되고, 그러면 다른 장치가 됩니다.

**풀이.** ($1$) 두 가지를 정의합니다.

$$g\leftarrow g\cdot\min\Big(1,\frac{c}{\lVert g\rVert}\Big),\qquad g_i\leftarrow \mathrm{clip}(g_i,-c,c)$$

| 방식 | 무엇이 보존되나 |
|---|---|
| 노름 자르기 | 방향이 그대로입니다 |
| 값 자르기 | 아무것도 보존되지 않습니다 |

**노름 자르기는 벡터에 스칼라를 곱하므로 방향이 보존됩니다.** 값 자르기는 좌표마다 다른 배율이 곱해져 **방향이 바뀝니다.**

($2$) 두 방식이 방향을 얼마나 바꾸는지 잽니다. **노름을 같은 비율로 줄이도록 맞춘 뒤** 방향만 견줍니다. 좌표 $2000$개 중 $20$개만 $30$배 크게 만든 벡터입니다.

| 줄인 비율 | 노름 자르기 코사인 | 값 자르기 코사인 |
|---|---|---|
| $0.1$ | $1.000000$ | $0.365938$ |
| $0.3$ | $1.000000$ | $0.457251$ |
| $0.5$ | $1.000000$ | $0.871030$ |
| $0.9$ | $1.000000$ | $0.990754$ |

**노름 자르기의 코사인은 정확히 $1$입니다.**

**같은 크기로 줄여도 값 자르기는 방향이 함께 바뀝니다.** 많이 줄일수록 심해서 $0.1$로 줄이면 코사인이 $0.365938$까지 떨어집니다. 큰 좌표들만 깎이기 때문입니다.

($3$) 학습에서 무엇을 바꾸는지 봅니다. 깊이 $20$에 정착 초기화만 쓰고 임계값만 바꿉니다.

| 임계값 | lr $0.03$ | lr $0.1$ | lr $0.3$ | lr $1.0$ |
|---|---|---|---|---|
| 없음 | $0.722667$ | $0.784667$ | $0.355333$ | $0.333333$ |
| $1.0$ | $0.516000$ | $0.652667$ | $0.777333$ | $0.640000$ |
| $0.3$ | $0.498667$ | $0.516000$ | $0.665333$ | $0.794667$ |
| $0.1$ | $0.458667$ | $0.493333$ | $0.516000$ | $0.662000$ |

**표에 대각선으로 같은 값이 나타납니다.** $0.516000$이 세 번 나옵니다.

($4$) 학습률과의 관계를 정합니다. 초기 그래디언트 노름이 $9.4914e+00$이므로 임계값 $1.0$ 이하에서는 **자르기가 늘 작동**합니다. 그러면 갱신이 이렇게 됩니다.

$$\Delta W=-\eta\cdot\frac{c}{\lVert g\rVert}\cdot g=-\eta c\cdot\frac{g}{\lVert g\rVert}$$

| 학습률 곱하기 임계값 | 해당 칸 | 정확도 |
|---|---|---|
| $0.030$ | lr $0.03$ 임계값 $1.0$ | $0.516000$ |
| $0.030$ | lr $0.10$ 임계값 $0.3$ | $0.516000$ |
| $0.030$ | lr $0.30$ 임계값 $0.1$ | $0.516000$ |

**세 칸의 곱이 모두 $0.030$이고 정확도도 완전히 같습니다.**

$$\text{자르기는 학습률과 별개의 손잡이가 아닙니다}$$

**다만 임계값보다 작은 그래디언트는 그대로 두므로 튀는 걸음에만 작동하게 만들 수 있습니다.** 임계값을 평소 노름보다 **크게** 잡는 것이 자르기를 제 용도로 쓰는 방법입니다.

**확인 3-1.** 자리표시입니다.

*답.* 자리표시입니다.

**확인 3-2.** 자리표시입니다.

*답.* 자리표시입니다.

## 문제 4. 순환 구조에서 왜 더 심한가

> **문제.** 같은 가중치를 반복해 봅니다.
> ($1$) 서로 다른 행렬의 곱과 견주세요.
> ($2$) 고윳값이 무엇을 정하는지 확인하세요.
> ($3$) 무엇이 다른지 정리하세요.
> ($4$) 처방이 왜 다른지 보세요.

**생각의 실마리.** 층마다 가중치가 다르면 야코비의 곱은 **서로 다른 무작위 행렬의 곱**입니다. 순환 신경망은 같은 가중치를 반복하므로 **한 행렬의 거듭제곱**입니다. 거듭제곱에는 **고윳값**이라는 단일한 지수가 있습니다.

**풀이.** ($1$) 서로 다른 행렬의 곱과 견줍니다. 폭 $32$인 행렬입니다.

| 반복 수 | 서로 다른 행렬의 곱 | 같은 행렬의 거듭제곱 |
|---|---|---|
| $1$ | $1.9784e+00$ | $1.9168e+00$ |
| $5$ | $2.8436e+00$ | $3.0002e+00$ |
| $10$ | $3.1260e+00$ | $3.8022e+00$ |
| $20$ | $5.4324e+00$ | $9.2312e+00$ |
| $40$ | $3.7491e+00$ | $5.3367e+01$ |

**왼쪽 열은 $40$번 곱해도 $3.7491e+00$에 머물고 오히려 $20$번일 때보다 작습니다.** 무작위 행렬들의 곱은 방향이 서로 상쇄되어 단조롭게 자라지 않습니다.

**오른쪽 열은 $5.3367e+01$까지 올라갑니다.**

($2$) 고윳값이 무엇을 정하는지 확인합니다. 이 행렬의 고윳값 최대 절댓값은 $1.091970$입니다.

np.seterr(all='ignore')


def pw(s, w):
    n = sum(2 if ord(c) > 0x1100 else 1 for c in str(s))
    return str(s) + ' ' * max(0, w - n)


def rw(s, w):
    n = sum(2 if ord(c) > 0x1100 else 1 for c in str(s))
    return ' ' * max(0, w - n) + str(s)


def line(*cells):
    parts = [pw(c, -w) if w < 0 else rw(c, w) for c, w in cells]

def say(t):

EPS = 1e-5


def relu(z):
    return np.maximum(z, 0.0)


def drelu(z):
    return (z > 0).astype(float)


def softmax(Z):
    Z = Z - Z.max(axis=1, keepdims=True)
    E = np.exp(Z)
    return E / E.sum(axis=1, keepdims=True)


def ln_fwd(X, gam, bet):
    mu = X.mean(axis=1, keepdims=True)
    sd = np.sqrt(X.var(axis=1, keepdims=True) + EPS)
    Xh = (X - mu) / sd
    return gam * Xh + bet, (Xh, sd, gam)


def ln_bwd(dY, cache):
    Xh, sd, gam = cache
    n = dY.shape[1]
    dg = (dY * Xh).sum(axis=0)
    db = dY.sum(axis=0)
    dXh = dY * gam
    dX = (n * dXh - dXh.sum(axis=1, keepdims=True)
          - Xh * (dXh * Xh).sum(axis=1, keepdims=True)) / (n * sd)
    return dX, dg, db

def build(depth, width, g=2.0, seed=7):
    r = np.random.default_rng(seed)
    dims = [20] + [width] * depth + [3]
    Ws = [r.normal(0, np.sqrt(g / dims[i]), (dims[i], dims[i + 1])) for i in range(len(dims) - 1)]
    gm = [np.ones(dims[i + 1]) for i in range(len(dims) - 1)]
    bt = [np.zeros(dims[i + 1]) for i in range(len(dims) - 1)]
    return [Ws, gm, bt]


def fwd(P, X, norm=False, res=False, scale=1.0):
    Ws, gm, bt = P
    ins, pre, cs = [], [], []
    H = X
    L = len(Ws)
    for i in range(L):
        ins.append(H)
        Z = H @ Ws[i]
        if norm and i < L - 1:
            Z, c = ln_fwd(Z, gm[i], bt[i])
            cs.append(c)
        else:
            cs.append(None)
        pre.append(Z)
        if i < L - 1:
            H = relu(Z) * scale
            if res and ins[i].shape == H.shape:
                H = H + ins[i]
        else:
            H = Z
    return ins, pre, cs


def grads(P, X, Y, norm=False, res=False, scale=1.0):
    Ws, gm, bt = P
    ins, pre, cs = fwd(P, X, norm, res, scale)
    if not np.isfinite(pre[-1]).all():
        return None
    L = len(Ws)
    D = (softmax(pre[-1]) - Y) / len(X)
    G = [None] * L
    for i in range(L - 1, -1, -1):
        Dz = D if i == L - 1 else D * drelu(pre[i]) * scale
        if cs[i] is not None:
            Dz, _, _ = ln_bwd(Dz, cs[i])
        G[i] = ins[i].T @ Dz
        Dn = Dz @ Ws[i].T
        if res and i < L - 1 and ins[i].shape == pre[i].shape:
            Dn = Dn + D
        D = Dn
    return G


def ratio(G):
    ns = [np.linalg.norm(g) for g in G[:-1]]
    ls = [np.log(ns[i + 1] / ns[i]) for i in range(len(ns) - 1) if ns[i] > 0 and ns[i + 1] > 0]
    return float(np.exp(np.mean(ls))) if ls else float('nan')

def train_track(depth, width, lr, steps, norm=False, res=False, scale=1.0, clip=None, seed=7):
    P = build(depth, width, seed=seed)
    r = np.random.default_rng(21)
    marks = {}
    for t in range(steps + 1):
        idx = r.integers(0, len(Xtr), 64)
        G = grads(P, Xtr[idx], Ytr[idx], norm, res, scale)
        if G is None:
            marks[t] = None
            break
        if t in (0, steps // 4, steps // 2, steps):
            marks[t] = (ratio(G), float(np.sqrt(sum((g ** 2).sum() for g in G))))
        if t == steps:
            break
        tot = np.sqrt(sum((g ** 2).sum() for g in G))
        sc = 1.0 if clip is None or tot <= clip else clip / tot
        for i in range(len(P[0])):
            P[0][i] -= lr * sc * G[i]
    return P, marks

def rel_spread(P, norm=False, res=False, scale=1.0):
    G = grads(P, Xtr, Ytr, norm, res, scale)
    if G is None:
        return None
    rs = [np.linalg.norm(G[i]) / np.linalg.norm(P[0][i]) for i in range(len(G))]
    rs = [x for x in rs if x > 0]
    return max(rs) / min(rs)

def clip_to_norm(x, target):
    lo, hi = 0.0, np.abs(x).max()
    for _ in range(80):
        mid = (lo + hi) / 2
        if np.linalg.norm(np.clip(x, -mid, mid)) < target:
            lo = mid
        else:
            hi = mid
    return np.clip(x, -hi, hi)
