이 단원은 191강부터 195강까지를 맡습니다. **설계로 답합니다.**

02단원이 물은 것은 **"얼마나 어떻게 다른가"**였습니다. 이 단원이 묻는 것은 다릅니다.

$$\text{바꾸면 어떻게 되는가}$$

관측된 관계와 개입의 결과가 다르다는 것이 출발점입니다. 그 둘을 잇는 것은 **더 좋은 계산이 아니라 더 좋은 설계**입니다.

# 이 단원의 흐름

| 강의 | 하는 일 |
|---|---|
| $191$ | 인과를 말할 언어를 세우고 무엇이 부족한지 밝힙니다 |
| $192$ | 무작위 배정으로 부족한 것을 설계로 채웁니다 |
| $193$ | 배정을 못 할 때 잰 변수로 실험을 흉내 냅니다 |
| $194$ | 같은 대상을 시간으로 견줘 안 잰 것을 지웁니다 |
| $195$ | 지렛대가 될 변수를 찾아 효과를 끄집어냅니다 |

**다섯 강이 하나의 순서를 이룹니다.** 앞 강이 못 한 것을 뒤 강이 새 가정으로 대신하며, 그 가정이 무엇인지가 각 강의 핵심입니다.

# 하나의 문장이 단원 전체를 관통합니다

$$\text{가정 없이 인과를 말하는 방법은 없습니다}$$

| 강의 | 무엇을 가정하나 | 무엇을 못 하나 |
|---|---|---|
| $191$ | 인과의 언어를 세움 | 추정 방법이 없음 |
| $192$ | 무작위 배정이 가능함 | 못 하는 자리가 많음 |
| $193$ | 잰 변수가 전부임 | 안 잰 것에 무력함 |
| $194$ | 추세가 평행함 | 군별 추세 변화에 무력함 |
| $195$ | 지렛대가 배제를 만족함 | 따르는 사람만 답함 |

**셋째 줄이 가장 흔히 쓰이고 가장 자주 어깁니다.** 193강 문제 4에서 성향 점수와 회귀와 매칭이 $3.90$, $3.93$, $3.90$으로 **똑같이 실패**했습니다. 방법이 아니라 자료가 정합니다.

# 방법이 무엇을 추정하는지가 다릅니다

| 무엇을 재는가 | 누구에 대해 | 어디서 |
|---|---|---|
| ATE | 모두 | $191$ 문제 $1$, IPW |
| ATT | 처치받은 사람 | $191$ 문제 $1$, 매칭, $194$ |
| LATE | 도구가 바꾼 사람 | $195$ 문제 $4$ |

**같은 자료에 세 방법을 쓰면 세 값이 나오는 것이 정상입니다.** 195강 문제 4에서 전체 평균은 $2.4964$인데 도구변수는 $2.0153$을 냈습니다. 모순이 아니라 **다른 물음에 대한 답**입니다.

# 무엇이 이 단원의 방법들을 깨뜨리는가

| 무엇 | 어디서 | 어느 방향으로 |
|---|---|---|
| 안 잰 교란 | $193$ 문제 $4$ | 방법과 무관하게 같은 크기 |
| 겹침 없음 | $193$ 문제 $3$ | 가중치 폭발과 유효 표본 소멸 |
| 추세 어긋남 | $194$ 문제 $3$ | 어긋난 만큼 그대로 |
| 평균 회귀 | $194$ 문제 $4$ | 없는 효과를 만듦 |
| 번짐 | $194$ 문제 $4$ | 있는 효과를 지움 |
| 약한 도구 | $195$ 문제 $3$ | 그냥 회귀 쪽으로 끌림 |
| 배제 제약 위반 | $195$ 문제 $3$ | $1$단계 계수만큼 확대돼 들어옴 |
| 불멸 시간 | $193$ 문제 $5$ | 없는 효과를 크게 만듦 |

**넷째 줄과 다섯째 줄이 서로 반대입니다.** "이 방법은 보수적이다" 같은 일반화가 안 되는 이유입니다.

# 진단은 균형과 겹침으로 합니다

| 무엇을 보는가 | 기준 |
|---|---|
| 표준화 차이 | $0.1$ 아래 |
| 겹침 그림 | 양쪽 끝에 한쪽만 있는지 |
| 유효 표본 | 실제 정보량 |
| $1$단계 F | $10$ 이상 |
| 처치 전 계수 | 평평한지 |
| 가짜 처치 검정 | $0$인지 |
| 민감도 분석 | 얼마여야 뒤집히는지 |

**첫째 줄이 가장 많이 보고되면서 가장 적게 말해 줍니다.** 193강 문제 4에서 $z$의 균형은 $0.0001$로 완벽했는데 $u$는 $1.0242$였고, **$u$는 표에 실리지 않습니다.**

| 가중치 자르기 | $175$강 문제 $5$, $193$강 문제 $3$ |
| 표본 크기와 검출력 | $183$강, $192$강 문제 $3$ |
| 다중비교와 사전 등록 | $182$강, $192$강 문제 $5$ |

**넷째 줄이 이 단원의 결론과 이어집니다.** 검사할 수 없는 가정을 진 채로 답할 때, **"얼마나 강한 교란이면 뒤집히는가"**가 유일하게 확인 가능한 진술입니다.

# 다음 단계

**04단원은 순서가 있는 자료를 다룹니다.** 이 단원의 모든 계산이 하나의 가정 위에 서 있었습니다.

$$\text{관측이 서로 독립이라는 가정}$$

194강에서 시점이 **둘뿐**인데도 표준오차를 군집 단위로 고쳐야 했고, 안 고치면 $0.4480$과 $0.0807$만큼 어긋났습니다. 시점이 백 개인 자료에서는 **173강 이후의 거의 모든 표준오차가 틀립니다.** 196강부터 그 구조를 정면으로 다룹니다.
