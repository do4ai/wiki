# 178강. 두 집단 비교와 t검정

177강까지가 **자료를 믿을 수 있는지**를 물었습니다. **이제 그 자료로 답을 만듭니다.**

$$\text{A와 B의 평균이 다릅니까}$$

가장 많이 묻는 물음이고, 가장 많이 틀리는 물음입니다. **평균이 다르게 나오는 것은 언제나 그렇기 때문**입니다. 같은 모집단에서 두 번 뽑아도 평균은 다릅니다.

**그래서 물음을 바꿔야 합니다.** "다릅니까"가 아니라 **"이만큼 다른 것이 우연으로 설명됩니까"**를 묻습니다.

| 무엇을 보는가 | 왜 |
|---|---|
| 차이의 크기 | 실제로 얼마나 다른지 |
| 흩어짐 | 우연이 만들 수 있는 폭 |
| 표본 크기 | 우연의 폭이 얼마나 좁은지 |

**셋을 한 숫자로 묶은 것이 $t$**입니다. 152강에서 가설검정의 뼈대를 세웠는데, 이 강의는 그것을 **실제 자료에 쓰는 자리**입니다.

**그리고 이 강의의 절반은 $t$가 말하지 않는 것에 대한 것입니다.** 유의하다는 말이 크다는 뜻이 아니고, 유의하지 않다는 말이 같다는 뜻이 아닙니다.

## 이 강의에서 할 수 있게 되는 것
- 두 집단의 $t$ 통계량과 $p$ 값을 정의부터 계산할 수 있습니다.
- 등분산 가정이 깨질 때 합동 $t$가 어떻게 무너지는지 판정하고 웰치를 쓸 수 있습니다.
- 짝지은 자료와 아닌 자료를 구분하고 잘못 짝지었을 때의 손해를 계산할 수 있습니다.
- $p$ 값이 뜻하는 것과 뜻하지 않는 것을 가르고 표본 크기와의 관계를 설명할 수 있습니다.
- 효과 크기와 신뢰구간으로 유의성만으로는 못 하는 판단을 할 수 있습니다.

## 문제 1. 차이를 무엇으로 나눌 것인가

> **문제.** 두 집단의 평균을 견줍니다.
> (1) $t$ 통계량과 $p$ 값을 구하세요.
> (2) 같은 차이라도 판단이 달라지는 경우를 만드세요.

**생각의 실마리.** 평균 차이가 $4.61$이라는 말만으로는 아무것도 알 수 없습니다. **$4.61$이 큰지 작은지 잴 자가 필요**하며, 그 자가 **우연이 만들 수 있는 폭**입니다.

**풀이.** (1) 두 집단을 봅니다.

| 집단 | 크기 | 평균 | 표준편차 |
|---|---|---|---|
| A | $10$ | $51.0200$ | $2.9078$ |
| B | $10$ | $46.4100$ | $2.4651$ |

**평균 차이는 $4.6100$입니다.** 이것을 차이의 표준오차로 나눕니다.

$$t=\frac{\bar{X}_{A}-\bar{X}_{B}}{s_{p}\sqrt{\frac{1}{n_{A}}+\frac{1}{n_{B}}}}\qquad s_{p}^{2}=\frac{(n_{A}-1)s_{A}^{2}+(n_{B}-1)s_{B}^{2}}{n_{A}+n_{B}-2}$$

**$t$는 $3.8242$이고 자유도는 $18$이며 양측 $p$ 값은 $0.001242$입니다.**

**$t$가 차이를 표준오차 단위로 잰 것**입니다. $3.82$는 우연이 만들 폭의 거의 네 배이므로, 우연으로 보기 어렵습니다.

(2) 같은 차이라도 나머지가 바뀌면 판단이 뒤집힙니다.

| 상황 | 평균 차이 | 표준편차 | $t$ | $p$ 값 |
|---|---|---|---|---|
| 기준 | $4.0000$ | $3.0000$ | $2.9814$ | $0.008002$ |
| 차이가 절반 | $2.0000$ | $3.0000$ | $1.4907$ | $0.153353$ |
| 흩어짐이 두 배 | $4.0000$ | $6.0000$ | $1.4907$ | $0.153353$ |
| 크기가 네 배 | $4.0000$ | $3.0000$ | $5.9628$ | $0.000000$ |

**둘째 줄과 셋째 줄의 $t$가 정확히 같습니다.** 차이를 절반으로 줄이는 것과 흩어짐을 두 배로 늘리는 것이 **$t$에게는 같은 일**입니다.

**넷째 줄에서 크기를 네 배로 하면 $t$가 두 배가 됩니다.** 174강의 $\sqrt{n}$ 그대로이며, $p$ 값은 소수 여섯째 자리 아래로 내려가 $0.000000$으로 반올림됩니다.

**이 문제에서 배우는 것.** **차이의 크기만 보고하는 표는 아무 정보가 없습니다.** "A가 B보다 $4.61$ 높습니다"는 흩어짐과 표본 크기를 모르면 판단할 수 없으며, 실무 보고서가 자주 이 상태로 멈춥니다. 반대로 $t$나 $p$만 보고하는 것도 모자란데, **셋을 한 숫자로 뭉갠 뒤에는 되돌릴 수 없기** 때문입니다. 문제 5에서 이 지점을 다시 다룹니다.

**바로 확인 1.**

**확인 1-1.** $t$ 통계량을 말로 쓰세요.

*답.* 평균 차이를 차이의 표준오차로 나눈 값입니다.

**확인 1-2.** 검산에서 문제 1의 자료의 $t$와 $p$ 값을 쓰세요.

*답.* $3.8242$이고 $p$ 값은 $0.001242$입니다.

**확인 1-3.** 검산에서 $t$가 같아진 두 줄과 그 값을 쓰세요.

*답.* 차이가 절반인 경우와 흩어짐이 두 배인 경우이며 둘 다 $1.4907$입니다.

## 문제 2. 등분산을 가정할 것인가

> **문제.** 합동 $t$의 가정을 검사합니다.
> (1) 등분산이 깨질 때의 실제 오류율을 모의로 재세요.
> (2) 웰치 검정의 자유도를 확인하세요.

**생각의 실마리.** 문제 1의 $s_{p}$는 **두 집단의 분산이 같다고 보고 합친 것**입니다. 다르면 무엇이 잘못되는지 재 봅니다.

**풀이.** (1) 참 차이가 $0$인 자료를 만들어 **$0.05$보다 자주 기각하는지** 셉니다.

| 두 집단의 크기와 분산 | 합동 $t$의 오류율 | 웰치 $t$의 오류율 | 목표 | 누가 맞는가 |
|---|---|---|---|---|
| 같은 크기 같은 분산 | $0.0508$ | $0.0508$ | $0.05$ | 둘 다 |
| 같은 크기 다른 분산 | $0.0510$ | $0.0473$ | $0.05$ | 둘 다 |
| 작은 쪽이 분산 큼 | $0.2567$ | $0.0527$ | $0.05$ | 웰치 |
| 큰 쪽이 분산 큼 | $0.0015$ | $0.0517$ | $0.05$ | 웰치 |

**둘째 줄이 중요합니다.** 크기가 같으면 **분산이 세 배 달라도 합동 $t$가 버팁니다.** 등분산 검정을 먼저 하라는 조언이 널리 퍼져 있는데, 크기가 같으면 필요가 없습니다.

**셋째 줄에서 오류율이 $0.2567$입니다.** 목표의 다섯 배이며, **없는 차이를 다섯 번에 한 번 넘게 있다고 말합니다.**

**넷째 줄은 반대 방향으로 틀립니다.** 오류율이 $0.0015$로 **너무 조심스러워** 있는 차이도 못 잡습니다.

$$\text{작은 집단의 분산이 크면}\;\to\;\text{과잉 기각}\qquad\text{큰 집단의 분산이 크면}\;\to\;\text{과소 기각}$$

**웰치 $t$는 네 경우 모두 목표에 가깝습니다.** 그래서 **기본값을 웰치로** 둡니다.

(2) 웰치는 분산을 합치지 않고 따로 씁니다.

$$t=\frac{\bar{X}_{A}-\bar{X}_{B}}{\sqrt{\frac{s_{A}^{2}}{n_{A}}+\frac{s_{B}^{2}}{n_{B}}}}\qquad \nu=\frac{\left(\frac{s_{A}^{2}}{n_{A}}+\frac{s_{B}^{2}}{n_{B}}\right)^{2}}{\frac{(s_{A}^{2}/n_{A})^{2}}{n_{A}-1}+\frac{(s_{B}^{2}/n_{B})^{2}}{n_{B}-1}}$$

$n_{A}=10$이고 $n_{B}=40$이며 분산이 다른 자료에서 재 봅니다.

| 무엇으로 | 자유도 | 양측 $p$ 값 |
|---|---|---|
| 합동 | $48.0000$ | $0.383891$ |
| 웰치 | $47.6690$ | $0.108252$ |

**자유도는 $48$에서 $47.6690$으로 조금 줄었을 뿐인데 $p$ 값이 네 배 가까이 다릅니다.**

**차이는 자유도가 아니라 분모에서 옵니다.** 합동은 큰 집단의 큰 분산을 작은 집단에도 섞어 **작은 집단의 평균까지 불안정하게 봅니다.** 위 표의 넷째 줄과 같은 상황이며, 합동 $t$가 너무 조심스러워 기각을 못 합니다.

**이 문제에서 배우는 것.** **가정을 먼저 검사하고 그 결과로 방법을 고르는 절차가 오히려 나쁩니다.** 등분산 검정을 하고 통과하면 합동, 실패하면 웰치를 쓰는 두 단계 절차는 **첫 단계의 오류가 둘째 단계로 새어 들어가** 전체 오류율이 $0.05$를 넘습니다. 웰치는 분산이 같아도 거의 손해가 없으므로, **검사하지 말고 처음부터 웰치를 쓰는 것**이 간단하고 정확합니다. 이 원리는 뒤에서도 되풀이되는데, **선택을 자료로 하면 그 선택의 불확실성도 세야** 합니다.

**바로 확인 2.**

**확인 2-1.** 검산에서 합동 $t$의 오류율이 가장 나빴던 경우와 값을 쓰세요.

*답.* 작은 쪽의 분산이 큰 경우이며 $0.2567$로 목표의 다섯 배입니다.

**확인 2-2.** 크기가 같을 때 등분산 검정이 필요 없는 이유를 검산 값과 함께 쓰세요.

*답.* 분산이 세 배 달라도 오류율이 $0.0510$으로 목표에 가깝기 때문입니다.

**확인 2-3.** 검산에서 합동과 웰치의 $p$ 값을 쓰고 왜 다른지 쓰세요.

*답.* $0.383891$과 $0.108252$이며 합동이 큰 집단의 분산을 작은 집단에 섞기 때문입니다.

## 문제 3. 짝지은 자료

> **문제.** 같은 대상을 두 번 잰 자료를 다룹니다.
> (1) 짝을 무시할 때와 지을 때를 비교하세요.
> (2) 짝이 없는데 짝지으면 어떻게 되는지 확인하세요.

**생각의 실마리.** 같은 사람을 전후로 재면 **두 값이 서로 얽혀 있습니다.** 사람마다의 차이가 두 값에 똑같이 들어 있으므로, **빼면 사라집니다.**

**풀이.** (1) 참 효과가 $3.0$이고 사람마다의 차이가 표준편차 $15$인 자료입니다.

| 어떻게 보는가 | $t$ | 자유도 | 양측 $p$ 값 |
|---|---|---|---|
| 따로 뽑은 것처럼 | $0.8834$ | $58$ | $0.380663$ |
| 짝지어서 | $5.0159$ | $29$ | $0.000024$ |

**같은 자료인데 $p$ 값이 $0.38$과 $0.000024$입니다.** 하나는 아무것도 못 찾고 하나는 강한 증거를 찾습니다.

이유는 분모에 있습니다.

| 무엇의 흩어짐인가 | 표준편차 |
|---|---|
| 각 관측 | $13.3079$ |
| 사람 안의 차이 | $3.3208$ |

**사람마다의 차이 $15$가 뺄셈에서 통째로 사라집니다.** 남는 것은 측정의 잡음뿐이라 흩어짐이 $13.31$에서 $3.32$로 줄고, **분모가 작아진 만큼 같은 효과가 또렷해집니다.**

$$\text{Var}(X_{\text{후}}-X_{\text{전}})=\sigma_{\text{후}}^{2}+\sigma_{\text{전}}^{2}-2\,\text{Cov}$$

**마지막 항이 짝짓기의 이득 전부**입니다. 두 값의 상관이 높을수록 많이 빠집니다.

(2) 그러면 언제나 짝지으면 좋은지 확인합니다. 참 효과 $3.0$을 두고 $4$만 번씩 되풀이했습니다.

| 자료의 구조 | 따로 뽑은 것처럼 | 짝지어서 | 어느 쪽이 나은가 |
|---|---|---|---|
| 같은 사람을 전후로 | $0.0000$ | $0.9999$ | 짝지어서 |
| 서로 다른 사람 | $0.1185$ | $0.1172$ | 비슷 |

**첫째 줄에서 검출력이 $0$과 $1$로 갈립니다.** 짝이 있는데 무시하면 **참 효과를 한 번도 못 잡습니다.**

**둘째 줄의 두 값은 사실상 같습니다.** 짝이 없으면 뺄셈에서 사라질 것이 없으므로 흩어짐이 그대로이고, 손해는 자유도에서만 옵니다. 그 손해가 언제 커지는지 따로 봅니다.

| 집단당 크기 | 기각에 필요한 $t$ 따로 | 짝지어서 | 검출력 따로 | 검출력 짝 |
|---|---|---|---|---|
| $5$ | $2.3060$ | $2.7764$ | $0.2003$ | $0.1648$ |
| $10$ | $2.1009$ | $2.2622$ | $0.3979$ | $0.3593$ |
| $30$ | $2.0017$ | $2.0452$ | $0.8596$ | $0.8490$ |
| $100$ | $1.9720$ | $1.9842$ | $0.9998$ | $0.9998$ |

**자유도가 $2n-2$에서 $n-1$로 절반이 되면 기각에 필요한 $t$가 오릅니다.** 크기가 $5$면 $2.3060$에서 $2.7764$로 올라 검출력이 $0.2003$에서 $0.1648$로 떨어지고, 크기가 $100$이면 차이가 거의 없습니다.

**짝짓기는 설계에서 정하는 것이지 분석에서 고르는 것이 아닙니다.**

**이 문제에서 배우는 것.** **자료의 구조를 잘못 읽으면 방법이 아무리 정확해도 답이 틀립니다.** 첫째 줄의 $0.0000$과 $0.9999$가 그 폭이며, 이것은 계산 실수가 아니라 **자료가 어떻게 만들어졌는지를 놓친 결과**입니다. 177강에서 "이 행이 어떻게 생겼는가"를 첫 질문으로 두라고 했는데, 그 질문의 답이 **어떤 검정을 쓸지까지 정합니다.** 그리고 짝짓기의 이득이 상관에서 오므로, **전후 측정 간격이 길어 상관이 낮아지면 이득도 줄어듭니다.**

**바로 확인 3.**

**확인 3-1.** 짝짓기가 무엇을 없애는지 쓰세요.

*답.* 대상마다 고정된 차이를 뺄셈에서 없앱니다.

**확인 3-2.** 검산에서 짝을 무시했을 때와 지었을 때의 $p$ 값을 쓰세요.

*답.* $0.380663$과 $0.000024$입니다.

**확인 3-3.** 짝이 없는데 짝지으면 무엇이 손해인지 검산 값과 함께 쓰세요.

*답.* 자유도가 절반이 되어 크기 $5$에서 검출력이 $0.2003$에서 $0.1648$로 떨어집니다.

## 문제 4. $p$ 값이 말하지 않는 것

> **문제.** $p$ 값의 뜻을 확인합니다.
> (1) 흔한 오해를 정리하세요.
> (2) 효과가 없을 때의 $p$ 값 분포를 확인하세요.
> (3) 표본 크기와 유의성의 관계를 확인하세요.

**생각의 실마리.** $p$ 값은 **귀무가설을 참이라고 두고 계산한 확률**입니다. 조건이 어느 쪽에 붙어 있는지가 오해의 전부입니다.

**풀이.** (1) $p=0.03$이 뜻하는 것을 가릅니다.

| $p=0.03$이 뜻하는 것 | 맞는가 |
|---|---|
| 귀무가설이 참일 확률이 $0.03$ | 아니오 |
| 대립가설이 참일 확률이 $0.97$ | 아니오 |
| 차이가 $0.03$만큼 크다 | 아니오 |
| 귀무가설 아래에서 이만한 차이를 볼 확률 | 예 |
| 같은 실험을 하면 $97$퍼센트 재현된다 | 아니오 |

$$p=P(\text{자료}\mid H_{0})\qquad\neq\qquad P(H_{0}\mid\text{자료})$$

**조건의 방향이 반대입니다.** 124강의 조건부확률에서 $P(A\mid B)$와 $P(B\mid A)$가 다르다고 한 것이 **여기서 가장 비싸게 나타납니다.**

(2) 효과가 정말 $0$인 자료에서 $p$ 값을 $2$만 번 구했습니다.

| $p$ 값 구간 | 들어간 비율 | 기대 |
|---|---|---|
| $0.0$ ~ $0.2$ | $0.1983$ | $0.20$ |

## 문제 5. 얼마나 다른가

> **문제.** 유의성 말고 크기를 봅니다.
> (1) 효과 크기를 정의하고 표본 크기와의 관계를 확인하세요.
> (2) 신뢰구간이 무엇을 더 말하는지 정리하세요.

**생각의 실마리.** 문제 4에서 $t$가 표본 크기에 끌려다녔습니다. **표본 크기에 안 끌려다니는 숫자**가 필요합니다.

**풀이.** (1) 차이를 표준편차 단위로 잽니다.

$$d=\frac{\bar{X}_{A}-\bar{X}_{B}}{s_{p}}\qquad t=d\sqrt{\frac{n}{2}}$$

**문제 1의 자료에서 $d$는 $1.7102$이고 $t$는 $3.8242$입니다.**

| $d$의 크기 | 흔히 부르는 말 |
|---|---|
| $0.2$ | 작다 |
| $0.5$ | 중간 |
| $0.8$ | 크다 |
| $1.2$ | 아주 크다 |

참 효과 $0.5$인 자료에서 표본만 늘려 봅니다.

| 표본 크기 | $d$의 평균 | $t$의 평균 | $t$를 $d$로 | 헤지스 보정 뒤 |
|---|---|---|---|---|
| $10$ | $0.5187$ | $1.1598$ | $0.5187$ | $0.4968$ |
| $40$ | $0.5071$ | $2.2679$ | $0.5071$ | $0.5022$ |
| $160$ | $0.5004$ | $4.4756$ | $0.5004$ | $0.4992$ |
| $640$ | $0.5001$ | $8.9461$ | $0.5001$ | $0.4998$ |

**$t$는 $1.1598$에서 $8.9461$로 여덟 배가 되는데 $d$는 $0.5$에 머뭅니다.**

**작은 표본에서 $d$가 조금 부풀어 있습니다.** 크기 $10$에서 $0.5187$인데, $s_{p}$가 참 표준편차를 조금 작게 잡기 때문입니다. **헤지스 보정**이 그것을 되돌립니다.

$$g=d\left(1-\frac{3}{4\nu-1}\right)$$

**보정 뒤 $0.4968$로 참값에 붙습니다.** 표본이 $40$을 넘으면 보정의 효과가 거의 없습니다.

(2) 그런데 $d$ 하나도 부족합니다. **추정에 딸린 불확실성**이 빠져 있습니다.

| 결과 | 차이의 추정 | $95$퍼센트 구간 | 무엇을 알 수 있나 |
|---|---|---|---|
| 유의, 좁음 | $5.0$ | $[4.2, 5.8]$ | 크고 정밀합니다 |
| 유의, 넓음 | $5.0$ | $[0.3, 9.7]$ | 방향만 압니다 |
| 무의, 좁음 | $0.2$ | $[-0.6, 1.0]$ | 작다고 말합니다 |
| 무의, 넓음 | $0.2$ | $[-8.0, 8.4]$ | 아무것도 모릅니다 |

**셋째 줄과 넷째 줄이 $p$ 값으로는 똑같이 "유의하지 않음"입니다.** 그런데 하나는 **효과가 작다는 증거**이고 다른 하나는 **증거가 없다는 뜻**입니다.

$$\text{유의하지 않음}\;\neq\;\text{차이가 없음}$$

**첫째 줄과 둘째 줄도 마찬가지입니다.** 둘 다 유의한데, 하나는 효과를 $[4.2, 5.8]$로 좁히고 하나는 $[0.3, 9.7]$이라 **거의 아무 값이나 가능합니다.**

**이 문제에서 배우는 것.** **보고할 것은 $p$ 값이 아니라 추정값과 구간입니다.** $p$ 값은 구간이 $0$을 포함하는지만 알려 주므로 **구간을 보고하면 $p$ 값이 따라오고 그 반대는 안 됩니다.** 그리고 넷째 줄이 실무에서 가장 자주 잘못 읽히는데, 표본이 작아 아무것도 못 잰 결과가 **"차이가 없음이 확인되었습니다"로 보고**됩니다. 정말로 차이가 없다고 말하려면 셋째 줄처럼 **구간이 의미 없는 크기 안에 갇혀야** 하며, 그것을 미리 설계하는 것이 183강의 검정력입니다.

**바로 확인 5.**

*답.* 평균 차이를 합동 표준편차로 나눈 값이며 $t=d\sqrt{n/2}$입니다.

*답.* $d$는 $0.5187$과 $0.5001$이고 $t$는 $1.1598$과 $8.9461$입니다.

**확인 5-3.** 유의하지 않은 두 결과가 어떻게 다를 수 있는지 쓰세요.

*답.* 구간이 좁으면 효과가 작다는 증거이고 넓으면 증거가 없다는 뜻입니다.

## 심화 문제

> **심화 1.** $t$ 분포가 어디서 오는지 정리하세요.

**분모가 상수가 아니라 확률변수**라서 꼬리가 두꺼워집니다.

**자유도가 커지면 정규분포로 갑니다.** $s$가 $\sigma$에 가까워져 분모의 흔들림이 사라지기 때문입니다.

**작은 표본에서 정규 기준값 $1.96$을 쓰면 너무 자주 기각합니다.** 자유도 $5$에서 진짜 기준은 $2.5706$이며, $1.96$을 쓰면 오류율이 $0.05$를 크게 넘습니다.

> **심화 3.** 단측검정을 정리하세요.

> **심화 4.** 검정을 반복해서 보는 위험을 정리하세요.

| 몇 번 들여다보는가 | 실제 오류율 | 목표 |
|---|---|---|
| $1$ | $0.0496$ | $0.05$ |
| $2$ | $0.0831$ | $0.05$ |
| $5$ | $0.1414$ | $0.05$ |
| $10$ | $0.1947$ | $0.05$ |

**열 번만 봐도 오류율이 $0.05$에서 $0.1947$로 네 배가 됩니다.** $p$ 값이 문제 4처럼 고르게 퍼져 있으므로, 계속 뽑으면 언젠가 $0.05$ 아래를 지나갑니다.

**멈추는 규칙이 검정의 일부입니다.** 표본 크기를 미리 정하거나, 여러 번 볼 것이면 **볼 때마다의 기준을 미리 나눠** 두어야 합니다. 182강의 다중비교와 같은 문제이며, 여기서는 **시간축을 따라** 일어납니다.

> **심화 5.** 비율의 비교를 정리하세요.

두 집단의 **비율**을 견주는 것도 같은 뼈대입니다.

$$z=\frac{\hat{p}_{A}-\hat{p}_{B}}{\sqrt{\hat{p}(1-\hat{p})\left(\frac{1}{n_{A}}+\frac{1}{n_{B}}\right)}}$$

**평균의 자리에 비율이 들어갑니다.** 이항의 분산이 $p(1-p)$로 평균에 매여 있는 것만 다릅니다.

| 여러 지표 동시 | 182강의 다중비교 |

import numpy as np

rng = np.random.default_rng(20260915)


def pw(s, n):
    k = n - sum(2 if ord(c) > 0x2FFF else 1 for c in str(s))
    return str(s) + " " * max(k, 0)


def rw(s, n):
    k = n - sum(2 if ord(c) > 0x2FFF else 1 for c in str(s))
    return " " * max(k, 0) + str(s)


def tstat_pooled(a, b):
    na, nb = len(a), len(b)
    sp2 = ((na - 1) * a.var(ddof=1) + (nb - 1) * b.var(ddof=1)) / (na + nb - 2)
    se = np.sqrt(sp2 * (1.0 / na + 1.0 / nb))
    return (a.mean() - b.mean()) / se, na + nb - 2


def tstat_welch(a, b):
    va, vb = a.var(ddof=1) / len(a), b.var(ddof=1) / len(b)
    se = np.sqrt(va + vb)
    df = (va + vb) ** 2 / (va ** 2 / (len(a) - 1) + vb ** 2 / (len(b) - 1))
    return (a.mean() - b.mean()) / se, df


def tcdf(t, df):
    x = df / (df + t * t)
    return 1.0 - 0.5 * betainc(0.5 * df, 0.5, x) if t > 0 else 0.5 * betainc(0.5 * df, 0.5, x)


def betainc(a, b, x):
    if x <= 0.0:
        return 0.0
    if x >= 1.0:
        return 1.0
    lbeta = gammaln(a) + gammaln(b) - gammaln(a + b)
    front = np.exp(a * np.log(x) + b * np.log(1.0 - x) - lbeta)
    if x < (a + 1.0) / (a + b + 2.0):
        return front * betacf(a, b, x) / a
    return 1.0 - np.exp(b * np.log(1.0 - x) + a * np.log(x) - lbeta) * betacf(b, a, 1.0 - x) / b


def betacf(a, b, x):
    c, d = 1.0, 1.0 - (a + b) * x / (a + 1.0)
    d = 1.0 / (1e-300 if abs(d) < 1e-300 else d)
    h = d
    for m in range(1, 300):
        num = m * (b - m) * x / ((a + 2 * m - 1) * (a + 2 * m))
        d = 1.0 + num * d
        c = 1.0 + num / c
        d = 1.0 / (1e-300 if abs(d) < 1e-300 else d)
        c = 1e-300 if abs(c) < 1e-300 else c
        h *= d * c
        num = -(a + m) * (a + b + m) * x / ((a + 2 * m) * (a + 2 * m + 1))
        d = 1.0 + num * d
        c = 1.0 + num / c
        d = 1.0 / (1e-300 if abs(d) < 1e-300 else d)
        c = 1e-300 if abs(c) < 1e-300 else c
        h *= d * c
    return h


def gammaln(z):
    g = [676.5203681218851, -1259.1392167224028, 771.32342877765313,
         -176.61502916214059, 12.507343278686905, -0.13857109526572012,
         9.9843695780195716e-6, 1.5056327351493116e-7]
    if z < 0.5:
        return np.log(np.pi / np.sin(np.pi * z)) - gammaln(1.0 - z)
    z -= 1.0
    x = 0.99999999999980993
    for i, gi in enumerate(g):
        x += gi / (z + i + 1.0)
    t = z + 7.5
    return 0.5 * np.log(2 * np.pi) + (z + 0.5) * np.log(t) - t + np.log(x)


def pval2(t, df):
    return 2.0 * (1.0 - tcdf(abs(t), df))


def tcrit(df, alpha=0.05):
    lo, hi = 0.0, 50.0
    for _ in range(200):
        mid = 0.5 * (lo + hi)
        if pval2(mid, df) > alpha:
            lo = mid
        else:
            hi = mid
    return 0.5 * (lo + hi)
