# 185강. 다중회귀의 해석

184강에서 변수가 **하나**였습니다. **하나 더 넣습니다.**

$$Y=\beta_{0}+\beta_{1}X_{1}+\beta_{2}X_{2}+\varepsilon$$

계산은 거의 같습니다. **바뀌는 것은 계수의 뜻**입니다.

| 어느 모형인가 | $x$의 계수가 무엇인가 |
|---|---|
| $x$만 | $z$를 놔둔 채 $x$가 $1$ 늘 때의 $y$ 변화 |
| $x$와 $z$ | $z$를 고정하고 $x$가 $1$ 늘 때의 $y$ 변화 |

**같은 자료에서 두 값이 크게 다를 수 있습니다.** 문제 1에서 $2.00$과 $1.02$가 나오는데, **어느 쪽도 계산 실수가 아닙니다.**

**177강 문제 3이 여기서 실행됩니다.** 교란과 충돌부와 중간변수를 그때는 그림으로 봤고, 이제 **회귀 한 줄로** 다룹니다. 그리고 무엇을 넣을지는 여전히 **자료가 안 정합니다.**

## 이 강의에서 할 수 있게 되는 것
- 누락변수 편향을 공식으로 분해하고 수치로 확인할 수 있습니다.
- 다중회귀 계수가 잔차끼리의 회귀와 같음을 보이고 해석할 수 있습니다.
- 무엇을 통제하느냐로 총효과와 직접효과가 갈리는 것을 판정할 수 있습니다.
- 계수의 크기로 중요도를 견줄 수 없는 이유를 단위 변환으로 보일 수 있습니다.
- 변수를 넣는 것이 정확도와 치우침에 어떻게 작용하는지 계산할 수 있습니다.

## 문제 1. 변수를 하나 더 넣으면

> **문제.** 변수 하나를 더합니다.
> (1) 두 모형의 계수를 견주세요.
> (2) 차이가 어디서 오는지 분해하세요.

**생각의 실마리.** 참 모형이 $y=1.0x+2.0z$인데 **$x$와 $z$가 서로 얽혀 있으면**, $x$만 넣은 회귀는 $z$의 몫까지 $x$에 얹습니다.

**풀이.** (1) $x$와 $z$의 상관이 $0.7019$입니다.

| 모형 | $x$의 계수 | 표준오차 | $R^{2}$ |
|---|---|---|---|
| $x$만 | $1.999538$ | $0.022480$ | $0.725195$ |
| $x$와 $z$ | $1.016679$ | $0.018496$ | $0.905649$ |

**참 계수가 $1.0$인데 $x$만 넣으면 $2.00$이 나옵니다.** 두 배입니다.

**표준오차가 $0.0225$라 우연으로 설명되지 않습니다.** 자료를 더 모아도 $2.00$에 더 정확히 수렴할 뿐입니다.

(2) 차이가 어디서 오는지 분해합니다. $z$를 $x$로 회귀한 기울기가 $0.500013$입니다.

| 무엇 | 값 |
|---|---|
| $z$를 고정한 $x$의 효과 | $1.016679$ |
| $z$의 효과 | $1.965668$ |
| $x$가 $1$ 늘 때 $z$가 느는 양 | $0.500013$ |
| 섞여 들어온 몫 | $0.982859$ |
| 둘의 합 | $1.999538$ |
| $x$만 넣었을 때의 계수 | $1.999538$ |

$$\hat{\beta}_{1}^{\text{단순}}=\beta_{1}+\beta_{2}\cdot\frac{S_{x z}}{S_{xx}}$$

**마지막 두 줄이 정확히 같습니다.** 이것이 **누락변수 편향 공식**이며, **빠진 변수의 효과에 그 변수가 $x$를 따라 움직이는 정도를 곱한 값**입니다.

**두 항 중 하나만 $0$이면 편향이 없습니다.** 빠진 변수가 $y$에 영향이 없거나, $x$와 무관하면 됩니다. 그래서 **무작위 배정이 강력합니다.** $x$를 동전으로 정하면 어떤 변수와도 상관이 $0$이 되어, **빠뜨려도 편향이 안 생깁니다.**

**이 문제에서 배우는 것.** **편향의 방향을 미리 짐작할 수 있다는 것이 이 공식의 실용적 가치입니다.** 교육 연수의 임금 효과를 추정할 때 능력을 못 쟀다면, 능력이 임금에 양의 효과($\beta_{2}>0$)이고 교육과 양의 상관($S_{xz}>0$)이므로 **계수가 위로 부풀어 있습니다.** 그러면 추정값을 상한으로 읽을 수 있고, 그것만으로도 결론이 서는 경우가 있습니다. 177강 문제 4의 민감도 분석이 이 발상을 일반화한 것입니다.

**바로 확인 1.**

**확인 1-1.** 누락변수 편향 공식을 쓰세요.

*답.* 빠진 변수의 효과에 그 변수를 $x$로 회귀한 기울기를 곱한 값입니다.

**확인 1-2.** 검산에서 두 모형의 $x$ 계수를 쓰세요.

*답.* $1.999538$과 $1.016679$입니다.

**확인 1-3.** 편향이 $0$이 되는 두 경우를 쓰세요.

*답.* 빠진 변수가 $y$에 영향이 없거나 $x$와 무관할 때입니다.

## 문제 2. 계수가 무엇을 재는지 정확히

> **문제.** 계수의 정확한 뜻을 밝힙니다.
> (1) 잔차끼리의 회귀와 같은지 확인하세요.
> (2) 어느 쪽을 잔차로 바꿔야 하는지 확인하세요.
> (3) 통제 변수에 따라 무엇이 달라지는지 보세요.

**생각의 실마리.** "$z$를 고정하고"라는 말이 무슨 뜻인지 계산으로 확인합니다. **$z$로 설명되는 몫을 빼고 남은 것**이 그 뜻입니다.

**풀이.** (1) $x$에서 $z$의 몫을 빼고, $y$에서도 $z$의 몫을 뺍니다.

**남은 것끼리 단순회귀한 기울기가 $1.016679$이고 다중회귀의 $x$ 계수도 $1.016679$입니다.**

$$\hat{\beta}_{1}=\frac{\langle \tilde{y},\tilde{x}\rangle}{\langle \tilde{x},\tilde{x}\rangle}\qquad\tilde{x}=x-\hat{x}(z),\;\tilde{y}=y-\hat{y}(z)$$

**이것을 프리슈-워-로벨 정리라 합니다.** 다중회귀가 **"다른 변수를 걷어 낸 뒤의 단순회귀"**임을 말해 줍니다.

(2) 어느 쪽을 잔차로 바꿔야 하는지 봅니다.

| 무엇을 회귀하는가 | 기울기 | 맞는가 |
|---|---|---|
| 잔차 대 잔차 | $1.016679$ | 예 |
| 원래 $y$ 대 $x$ 잔차 | $1.016679$ | 예 |
| $y$ 잔차 대 원래 $x$ | $0.515823$ | 아니오 |

**$x$ 쪽만 잔차로 바꾸면 됩니다.** $y$를 그대로 둬도 같은 값이 나오는데, $\tilde{x}$가 $z$와 직교하므로 **$y$의 $z$ 성분이 어차피 걸리지 않기** 때문입니다.

**반대로 $y$만 바꾸고 $x$를 그대로 두면 $0.5158$로 다른 값**입니다. 대칭이 아닙니다.

(3) 통제 변수에 따라 무엇이 달라지는지 봅니다. 177강 문제 3의 세 구조를 회귀로 다시 봅니다.

| 무엇을 넣는가 | $t$의 계수 | 겨냥한 참값 | 무엇을 재는가 |
|---|---|---|---|
| $t$만 | $3.769792$ | $3.0$ | 총효과인데 $u$로 교란됨 |
| $t$와 $u$ | $3.019059$ | $3.0$ | 총효과 |
| $t$와 $m$ | $1.788148$ | $1.0$ | 직접효과인데 $u$로 교란됨 |
| $t$와 $m$과 $u$ | $0.992800$ | $1.0$ | 직접효과 |
| $t$와 $c$를 넣음 | $0.713272$ | $1.0$ | 충돌부라 망가짐 |

**교란 $u$를 넣어야 겨냥한 값에 닿습니다.** $3.019059$와 $0.992800$이 그 두 줄입니다.

**중간변수 $m$을 넣으면 직접효과가 되고 안 넣으면 총효과가 됩니다.** 둘 다 옳은 답인데, **다른 물음에 대한 답**입니다.

**마지막 줄은 충돌부라 겨냥한 값이 없습니다.** $0.713272$는 아무것도 아닙니다.

**어느 것이 옳은지는 무엇을 알고 싶은지가 정합니다.** 자료는 안 정합니다.

**이 문제에서 배우는 것.** **"모든 변수를 통제했습니다"는 문장이 성립할 수 없습니다.** 위 표에서 다섯 모형이 다 다른 답을 주고, 그중 넷은 어떤 물음에는 옳습니다. 그래서 회귀 결과를 읽을 때 **어느 변수가 들어갔는지 목록을 먼저 봐야** 하며, 목록이 없는 계수는 해석할 수 없습니다. 실무의 보고서가 "여러 요인을 통제한 결과"라고만 적으면 그 계수는 **총효과인지 직접효과인지도 알 수 없는 숫자**입니다.

**바로 확인 2.**

**확인 2-1.** 프리슈-워-로벨 정리를 한 문장으로 쓰세요.

*답.* 다중회귀의 계수가 다른 변수를 걷어 낸 잔차끼리의 단순회귀와 같습니다.

**확인 2-2.** 검산에서 $y$만 잔차로 바꿨을 때의 기울기를 쓰세요.

*답.* $0.515823$으로 다중회귀 값 $1.016679$와 다릅니다.

**확인 2-3.** 검산에서 총효과와 직접효과에 닿은 두 모형을 쓰세요.

*답.* $t$와 $u$가 $3.019059$이고 $t$와 $m$과 $u$가 $0.992800$입니다.

## 문제 3. 계수를 견줄 수 있는가

> **문제.** 계수의 크기를 다룹니다.
> (1) 단위가 다른 두 변수의 계수를 견주세요.
> (2) 단위를 바꿔 무엇이 변하는지 확인하세요.
> (3) 전체 유의성과 개별 유의성을 구분하세요.

**생각의 실마리.** 계수는 **"$x$가 한 단위 늘 때"**의 변화입니다. 한 단위가 무엇이냐가 변수마다 다르면, **계수를 나란히 놓는 것이 뜻이 없습니다.**

**풀이.** (1) 참 계수가 $0.2$와 $30.0$입니다.

| 변수 | 계수 | 표준편차 | 표준화 계수 | $t$ |
|---|---|---|---|---|
| $a$ | $0.192787$ | $10.375924$ | $0.492426$ | $45.4503$ |
| $b$ | $29.636562$ | $0.099111$ | $0.723077$ | $66.7392$ |

**계수는 $30$ 대 $0.2$로 $150$배 차이인데 표준화하면 $0.49$ 대 $0.72$입니다.**

$$\text{표준화 계수}=\hat{\beta}_{j}\cdot\frac{s_{x_{j}}}{s_{y}}$$

**표준편차 한 개만큼 움직일 때의 변화**로 바꾼 것이며, 그래야 견줄 수 있습니다.

(2) 단위를 바꿔 확인합니다.

| $b$를 무엇으로 재는가 | $b$의 계수 | $t$ |
|---|---|---|
| 원래 단위 | $29.636562$ | $66.7392$ |
| $100$배 단위 | $2963.656210$ | $66.7392$ |
| $0.01$배 단위 | $0.296366$ | $66.7392$ |

**계수는 $100$배씩 바뀌는데 $t$는 소수 넷째 자리까지 그대로입니다.**

**표준오차도 같은 비율로 바뀌기** 때문입니다. **$t$와 $p$ 값은 단위와 무관하고, 계수의 크기만 단위에 매여 있습니다.**

(3) 전체가 유의한지는 $F$로 봅니다.

| 무엇 | 값 | 자유도 | $p$ 값 |
|---|---|---|---|
| 전체 $F$ | $3261.044281$ | $2, 1997$ | $0.0000000000$ |
| $a$의 $t$ | $45.450346$ | $1997$ | $0.0000000000$ |
| $b$의 $t$ | $66.739200$ | $1997$ | $0.0000000000$ |

**전체 $F$는 모든 계수가 $0$인가를 묻고 각 $t$는 그 변수 하나를 묻습니다.**

**180강 문제 1의 구조 그대로입니다.** 개별 $t$를 여럿 보면 **다중비교**가 되며, 변수가 $20$개면 182강의 문제가 그대로 생깁니다.

**이 문제에서 배우는 것.** **표준화 계수도 만능이 아닙니다.** 표준편차로 나누는 것은 "이 변수가 실제로 얼마나 움직이는가"를 반영하는 것인데, **그 움직임의 범위는 표본이 정합니다.** 184강 문제 3에서 $R^{2}$이 $x$의 퍼짐에 끌려다닌 것과 같은 문제이며, 다른 표본에서는 표준화 계수의 순서도 바뀔 수 있습니다. 그리고 더미변수는 표준편차가 $\sqrt{p(1-p)}$라 **비율에 따라 표준화 계수가 달라지므로** 특히 조심해야 합니다. 결국 "어느 변수가 더 중요한가"는 통계가 아니라 **의사결정의 물음**이며, 그 변수를 실제로 얼마나 바꿀 수 있는지가 답을 정합니다.

**바로 확인 3.**

**확인 3-1.** 표준화 계수를 식으로 쓰세요.

*답.* 계수에 그 변수의 표준편차를 곱하고 $y$의 표준편차로 나눕니다.

**확인 3-2.** 검산에서 단위를 $100$배로 바꿨을 때 계수와 $t$를 쓰세요.

*답.* 계수는 $2963.656210$이 되고 $t$는 $66.7392$로 그대로입니다.

**확인 3-3.** 전체 $F$와 개별 $t$가 묻는 것을 각각 쓰세요.

*답.* $F$는 모든 계수가 $0$인가를, $t$는 그 변수 하나를 묻습니다.

## 문제 4. $R^{2}$은 반드시 오릅니다

> **문제.** 변수를 늘려 봅니다.
> (1) 잡음 변수만 넣어 $R^{2}$을 재세요.
> (2) 조정된 $R^{2}$의 벌점을 확인하세요.
> (3) 진짜 신호가 있을 때와 견주세요.

**생각의 실마리.** 변수를 하나 더 넣으면 **잔차 제곱합이 절대 늘지 않습니다.** 최악이라도 계수를 $0$으로 두면 되므로, $R^{2}$은 **반드시 오릅니다.**

**풀이.** (1) 관측 $60$개에 $y$와 아무 관계 없는 잡음 변수를 더해 봅니다.

| 넣은 변수 수 | $R^{2}$ | 조정된 $R^{2}$ | 전체 $F$의 $p$ 값 |
|---|---|---|---|
| $0$ | $0.000000$ | $0.000000$ | 없음 |
| $5$ | $0.006313$ | $-0.085695$ | $0.996563$ |
| $10$ | $0.164630$ | $-0.005854$ | $0.484547$ |
| $20$ | $0.310204$ | $-0.043537$ | $0.614194$ |
| $40$ | $0.701321$ | $0.072522$ | $0.410709$ |
| $58$ | $0.981785$ | $-0.074671$ | $0.696113$ |

**변수 $58$개를 넣으면 $R^{2}$이 $0.981785$입니다.** 참 관계가 하나도 없는데 **거의 완벽하게 설명**합니다.

**관측이 $60$개인데 계수가 $59$개**라 그렇습니다. 자유도가 $1$만 남으므로 **점들을 거의 정확히 지나는 면**을 만들 수 있습니다.

**조정된 $R^{2}$은 $0$ 근처를 맴돕니다.** 잡음만 넣었으므로 **벌점이 이득을 정확히 상쇄**합니다.

**전체 $F$의 $p$ 값은 유의해지지 않습니다.** 자유도가 줄어 검정이 힘을 잃기 때문이며, **$R^{2}$이 $0.98$인데 $p$가 $0.70$**인 것이 이 상황의 요약입니다.

(2) 벌점을 봅니다.

$$R^{2}_{\text{adj}}=1-(1-R^{2})\frac{n-1}{n-p}$$

| 변수 수 | 자유도 | $(n-1)/(n-p)$ | $R^{2}$이 $0.5$일 때 |
|---|---|---|---|
| $1$ | $58$ | $1.017241$ | $0.491379$ |
| $5$ | $54$ | $1.092593$ | $0.453704$ |
| $10$ | $49$ | $1.204082$ | $0.397959$ |
| $20$ | $39$ | $1.512821$ | $0.243590$ |
| $40$ | $19$ | $3.105263$ | $-0.552632$ |

**변수가 늘수록 벌점이 커집니다.** $40$개면 $R^{2}$ $0.5$가 조정 후 $-0.5526$으로 **음수**가 됩니다.

**189강에서 이 발상이 AIC와 BIC로 이어집니다.**

## 심화 문제

> **심화 1.** 행렬로 쓰면 어떻게 되는지 정리하세요.

변수가 여럿이면 **행렬 표기가 훨씬 짧습니다.**

$$\hat{\boldsymbol{\beta}}=(X^{\top}X)^{-1}X^{\top}\mathbf{y}\qquad\text{Var}(\hat{\boldsymbol{\beta}})=\sigma^{2}(X^{\top}X)^{-1}$$

| 무엇 | 어디서 나오는가 |
|---|---|
| 정규방정식 | $X^{\top}(\mathbf{y}-X\boldsymbol{\beta})=0$ |
| 사영행렬 | $H=X(X^{\top}X)^{-1}X^{\top}$ |
| 레버리지 | $H$의 대각성분 |
| 잔차 | $(I-H)\mathbf{y}$ |

**80강부터 83강의 최소제곱이 그대로입니다.** $\mathbf{y}$를 $X$의 열공간에 **정사영**한 것이 예측값이고, 잔차는 그 공간에 **수직**입니다.

**184강 문제 1에서 잔차의 합과 $\sum e_{i}x_{i}$가 $0$이었던 것**이 이 수직성입니다. 열공간의 모든 벡터와 직교하므로, $\mathbf{1}$과 $\mathbf{x}$ 각각에 대해 $0$이 됩니다.

**$H$의 대각합이 $p$입니다.** 184강에서 레버리지의 합이 계수의 수라고 한 것이 여기서 나옵니다.

> **심화 2.** $X^{\top}X$가 뒤집히지 않을 때를 정리하세요.

| 언제 | 왜 |
|---|---|
| 변수가 관측보다 많음 | 열이 독립일 수 없습니다 |
| 한 변수가 다른 것의 조합 | 열이 종속입니다 |
| 더미를 전부 넣음 | 합이 상수열과 같습니다 |

**셋째 줄이 더미변수 함정이며 186강에서 다룹니다.** 범주가 셋이면 더미를 셋 다 넣으면 안 되고 **둘만** 넣습니다.

**완전히 종속이 아니라 거의 종속이면 더 나쁩니다.** 역행렬이 존재하지만 원소가 폭발하며, **187강의 다중공선성**이 그 이야기입니다.

**해결책은 세 가지입니다.** 변수를 빼거나, 합치거나, 211강의 정규화로 **뒤집히게 만듭니다.** 능형회귀는 대각선에 상수를 더해 강제로 뒤집는 방법입니다.

> **심화 3.** 부분 상관과 편상관을 정리하세요.

문제 2의 잔차끼리 회귀를 **상관으로** 보면 다른 이름이 붙습니다.

| 이름 | 무엇의 상관 |
|---|---|
| 단순 상관 | $x$와 $y$ |
| 편상관 | $\tilde{x}$와 $\tilde{y}$ |
| 부분 상관 | $\tilde{x}$와 원래 $y$ |

**둘째 줄이 다중회귀 계수와 부호가 같습니다.** 문제 2에서 잔차 대 잔차가 다중회귀 계수와 같았던 것의 상관 버전입니다.

$$r_{xy\cdot z}=\frac{r_{xy}-r_{xz}r_{yz}}{\sqrt{(1-r_{xz}^{2})(1-r_{yz}^{2})}}$$

**166강 문제 4의 심슨 역설이 이 식으로 설명됩니다.** $r_{xy}$가 양수여도 $r_{xz}r_{yz}$가 더 크면 편상관이 음수가 됩니다.

> **심화 4.** 상호작용 없이 더한다는 가정을 정리하세요.

$$Y=\beta_{0}+\beta_{1}X_{1}+\beta_{2}X_{2}$$

**이 식은 $X_{1}$의 효과가 $X_{2}$와 무관하다고 가정합니다.** $X_{2}$가 무엇이든 $X_{1}$이 $1$ 늘면 $\beta_{1}$만큼 오릅니다.

| 교육 수익이 성별에 따라 다름 | 차이가 있습니다 |

**셋 다 덧셈 모형으로는 못 담습니다.** 곱셈 항을 넣어야 하며, **186강의 교호작용**입니다.

**교호작용을 안 넣으면 계수가 평균 효과가 됩니다.** 어느 집단에도 정확히 맞지 않는 값이며, 그것이 유용한지는 물음이 정합니다.

> **심화 5.** 계수의 신뢰구간과 결합 검정을 정리하세요.

계수마다 구간을 만들면 **각각은 $95$퍼센트**입니다. 둘을 함께 보면 다릅니다.

| 무엇 | 무엇을 담는가 |
|---|---|
| 개별 구간 두 개 | 직사각형 |

def gammaln(z):

def betacf(a, b, x):
    c, d = 1.0, 1.0 - (a + b) * x / (a + 1.0)
    d = 1.0 / (1e-300 if abs(d) < 1e-300 else d)
    h = d
    for m in range(1, 400):
        num = m * (b - m) * x / ((a + 2 * m - 1) * (a + 2 * m))
        d = 1.0 + num * d
        c = 1.0 + num / c
        d = 1.0 / (1e-300 if abs(d) < 1e-300 else d)
        c = 1e-300 if abs(c) < 1e-300 else c
        h *= d * c
        num = -(a + m) * (a + b + m) * x / ((a + 2 * m) * (a + 2 * m + 1))
        d = 1.0 + num * d
        c = 1.0 + num / c
        d = 1.0 / (1e-300 if abs(d) < 1e-300 else d)
        c = 1e-300 if abs(c) < 1e-300 else c
        de = d * c

    if x <= 0.0:

    if x >= 1.0:

    return betainc(0.5 * d2, 0.5 * d1, d2 / (d2 + d1 * f))


def ols(y, *xs):
    A = np.stack([np.ones(len(y))] + list(xs), axis=1)
    b, *_ = np.linalg.lstsq(A, y, rcond=None)
    yh = A @ b
    e = y - yh
    n, p = A.shape
    s2 = (e ** 2).sum() / (n - p)
    XtXi = np.linalg.inv(A.T @ A)
    se = np.sqrt(s2 * np.diag(XtXi))
    sst = ((y - y.mean()) ** 2).sum()
    sse = (e ** 2).sum()
    r2 = 1.0 - sse / sst
    adj = 1.0 - (1.0 - r2) * (n - 1) / (n - p)
    return dict(b=b, se=se, e=e, s2=s2, n=n, p=p, sse=sse, sst=sst,
                r2=r2, adj=adj, df=n - p)
