# 02. 집합과 함수

이 단원은 논리의 언어로 대상을 다루는 그릇을 만듭니다. 먼저 집합을 정의하고 합집합·교집합·차집합·여집합·곱집합을 논리 연산과 짝지어 읽습니다. 그다음 한 집합에서 다른 집합으로 가는 함수를 정의하고 단사·전사·전단사를 판정합니다. 마지막으로 멱집합과 집합족, 여러 집합의 데카르트 곱으로 다루는 대상의 범위를 넓힙니다.

# 이 단원을 읽기 전에

- [01. 명제와 논리](../01. 명제와 논리/index.md)를 먼저 읽어야 합니다. 집합의 상등과 부분집합은 모두 조건명제와 한정기호로 정의됩니다.
- 집합 연산의 법칙은 1강의 논리 동치를 그대로 옮긴 것입니다. 드모르간 법칙을 논리 쪽에서 확인해 둡니다.
- 공허하게 참인 조건명제를 이해하지 못하면 공집합이 모든 집합의 부분집합이라는 사실을 받아들이기 어렵습니다.

# 각 강의가 맡는 역할

- 3. 집합과 함수
  집합의 표기와 연산을 정의하고, 집합의 상등을 원소의 소속으로 증명합니다. 함수의 정의역·공역·치역을 구분하고 단사·전사·전단사와 합성, 역함수를 다룹니다.
- 4. 멱집합, 집합족, 데카르트 곱
  부분집합 전체를 모은 멱집합과 집합을 원소로 갖는 집합족을 다루고, 첨수집합 위의 합집합·교집합을 정의합니다. 여러 집합의 데카르트 곱으로 순서쌍을 순서열로 확장합니다.
- 문제집 - 02. 집합과 함수
  두 강의의 집합 증명과 함수 판정을 본문보다 한 단계 어려운 문항으로 훈련합니다.

# 이 단원을 마치면 할 수 있는 것

- 집합을 원소나열법과 조건제시법으로 적고 서로 옮길 수 있습니다.
- 두 집합의 상등을 양방향 부분집합 또는 소속의 동치로 증명할 수 있습니다.
- 주어진 함수의 단사·전사·전단사를 판정하고 근거를 증명으로 쓸 수 있습니다.
- 유한집합의 멱집합을 모두 나열하고 그 크기가 $2^n$임을 설명할 수 있습니다.
- 첨수집합 위의 합집합과 교집합을 정의대로 계산할 수 있습니다.
