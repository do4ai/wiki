# 11. 실습 코드 레퍼런스
이 장은 앞의 열 개 장이 설명한 내용을 실제로 구현한 코드를 그대로 담습니다. 1장부터 10장까지는 무엇을 왜 그렇게 만드는지를 설명하고 코드를 싣지 않습니다. 그래서 설명을 다 읽고 나면 "그래서 파일이 정확히 어떻게 생겼는가"라는 질문이 남습니다. 이 장이 그 질문에 답합니다.

# 이 장을 쓰는 방법
- 먼저 해당 장의 설명을 읽고, 그다음에 이 장에서 같은 부분의 코드를 봅니다.
- 코드를 먼저 읽지 않습니다. 설계 의도를 모른 채 코드를 보면 구조가 왜 그렇게 나뉘었는지 알 수 없습니다.
- 각 절의 도입부에 어느 장의 어느 절과 짝을 이루는지 적어 두었으므로, 그 연결을 따라 오갑니다.

# 코드를 싣는 범위
- 저장소가 가진 소스 파일과 명세 문서를 모두 싣습니다.
- 패키지 잠금 파일(`pnpm-lock.yaml`, `server/uv.lock`)은 도구가 다시 만들어 내는 파일이므로 싣지 않습니다.
- 저장소 공통 자동화 스크립트(`sdd/99_toolchain/`)는 이 교재의 내용이 아니라 여러 저장소가 공유하는 도구이므로 싣지 않습니다.
