# 02. 점화식과 생성함수

이 단원은 "다음 항이 앞의 항들로 정해지는" 수열을 다룹니다. 계단을 한 칸 또는 두 칸씩 오르는 방법의 수, 원금에 이자가 붙는 예금, 재귀 알고리즘의 호출 횟수가 모두 그런 수열입니다. 이 단원은 점화식을 세우는 법에서 출발해, 항 번호만 넣으면 값이 나오는 닫힌 식을 구하는 두 가지 표준 도구인 생성함수와 특성방정식을 세웁니다.

# 이 단원을 읽기 전에

- [1강. 조합과 셈](../01. 셈과 조합/1. 조합과 셈/index.md)의 순열, 조합, 이항계수를 점화식 세우기와 생성함수 전개에 씁니다.
- `집합론과 논리`의 [7강. 증명법](../../집합론과 논리/04. 증명법/7. 증명법/index.md)의 수학적 귀납법으로 닫힌 식이 맞는지 검증합니다.
- 이 단원은 3강, 4강 순서로 읽어야 합니다. 4강의 일반해 이론은 3강에서 손으로 푼 예를 일반화한 것입니다.

# 이 단원의 읽기 순서

1. 3. 점화식과 생성함수
2. 4. 선형점화식의 일반해

# 각 강의가 맡는 역할

- 3. 점화식과 생성함수
  점화식과 초기조건으로 수열을 정의하고, 등차·등비 점화식을 닫힌 식으로 풀고, 생성함수로 점화식을 푸는 절차를 익힙니다.
- 4. 선형점화식의 일반해
  상수계수 선형점화식의 특성방정식을 세우고, 중근과 비동차항이 있는 경우까지 일반해의 구조를 정리합니다.

# 이 단원을 마치면 할 수 있는 것

- 말로 서술된 상황에서 점화식과 초기조건을 세울 수 있습니다.
- 등차·등비 점화식을 닫힌 식으로 풀 수 있습니다.
- 특성방정식으로 상수계수 선형 동차 점화식의 일반해를 구할 수 있습니다.
- 중근과 비동차항이 있는 점화식의 해를 구성할 수 있습니다.
- 생성함수를 세워 부분분수 분해로 일반항을 뽑을 수 있습니다.
