# 22강. 한정 기호와 부정

21강 문제 1에서 "$x+1=4$입니다"는 명제가 되지 못했습니다. $x$가 무엇인지 모르면 참거짓을 말할 수 없기 때문입니다. 그때 명제로 만드는 방법이 두 가지라고 했고, 그중 하나가 범위를 지정하는 말을 붙이는 것이었습니다. 이 강의는 그 말을 기호로 적습니다.

이 기호가 없으면 수학의 정리를 정확히 읽을 수 없습니다. "연속함수는 최댓값을 가집니다"라는 문장은 실제로는 "닫힌구간에서 정의된 **모든** 연속함수 $f$에 대하여, $f(c)$가 최대가 되는 점 $c$가 그 구간 안에 **존재합니다**"라는 뜻입니다. 36강에서 이 정리를 만날 때 두 한정 기호의 위치가 정리의 내용 전부를 결정합니다.

## 이 강의에서 할 수 있게 되는 것
- "모든"과 "어떤"을 $\forall$과 $\exists$로 적고 범위를 함께 밝힐 수 있습니다.
- 한정 기호가 붙은 명제의 부정을 규칙에 따라 만들 수 있습니다.
- 반례 하나를 제시해 "모든" 명제가 거짓임을 보일 수 있습니다.
- 두 한정 기호의 순서를 바꾸면 뜻이 달라짐을 예로 보일 수 있습니다.
- 조건문이 섞인 정리의 부정을 정확히 쓸 수 있습니다.

## 문제 1. "모든"과 "어떤"을 어떻게 적는가

> **문제.** 다음 세 문장을 기호로 적고 참거짓을 판정하세요. 범위는 실수 전체 $\mathbb{R}$로 합니다.
> (가) 모든 실수의 제곱은 $0$ 이상입니다.
> (나) 어떤 실수는 제곱하면 $2$가 됩니다.
> (다) 모든 실수는 제곱하면 $2$가 됩니다.

**생각의 실마리.** 세 문장 모두 $x^{2}$에 대한 조건을 말하고 있는데 앞에 붙은 말이 다릅니다. "모든"은 범위 안의 하나도 빠짐없이 성립해야 하고, "어떤"은 하나라도 성립하면 됩니다. 이 차이가 참거짓을 어떻게 가르는지 봅니다.

**풀이.** (가)는 $\forall x\in\mathbb{R},\; x^{2}\ge 0$으로 씁니다. 1강에서 확인한 대로 실수를 제곱하면 음수가 나오지 않으므로 참입니다.

(나)는 $\exists x\in\mathbb{R},\; x^{2}=2$로 씁니다. $x=\sqrt{2}$가 실제로 존재하고 $(\sqrt{2})^{2}=2$이므로 참입니다. 하나만 찾으면 되므로 이것으로 증명이 끝났습니다.

(다)는 $\forall x\in\mathbb{R},\; x^{2}=2$로 씁니다. $x=0$을 넣으면 $0^{2}=0\ne 2$이므로 성립하지 않는 실수가 있습니다. 따라서 거짓입니다.

**이 문제에서 배우는 것: 전칭 기호와 존재 기호.**

$\forall$을 **전칭 기호**라고 하고 "모든"이라고 읽습니다. $\forall x\in A,\;P(x)$는 "집합 $A$의 모든 원소 $x$에 대하여 $P(x)$가 성립합니다"라는 뜻입니다.

$\exists$를 **존재 기호**라고 하고 "어떤" 또는 "존재합니다"라고 읽습니다. $\exists x\in A,\;P(x)$는 "$P(x)$가 성립하는 $x$가 $A$ 안에 적어도 하나 있습니다"라는 뜻입니다.

여기서 두 가지를 반드시 지킵니다.

첫째, **범위를 항상 밝힙니다.** $\exists x,\;x^{2}=2$는 범위가 실수면 참이지만 유리수면 거짓입니다. 24강에서 $\sqrt{2}$가 유리수가 아님을 증명하면서 이 차이를 확인합니다. 범위를 적지 않은 한정 명제는 참거짓을 말할 수 없습니다.

둘째, **"어떤"은 적어도 하나라는 뜻입니다.** 일상어에서 "어떤 학생은 지각했습니다"라고 하면 전부는 아니라는 뜻으로 들리지만, 수학에서 $\exists$는 하나 이상이면 참이고 전부여도 참입니다.

한정 기호가 하는 일을 한 줄로 정리하면, 변수가 들어 있어 참거짓이 정해지지 않던 **조건** $P(x)$를 참거짓이 정해지는 **명제**로 바꾸는 것입니다.

**바로 확인.**

**확인 1-1.** "모든 자연수는 $0$보다 큽니다"를 기호로 적고 참거짓을 판정하세요.

*답.* $\forall n\in\mathbb{N},\; n>0$입니다. 1강의 약속에서 자연수는 $1$부터이므로 참입니다.

**확인 1-2.** $\exists n\in\mathbb{N},\; n^{2}=n$의 참거짓을 판정하세요.

*답.* 참입니다. $n=1$이면 $1^{2}=1$이므로 조건을 만족하는 자연수가 존재합니다.

**확인 1-3.** $\forall x\in\mathbb{R},\; x^{2}>0$의 참거짓을 판정하세요.

*답.* 거짓입니다. $x=0$이면 $0^{2}=0$이므로 $0$보다 크지 않습니다. 부등호에 등호가 없다는 점이 (가)와의 차이입니다.

## 문제 2. 한정 기호가 붙은 문장을 어떻게 부정하는가

> **문제.** 다음 두 명제의 부정을 만들고, 부정이 참인지 거짓인지 판정하세요.
> (가) $\forall n\in\mathbb{N},\; n$은 짝수입니다.
> (나) $\exists x\in\mathbb{R},\; x^{2}+1=0$입니다.

**생각의 실마리.** (가)가 거짓이 되려면 무엇이 필요한지 말로 먼저 정리합니다. "모든 자연수가 짝수는 아니다"를 더 정확히 말하면 무엇입니까? 하나도 짝수가 아니라는 뜻입니까, 아니면 짝수가 아닌 것이 하나라도 있다는 뜻입니까?

**풀이.** (가)에서 "모든 자연수가 짝수"라는 주장이 무너지려면 짝수가 아닌 자연수가 **하나만** 있으면 충분합니다. 전부가 홀수일 필요는 없습니다. 그러므로 부정은

$$\exists n\in\mathbb{N},\; n\text{은 짝수가 아닙니다}$$

입니다. $n=1$이 그런 자연수이므로 이 부정은 참입니다. 따라서 원래 명제 (가)는 거짓입니다.

(나)에서 "$x^{2}+1=0$인 실수가 존재한다"는 주장이 무너지려면 그런 실수가 하나도 없어야 합니다. 그러므로 부정은

$$\forall x\in\mathbb{R},\; x^{2}+1\ne 0$$

입니다. 모든 실수에서 $x^{2}\ge 0$이므로 $x^{2}+1\ge 1>0$이고, 따라서 $x^{2}+1$은 결코 $0$이 되지 않습니다. 부정이 참이므로 원래 명제 (나)는 거짓입니다.

**이 문제에서 배우는 것: 한정 기호의 부정 규칙.**

$$\lnot\big(\forall x\in A,\;P(x)\big)\;\equiv\;\exists x\in A,\;\lnot P(x)$$
$$\lnot\big(\exists x\in A,\;P(x)\big)\;\equiv\;\forall x\in A,\;\lnot P(x)$$

말로 옮기면 **부정이 한정 기호를 통과하면서 $\forall$과 $\exists$가 서로 뒤바뀌고, 안쪽 조건에 부정이 붙습니다.**

이 규칙이 21강의 드모르간 법칙과 같은 것임을 보면 기억하기 쉽습니다. 범위가 $A=\{a_{1},a_{2},a_{3}\}$처럼 유한하면

$$\forall x\in A,\;P(x)\;\equiv\;P(a_{1})\land P(a_{2})\land P(a_{3})$$

이고, 여기에 드모르간 법칙을 적용하면 $\lnot P(a_{1})\lor\lnot P(a_{2})\lor\lnot P(a_{3})$이 되어 $\exists x\in A,\;\lnot P(x)$가 됩니다. $\forall$은 무한히 긴 $\land$이고 $\exists$는 무한히 긴 $\lor$인 셈입니다.

**범위는 부정할 때 바뀌지 않습니다.** $\forall x\in\mathbb{R}$의 부정은 $\exists x\in\mathbb{R}$이지 $\exists x\notin\mathbb{R}$이 아닙니다. 부정되는 것은 범위가 아니라 조건입니다.

**바로 확인.**

**확인 2-1.** $\forall x\in\mathbb{R},\; x^{3}>x$의 부정을 쓰고 참거짓을 판정하세요.

*답.* 부정은 $\exists x\in\mathbb{R},\; x^{3}\le x$입니다. $x=0$이면 $0\le 0$이므로 부정이 참이고 원래 명제는 거짓입니다.

**확인 2-2.** $\exists n\in\mathbb{N},\; n+1<n$의 부정을 쓰고 참거짓을 판정하세요.

*답.* 부정은 $\forall n\in\mathbb{N},\; n+1\ge n$입니다. 모든 자연수에서 $n+1$은 $n$보다 크므로 부정이 참이고 원래 명제는 거짓입니다.

**확인 2-3.** "모든 학생이 시험에 합격하지는 않았습니다"와 "모든 학생이 시험에 불합격했습니다"를 각각 기호로 적어 다름을 보이세요.

*답.* 앞은 $\lnot(\forall x,\;\text{합격}(x))$이고 이는 $\exists x,\;\lnot\text{합격}(x)$입니다. 뒤는 $\forall x,\;\lnot\text{합격}(x)$입니다. 앞은 불합격자가 하나라도 있다는 뜻이고 뒤는 전원이 불합격이라는 뜻입니다. 21강 문제 12에서 한국어로 구분하기 어려웠던 차이가 기호로는 분명해집니다.

## 문제 3. 반례 하나로 무엇을 무너뜨릴 수 있는가

> **문제.** "모든 소수는 홀수입니다"가 거짓임을 보이세요. 그리고 "모든 자연수 $n$에 대하여 $n^{2}+n+41$은 소수입니다"가 거짓임을 보이세요.

**생각의 실마리.** 앞 문제에서 $\forall$ 명제의 부정이 $\exists$ 명제임을 확인했습니다. 그러니 $\forall$ 명제가 거짓임을 보이려면 조건을 만족하지 않는 대상을 **하나만** 찾아 제시하면 끝입니다. 두 번째 식에서는 작은 수부터 넣어 보되, 소수가 되지 않을 만한 구조가 보이는지도 살핍니다.

**풀이.** 첫 번째 명제에서 $n=2$를 봅니다. $2$는 약수가 $1$과 $2$뿐이므로 소수이고, 동시에 짝수입니다. 소수이면서 홀수가 아닌 수가 존재하므로 명제는 거짓입니다.

두 번째 명제는 작은 값에서 잘 맞습니다. $n=1$이면 $43$, $n=2$이면 $47$, $n=3$이면 $53$으로 모두 소수입니다. 이런 식으로 $n=39$까지 계속 소수가 나옵니다. 그러나 $n=40$을 넣으면

$$40^{2}+40+41=1600+40+41=1681=41^{2}$$

이므로 $41$로 나누어떨어져 소수가 아닙니다. $n=41$에서도 $41^{2}+41+41=41\cdot 43$이므로 소수가 아닙니다. 반례가 존재하므로 명제는 거짓입니다.

**이 문제에서 배우는 것: 반례.**

$\forall x\in A,\;P(x)$가 거짓임을 보이는 방법은 **$P(a)$가 거짓이 되는 $a\in A$를 하나 제시하는 것**이며, 이 $a$를 **반례**라고 합니다. 부정 규칙에 따라 $\forall$ 명제의 부정이 $\exists$ 명제이고, $\exists$ 명제를 증명하는 방법은 실제 예를 하나 드는 것이기 때문입니다.

반례를 제시할 때 지켜야 할 것이 두 가지입니다.

첫째, 반례는 **범위 안에 있어야** 합니다. "모든 자연수는 $\ldots$"에 대한 반례로 $-3$을 들 수 없습니다.

둘째, 반례가 실제로 조건을 깨는지 **계산으로 보여야** 합니다. $n=40$이 반례라고 말만 하는 것이 아니라 $1681=41^{2}$까지 적어야 증명이 완성됩니다.

두 번째 명제가 주는 교훈이 더 중요합니다. **$39$개의 사례가 맞는다고 해서 $\forall$ 명제가 참이 되지는 않습니다.** 확인한 사례가 아무리 많아도 그것은 증명이 아닙니다. $\forall$ 명제를 참이라고 주장하려면 범위 안의 모든 대상을 한꺼번에 다루는 논증이 필요하며, 그 방법이 23강부터 25강까지의 내용입니다.

여기서 비대칭이 하나 생깁니다. $\forall$ 명제는 **반박은 하나로 끝나지만 증명은 전부를 다뤄야** 합니다. $\exists$ 명제는 반대로 **증명은 하나로 끝나지만 반박은 전부를 다뤄야** 합니다.

| 명제 | 참임을 보이려면 | 거짓임을 보이려면 |
|---|---|---|
| $\forall x\in A,\;P(x)$ | 임의의 $x$에 대해 논증합니다 | 반례 하나를 듭니다 |
| $\exists x\in A,\;P(x)$ | 예 하나를 듭니다 | 모든 $x$에 대해 논증합니다 |

**바로 확인.**

**확인 3-1.** "모든 실수 $x$에 대하여 $|x|=x$입니다"의 반례를 하나 드세요.

*답.* $x=-1$입니다. $|-1|=1$인데 $x=-1$이므로 같지 않습니다.

**확인 3-2.** "모든 자연수 $n$에 대하여 $2^{n}>n^{2}$입니다"의 반례를 하나 드세요.

*답.* $n=2$입니다. $2^{2}=4$이고 $2^{2}=4$이므로 $>$가 성립하지 않습니다. $n=3$과 $n=4$도 반례입니다. $2^{3}=8<9$이고 $2^{4}=16=16$입니다.

**확인 3-3.** $\exists x\in\mathbb{R},\; x^{2}<0$이 거짓임을 보이려면 무엇을 해야 합니까?

*답.* 예를 드는 것으로는 안 되고, 모든 실수에서 $x^{2}\ge 0$임을 논증해야 합니다. $\exists$ 명제의 부정이 $\forall$ 명제이기 때문입니다.

## 문제 4. 두 한정 기호의 순서를 바꾸면 뜻이 달라지는가

> **문제.** 범위를 실수 전체로 하고 다음 두 명제를 비교하세요.
> (가) $\forall x\in\mathbb{R},\;\exists y\in\mathbb{R},\; x+y=0$
> (나) $\exists y\in\mathbb{R},\;\forall x\in\mathbb{R},\; x+y=0$
> 각각을 말로 옮기고 참거짓을 판정하세요.

**생각의 실마리.** 한정 기호는 왼쪽부터 순서대로 읽습니다. 앞에 있는 변수가 먼저 정해지고, 뒤에 있는 변수는 앞 변수를 **알고 나서** 고를 수 있습니다. 이 순서가 (가)와 (나)에서 누가 누구에게 맞추는지를 결정합니다.

**풀이.** (가)를 말로 옮기면 "어떤 실수 $x$를 가져오든, 그에 맞는 $y$를 찾아 $x+y=0$이 되게 할 수 있습니다"입니다. $x$가 먼저 주어지고 $y$는 그 뒤에 고릅니다. $x$가 무엇이든 $y=-x$로 잡으면 $x+(-x)=0$이므로 항상 성립합니다. 따라서 (가)는 **참**입니다.

(나)를 말로 옮기면 "어떤 실수 $y$ 하나가 있어서, 그 하나가 모든 $x$에 대하여 $x+y=0$을 만족시킵니다"입니다. 여기서는 $y$가 먼저 정해지고, 그다음 모든 $x$가 들어옵니다. $y$를 하나 고정했다고 합시다. $x=0$을 넣으면 $y=0$이어야 합니다. 그런데 $x=1$을 넣으면 $1+y=0$에서 $y=-1$이어야 합니다. 하나의 $y$가 $0$이면서 동시에 $-1$일 수는 없으므로 그런 $y$는 존재하지 않습니다. 따라서 (나)는 **거짓**입니다.

**이 문제에서 배우는 것: 한정 기호의 순서와 의존.**

한정 기호는 **왼쪽에서 오른쪽으로 순서대로** 읽습니다. 뒤에 오는 변수는 앞에 오는 변수에 **의존할 수 있고**, 앞에 오는 변수는 뒤에 오는 변수를 알 수 없습니다.

$\forall x\,\exists y$는 "$x$마다 $y$를 따로 골라도 된다"는 뜻이고, $\exists y\,\forall x$는 "모든 $x$에 통하는 $y$ 하나가 있다"는 뜻입니다. 뒤쪽이 훨씬 강한 주장입니다. 실제로 $\exists y\,\forall x$가 참이면 $\forall x\,\exists y$도 참이지만, 그 역은 (가)와 (나)가 보여 주듯 성립하지 않습니다.

$$\big(\exists y\,\forall x,\;P(x,y)\big)\;\to\;\big(\forall x\,\exists y,\;P(x,y)\big)$$

같은 기호끼리는 순서를 바꿔도 됩니다. $\forall x\,\forall y$와 $\forall y\,\forall x$는 같고, $\exists x\,\exists y$와 $\exists y\,\exists x$도 같습니다. **다른 기호가 섞였을 때만 순서가 뜻을 바꿉니다.**

이 구별은 뒤에서 계속 결정적입니다. 33강의 수열 수렴 정의와 35강의 연속 정의는 모두 $\forall\varepsilon\,\exists N$ 꼴이며, 이 순서를 $\exists N\,\forall\varepsilon$으로 바꾸면 훨씬 강한 조건인 균등수렴이 되어 다른 개념이 됩니다.

부정 규칙은 여러 개가 붙어 있어도 그대로 적용됩니다. 왼쪽부터 차례로 뒤집습니다.

$$\lnot\big(\forall x\,\exists y,\;P(x,y)\big)\;\equiv\;\exists x\,\forall y,\;\lnot P(x,y)$$

**바로 확인.**

**확인 4-1.** $\forall x\in\mathbb{R},\;\exists y\in\mathbb{R},\; y>x$의 참거짓을 판정하세요.

*답.* 참입니다. $x$가 주어지면 $y=x+1$로 잡으면 됩니다.

**확인 4-2.** $\exists y\in\mathbb{R},\;\forall x\in\mathbb{R},\; y>x$의 참거짓을 판정하세요.

*답.* 거짓입니다. 모든 실수보다 큰 실수 하나가 있다는 뜻인데, $y$를 고정하면 $x=y+1$이 그보다 크므로 그런 $y$는 없습니다.

**확인 4-3.** $\forall x\,\exists y,\;P(x,y)$의 부정을 쓰세요.

*답.* $\exists x\,\forall y,\;\lnot P(x,y)$입니다.

## 문제 5. 정리의 표준형을 어떻게 부정하는가

> **문제.** 수학의 정리는 대개 "범위 안의 모든 대상에 대하여, 조건을 만족하면 결론이 성립합니다"라는 꼴입니다. 다음 명제를 기호로 적고 부정을 만드세요.
> "모든 실수 $x$에 대하여, $x>2$이면 $x^{2}>4$입니다."
> 그리고 같은 방법으로 "모든 실수 $x$에 대하여, $x^{2}>4$이면 $x>2$입니다"의 부정을 만들고 이 명제의 참거짓을 판정하세요.

**생각의 실마리.** 전체 구조가 $\forall x,\;(P(x)\to Q(x))$입니다. 부정할 것이 두 겹이므로 바깥부터 차례로 처리합니다. 먼저 $\forall$을 $\exists$로 바꾸고, 그다음 안쪽 조건문의 부정을 21강 문제 4의 결과로 처리합니다.

**풀이.** 첫 명제를 기호로 적으면

$$\forall x\in\mathbb{R},\;(x>2\to x^{2}>4)$$

입니다. 부정을 두 단계로 만듭니다. 먼저 한정 기호를 뒤집습니다.

$$\exists x\in\mathbb{R},\;\lnot(x>2\to x^{2}>4)$$

이제 안쪽에 21강의 $\lnot(p\to q)\equiv p\land\lnot q$를 적용합니다.

$$\exists x\in\mathbb{R},\;(x>2\;\land\;x^{2}\le 4)$$

말로 옮기면 "$2$보다 큰데 제곱은 $4$ 이하인 실수가 존재합니다"입니다. 이것이 바로 반례의 정의입니다. $x>2$이면 양변에 양수 $x$를 곱해 $x^{2}>2x>4$이므로 그런 $x$는 없고, 원래 명제는 참입니다.

두 번째 명제는 $\forall x\in\mathbb{R},\;(x^{2}>4\to x>2)$이고 부정은

$$\exists x\in\mathbb{R},\;(x^{2}>4\;\land\;x\le 2)$$

입니다. $x=-3$을 봅니다. $(-3)^{2}=9>4$이고 $-3\le 2$이므로 부정이 참입니다. 따라서 두 번째 명제는 **거짓**이며 $x=-3$이 반례입니다.

**이 문제에서 배우는 것: 정리의 표준형과 그 부정.**

수학의 정리는 거의 모두 다음 꼴입니다.

$$\forall x\in A,\;\big(P(x)\to Q(x)\big)$$

여기서 $P$를 가정, $Q$를 결론이라고 합니다. 이 명제의 부정은 항상 같은 모양으로 나옵니다.

$$\exists x\in A,\;\big(P(x)\land\lnot Q(x)\big)$$

말로 옮기면 **"가정은 만족하는데 결론은 만족하지 않는 대상이 존재합니다"**이며, 이 대상이 반례입니다. 반례가 갖춰야 할 조건이 여기서 정확히 나옵니다. 반례는 $A$ 안에 있고, $P$를 만족하며, $Q$를 만족하지 않아야 합니다. 셋 중 하나라도 확인하지 않으면 반례로 인정되지 않습니다.

두 번째 명제는 첫 명제의 역이라는 점에 주목합니다. 21강에서 역이 원래 명제와 동치가 아님을 진리표로 확인했는데, 여기서는 그 사실이 구체적인 반례 $x=-3$으로 나타났습니다. 역이 성립하지 않는다는 것은 곧 반례가 존재한다는 뜻입니다.

**바로 확인.**

**확인 5-1.** "모든 자연수 $n$에 대하여, $n$이 $6$의 배수이면 $n$은 $3$의 배수입니다"의 부정을 쓰세요.

*답.* $\exists n\in\mathbb{N}$, $n$은 $6$의 배수이고 $3$의 배수가 아닙니다.

**확인 5-2.** "모든 자연수 $n$에 대하여, $n$이 $3$의 배수이면 $n$은 $6$의 배수입니다"의 반례를 드세요.

*답.* $n=3$입니다. $3$은 $3$의 배수이지만 $6$의 배수가 아니므로 가정은 참, 결론은 거짓입니다.

**확인 5-3.** "모든 실수 $x$에 대하여, $x\ne 0$이면 $x^{2}>0$입니다"의 부정을 쓰고, 이 명제가 참인지 판정하세요.

*답.* 부정은 $\exists x\in\mathbb{R}$, $x\ne 0$이고 $x^{2}\le 0$입니다. $x\ne 0$이면 $x^{2}>0$이므로 그런 $x$는 없고 원래 명제는 참입니다.

## 유형 총정리(치트시트)

| 기호 | 읽는 법 | 참이 되는 때 |
|---|---|---|
| $\forall x\in A,\;P(x)$ | 모든 | $A$의 모든 원소가 $P$를 만족할 때 |
| $\exists x\in A,\;P(x)$ | 어떤, 존재 | $P$를 만족하는 원소가 하나 이상 있을 때 |

| 원래 | 부정 |
|---|---|
| $\forall x,\;P(x)$ | $\exists x,\;\lnot P(x)$ |
| $\exists x,\;P(x)$ | $\forall x,\;\lnot P(x)$ |
| $\forall x\,\exists y,\;P(x,y)$ | $\exists x\,\forall y,\;\lnot P(x,y)$ |
| $\forall x,\;(P(x)\to Q(x))$ | $\exists x,\;(P(x)\land\lnot Q(x))$ |

| 상황 | 쓸 도구 |
|---|---|
| $\forall$ 명제가 거짓임을 보입니다 | 반례 하나를 제시합니다 |
| $\exists$ 명제가 참임을 보입니다 | 예 하나를 제시합니다 |
| $\forall$ 명제가 참임을 보입니다 | 임의의 원소로 논증합니다 |
| $\exists$ 명제가 거짓임을 보입니다 | 모든 원소에 대해 논증합니다 |
| 두 한정 기호가 섞여 있습니다 | 왼쪽부터 순서대로 읽습니다 |

## 종합 문제 드릴

> **문제 6.** $\forall x\in\mathbb{R},\; x^{2}\ge x$의 반례를 드세요.

*답.* $x=\tfrac{1}{2}$입니다. $\left(\tfrac{1}{2}\right)^{2}=\tfrac{1}{4}$이고 $\tfrac{1}{4}<\tfrac{1}{2}$입니다. $0<x<1$인 모든 실수가 반례입니다.

> **문제 7.** $\exists n\in\mathbb{N},\; n^{2}=2n$의 참거짓을 판정하세요.

*답.* 참입니다. $n=2$이면 $4=4$입니다.

> **문제 8.** "모든 자연수 $n$에 대하여 $n^{2}\ge n$입니다"가 참인 이유를 설명하세요.

*답.* $n\ge 1$이므로 양변에 양수 $n$을 곱하면 $n^{2}\ge n$입니다. 문제 6의 반례가 자연수가 아니었다는 점이 범위의 차이입니다.

> **문제 9.** $\lnot(\exists x\in\mathbb{R},\;\forall y\in\mathbb{R},\;xy=1)$을 한정 기호가 앞에 오도록 정리하세요.

*답.* $\forall x\in\mathbb{R},\;\exists y\in\mathbb{R},\;xy\ne 1$입니다.

> **문제 10.** $\forall x\in\mathbb{R},\;\exists y\in\mathbb{R},\; xy=1$의 참거짓을 판정하세요.

*답.* 거짓입니다. $x=0$이면 어떤 $y$에 대해서도 $0\cdot y=0\ne 1$이므로 $x=0$이 반례입니다. 범위를 $x\ne 0$인 실수로 좁히면 $y=1/x$로 잡을 수 있어 참이 됩니다.

> **문제 11.** 공집합을 범위로 하는 $\forall x\in\varnothing,\;P(x)$의 진리값은 무엇입니까?

*답.* 참입니다. 거짓이 되려면 $P$를 만족하지 않는 원소가 있어야 하는데 원소가 하나도 없으므로 반례를 찾을 수 없습니다. 21강의 공허하게 참과 같은 현상입니다.

> **문제 12.** $\exists x\in\varnothing,\;P(x)$의 진리값은 무엇입니까?

*답.* 거짓입니다. 참이 되려면 조건을 만족하는 원소가 있어야 하는데 원소가 하나도 없습니다.

> **문제 13.** "모든 정수 $n$에 대하여, $n$이 짝수이면 $n^{2}$도 짝수입니다"의 부정을 쓰세요.

*답.* $\exists n\in\mathbb{Z}$, $n$은 짝수이고 $n^{2}$은 홀수입니다.

> **문제 14.** $\forall x\in\mathbb{R},\;(x>0\lor x\le 0)$의 참거짓을 판정하세요.

*답.* 참입니다. 실수는 $0$보다 크거나 $0$ 이하 중 정확히 하나에 속하므로 논리합이 항상 참입니다.

> **문제 15.** "적어도 하나의 자연수는 소수가 아닙니다"를 기호로 적고 참거짓을 판정하세요.

*답.* $\exists n\in\mathbb{N},\; n$은 소수가 아닙니다. $n=1$이 소수가 아니므로 참입니다.

> **문제 16.** $\forall x\,\forall y,\;P(x,y)$와 $\forall y\,\forall x,\;P(x,y)$는 같은 뜻입니까?

*답.* 같습니다. 같은 한정 기호끼리는 순서를 바꿔도 뜻이 변하지 않습니다. 두 변수 모두 범위 전체를 훑기 때문입니다.

> **문제 17.** "어떤 학생은 모든 과목을 통과했습니다"와 "모든 과목은 어떤 학생이 통과했습니다"의 차이를 설명하세요.

*답.* 앞은 $\exists s\,\forall c$이므로 전 과목을 혼자 통과한 학생이 있다는 뜻입니다. 뒤는 $\forall c\,\exists s$이므로 과목마다 통과한 학생이 있으면 되고 그 학생이 과목마다 달라도 됩니다. 앞이 뒤보다 강한 주장이며, 앞이 참이면 뒤도 참이지만 역은 성립하지 않습니다.

> **문제 18.** "모든 실수 $x$에 대하여 $|x|>0$입니다"의 반례를 들고, 명제를 참이 되도록 최소한으로 고치세요.

*답.* $x=0$이 반례입니다. $|0|=0$이므로 $0$보다 크지 않습니다. 부등호를 고쳐 $|x|\ge 0$으로 하거나, 범위를 좁혀 "$x\ne 0$인 모든 실수"로 하면 참이 됩니다.

## 심화 문제

> **심화 1.** $\forall x\,\exists y,\;P(x,y)$가 참인데 $\exists y\,\forall x,\;P(x,y)$가 거짓인 예를 자연수 범위에서 하나 만드세요.

*답.* $P(x,y)$를 "$y>x$"로 잡습니다.

*풀이.* $\forall x\in\mathbb{N},\;\exists y\in\mathbb{N},\;y>x$는 $y=x+1$로 잡으면 항상 성립하므로 참입니다. 반면 $\exists y\in\mathbb{N},\;\forall x\in\mathbb{N},\;y>x$는 모든 자연수보다 큰 자연수가 있다는 뜻인데, $y$를 고정하면 $x=y$가 $y>x$를 깨므로 거짓입니다.

**남는 것.** 이 예에서 $y$가 $x$에 의존한다는 것이 핵심입니다. $\forall x\,\exists y$에서는 $y$를 $x$의 식으로 적을 수 있으면 증명이 끝나고, $\exists y\,\forall x$에서는 $y$가 $x$를 포함하면 안 됩니다. 증명을 쓸 때 "$y=x+1$로 잡습니다"라는 한 줄에 $y$가 $x$를 쓰고 있는지 확인하는 습관을 들입니다.

> **심화 2.** 유한한 범위 $A=\{1,2,3\}$에서 $\lnot(\forall x\in A,\;P(x))\equiv\exists x\in A,\;\lnot P(x)$를 드모르간 법칙만으로 유도하세요.

*답.* 유한 논리곱을 펼쳐 드모르간 법칙을 두 번 적용하면 됩니다.

*풀이.* 범위가 세 원소이므로 $\forall x\in A,\;P(x)$는 $P(1)\land P(2)\land P(3)$입니다. 부정하면 드모르간 법칙에 의해 $\lnot P(1)\lor\lnot(P(2)\land P(3))$이고, 오른쪽에 한 번 더 적용하면 $\lnot P(1)\lor\lnot P(2)\lor\lnot P(3)$입니다. 이것이 곧 $\exists x\in A,\;\lnot P(x)$입니다.

**남는 것.** 범위가 무한하면 이렇게 펼칠 수 없으므로 무한 범위의 부정 규칙은 유도가 아니라 **정의**로 받아들입니다. 다만 유한한 경우에 드모르간 법칙과 일치한다는 사실이 그 정의가 자연스러운 근거입니다.

> **심화 3.** "모든 자연수 $n$에 대하여 $n^{2}+n+41$은 소수입니다"에서 $n=40$이 반례임을 이미 보았습니다. 이 식이 왜 $n=40$에서 처음 깨지는지, $n=41$에서도 깨지는 이유와 함께 설명하세요.

*답.* 식이 상수 $41$을 포함하므로 $n$이 $41$의 배수가 되면 전체가 $41$로 나누어떨어집니다.

*풀이.* $n=41k$로 놓으면 $n^{2}+n+41=41(41k^{2}+k+1)$이므로 $41$의 배수입니다. $k\ge 1$이면 괄호 안이 $1$보다 크므로 소수가 아닙니다. 그래서 $n=41$에서 반드시 깨집니다. $n=40$의 경우는 다른 이유로, $40^{2}+40+41=1681=41^{2}$이 되어 우연히 $41$의 제곱이 됩니다.

**남는 것.** 반례를 찾을 때 무작정 대입하는 것보다 **식의 구조를 보고 깨질 자리를 예측하는 것**이 빠릅니다. 상수항이 $41$이므로 $41$의 배수를 먼저 시도하는 것이 자연스러운 전략이며, 이 사고방식은 24강에서 반례를 체계적으로 찾을 때 다시 씁니다.

> **심화 4.** $\exists!x\in A,\;P(x)$는 "$P$를 만족하는 $x$가 정확히 하나 존재합니다"를 뜻합니다. 이것을 $\exists$와 $\forall$만으로 적으세요.

*답.* $\exists x\in A,\;\big(P(x)\land\forall y\in A,\;(P(y)\to y=x)\big)$입니다.

*풀이.* 정확히 하나라는 것은 두 가지 주장을 합친 것입니다. 하나는 존재한다는 것이고, 다른 하나는 두 개 이상은 아니라는 것입니다. 앞은 $\exists x,\;P(x)$이고, 뒤는 "$P$를 만족하는 것은 무엇이든 그 $x$와 같습니다"이므로 $\forall y,\;(P(y)\to y=x)$입니다. 두 주장을 논리곱으로 묶습니다.

**남는 것.** 유일성 증명은 언제나 이 두 단계로 나뉩니다. 존재를 보이고, 그다음 두 개를 가정해 같음을 보입니다. 28강에서 역함수가 유일함을 증명할 때 정확히 이 구조를 씁니다.

> **심화 5.** 수열이 $L$에 수렴한다는 정의는 $\forall\varepsilon>0,\;\exists N\in\mathbb{N},\;\forall n\ge N,\;|a_{n}-L|<\varepsilon$입니다. 이 명제의 부정을 만드세요.

*답.* $\exists\varepsilon>0,\;\forall N\in\mathbb{N},\;\exists n\ge N,\;|a_{n}-L|\ge\varepsilon$입니다.

*풀이.* 왼쪽부터 차례로 뒤집습니다. $\forall\varepsilon$은 $\exists\varepsilon$이 되고, $\exists N$은 $\forall N$이 되며, $\forall n$은 $\exists n$이 됩니다. 마지막으로 안쪽 부등식 $|a_{n}-L|<\varepsilon$의 부정은 $|a_{n}-L|\ge\varepsilon$입니다. 범위 조건인 $\varepsilon>0$과 $n\ge N$은 부정되지 않습니다.

**남는 것.** 이 부정이 33강에서 발산을 증명할 때 그대로 쓰입니다. 말로 옮기면 "아무리 뒤로 가도 $L$에서 $\varepsilon$ 이상 떨어지는 항이 계속 나오는 그런 $\varepsilon$이 있습니다"입니다. 한정 기호 세 개짜리 문장을 기계적으로 부정할 수 있으면 해석학의 반쪽을 얻은 셈입니다.

> **심화 6.** $\forall x\in A,\;(P(x)\to Q(x))$가 참이고 $\exists x\in A,\;P(x)$가 참이면 $\exists x\in A,\;Q(x)$는 반드시 참입니까?

*답.* 반드시 참입니다.

*풀이.* 두 번째 가정에서 $P(a)$가 참인 $a\in A$가 존재합니다. 첫 번째 가정을 이 $a$에 적용하면 $P(a)\to Q(a)$가 참이고, $P(a)$가 참이므로 $Q(a)$가 참입니다. 따라서 $Q$를 만족하는 원소가 존재합니다.

**남는 것.** 여기서 $\exists x,\;P(x)$라는 가정이 반드시 필요합니다. 이것이 없으면 $A$ 안에 $P$를 만족하는 원소가 하나도 없을 수 있고, 그때 첫 번째 명제는 공허하게 참이면서도 $Q$를 만족하는 원소를 하나도 주지 못합니다. 정리를 적용할 때 **가정을 만족하는 대상이 실제로 있는지 확인하는 것**이 빠뜨리기 쉬운 단계입니다.

## 코드 검산

한정 기호는 유한한 범위에서라면 numpy의 `all`과 `any`로 그대로 계산됩니다. 무한 범위는 계산할 수 없으므로 유한한 구간으로 잘라 확인하고, 그 결과가 증명을 대신하지 못한다는 점을 함께 기억합니다.

```python
import numpy as np

# 문제 3: n^2 + n + 41 은 n=39 까지 소수이지만 n=40 에서 깨집니다.
def is_prime(m):
    if m < 2:
        return False
    d = np.arange(2, int(m**0.5) + 1)
    return bool(len(d) == 0 or np.all(m % d != 0))

n = np.arange(1, 42)
vals = n**2 + n + 41
flags = np.array([is_prime(int(v)) for v in vals])
print(int(n[~flags][0]))            # 40
print(int(vals[n == 40][0]))        # 1681
print(1681 == 41**2)                # True

# 문제 4: 순서가 뜻을 바꿉니다. x + y = 0 을 격자에서 확인합니다.
xs = np.linspace(-5, 5, 11)
ys = np.linspace(-5, 5, 11)
table = xs[:, None] + ys[None, :] == 0
print(bool(np.all(np.any(table, axis=1))))   # True   forall x exists y
print(bool(np.any(np.all(table, axis=0))))   # False  exists y forall x

# 문제 6: x^2 >= x 는 실수에서 거짓, 자연수에서 참입니다.
r = np.linspace(0.1, 0.9, 9)
print(bool(np.all(r**2 >= r)))               # False
k = np.arange(1, 1001)
print(bool(np.all(k**2 >= k)))               # True

# 문제 18: |x| > 0 의 반례는 x = 0 하나뿐입니다.
z = np.linspace(-2, 2, 401)
print(z[np.abs(z) <= 0])                     # [0.]
```

출력이 주석과 모두 일치합니다. 마지막 두 검산에서 주의할 점이 있습니다. 자연수 $1000$개까지 확인했다고 해서 $\forall n\in\mathbb{N}$이 증명된 것은 아닙니다. 문제 3이 보여 준 대로 $39$개가 맞아도 $40$번째에서 깨질 수 있습니다. 코드는 반례를 **찾는** 데는 강하지만 전칭 명제를 **증명하는** 데는 쓸 수 없습니다.

## 부록. 기호 정리

| 기호 | 읽는 법 | 뜻 |
|---|---|---|
| $\forall$ | 모든 | 범위 안 전부에 대해 성립합니다 |
| $\exists$ | 어떤, 존재 | 범위 안에 적어도 하나 있습니다 |
| $\exists!$ | 유일하게 존재 | 정확히 하나 있습니다 |
| $P(x)$ | 피 오브 엑스 | 변수를 담은 조건입니다 |
| $x\in A$ | 엑스는 에이의 원소 | $x$가 범위 $A$ 안에 있습니다 |
| $\varnothing$ | 공집합 | 원소가 하나도 없는 집합입니다 |

다음 23강에서는 지금까지 읽기만 한 명제를 직접 증명하는 법을 배웁니다. $\forall$ 명제를 참이라고 주장하려면 임의의 원소로 논증해야 한다고 했는데, 그 논증을 실제로 쓰는 방법이 직접증명과 대우증명입니다.
