# 27강. 함수, 단사와 전사

9강에서 함수를 "$x$ 하나에 $y$ 하나가 대응하는 관계"라고 배웠고 그래프로 확인했습니다. 그 설명은 그림에 기대고 있어서, 그래프를 그릴 수 없는 대상에는 쓸 수 없습니다. 예를 들어 집합에서 집합으로 가는 대응이나 함수를 함수로 보내는 대응은 좌표평면에 그려지지 않습니다.

이 강의는 26강의 곱집합을 써서 함수를 그림 없이 정의합니다. 그리고 9강에서 나눌 수 없었던 함수의 성질을 단사와 전사라는 두 축으로 갈라 놓습니다. 이 구분이 28강의 역함수 존재 조건을 결정하고, 29강에서 무한집합의 크기를 비교하는 잣대가 됩니다.

## 이 강의에서 할 수 있게 되는 것
- 함수를 곱집합의 부분집합으로 정의하고 함수가 아닌 대응을 가려낼 수 있습니다.
- 정의역, 공역, 치역을 구분하고 두 함수가 같은지 판정할 수 있습니다.
- 단사인지 증명하거나 반례로 아님을 보일 수 있습니다.
- 전사인지 증명하거나 반례로 아님을 보일 수 있습니다.
- 공역을 바꾸면 전사 여부가 달라짐을 설명할 수 있습니다.

## 문제 1. 함수를 그림 없이 어떻게 정의하는가

> **문제.** $A=\{1,2,3\}$, $B=\{a,b\}$일 때 다음 세 대응 중 $A$에서 $B$로 가는 함수인 것을 고르고, 아닌 것은 이유를 적으세요.
> (가) $f=\{(1,a),(2,a),(3,b)\}$
> (나) $g=\{(1,a),(2,b)\}$
> (다) $h=\{(1,a),(1,b),(2,a),(3,a)\}$

**생각의 실마리.** 세 대응 모두 $A\times B$의 부분집합입니다. 그런데 함수라고 부르려면 조건이 더 필요합니다. 9강에서 "$x$ 하나에 $y$ 하나"라고 했던 말을 두 조각으로 나눠 봅니다. 하나도 없으면 안 되고, 둘 이상이어도 안 됩니다.

**풀이.** (가)는 $1,2,3$ 각각에 대해 짝이 정확히 하나씩 있습니다. 함수입니다.

(나)는 $3$에 대응하는 원소가 없습니다. $A$의 모든 원소에 짝이 있어야 하는데 $3$이 빠졌으므로 함수가 아닙니다.

(다)는 $1$에 대응하는 원소가 $a$와 $b$ 둘입니다. 하나여야 하므로 함수가 아닙니다.

**이 문제에서 배우는 것: 함수의 정의.**

$A$에서 $B$로 가는 **함수** $f$는 $A\times B$의 부분집합으로서 다음 조건을 만족하는 것입니다.

$$\forall a\in A,\;\exists!\,b\in B,\;(a,b)\in f$$

여기서 $\exists!$는 22강 심화 4에서 정의한 "정확히 하나 존재"입니다. 이 한 줄이 두 가지를 동시에 요구합니다.

- **존재.** $A$의 모든 원소에 짝이 있어야 합니다. (나)가 이 조건을 어겼습니다.
- **유일.** 그 짝이 하나뿐이어야 합니다. (다)가 이 조건을 어겼습니다.

$(a,b)\in f$일 때 $b=f(a)$로 씁니다. 그리고 $f$가 $A$에서 $B$로 가는 함수임을 $f:A\to B$로 적습니다.

여기서 세 가지 집합을 구분합니다.

| 이름 | 기호 | 뜻 |
|---|---|---|
| 정의역 | $A$ | 출발하는 집합입니다 |
| 공역 | $B$ | 도착할 수 있는 집합입니다 |
| 치역 | $f(A)$ | 실제로 도착하는 값들의 집합입니다 |

치역은 $f(A)=\{f(a)\mid a\in A\}$로 정의되며 항상 $f(A)\subseteq B$입니다. (가)에서 치역은 $\{a,b\}$이고 공역과 같지만, 만약 $f=\{(1,a),(2,a),(3,a)\}$였다면 치역은 $\{a\}$로 공역보다 작습니다.

9강의 수직선 판정법이 여기서 설명됩니다. 그래프에 수직선을 그어 두 점 이상에서 만나면 유일 조건이 깨지고, 한 점도 만나지 않는 $x$가 정의역에 있으면 존재 조건이 깨집니다.

**바로 확인.**

**확인 1-1.** $\{(1,a),(2,b),(3,a),(2,a)\}$는 $A=\{1,2,3\}$에서 $B=\{a,b\}$로 가는 함수입니까?

*답.* 아닙니다. $2$에 $b$와 $a$가 모두 대응하므로 유일 조건이 깨집니다.

**확인 1-2.** $f:\mathbb{R}\to\mathbb{R}$, $f(x)=x^{2}$의 정의역, 공역, 치역을 각각 쓰세요.

*답.* 정의역은 $\mathbb{R}$, 공역은 $\mathbb{R}$, 치역은 $[0,\infty)$입니다. 실수의 제곱은 음수가 되지 않기 때문입니다.

**확인 1-3.** $y^{2}=x$가 $x\ge 0$에서 $y$를 정하는 함수입니까?

*답.* 아닙니다. $x=4$일 때 $y=2$와 $y=-2$가 모두 가능하므로 유일 조건이 깨집니다.

## 문제 2. 두 함수가 같다는 것은 무슨 뜻인가

> **문제.** 다음 세 함수가 서로 같은지 판정하세요.
> (가) $f:\mathbb{R}\to\mathbb{R}$, $f(x)=x^{2}$
> (나) $g:\mathbb{R}\to[0,\infty)$, $g(x)=x^{2}$
> (다) $h:[0,\infty)\to\mathbb{R}$, $h(x)=x^{2}$

**생각의 실마리.** 세 함수의 계산식이 모두 같습니다. 그런데 함수는 곱집합의 부분집합으로 정의했으므로, 어느 곱집합의 부분집합인지가 함수의 일부입니다. 정의역과 공역이 다르면 서로 다른 곱집합을 쓰고 있다는 점에 주목합니다.

**풀이.** (가)와 (다)를 비교합니다. 정의역이 다릅니다. (가)는 $-1$에서 값을 가지지만 (다)는 $-1$이 정의역에 없어 값을 가지지 않습니다. 두 함수는 서로 다른 순서쌍의 집합이므로 같지 않습니다.

(가)와 (나)를 비교합니다. 정의역이 같고 모든 $x$에서 값도 같습니다. 순서쌍의 집합으로 보면 정확히 같습니다. 그러나 공역이 다릅니다.

여기서 판단이 갈립니다. 함수를 순서쌍의 집합으로만 보면 (가)와 (나)는 같고, 공역까지 포함해 정의하면 다릅니다. 이 강의에서는 **공역까지 함수의 일부로 봅니다.** 그렇게 정해야 전사 여부가 함수의 성질로 말이 되기 때문입니다. 이 약속에 따라 (가)와 (나)도 서로 다른 함수입니다.

**이 문제에서 배우는 것: 함수의 상등과 공역의 역할.**

두 함수 $f:A\to B$와 $g:C\to D$가 **같다**는 것은 다음 세 가지가 모두 성립한다는 뜻입니다.

1. 정의역이 같습니다. $A=C$입니다.
2. 공역이 같습니다. $B=D$입니다.
3. 모든 $a\in A$에서 $f(a)=g(a)$입니다.

세 조건 중 하나라도 어긋나면 다른 함수입니다. 계산식이 같다고 같은 함수인 것이 아닙니다.

공역을 함수의 일부로 두는 이유가 중요합니다. 문제 4에서 볼 **전사**라는 성질은 "치역이 공역과 같습니까"를 묻는 것인데, 공역이 함수에 붙어 있지 않으면 이 질문 자체가 성립하지 않습니다. (가)는 전사가 아니고 (나)는 전사인데, 둘을 같은 함수로 본다면 같은 함수가 전사이면서 전사가 아니게 되어 모순입니다.

정의역을 바꾸는 것을 **제한**, 공역을 치역까지 줄이는 것을 **공역 축소**라고 부릅니다. 둘 다 원래 함수와 다른 함수를 만듭니다.

**바로 확인.**

**확인 2-1.** $f:\mathbb{R}\to\mathbb{R}$, $f(x)=|x|$와 $g:\mathbb{R}\to\mathbb{R}$, $g(x)=\sqrt{x^{2}}$은 같은 함수입니까?

*답.* 같습니다. 정의역과 공역이 같고, 1강에서 확인한 대로 모든 실수에서 $\sqrt{x^{2}}=|x|$이므로 값도 같습니다.

**확인 2-2.** $f:\mathbb{R}\to\mathbb{R}$, $f(x)=\dfrac{x^{2}-1}{x-1}$과 $g:\mathbb{R}\to\mathbb{R}$, $g(x)=x+1$은 같은 함수입니까?

*답.* 같지 않습니다. $f$는 $x=1$에서 정의되지 않으므로 정의역이 $\mathbb{R}\setminus\{1\}$이고 $g$의 정의역은 $\mathbb{R}$입니다. 24강 문제 4의 (다)와 같은 상황입니다.

**확인 2-3.** 함수의 상등을 판정할 때 확인할 세 가지를 쓰세요.

*답.* 정의역이 같은지, 공역이 같은지, 모든 점에서 값이 같은지입니다.

## 문제 3. 서로 다른 것이 서로 다르게 가는가

> **문제.** 다음 세 함수가 단사인지 판정하세요. 단사란 서로 다른 입력이 서로 다른 출력으로 간다는 뜻입니다.
> (가) $f:\mathbb{R}\to\mathbb{R}$, $f(x)=3x+1$
> (나) $g:\mathbb{R}\to\mathbb{R}$, $g(x)=x^{2}$
> (다) $h:[0,\infty)\to\mathbb{R}$, $h(x)=x^{2}$

**생각의 실마리.** "서로 다르면 서로 다르게 간다"를 그대로 증명하려면 $x_{1}\ne x_{2}$라는 부정형 가정에서 출발해야 합니다. 23강 문제 3에서 부정형이 나오면 대우를 보라고 했습니다. 대우를 적어 보면 훨씬 다루기 쉬운 형태가 나옵니다.

**풀이.** 단사의 정의는 $\forall x_{1},x_{2}\in A,\;(x_{1}\ne x_{2}\to f(x_{1})\ne f(x_{2}))$입니다. 대우를 취하면

$$\forall x_{1},x_{2}\in A,\;(f(x_{1})=f(x_{2})\to x_{1}=x_{2})$$

이고 이쪽이 계산하기 쉽습니다.

(가) $f(x_{1})=f(x_{2})$라고 하면 $3x_{1}+1=3x_{2}+1$입니다. 양변에서 $1$을 빼고 $3$으로 나누면 $x_{1}=x_{2}$입니다. 따라서 **단사입니다.**

(나) $g(x_{1})=g(x_{2})$라고 하면 $x_{1}^{2}=x_{2}^{2}$이고, 23강 문제 14에서 본 대로 여기서 $x_{1}=x_{2}$가 나오지 않습니다. 실제로 $g(-2)=4=g(2)$이지만 $-2\ne 2$이므로 **단사가 아닙니다.** $x_{1}=-2$, $x_{2}=2$가 반례입니다.

(다) 정의역이 $[0,\infty)$로 좁혀졌습니다. $h(x_{1})=h(x_{2})$이면 $x_{1}^{2}=x_{2}^{2}$이고 $x_{1},x_{2}\ge 0$이므로 양변에 제곱근을 취하면 $x_{1}=x_{2}$입니다. **단사입니다.** (나)의 반례였던 $-2$가 정의역에서 빠졌기 때문입니다.

**이 문제에서 배우는 것: 단사.**

$f:A\to B$가 **단사**라는 것은 다음이 성립한다는 뜻이며, 두 표현은 대우 관계로 동치입니다.

$$x_{1}\ne x_{2}\;\to\;f(x_{1})\ne f(x_{2})$$
$$f(x_{1})=f(x_{2})\;\to\;x_{1}=x_{2}$$

일대일 함수라고도 부릅니다. 판정 방법을 정리합니다.

| 무엇을 보입니까 | 어떻게 합니까 |
|---|---|
| 단사임을 증명합니다 | $f(x_{1})=f(x_{2})$를 놓고 계산해 $x_{1}=x_{2}$를 유도합니다 |
| 단사가 아님을 보입니다 | $f(a)=f(b)$이면서 $a\ne b$인 구체적인 $a,b$를 제시합니다 |

**증명은 대우로, 반박은 반례로**입니다. 22강에서 정리한 전칭 명제의 비대칭이 그대로 나타납니다.

(나)와 (다)의 차이가 알려 주는 것이 있습니다. **단사 여부는 계산식만으로 정해지지 않고 정의역에 달려 있습니다.** 같은 $x^{2}$이라도 정의역을 좁히면 단사가 됩니다. 11강에서 역함수를 구할 때 정의역을 제한했던 이유가 이것이며, 28강에서 정식으로 다룹니다.

그래프로는 **수평선 판정**이 됩니다. 어떤 수평선도 그래프와 두 점 이상에서 만나지 않으면 단사입니다. (나)의 그래프에서 $y=4$인 수평선이 두 점에서 만나는 것이 반례를 그림으로 본 것입니다.

**바로 확인.**

**확인 3-1.** $f:\mathbb{R}\to\mathbb{R}$, $f(x)=x^{3}$은 단사입니까?

*답.* 단사입니다. $x_{1}^{3}=x_{2}^{3}$이면 세제곱근이 실수에서 유일하므로 $x_{1}=x_{2}$입니다. 홀수 차수 거듭제곱은 부호를 보존하므로 짝수 차수와 달리 겹치지 않습니다.

**확인 3-2.** $f:\mathbb{R}\to\mathbb{R}$, $f(x)=\sin x$가 단사가 아님을 반례로 보이세요.

*답.* $f(0)=0=f(\pi)$이고 $0\ne\pi$이므로 단사가 아닙니다. 16강에서 본 주기성 때문에 반례가 무한히 많습니다.

**확인 3-3.** $f:\mathbb{R}\to\mathbb{R}$, $f(x)=|x|$가 단사가 아님을 보이고, 단사가 되도록 정의역을 좁히세요.

*답.* $f(-1)=1=f(1)$이므로 단사가 아닙니다. 정의역을 $[0,\infty)$로 좁히면 $f(x)=x$가 되어 단사입니다.

## 문제 4. 공역을 빠짐없이 채우는가

> **문제.** 다음 세 함수가 전사인지 판정하세요. 전사란 공역의 모든 원소가 적어도 하나의 입력에서 나온다는 뜻입니다.
> (가) $f:\mathbb{R}\to\mathbb{R}$, $f(x)=3x+1$
> (나) $g:\mathbb{R}\to\mathbb{R}$, $g(x)=x^{2}$
> (다) $k:\mathbb{R}\to[0,\infty)$, $k(x)=x^{2}$

**생각의 실마리.** 전사임을 보이려면 공역의 임의의 원소 $y$를 잡고 $f(x)=y$가 되는 $x$를 실제로 찾아야 합니다. 22강에서 $\forall y\,\exists x$ 꼴이었으므로, $x$를 $y$의 식으로 적을 수 있으면 증명이 끝납니다. 방정식을 $x$에 대해 푸는 일과 같습니다.

**풀이.** 전사의 정의는 $\forall y\in B,\;\exists x\in A,\;f(x)=y$입니다.

(가) 임의의 $y\in\mathbb{R}$를 잡습니다. $3x+1=y$를 $x$에 대해 풀면 $x=\dfrac{y-1}{3}$입니다. 이것은 실수이므로 정의역 안에 있고, 대입하면 $f\!\left(\dfrac{y-1}{3}\right)=3\cdot\dfrac{y-1}{3}+1=y$입니다. 따라서 **전사입니다.**

(나) $y=-1$을 봅니다. $x^{2}=-1$을 만족하는 실수 $x$는 없습니다. 공역의 원소 중 도달되지 않는 것이 있으므로 **전사가 아닙니다.** $y=-1$이 반례입니다.

(다) 공역이 $[0,\infty)$로 줄었습니다. 임의의 $y\ge 0$을 잡으면 $x=\sqrt{y}$가 실수이고 $k(\sqrt{y})=y$입니다. 따라서 **전사입니다.** (나)의 반례였던 음수가 공역에서 빠졌기 때문입니다.

**이 문제에서 배우는 것: 전사.**

$f:A\to B$가 **전사**라는 것은

$$\forall y\in B,\;\exists x\in A,\;f(x)=y$$

라는 뜻이며, 이는 **치역이 공역과 같다**는 말과 같습니다.

$$f\text{가 전사}\;\;\Longleftrightarrow\;\;f(A)=B$$

판정 방법을 정리합니다.

| 무엇을 보입니까 | 어떻게 합니까 |
|---|---|
| 전사임을 증명합니다 | 임의의 $y\in B$를 잡고 $f(x)=y$를 $x$에 대해 풀어 그 해가 $A$에 있음을 확인합니다 |
| 전사가 아님을 보입니다 | 어떤 $x$로도 도달되지 않는 $y\in B$를 하나 제시합니다 |

(나)와 (다)의 차이가 문제 2에서 공역을 함수의 일부로 둔 이유를 보여 줍니다. **전사 여부는 계산식이 아니라 공역이 무엇인지에 달려 있습니다.** 어떤 함수든 공역을 치역으로 줄이면 전사가 됩니다.

단사와 전사를 나란히 놓으면 대칭이 보입니다.

| | 단사 | 전사 |
|---|---|---|
| 무엇을 요구합니까 | 겹치지 않습니다 | 빠짐없이 채웁니다 |
| $f(x)=y$의 해 | 많아야 하나입니다 | 적어도 하나입니다 |
| 무엇에 달려 있습니까 | 정의역 | 공역 |
| 그래프 판정 | 수평선이 두 번 만나지 않습니다 | 모든 수평선이 적어도 한 번 만납니다 |

둘을 합치면 **모든 $y$에 대해 $f(x)=y$의 해가 정확히 하나**가 됩니다. 이것이 다음 문제의 전단사이며, 28강의 역함수가 존재하는 조건입니다.

**바로 확인.**

**확인 4-1.** $f:\mathbb{Z}\to\mathbb{Z}$, $f(n)=2n$은 전사입니까?

*답.* 아닙니다. $y=1$에 대해 $2n=1$을 만족하는 정수 $n$이 없으므로 반례입니다.

**확인 4-2.** $f:\mathbb{R}\to\mathbb{R}$, $f(x)=x^{3}$은 전사입니까?

*답.* 전사입니다. 임의의 $y$에 대해 $x=\sqrt[3]{y}$가 실수이고 $f(x)=y$입니다.

**확인 4-3.** $f:\mathbb{R}\to\mathbb{R}$, $f(x)=\sin x$의 치역을 구하고 전사 여부를 판정하세요.

*답.* 16강에서 본 대로 치역은 $[-1,1]$입니다. 공역 $\mathbb{R}$과 다르므로 전사가 아니며 $y=2$가 반례입니다. 공역을 $[-1,1]$로 줄이면 전사가 됩니다.

## 문제 5. 두 성질을 모두 가지면 무엇이 되는가

> **문제.** $A=\{1,2,3\}$, $B=\{a,b,c\}$입니다.
> (1) $f=\{(1,a),(2,b),(3,c)\}$가 단사이면서 전사임을 확인하세요.
> (2) $A$에서 $B$로 가는 함수 중 단사인데 전사가 아닌 것이 있습니까?
> (3) $|A|=|B|$인 유한집합에서 단사와 전사가 동치인 이유를 설명하세요.

**생각의 실마리.** (2)에서 무작정 예를 찾기보다 개수를 세어 봅니다. $A$의 원소 $3$개가 서로 다른 곳으로 간다면 도착점이 몇 개 생깁니까? $B$의 크기와 비교하면 답이 나옵니다.

**풀이.** (1) 서로 다른 세 입력이 서로 다른 세 출력으로 가므로 단사입니다. 치역이 $\{a,b,c\}=B$이므로 전사입니다.

(2) 없습니다. $f$가 단사라면 $1,2,3$의 상이 서로 달라 치역의 원소가 $3$개입니다. 그런데 치역은 $B$의 부분집합이고 $|B|=3$이므로 원소가 $3$개인 부분집합은 $B$ 자신뿐입니다. 따라서 치역이 $B$와 같아지고 전사가 됩니다.

(3) 일반적으로 $|A|=|B|=n$이라고 합니다.

단사이면 치역의 원소가 정확히 $n$개이고, 치역은 $B$의 부분집합이며 $|B|=n$이므로 치역이 $B$ 전체입니다. 따라서 전사입니다.

전사이면 치역이 $B$ 전체이므로 원소가 $n$개입니다. $A$의 원소 $n$개가 이 $n$개의 값을 모두 만들어야 하는데, 만약 두 원소가 같은 값으로 간다면 서로 다른 값이 $n-1$개 이하가 되어 모자랍니다. 따라서 모든 원소가 서로 다른 값으로 가고 단사입니다.

**이 문제에서 배우는 것: 전단사와 유한집합에서의 동치.**

단사이면서 전사인 함수를 **전단사**라고 합니다. 일대일 대응이라고도 부릅니다. 전단사의 뜻을 한 줄로 적으면

$$\forall y\in B,\;\exists!\,x\in A,\;f(x)=y$$

입니다. 모든 $y$에 대해 $f(x)=y$의 해가 정확히 하나 있다는 뜻이며, 이것이 28강에서 역함수를 정의할 수 있게 하는 조건입니다.

방금 증명한 것을 정리합니다. **$A$와 $B$가 같은 크기의 유한집합이면 단사, 전사, 전단사가 모두 같은 말입니다.** 셋 중 하나만 확인하면 나머지가 따라옵니다.

$$|A|=|B|<\infty\;\;\Longrightarrow\;\;(f\text{가 단사}\iff f\text{가 전사}\iff f\text{가 전단사})$$

**이 동치는 유한집합에서만 성립합니다.** 무한집합에서는 깨집니다. $f:\mathbb{N}\to\mathbb{N}$, $f(n)=2n$은 단사이지만 홀수에 도달하지 못해 전사가 아닙니다. $\mathbb{N}$은 자기 자신과 크기가 같은데도 그렇습니다.

이 실패가 우연이 아니라 무한집합의 본질입니다. 29강에서 이 성질을 무한의 정의로 삼고, 그 위에서 무한집합끼리도 크기를 비교하는 방법을 만듭니다.

**바로 확인.**

**확인 5-1.** $A=\{1,2\}$에서 $B=\{a,b,c\}$로 가는 전사 함수가 있습니까?

*답.* 없습니다. 치역의 원소가 많아야 $2$개인데 $B$는 $3$개이므로 항상 도달되지 않는 원소가 남습니다.

**확인 5-2.** $A=\{1,2,3\}$에서 $B=\{a,b\}$로 가는 단사 함수가 있습니까?

*답.* 없습니다. 서로 다른 세 값이 필요한데 $B$에는 두 개뿐이므로 19강의 비둘기집 원리에 따라 반드시 겹칩니다.

**확인 5-3.** $f:\mathbb{N}\to\mathbb{N}$, $f(n)=n+1$은 단사입니까? 전사입니까?

*답.* 단사입니다. $n_{1}+1=n_{2}+1$이면 $n_{1}=n_{2}$입니다. 그러나 $y=1$에 도달하는 자연수가 없으므로 전사가 아닙니다. 무한집합에서 동치가 깨지는 또 하나의 예입니다.

## 유형 총정리(치트시트)

| 개념 | 정의 |
|---|---|
| 함수 $f:A\to B$ | $\forall a\in A,\;\exists!\,b\in B,\;(a,b)\in f$ |
| 치역 | $f(A)=\{f(a)\mid a\in A\}$ |
| 단사 | $f(x_{1})=f(x_{2})\to x_{1}=x_{2}$ |
| 전사 | $\forall y\in B,\;\exists x\in A,\;f(x)=y$ |
| 전단사 | 단사이면서 전사입니다 |
| 함수의 상등 | 정의역, 공역, 모든 점의 값이 같습니다 |

| 무엇을 보입니까 | 어떻게 합니까 |
|---|---|
| 단사임을 증명 | $f(x_{1})=f(x_{2})$에서 $x_{1}=x_{2}$를 유도합니다 |
| 단사가 아님 | 값이 같은 서로 다른 두 입력을 제시합니다 |
| 전사임을 증명 | 임의의 $y$에 대해 $x$를 $y$의 식으로 만듭니다 |
| 전사가 아님 | 도달되지 않는 $y$를 제시합니다 |
| 단사로 만들기 | 정의역을 좁힙니다 |
| 전사로 만들기 | 공역을 치역으로 줄입니다 |

## 종합 문제 드릴

> **문제 6.** $f:\mathbb{R}\to\mathbb{R}$, $f(x)=5x-2$가 전단사임을 증명하세요.

*답.* $5x_{1}-2=5x_{2}-2$이면 $x_{1}=x_{2}$이므로 단사입니다. 임의의 $y$에 대해 $x=\dfrac{y+2}{5}$이면 $f(x)=y$이므로 전사입니다.

> **문제 7.** $f:\mathbb{R}\to\mathbb{R}$, $f(x)=x^{2}-4x+7$이 단사가 아님을 보이세요.

*답.* $f(x)=(x-2)^{2}+3$이므로 $f(1)=4=f(3)$입니다. $1\ne 3$이므로 단사가 아닙니다.

> **문제 8.** 문제 7의 함수가 단사가 되도록 정의역을 좁히세요.

*답.* $[2,\infty)$ 또는 $(-\infty,2]$로 좁히면 됩니다. 6강에서 본 대로 꼭짓점 $x=2$를 기준으로 한쪽만 남기면 겹치지 않습니다.

> **문제 9.** 문제 7의 함수의 치역을 구하고 전사 여부를 판정하세요.

*답.* $(x-2)^{2}\ge 0$이므로 치역은 $[3,\infty)$입니다. 공역 $\mathbb{R}$과 다르므로 전사가 아니며 $y=0$이 반례입니다.

> **문제 10.** $f:\mathbb{Z}\to\mathbb{Z}$, $f(n)=n+3$이 전단사임을 보이세요.

*답.* $n_{1}+3=n_{2}+3$이면 $n_{1}=n_{2}$이므로 단사입니다. 임의의 정수 $m$에 대해 $n=m-3$이 정수이고 $f(n)=m$이므로 전사입니다.

> **문제 11.** $f:\mathbb{R}\to\mathbb{R}$, $f(x)=\dfrac{1}{1+x^{2}}$의 치역을 구하세요.

*답.* $1+x^{2}\ge 1$이므로 $0<f(x)\le 1$이고, $x$가 커지면 값이 $0$에 가까워지지만 $0$이 되지는 않습니다. 치역은 $(0,1]$입니다.

> **문제 12.** $A=\{1,2,3\}$에서 $B=\{a,b\}$로 가는 함수는 몇 개입니까?

*답.* 각 원소가 두 곳 중 하나로 가므로 $2^{3}=8$개입니다.

> **문제 13.** 문제 12에서 전사인 것은 몇 개입니까?

*답.* 전체 $8$개에서 치역이 한 원소뿐인 경우 $2$개를 빼면 $6$개입니다. 19강의 여사건 방식입니다.

> **문제 14.** $f:A\to B$가 단사이고 $|A|=5$일 때 $|f(A)|$를 구하세요.

*답.* $5$입니다. 단사이면 서로 다른 입력이 서로 다른 출력으로 가므로 치역의 크기가 정의역의 크기와 같습니다.

> **문제 15.** $f:\mathbb{N}\to\mathbb{N}$, $f(n)=n^{2}$은 단사입니까? 전사입니까?

*답.* 단사입니다. 자연수에서 $n_{1}^{2}=n_{2}^{2}$이면 둘 다 양수이므로 $n_{1}=n_{2}$입니다. 전사는 아닙니다. $y=2$가 어떤 자연수의 제곱도 아니므로 반례입니다.

> **문제 16.** $f:\mathbb{R}\to\mathbb{R}$, $f(x)=2^{x}$의 치역을 구하고 공역을 어떻게 바꾸면 전사가 되는지 쓰세요.

*답.* 13강에서 본 대로 치역은 $(0,\infty)$입니다. 공역을 $(0,\infty)$로 바꾸면 전사가 됩니다.

> **문제 17.** 상수함수 $f:\mathbb{R}\to\mathbb{R}$, $f(x)=5$는 단사입니까? 전사입니까?

*답.* 둘 다 아닙니다. $f(0)=f(1)$이므로 단사가 아니고, 치역이 $\{5\}$뿐이라 $y=0$에 도달하지 못하므로 전사가 아닙니다.

> **문제 18.** $f:A\to B$가 전사일 때 $|A|$와 $|B|$의 대소 관계는 어떻게 됩니까? 유한집합에서 답하세요.

*답.* $|A|\ge|B|$입니다. $B$의 각 원소마다 적어도 하나의 원소가 대응되어야 하므로 정의역이 공역보다 작을 수 없습니다.

## 심화 문제

> **심화 1.** 단사임을 증명할 때 왜 대우 형태를 쓰는지 설명하세요.

*답.* 원래 형태의 가정이 부정형이라 식으로 옮기기 어렵기 때문입니다.

*풀이.* 원래 정의는 $x_{1}\ne x_{2}\to f(x_{1})\ne f(x_{2})$입니다. 가정 $x_{1}\ne x_{2}$에서 시작하면 두 수가 다르다는 것 말고는 쓸 정보가 없고, 결론도 부정형이라 계산으로 도달하기 어렵습니다. 대우를 취하면 가정이 $f(x_{1})=f(x_{2})$라는 등식이 되어 양변을 계산할 수 있고 결론도 등식이 됩니다. 23강 문제 3의 첫 번째 신호와 정확히 같은 상황입니다.

**남는 것.** 정의를 그대로 쓰지 않고 동치인 형태로 바꿔 쓰는 것이 실전에서 늘 필요합니다. 단사의 두 표현은 어느 쪽을 정의로 삼아도 되지만, 증명에는 등식 쪽이 압도적으로 편합니다.

> **심화 2.** $f:A\to B$에 대하여 $f$가 단사일 필요충분조건이 "모든 $y\in B$에 대해 $f(x)=y$의 해가 많아야 하나"임을 보이세요.

*답.* 두 조건이 동치입니다.

*풀이.* $f$가 단사라고 합시다. 어떤 $y$에 대해 해가 둘이라면 $f(x_{1})=y=f(x_{2})$이고 $x_{1}\ne x_{2}$이므로 단사에 어긋납니다. 따라서 해는 많아야 하나입니다.

역으로 모든 $y$에서 해가 많아야 하나라고 합시다. $f(x_{1})=f(x_{2})=y$이면 $x_{1}$과 $x_{2}$가 모두 $f(x)=y$의 해이므로 해가 하나뿐이라는 조건에서 $x_{1}=x_{2}$입니다.

**남는 것.** 단사와 전사를 방정식 $f(x)=y$의 해의 개수로 통일해 읽을 수 있습니다. 단사는 해가 $0$개나 $1$개, 전사는 해가 $1$개 이상, 전단사는 정확히 $1$개입니다. 이 관점이 28강의 역함수를 자연스럽게 만듭니다. 해가 정확히 하나면 그 해를 $y$에 대응시키는 함수를 만들 수 있습니다.

> **심화 3.** $f:\mathbb{N}\to\mathbb{N}$ 중에서 단사이지만 전사가 아닌 것과, 전사이지만 단사가 아닌 것을 각각 만드세요.

*답.* $f(n)=2n$과 아래의 $g$가 각각 그런 예입니다.

*풀이.* $f(n)=2n$은 $2n_{1}=2n_{2}$에서 $n_{1}=n_{2}$이므로 단사이고, 홀수에 도달하지 못하므로 전사가 아닙니다.

$g$를 $g(1)=1$이고 $n\ge 2$에서 $g(n)=n-1$로 정의합니다. 임의의 $m\in\mathbb{N}$에 대해 $g(m+1)=m$이므로 전사입니다. 그러나 $g(1)=1=g(2)$이므로 단사가 아닙니다.

**남는 것.** 두 예가 함께 보여 주는 것은 무한집합에서 단사와 전사가 완전히 독립적인 성질이라는 사실입니다. 문제 5에서 본 유한집합의 동치가 무한에서는 어느 방향으로도 성립하지 않습니다. 이 실패를 뒤집어 정의로 삼으면 "자기 자신의 진부분집합과 전단사 대응이 되는 집합"이 무한집합이며, 29강에서 이 관점을 씁니다.

> **심화 4.** $f:A\to B$가 단사일 때 $f$의 공역을 치역으로 줄인 함수 $\tilde{f}:A\to f(A)$가 전단사임을 증명하세요.

*답.* 전단사입니다.

*풀이.* $\tilde{f}$는 정의역과 값이 $f$와 같고 공역만 다릅니다. 단사는 정의역과 값만으로 결정되므로 $\tilde{f}$도 단사입니다. 전사를 봅니다. 임의의 $y\in f(A)$를 잡으면 치역의 정의에 따라 $y=f(a)$인 $a\in A$가 존재하고, 그 $a$에 대해 $\tilde{f}(a)=y$입니다. 따라서 전사입니다.

**남는 것.** 어떤 함수든 공역을 치역으로 줄이면 전사가 되고, 단사이기까지 하면 전단사가 됩니다. 이것이 29강에서 집합의 크기를 비교할 때 결정적으로 쓰입니다. "$A$에서 $B$로 가는 단사가 있다"는 것은 "$A$가 $B$의 어떤 부분집합과 일대일로 대응한다"와 같은 말이 되기 때문입니다.

> **심화 5.** $|A|=m$, $|B|=n$인 유한집합에서 $A$에서 $B$로 가는 단사 함수의 개수를 구하세요.

*답.* $m\le n$이면 $\dfrac{n!}{(n-m)!}$개이고, $m>n$이면 $0$개입니다.

*풀이.* 단사이므로 $A$의 원소들이 서로 다른 곳으로 가야 합니다. 첫 원소의 상을 고르는 방법이 $n$가지, 둘째는 이미 쓴 하나를 빼고 $n-1$가지, 이런 식으로 $m$번 고릅니다. 19강의 순열이 정확히 이 셈이므로 개수는

$$n(n-1)\cdots(n-m+1)={}_{n}\mathrm{P}_{m}=\frac{n!}{(n-m)!}$$

입니다. $m>n$이면 도중에 고를 것이 떨어지므로 단사가 존재하지 않고 개수는 $0$입니다.

**남는 것.** 19강에서 "$n$개 중 $m$개를 순서 있게 뽑는다"고 설명했던 순열이 실제로는 **단사 함수를 세는 일**이었습니다. 셈의 대상에 이름을 붙이면 같은 공식이 여러 문맥에서 재사용됩니다. 이 관점은 확률에서 표본공간을 세울 때 다시 쓰입니다.

> **심화 6.** $f:A\to B$가 단사가 아니면서 전사가 아닌 예를 유한집합에서 만들고, 그런 예가 $|A|=|B|$일 때 존재할 수 있는지 판정하세요.

*답.* $|A|=|B|$일 때는 존재할 수 없습니다.

*풀이.* $A=\{1,2\}$, $B=\{a,b\}$에서 $f(1)=f(2)=a$로 두면 단사가 아니고 $b$에 도달하지 못해 전사도 아닙니다. 그런데 이 예는 $|A|=|B|=2$입니다. 문제 5의 결과와 어긋나 보이지만 그렇지 않습니다. 문제 5는 단사와 전사가 **서로 동치**라고 했지 둘 중 하나가 반드시 성립한다고 하지 않았습니다. 둘 다 거짓인 경우는 동치를 깨지 않습니다.

**남는 것.** 동치 $p\leftrightarrow q$는 두 진리값이 같다는 뜻이며, 21강 문제 17에서 확인한 대로 둘 다 참인 경우와 둘 다 거짓인 경우 모두를 허용합니다. 정리를 읽을 때 동치를 "둘 중 하나는 성립한다"로 잘못 읽지 않도록 주의합니다.

## 코드 검산

유한집합 위의 함수는 대응표로 나타낼 수 있으므로 단사와 전사를 직접 세어 판정할 수 있습니다. 무한집합의 함수는 유한한 구간에서 확인합니다.

```python
import numpy as np

# 문제 5: |A| = |B| 인 유한집합에서 단사와 전사는 동치입니다.
def check(vals, codomain):
    vals = np.asarray(vals)
    inj = len(np.unique(vals)) == len(vals)
    sur = len(np.unique(vals)) == len(codomain)
    return inj, sur

B3 = np.arange(3)
print(check([0, 1, 2], B3))     # (True, True)
print(check([0, 0, 2], B3))     # (False, False)

# 문제 3: x^2 은 R 에서 단사가 아니고 [0, inf) 에서 단사입니다.
x = np.linspace(-3, 3, 7)
print(x[x**2 == 4])             # [-2.  2.]
xp = np.linspace(0, 3, 7)
print(len(np.unique(xp**2)) == len(xp))    # True

# 문제 4: 전사 판정은 공역에 달려 있습니다.
y = np.linspace(-2, 2, 5)
print(y[y < 0])                 # [-2. -1.]
print(np.allclose(np.sqrt(np.abs(y[y >= 0]))**2, y[y >= 0]))   # True

# 심화 3: 무한집합에서 단사와 전사가 갈라집니다.
n = np.arange(1, 21)
f = 2 * n
print(len(np.unique(f)) == len(n), bool(np.any(f == 3)))       # True False
g = np.where(n == 1, 1, n - 1)
print(len(np.unique(g)) == len(n), [int(v) for v in np.unique(g)[:3]])   # False [1, 2, 3]

# 심화 5: 단사 함수의 개수는 순열과 같습니다.
def perm(n, m):
    r = 1
    for i in range(m):
        r *= (n - i)
    return r
print(perm(5, 3), 5 * 4 * 3)    # 60 60
print(perm(3, 5))               # 0
```

출력이 주석과 모두 일치합니다. 마지막 줄에서 $m>n$일 때 곱이 $0$이 되는 것을 확인합니다. $n-i$가 $i=n$일 때 $0$이 되어 곱 전체를 $0$으로 만들기 때문이며, 손으로 세었을 때 "고를 것이 떨어진다"고 한 상황이 식에서 그대로 나타납니다.
