# 26강. 집합의 연산

1강부터 집합을 써 왔습니다. $\mathbb{N}$, $\mathbb{Z}$, $\mathbb{Q}$, $\mathbb{R}$가 모두 집합이고, 22강에서 한정 기호를 쓸 때마다 "$x\in A$"라고 범위를 밝혔습니다. 그러나 집합이 무엇인지, 두 집합이 같다는 것이 무슨 뜻인지는 한 번도 정하지 않았습니다.

이 강의가 그 자리를 메웁니다. 그리고 여기서 얻는 것은 새로운 계산 규칙이 아니라 **21강의 논리를 그대로 옮긴 것**입니다. 집합의 교집합은 논리곱이고 합집합은 논리합이며, 집합의 드모르간 법칙은 명제의 드모르간 법칙과 같은 식입니다. 두 세계가 같은 구조라는 사실을 확인하는 것이 이 강의의 실제 내용입니다.

## 이 강의에서 할 수 있게 되는 것
- 집합을 원소나열법과 조건제시법으로 적을 수 있습니다.
- 두 집합이 같음을 양쪽 포함을 보여 증명할 수 있습니다.
- 합집합, 교집합, 차집합, 여집합을 계산하고 벤 다이어그램으로 확인할 수 있습니다.
- 집합의 드모르간 법칙과 분배법칙을 논리 법칙에서 유도할 수 있습니다.
- 멱집합과 곱집합의 원소 개수를 셀 수 있습니다.

## 문제 1. 집합을 어떻게 적는가

> **문제.** 다음 세 집합을 각각 원소를 모두 나열하는 방식과 조건을 적는 방식으로 쓰세요.
> (가) $10$보다 작은 짝수인 자연수
> (나) $x^{2}-5x+6=0$의 실근
> (다) $x^{2}+1=0$의 실근

**생각의 실마리.** 나열하는 방식은 원소가 적을 때 편하고, 조건을 적는 방식은 원소가 많거나 무한할 때 필요합니다. (다)에서는 조건을 만족하는 것이 하나도 없을 수 있다는 점에 주의합니다.

**풀이.** (가)를 나열하면 $\{2,4,6,8\}$입니다. 조건으로 적으면 $\{n\in\mathbb{N}\mid n<10,\;n\text{은 짝수}\}$입니다.

(나)는 5강에서 배운 대로 $x^{2}-5x+6=(x-2)(x-3)$이므로 근이 $2$와 $3$입니다. 나열하면 $\{2,3\}$이고, 조건으로 적으면 $\{x\in\mathbb{R}\mid x^{2}-5x+6=0\}$입니다.

(다)는 모든 실수에서 $x^{2}+1\ge 1>0$이므로 조건을 만족하는 실수가 하나도 없습니다. 나열하면 $\{\;\}$이고 이것을 $\varnothing$으로 씁니다. 조건으로 적으면 $\{x\in\mathbb{R}\mid x^{2}+1=0\}$이며, 이 집합이 공집합입니다.

**이 문제에서 배우는 것: 집합과 두 가지 표기법.**

**집합**은 어떤 대상들의 모임이고, 그 대상 하나하나를 **원소**라고 합니다. $a$가 집합 $A$의 원소임을 $a\in A$로 쓰고, 원소가 아님을 $a\notin A$로 씁니다.

집합을 적는 방법은 두 가지입니다.

| 방법 | 모양 | 쓸 때 |
|---|---|---|
| 원소나열법 | $\{2,4,6,8\}$ | 원소가 적고 전부 적을 수 있을 때 |
| 조건제시법 | $\{x\in A\mid P(x)\}$ | 원소가 많거나 무한할 때 |

조건제시법의 세로줄 $\mid$은 "그런 것들"이라고 읽습니다. $\{x\in\mathbb{R}\mid x>0\}$은 "실수 $x$ 중에서 $x>0$인 것들의 집합"입니다.

집합에서 지켜야 할 두 가지 약속이 있습니다.

첫째, **원소의 순서는 의미가 없습니다.** $\{1,2\}$와 $\{2,1\}$은 같은 집합입니다.

둘째, **같은 원소를 여러 번 적어도 한 번 적은 것과 같습니다.** $\{1,1,2\}$는 $\{1,2\}$입니다.

원소가 하나도 없는 집합을 **공집합**이라 하고 $\varnothing$으로 씁니다. 공집합은 하나뿐입니다. 원소가 없다는 조건이 집합을 완전히 결정하기 때문입니다.

**바로 확인.**

**확인 1-1.** $\{x\in\mathbb{Z}\mid x^{2}<10\}$을 원소나열법으로 쓰세요.

*답.* $\{-3,-2,-1,0,1,2,3\}$입니다. $(\pm 3)^{2}=9<10$이고 $(\pm 4)^{2}=16>10$입니다.

**확인 1-2.** $\{1,3,5,7,\ldots\}$을 조건제시법으로 쓰세요.

*답.* $\{n\in\mathbb{N}\mid n\text{은 홀수}\}$ 또는 $\{2k-1\mid k\in\mathbb{N}\}$입니다.

**확인 1-3.** $\varnothing$과 $\{\varnothing\}$은 같은 집합입니까?

*답.* 다릅니다. $\varnothing$은 원소가 하나도 없고, $\{\varnothing\}$은 공집합을 원소로 하나 가지는 집합입니다. 원소 개수가 각각 $0$개와 $1$개입니다.

## 문제 2. 두 집합이 같다는 것은 무슨 뜻인가

> **문제.** $A=\{x\in\mathbb{R}\mid x^{2}-3x+2=0\}$이고 $B=\{1,2\}$일 때 $A=B$임을 증명하세요. 증명은 무엇을 보이는 것으로 이루어져야 합니까?

**생각의 실마리.** 두 집합이 같다는 것을 눈으로 확인하는 것이 아니라 증명해야 합니다. 그러려면 "같다"의 정의가 필요합니다. 집합은 원소로만 결정되므로, 두 집합이 같다는 것은 원소가 정확히 일치한다는 뜻입니다. 그것을 22강의 한정 기호로 어떻게 적을지 생각합니다.

**풀이.** 두 집합이 같다는 것은 $\forall x,\;(x\in A\leftrightarrow x\in B)$입니다. 21강에서 $p\leftrightarrow q$가 $(p\to q)\land(q\to p)$였으므로 이 증명은 두 방향으로 나뉩니다.

**$A\subseteq B$ 방향.** $x\in A$라고 하면 $x^{2}-3x+2=0$입니다. 인수분해하면 $(x-1)(x-2)=0$이고, 실수에서 곱이 $0$이면 두 인수 중 하나가 $0$이므로 $x=1$ 또는 $x=2$입니다. 어느 쪽이든 $x\in B$입니다.

**$B\subseteq A$ 방향.** $x\in B$라고 하면 $x=1$ 또는 $x=2$입니다. $x=1$이면 $1-3+2=0$이고, $x=2$이면 $4-6+2=0$입니다. 두 경우 모두 $x^{2}-3x+2=0$이므로 $x\in A$입니다.

양쪽이 모두 성립하므로 $A=B$입니다.

**이 문제에서 배우는 것: 부분집합과 집합의 상등.**

$A$의 모든 원소가 $B$의 원소일 때 $A$를 $B$의 **부분집합**이라 하고 $A\subseteq B$로 씁니다. 기호로 적으면

$$A\subseteq B\;\;\text{는}\;\;\forall x,\;(x\in A\to x\in B)$$

입니다. 정의가 조건문이므로 부분집합임을 증명하는 방법이 정해집니다. **임의의 $x\in A$를 잡고 $x\in B$를 보입니다.** 23강 문제 2에서 배운 임의의 원소 잡기가 그대로 쓰입니다.

두 집합이 **같다**는 것은 원소가 정확히 일치한다는 뜻이며

$$A=B\;\;\Longleftrightarrow\;\;A\subseteq B\;\text{ 그리고 }\;B\subseteq A$$

입니다. 그래서 집합의 상등을 증명할 때는 언제나 **두 방향을 각각 증명합니다.** 이것을 양쪽 포함 증명이라고 하며, 이 단원에서 계속 쓰는 표준 절차입니다.

부분집합에 대해 기억할 사실이 세 가지 있습니다.

- 모든 집합 $A$에 대하여 $\varnothing\subseteq A$입니다. 정의가 조건문이고 $x\in\varnothing$이 항상 거짓이므로 21강의 공허하게 참에 해당합니다.
- 모든 집합 $A$에 대하여 $A\subseteq A$입니다.
- $A\subseteq B$이고 $B\subseteq C$이면 $A\subseteq C$입니다.

$A\subseteq B$이면서 $A\ne B$일 때 $A$를 $B$의 **진부분집합**이라 하고 $A\subsetneq B$로 씁니다. 1강에서 $\mathbb{N}\subset\mathbb{Z}\subset\mathbb{Q}\subset\mathbb{R}$라고 쓴 것이 모두 진부분집합입니다.

**바로 확인.**

**확인 2-1.** $\{1,2\}\subseteq\{1,2,3\}$입니까? $\{1,2\}\in\{1,2,3\}$입니까?

*답.* 앞은 참이고 뒤는 거짓입니다. $\{1,2,3\}$의 원소는 $1,2,3$이지 $\{1,2\}$가 아닙니다. $\in$과 $\subseteq$를 혼동하지 않아야 합니다.

**확인 2-2.** $A=\{x\in\mathbb{Z}\mid x\text{는 }4\text{의 배수}\}$이고 $B=\{x\in\mathbb{Z}\mid x\text{는 짝수}\}$일 때 $A\subseteq B$임을 증명하고, $B\subseteq A$가 거짓임을 보이세요.

*답.* $x\in A$이면 $x=4k=2(2k)$이므로 짝수이고 $x\in B$입니다. 반대로 $2\in B$이지만 $2\notin A$이므로 $B\subseteq A$는 거짓입니다.

**확인 2-3.** $\varnothing\subseteq\varnothing$입니까?

*답.* 참입니다. 정의가 공허하게 참이므로 성립하며, 따라서 $\varnothing=\varnothing$입니다.

## 문제 3. 집합의 연산은 논리와 어떻게 이어지는가

> **문제.** 전체집합을 $U=\{1,2,3,4,5,6\}$, $A=\{1,2,3\}$, $B=\{3,4,5\}$라고 합니다.
> (1) $A\cup B$, $A\cap B$, $A\setminus B$, $A^{c}$를 각각 구하세요.
> (2) $(A\cup B)^{c}$와 $A^{c}\cap B^{c}$를 각각 계산해 비교하세요.

**생각의 실마리.** (2)의 결과가 21강 문제 3의 드모르간 법칙과 같은 모양임을 확인하고, 왜 같아지는지 그 이유까지 봅니다. 집합 연산의 정의를 논리 연결사로 적어 보면 답이 보입니다.

**풀이.** (1) 합집합은 둘 중 하나에라도 속하는 원소를 모읍니다.
$$A\cup B=\{1,2,3,4,5\}$$

교집합은 둘 다에 속하는 원소를 모읍니다.
$$A\cap B=\{3\}$$

차집합 $A\setminus B$는 $A$에는 속하지만 $B$에는 속하지 않는 원소입니다.
$$A\setminus B=\{1,2\}$$

여집합 $A^{c}$는 전체집합에서 $A$를 뺀 것입니다.
$$A^{c}=U\setminus A=\{4,5,6\}$$

(2) $A\cup B=\{1,2,3,4,5\}$이므로
$$(A\cup B)^{c}=\{6\}$$

한편 $A^{c}=\{4,5,6\}$이고 $B^{c}=\{1,2,6\}$이므로
$$A^{c}\cap B^{c}=\{6\}$$

두 결과가 같습니다.

**이 문제에서 배우는 것: 집합 연산과 논리 연결사의 대응.**

집합 연산의 정의를 조건제시법으로 적으면 논리 연결사가 그대로 나타납니다.

| 집합 연산 | 정의 | 대응하는 논리 |
|---|---|---|
| $A\cup B$ | $\{x\mid x\in A\lor x\in B\}$ | 논리합 $\lor$ |
| $A\cap B$ | $\{x\mid x\in A\land x\in B\}$ | 논리곱 $\land$ |
| $A^{c}$ | $\{x\in U\mid x\notin A\}$ | 부정 $\lnot$ |
| $A\setminus B$ | $\{x\mid x\in A\land x\notin B\}$ | $p\land\lnot q$ |
| $A\subseteq B$ | $\forall x,\;(x\in A\to x\in B)$ | 조건문 $\to$ |

이 대응 덕분에 21강에서 증명한 논리 법칙이 집합 법칙으로 그대로 번역됩니다. 드모르간 법칙이 그 예입니다.

$$(A\cup B)^{c}=A^{c}\cap B^{c},\qquad (A\cap B)^{c}=A^{c}\cup B^{c}$$

첫 식을 증명해 봅니다. $x\in(A\cup B)^{c}$는 $\lnot(x\in A\lor x\in B)$이고, 21강의 드모르간 법칙으로 이는 $x\notin A\land x\notin B$이며, 이것이 곧 $x\in A^{c}\cap B^{c}$입니다. 모든 단계가 동치이므로 양쪽 포함이 한꺼번에 증명됩니다.

같은 방식으로 분배법칙도 얻습니다.

$$A\cap(B\cup C)=(A\cap B)\cup(A\cap C)$$
$$A\cup(B\cap C)=(A\cup B)\cap(A\cup C)$$

21강 문제 11에서 명제로 확인한 것과 같은 식입니다. 여기서 주의할 점이 있습니다. 수의 연산에서는 곱셈만 덧셈에 분배되지만, 집합에서는 **양방향 모두 분배됩니다.** $\cap$이 $\cup$에 분배되고 $\cup$도 $\cap$에 분배됩니다.

**바로 확인.**

**확인 3-1.** $U=\{1,\ldots,10\}$, $A=\{2,4,6,8\}$, $B=\{1,2,3,4\}$일 때 $A\setminus B$와 $B\setminus A$를 구하세요.

*답.* $A\setminus B=\{6,8\}$이고 $B\setminus A=\{1,3\}$입니다. 차집합은 순서를 바꾸면 달라집니다.

**확인 3-2.** $(A\cap B)^{c}=A^{c}\cup B^{c}$를 논리의 드모르간 법칙으로 증명하세요.

*답.* $x\in(A\cap B)^{c}$는 $\lnot(x\in A\land x\in B)$이고, 드모르간 법칙으로 $x\notin A\lor x\notin B$이며 이는 $x\in A^{c}\cup B^{c}$입니다.

**확인 3-3.** $A\setminus B=A\cap B^{c}$임을 정의로 확인하세요.

*답.* $A\setminus B$의 정의가 $x\in A\land x\notin B$이고, $x\notin B$는 $x\in B^{c}$이므로 $A\cap B^{c}$와 같습니다.

## 문제 4. 집합의 등식을 어떻게 증명하는가

> **문제.** 임의의 집합 $A$, $B$, $C$에 대하여 $A\cap(B\cup C)=(A\cap B)\cup(A\cap C)$임을 양쪽 포함으로 증명하세요.

**생각의 실마리.** 문제 3에서는 논리 법칙을 인용해 한 줄로 끝냈지만, 여기서는 정의만 써서 양쪽 포함을 각각 증명합니다. 각 방향에서 임의의 원소를 잡고 정의를 풀어 쓰는 것부터 시작합니다. 21강의 논리곱과 논리합의 정의가 계산 규칙이 됩니다.

**풀이.** **$\subseteq$ 방향.** 임의의 $x\in A\cap(B\cup C)$를 잡습니다.

교집합의 정의에 따라 $x\in A$이고 $x\in B\cup C$입니다. 합집합의 정의에 따라 $x\in B$이거나 $x\in C$입니다. 경우를 나눕니다.

$x\in B$인 경우, $x\in A$이므로 $x\in A\cap B$입니다. 따라서 $x\in(A\cap B)\cup(A\cap C)$입니다.

$x\in C$인 경우, $x\in A$이므로 $x\in A\cap C$입니다. 따라서 역시 $x\in(A\cap B)\cup(A\cap C)$입니다.

두 경우가 전부이고 각각에서 결론이 나왔으므로 이 방향이 증명되었습니다.

**$\supseteq$ 방향.** 임의의 $x\in(A\cap B)\cup(A\cap C)$를 잡습니다. 합집합의 정의에 따라 $x\in A\cap B$이거나 $x\in A\cap C$입니다.

$x\in A\cap B$인 경우, $x\in A$이고 $x\in B$입니다. $x\in B$이므로 $x\in B\cup C$이고, 따라서 $x\in A\cap(B\cup C)$입니다.

$x\in A\cap C$인 경우도 같은 방식으로 $x\in A$이고 $x\in C\subseteq B\cup C$이므로 $x\in A\cap(B\cup C)$입니다.

양쪽 포함이 모두 성립하므로 두 집합은 같습니다.

**이 문제에서 배우는 것: 집합 등식 증명의 표준 절차.**

집합의 등식 $X=Y$를 증명하는 절차는 언제나 같습니다.

1. **$X\subseteq Y$를 증명합니다.** 임의의 $x\in X$를 잡고, 정의를 풀어 논리식으로 바꾼 뒤, $x\in Y$를 유도합니다.
2. **$Y\subseteq X$를 증명합니다.** 방향만 바꿔 같은 일을 합니다.

각 방향에서 하는 일은 결국 21강의 논리 계산입니다. 집합 기호를 논리식으로 바꾸고, 논리 법칙으로 변형하고, 다시 집합 기호로 돌아옵니다.

**모든 단계가 동치**라면 두 방향을 따로 쓰지 않고 한 줄로 이을 수 있습니다. 문제 3에서 드모르간 법칙을 증명할 때 그렇게 했습니다. 그러나 한쪽 방향만 성립하는 단계가 섞이면 반드시 나눠 써야 하므로, 처음에는 두 방향을 항상 따로 쓰는 습관을 들이는 편이 안전합니다.

증명 안에서 경우 나누기를 쓴 자리에 주목합니다. **합집합이 가정 쪽에 있으면 경우를 나눕니다.** $x\in B\cup C$라는 가정은 "$x\in B$ 또는 $x\in C$"이므로 23강 문제 4의 경우 나누기가 그대로 필요합니다. 반대로 합집합이 결론 쪽에 있으면 둘 중 하나만 보이면 됩니다.

**바로 확인.**

**확인 4-1.** $A\cup(B\cap C)=(A\cup B)\cap(A\cup C)$의 $\subseteq$ 방향을 증명하세요.

*답.* $x\in A\cup(B\cap C)$를 잡습니다. $x\in A$이면 $x\in A\cup B$이고 $x\in A\cup C$이므로 교집합에 속합니다. $x\in B\cap C$이면 $x\in B$에서 $x\in A\cup B$이고 $x\in C$에서 $x\in A\cup C$이므로 역시 교집합에 속합니다.

**확인 4-2.** $A\subseteq B$이면 $A\cap B=A$임을 증명하세요.

*답.* $A\cap B\subseteq A$는 교집합의 정의로 자명합니다. 반대로 $x\in A$이면 $A\subseteq B$에 의해 $x\in B$이므로 $x\in A\cap B$입니다.

**확인 4-3.** 증명에서 합집합이 가정 쪽에 나오면 무엇을 합니까?

*답.* 경우를 나눕니다. 결론 쪽에 나오면 둘 중 하나만 보이면 됩니다.

## 문제 5. 집합으로 만든 집합은 몇 개인가

> **문제.** $A=\{1,2,3\}$일 때
> (1) $A$의 부분집합을 모두 적고 개수를 세세요.
> (2) $B=\{a,b\}$일 때 $A\times B$의 원소를 모두 적고 개수를 세세요.
> (3) 원소가 $n$개인 집합의 부분집합 개수와, 원소가 $m$개와 $n$개인 두 집합의 곱집합 원소 개수를 각각 구하세요.

**생각의 실마리.** (1)에서 부분집합을 만드는 과정을 선택의 연속으로 보면 19강의 곱의 법칙이 그대로 적용됩니다. 원소 하나하나에 대해 무엇을 결정해야 합니까? (2)에서는 순서쌍을 만드는 것이므로 앞자리와 뒷자리를 각각 정합니다.

**풀이.** (1) 부분집합을 원소 개수별로 적습니다.

- 원소 $0$개: $\varnothing$
- 원소 $1$개: $\{1\},\{2\},\{3\}$
- 원소 $2$개: $\{1,2\},\{1,3\},\{2,3\}$
- 원소 $3$개: $\{1,2,3\}$

모두 $1+3+3+1=8$개입니다. 각 줄의 개수가 $\binom{3}{0},\binom{3}{1},\binom{3}{2},\binom{3}{3}$으로 19강의 조합과 일치합니다.

(2) 순서쌍을 앞자리 기준으로 적습니다.

$$A\times B=\{(1,a),(1,b),(2,a),(2,b),(3,a),(3,b)\}$$

$6$개입니다.

(3) 부분집합을 만드는 일은 각 원소마다 "넣는다"와 "넣지 않는다" 중 하나를 고르는 것입니다. 원소가 $n$개이고 각각 $2$가지이므로 19강의 곱의 법칙에 따라 $2^{n}$개입니다. 25강 문제 16에서 귀납법으로도 증명했습니다.

곱집합의 원소는 앞자리를 $m$가지, 뒷자리를 $n$가지로 고르므로 $mn$개입니다.

**이 문제에서 배우는 것: 멱집합과 곱집합.**

$A$의 모든 부분집합을 원소로 하는 집합을 $A$의 **멱집합**이라 하고 $\mathcal{P}(A)$로 씁니다.

$$\mathcal{P}(A)=\{X\mid X\subseteq A\},\qquad |\mathcal{P}(A)|=2^{|A|}$$

여기서 $|A|$는 $A$의 원소 개수입니다. 멱집합의 원소는 **집합**이라는 점에 주의합니다. $1\in A$이지만 $1\notin\mathcal{P}(A)$이고 $\{1\}\in\mathcal{P}(A)$입니다.

$A$와 $B$의 **곱집합**은 앞자리를 $A$에서, 뒷자리를 $B$에서 고른 순서쌍의 집합입니다.

$$A\times B=\{(a,b)\mid a\in A,\;b\in B\},\qquad |A\times B|=|A|\cdot|B|$$

순서쌍에서는 순서가 의미를 가집니다. $(1,a)$와 $(a,1)$은 다르고, $A\times B$와 $B\times A$도 일반적으로 다릅니다. 집합 $\{1,2\}=\{2,1\}$과 대비되는 점입니다.

곱집합이 중요한 이유는 27강에서 함수를 정의할 때 쓰이기 때문입니다. 함수는 $A\times B$의 특별한 부분집합으로 정의됩니다. 9강에서 그래프로 그렸던 것이 실제로는 곱집합의 부분집합이었습니다.

유한집합의 크기를 셀 때 자주 쓰는 식도 정리해 둡니다. 19강의 포함배제와 같은 원리입니다.

$$|A\cup B|=|A|+|B|-|A\cap B|$$

**바로 확인.**

**확인 5-1.** $\mathcal{P}(\varnothing)$을 구하고 원소 개수를 세세요.

*답.* $\mathcal{P}(\varnothing)=\{\varnothing\}$이고 원소가 $1$개입니다. $2^{0}=1$과 일치합니다.

**확인 5-2.** $|A|=4$, $|B|=3$, $|A\cap B|=2$일 때 $|A\cup B|$를 구하세요.

*답.* $4+3-2=5$입니다.

**확인 5-3.** $\mathcal{P}(\{1,2\})$의 원소를 모두 적으세요.

*답.* $\varnothing,\{1\},\{2\},\{1,2\}$ 네 개입니다.

## 종합 문제 드릴

> **문제 6.** $A=\{1,2,3,4\}$, $B=\{3,4,5\}$일 때 $A\cup B$, $A\cap B$, $A\setminus B$를 구하세요.

*답.* $A\cup B=\{1,2,3,4,5\}$, $A\cap B=\{3,4\}$, $A\setminus B=\{1,2\}$입니다.

> **문제 7.** $A\cap\varnothing$과 $A\cup\varnothing$을 구하세요.

*답.* $A\cap\varnothing=\varnothing$이고 $A\cup\varnothing=A$입니다.

> **문제 8.** $A\subseteq B$와 $A\cup B=B$가 동치임을 증명하세요.

*답.* $A\subseteq B$라면 $x\in A\cup B$일 때 $x\in A$면 $x\in B$이고 $x\in B$면 그대로이므로 $A\cup B\subseteq B$이고, 반대 포함은 자명하므로 $A\cup B=B$입니다. 역으로 $A\cup B=B$라면 $x\in A$일 때 $x\in A\cup B=B$이므로 $A\subseteq B$입니다.

> **문제 9.** $(A\setminus B)\cap B=\varnothing$임을 증명하세요.

*답.* $x$가 양쪽에 속한다면 $x\notin B$이면서 $x\in B$가 되어 모순입니다. 그런 $x$가 없으므로 교집합이 공집합입니다.

> **문제 10.** $|A|=6$, $|B|=8$, $|A\cup B|=11$일 때 $|A\cap B|$를 구하세요.

*답.* $6+8-|A\cap B|=11$이므로 $|A\cap B|=3$입니다.

> **문제 11.** $\mathcal{P}(\{1,2,3,4\})$의 원소 개수를 구하세요.

*답.* $2^{4}=16$개입니다.

> **문제 12.** $A\times B=B\times A$가 항상 성립합니까? 반례를 드세요.

*답.* 성립하지 않습니다. $A=\{1\}$, $B=\{2\}$이면 $A\times B=\{(1,2)\}$이고 $B\times A=\{(2,1)\}$이며 순서쌍이 다릅니다. 다만 $A=B$이거나 한쪽이 공집합이면 같습니다.

> **문제 13.** $A\setminus(B\cup C)=(A\setminus B)\cap(A\setminus C)$임을 드모르간 법칙으로 증명하세요.

*답.* $A\setminus(B\cup C)=A\cap(B\cup C)^{c}=A\cap B^{c}\cap C^{c}$입니다. 오른쪽은 $(A\cap B^{c})\cap(A\cap C^{c})=A\cap B^{c}\cap C^{c}$이므로 같습니다.

> **문제 14.** $A\cap B=A\cup B$이면 $A=B$임을 증명하세요.

*답.* $x\in A$이면 $x\in A\cup B=A\cap B$이므로 $x\in B$입니다. 대칭적으로 $x\in B$이면 $x\in A$입니다. 따라서 $A=B$입니다.

> **문제 15.** $\{x\in\mathbb{R}\mid x^{2}<4\}$를 구간으로 쓰세요.

*답.* $x^{2}<4$는 $|x|<2$이므로 $(-2,2)$입니다. 8강의 절댓값 부등식과 같습니다.

> **문제 16.** $A\subseteq B$이고 $B\subseteq A$이면 $A=B$인 이유를 설명하세요.

*답.* 집합의 상등이 그렇게 정의되어 있기 때문입니다. 원소가 서로 완전히 포함되면 원소 전체가 일치합니다.

> **문제 17.** $|A|=3$일 때 $A$의 부분집합 중 원소가 정확히 $2$개인 것은 몇 개입니까?

*답.* $\binom{3}{2}=3$개입니다.

> **문제 18.** $\varnothing\in\mathcal{P}(A)$입니까? $A\in\mathcal{P}(A)$입니까?

*답.* 둘 다 참입니다. 공집합과 자기 자신은 언제나 부분집합이므로 멱집합의 원소입니다.

## 심화 문제

> **심화 1.** 집합의 드모르간 법칙이 왜 논리의 드모르간 법칙과 같은 식인지 설명하세요.

*답.* 집합 연산이 논리 연결사의 번역이기 때문입니다.

*풀이.* $x\in A\cup B$는 정의상 $x\in A\lor x\in B$이고, $x\in A^{c}$는 $\lnot(x\in A)$입니다. 그러므로 $x\in(A\cup B)^{c}$를 논리식으로 옮기면 정확히 $\lnot(p\lor q)$이고, 여기에 논리의 드모르간 법칙을 적용해 $\lnot p\land\lnot q$를 얻으면 다시 집합 기호로 $x\in A^{c}\cap B^{c}$가 됩니다.

**남는 것.** 집합론의 법칙을 따로 외울 필요가 없습니다. 21강의 논리 법칙을 알고 있으면 $\cup\leftrightarrow\lor$, $\cap\leftrightarrow\land$, $^{c}\leftrightarrow\lnot$로 바꾸기만 하면 됩니다. 두 이론이 같은 구조를 가진다는 사실은 뒤에서 다시 나타납니다. 확률에서 사건의 연산도 정확히 같은 규칙을 따르므로 121강 이후의 계산이 여기서 이미 준비됩니다.

> **심화 2.** $\mathcal{P}(A\cap B)=\mathcal{P}(A)\cap\mathcal{P}(B)$임을 증명하고, $\mathcal{P}(A\cup B)=\mathcal{P}(A)\cup\mathcal{P}(B)$가 거짓임을 반례로 보이세요.

*답.* 앞은 참이고 뒤는 거짓입니다.

*풀이.* 앞을 증명합니다. $X\in\mathcal{P}(A\cap B)$는 $X\subseteq A\cap B$이고, 이는 $X\subseteq A$이면서 $X\subseteq B$와 같습니다. 따라서 $X\in\mathcal{P}(A)\cap\mathcal{P}(B)$이며 모든 단계가 동치이므로 양쪽 포함이 동시에 성립합니다.

뒤에 대해서는 $A=\{1\}$, $B=\{2\}$를 봅니다. $A\cup B=\{1,2\}$이므로 $\{1,2\}\in\mathcal{P}(A\cup B)$입니다. 그러나 $\{1,2\}$는 $A$의 부분집합도 아니고 $B$의 부분집합도 아니므로 오른쪽에 속하지 않습니다. 반례입니다.

**남는 것.** 두 결과의 차이는 $\subseteq$가 $\cap$과는 잘 맞지만 $\cup$과는 맞지 않는다는 데서 옵니다. "$X$가 둘 다의 부분집합"과 "$X$가 교집합의 부분집합"은 같지만, "$X$가 둘 중 하나의 부분집합"은 "$X$가 합집합의 부분집합"보다 강합니다. 한 방향만 성립하는 관계를 등식으로 잘못 적는 것이 집합론에서 가장 흔한 실수입니다.

> **심화 3.** 세 집합에 대한 포함배제 공식 $|A\cup B\cup C|$를 유도하세요.

*답.* $|A|+|B|+|C|-|A\cap B|-|B\cap C|-|C\cap A|+|A\cap B\cap C|$입니다.

*풀이.* 두 집합의 공식을 두 번 씁니다. $A\cup B$를 하나의 집합으로 보면

$$|A\cup B\cup C|=|A\cup B|+|C|-|(A\cup B)\cap C|$$

입니다. 첫 항에 두 집합 공식을 적용하고, 마지막 항에 분배법칙을 써서 $(A\cup B)\cap C=(A\cap C)\cup(B\cap C)$로 바꾼 뒤 다시 두 집합 공식을 적용합니다.

$$|(A\cap C)\cup(B\cap C)|=|A\cap C|+|B\cap C|-|A\cap B\cap C|$$

세 식을 합치면 결과가 나옵니다.

**남는 것.** 19강에서 여사건과 포함배제를 셈으로 다뤘는데, 여기서는 집합 연산으로 유도했습니다. 같은 결과에 이르는 두 길이며, 집합 쪽 유도가 원소 개수가 늘어나도 그대로 확장된다는 장점이 있습니다.

> **심화 4.** $A\triangle B=(A\setminus B)\cup(B\setminus A)$를 대칭차라고 합니다. $A\triangle B=(A\cup B)\setminus(A\cap B)$임을 증명하세요.

*답.* 두 표현이 같습니다.

*풀이.* $x\in A\triangle B$는 "$x\in A$이고 $x\notin B$" 또는 "$x\in B$이고 $x\notin A$"입니다. 두 경우 모두에서 $x$는 $A$와 $B$ 중 적어도 하나에 속하므로 $x\in A\cup B$이고, 동시에 둘 다에 속하지는 않으므로 $x\notin A\cap B$입니다. 따라서 왼쪽이 오른쪽에 포함됩니다.

반대로 $x\in(A\cup B)\setminus(A\cap B)$이면 적어도 하나에 속하고 둘 다에는 속하지 않으므로 정확히 하나에 속합니다. $A$에만 속하면 $x\in A\setminus B$이고 $B$에만 속하면 $x\in B\setminus A$이므로 왼쪽에 속합니다.

**남는 것.** 대칭차는 21강의 배타적 논리합에 대응합니다. "둘 중 정확히 하나"라는 일상어의 "또는"이 여기 있습니다. 논리 연결사와 집합 연산의 대응이 $\lor$와 $\cup$을 넘어 계속 이어진다는 것을 보여 주는 예입니다.

> **심화 5.** $A\subseteq B$일 때 $\mathcal{P}(A)\subseteq\mathcal{P}(B)$임을 증명하고, 역이 성립하는지 판정하세요.

*답.* 참이고 역도 참입니다.

*풀이.* $X\in\mathcal{P}(A)$이면 $X\subseteq A$이고 $A\subseteq B$이므로 포함의 추이성에 의해 $X\subseteq B$이며 $X\in\mathcal{P}(B)$입니다.

역을 봅니다. $\mathcal{P}(A)\subseteq\mathcal{P}(B)$라고 하면 $A\subseteq A$이므로 $A\in\mathcal{P}(A)\subseteq\mathcal{P}(B)$이고, 따라서 $A\subseteq B$입니다.

**남는 것.** 역의 증명에서 $A$ 자신을 멱집합의 원소로 쓰는 것이 요령입니다. 멱집합에 대한 명제를 원래 집합에 대한 명제로 되돌릴 때 가장 큰 원소인 $A$를 대입하는 이 수법은 자주 쓰입니다.

> **심화 6.** "모든 집합의 집합"을 만들 수 있습니까?

*답.* 만들 수 없습니다.

*풀이.* 모든 집합의 집합 $V$가 있다고 가정합니다. 그러면 $\mathcal{P}(V)$의 모든 원소도 집합이므로 $\mathcal{P}(V)\subseteq V$입니다. 그런데 29강에서 증명할 정리에 따르면 어떤 집합도 자기 멱집합과 크기가 같을 수 없고 멱집합이 항상 더 큽니다. $\mathcal{P}(V)$가 $V$의 부분집합이면서 $V$보다 크다는 것은 모순입니다.

더 직접적인 모순도 있습니다. $R=\{X\mid X\notin X\}$를 생각합니다. $R\in R$이라면 정의에 따라 $R\notin R$이고, $R\notin R$이라면 정의에 따라 $R\in R$입니다. 어느 쪽도 불가능합니다.

**남는 것.** 21강 심화 6의 "이 문장은 거짓입니다"와 같은 구조입니다. 자기 자신을 가리키는 대상은 다루는 범위를 제한하지 않으면 모순을 낳습니다. 그래서 현대의 집합론은 아무 모임이나 집합으로 인정하지 않고, 이미 있는 집합에서 만들어지는 것만 집합으로 받아들입니다. 22강에서 한정 기호의 범위를 반드시 밝히라고 한 이유가 여기까지 이어집니다.

## 코드 검산

집합 연산은 파이썬의 집합 자료형으로 그대로 확인할 수 있습니다. 표준 자료형이므로 외부 라이브러리가 아니며, 원소 개수 계산에는 numpy를 씁니다.

```python
import numpy as np

U = set(range(1, 7))
A = {1, 2, 3}
B = {3, 4, 5}

# 문제 3: 기본 연산
print(sorted(A | B), sorted(A & B), sorted(A - B), sorted(U - A))
# [1, 2, 3, 4, 5] [3] [1, 2] [4, 5, 6]

# 문제 3: 드모르간 법칙
print((U - (A | B)) == ((U - A) & (U - B)))          # True
print((U - (A & B)) == ((U - A) | (U - B)))          # True

# 문제 4: 분배법칙
C = {2, 5, 6}
print((A & (B | C)) == ((A & B) | (A & C)))          # True
print((A | (B & C)) == ((A | B) & (A | C)))          # True

# 문제 5: 멱집합의 크기와 포함배제
n = np.arange(0, 11)
print(2**n)          # [   1    2    4    8   16   32   64  128  256  512 1024]
print(len(A | B) == len(A) + len(B) - len(A & B))    # True

# 심화 2: 멱집합은 교집합과는 맞고 합집합과는 어긋납니다.
def powerset(s):
    s = sorted(s)
    out = []
    for mask in range(2 ** len(s)):
        out.append(frozenset(x for i, x in enumerate(s) if mask >> i & 1))
    return set(out)

P, Q = {1}, {2}
print(powerset(P & Q) == (powerset(P) & powerset(Q)))   # True
print(powerset(P | Q) == (powerset(P) | powerset(Q)))   # False
print(sorted(powerset(P | Q) - (powerset(P) | powerset(Q)), key=sorted))
# [frozenset({1, 2})]

# 심화 4: 대칭차의 두 표현
print((A ^ B) == ((A | B) - (A & B)))                # True
```

출력이 주석과 모두 일치합니다. 마지막에서 두 번째 줄이 심화 2의 반례를 그대로 찍어 줍니다. $\mathcal{P}(A\cup B)$에는 있는데 $\mathcal{P}(A)\cup\mathcal{P}(B)$에는 없는 원소가 정확히 $\{1,2\}$ 하나이며, 손으로 든 반례와 일치합니다.

## 부록. 기호 정리

| 기호 | 읽는 법 | 뜻 |
|---|---|---|
| $\in$, $\notin$ | 원소입니다, 원소가 아닙니다 | 소속 관계입니다 |
| $\subseteq$, $\subsetneq$ | 부분집합, 진부분집합 | 포함 관계입니다 |
| $\cup$, $\cap$ | 합집합, 교집합 | 논리합과 논리곱에 대응합니다 |
| $\setminus$ | 차집합 | $A$에서 $B$를 뺍니다 |
| $A^{c}$ | 여집합 | 전체집합에서 $A$를 뺍니다 |
| $\triangle$ | 대칭차 | 정확히 하나에만 속하는 원소입니다 |
| $\mathcal{P}(A)$ | 멱집합 | 부분집합 전체의 집합입니다 |
| $A\times B$ | 곱집합 | 순서쌍의 집합입니다 |
| $\lvert A\rvert$ | 크기 | 원소의 개수입니다 |
| $\{x\in A\mid P(x)\}$ | 조건제시법 | 조건을 만족하는 원소들입니다 |
