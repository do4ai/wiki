# 30강. 복소수와 극형식

6강에서 이차방정식의 판별식을 배우면서 $D<0$이면 "실근이 없습니다"라고 했습니다. 그때 근이 아예 없다고 하지 않고 굳이 **실근**이라고 적은 이유가 이 강의에 있습니다. 실수 밖으로 나가면 근이 있습니다.

수를 넓히는 일은 이번이 처음이 아닙니다. 1강에서 $\mathbb{N}$에서 뺄셈이 막혀 $\mathbb{Z}$로, 나눗셈이 막혀 $\mathbb{Q}$로, 제곱근이 막혀 $\mathbb{R}$로 넓혔습니다. 이번에는 음수의 제곱근이 막혀 있습니다. 같은 방식으로 한 번 더 넓히면 놀라운 일이 일어납니다. **더 이상 넓힐 필요가 없어집니다.**

## 이 강의에서 할 수 있게 되는 것
- 복소수를 정의하고 사칙연산을 계산할 수 있습니다.
- 켤레복소수와 절댓값의 성질을 유도할 수 있습니다.
- 복소수를 평면 위의 점으로 읽고 극형식으로 바꿀 수 있습니다.
- 드무아브르 정리로 거듭제곱과 $n$제곱근을 계산할 수 있습니다.
- 실수에서 성립하던 성질 중 복소수에서 깨지는 것을 반례로 지목할 수 있습니다.

## 문제 1. 음수의 제곱근을 어떻게 다루는가

> **문제.** $x^{2}+1=0$은 실근이 없습니다. 이 방정식이 근을 가지도록 수를 넓히려면 무엇을 새로 도입해야 합니까? 그리고 그렇게 넓힌 수 체계에서 $x^{2}+4x+13=0$을 푸세요.

**생각의 실마리.** 1강에서 $\sqrt{2}$가 유리수 밖에 있어서 실수로 넓혔던 것을 떠올립니다. 그때 한 일은 "제곱해서 $2$가 되는 것"에 이름을 붙이고 계산 규칙을 정한 것이었습니다. 여기서도 같은 일을 합니다. 제곱해서 $-1$이 되는 것에 이름을 붙이면 어떻게 됩니까.

**풀이.** 제곱해서 $-1$이 되는 새 수를 도입하고 $i$라고 부릅니다.

$$i^{2}=-1$$

이 하나만 약속하면 $x^{2}+1=0$의 근이 $x=\pm i$가 됩니다.

이제 $x^{2}+4x+13=0$을 풉니다. 5강의 근의 공식을 그대로 씁니다.

$$x=\frac{-4\pm\sqrt{16-52}}{2}=\frac{-4\pm\sqrt{-36}}{2}$$

$\sqrt{-36}$을 처리합니다. $-36=36\cdot(-1)$이므로 $\sqrt{-36}=6i$입니다. 따라서

$$x=\frac{-4\pm 6i}{2}=-2\pm 3i$$

입니다. 검산해 봅니다. $x=-2+3i$를 넣으면

$$(-2+3i)^{2}+4(-2+3i)+13=(4-12i+9i^{2})-8+12i+13$$

$i^{2}=-1$이므로 $9i^{2}=-9$이고, 정리하면 $(4-12i-9)-8+12i+13=0$입니다. 근이 맞습니다.

**이 문제에서 배우는 것: 허수단위와 복소수.**

$i^{2}=-1$인 새 수 $i$를 **허수단위**라고 합니다. 그리고 실수 $a,b$에 대하여

$$z=a+bi$$

꼴로 적히는 수를 **복소수**라고 하며, 복소수 전체의 집합을 $\mathbb{C}$로 씁니다. $a$를 **실수부** $\operatorname{Re}z$, $b$를 **허수부** $\operatorname{Im}z$라고 합니다. 허수부가 $b$이지 $bi$가 아니라는 점에 주의합니다.

26강의 곱집합으로 정확히 말하면 복소수는 실수의 순서쌍 $(a,b)$이고, 덧셈과 곱셈을 다음과 같이 정의한 것입니다.

$$(a,b)+(c,d)=(a+c,\;b+d)$$
$$(a,b)\cdot(c,d)=(ac-bd,\;ad+bc)$$

곱셈 규칙이 이상해 보이지만 $a+bi$ 꼴로 적고 $i^{2}=-1$을 써서 전개하면 그대로 나옵니다.

$$(a+bi)(c+di)=ac+adi+bci+bdi^{2}=(ac-bd)+(ad+bc)i$$

실수 $a$는 $a+0i$로 보면 복소수이므로 $\mathbb{R}\subset\mathbb{C}$입니다. 1강의 수 체계 사슬이 한 칸 늘어납니다.

$$\mathbb{N}\subset\mathbb{Z}\subset\mathbb{Q}\subset\mathbb{R}\subset\mathbb{C}$$

두 복소수가 **같다**는 것은 실수부와 허수부가 각각 같다는 뜻입니다. 그래서 복소수 등식 하나는 실수 등식 두 개와 같습니다. 이 성질이 문제를 푸는 데 자주 쓰입니다.

$$a+bi=c+di\;\;\Longleftrightarrow\;\;a=c\;\text{이고}\;b=d$$

**바로 확인.**

**확인 1-1.** $(3+2i)+(1-5i)$와 $(3+2i)(1-5i)$를 각각 계산하세요.

*답.* 합은 $4-3i$입니다. 곱은 $3-15i+2i-10i^{2}=3-13i+10=13-13i$입니다.

**확인 1-2.** $x^{2}-2x+5=0$을 푸세요.

*답.* $x=\dfrac{2\pm\sqrt{4-20}}{2}=\dfrac{2\pm 4i}{2}=1\pm 2i$입니다.

**확인 1-3.** $i^{3}$과 $i^{4}$를 계산하고 $i^{n}$의 규칙을 말하세요.

*답.* $i^{3}=i^{2}\cdot i=-i$이고 $i^{4}=(i^{2})^{2}=1$입니다. $i^{4}=1$이므로 지수는 $4$를 주기로 $i,-1,-i,1$이 반복됩니다.

## 문제 2. 복소수로 나누려면 어떻게 하는가

> **문제.** $\dfrac{3+2i}{1-i}$를 $a+bi$ 꼴로 나타내세요.

**생각의 실마리.** 분모에 $i$가 있으면 실수부와 허수부를 읽을 수 없습니다. 4강에서 분모의 무리수를 없앨 때 무엇을 곱했는지 떠올립니다. $\sqrt{2}-1$의 분모를 정리하려고 $\sqrt{2}+1$을 곱했던 것과 같은 발상을 씁니다.

**풀이.** 분모 $1-i$의 부호를 뒤집은 $1+i$를 분자와 분모에 곱합니다.

$$\frac{3+2i}{1-i}\cdot\frac{1+i}{1+i}=\frac{(3+2i)(1+i)}{(1-i)(1+i)}$$

분모를 먼저 계산합니다. 2강의 합차 공식을 씁니다.

$$(1-i)(1+i)=1^{2}-i^{2}=1-(-1)=2$$

**실수가 되었습니다.** 분자를 계산합니다.

$$(3+2i)(1+i)=3+3i+2i+2i^{2}=3+5i-2=1+5i$$

따라서

$$\frac{3+2i}{1-i}=\frac{1+5i}{2}=\frac{1}{2}+\frac{5}{2}i$$

입니다.

**이 문제에서 배우는 것: 켤레복소수와 절댓값.**

$z=a+bi$에 대하여 $\bar{z}=a-bi$를 **켤레복소수**라고 합니다. 방금 계산에서 핵심은 다음 성질이었습니다.

$$z\bar{z}=(a+bi)(a-bi)=a^{2}-b^{2}i^{2}=a^{2}+b^{2}$$

**복소수와 그 켤레의 곱은 항상 $0$ 이상의 실수입니다.** 그래서 분모에 켤레를 곱하면 분모가 실수가 됩니다.

이 값의 제곱근을 **절댓값**이라고 합니다.

$$|z|=\sqrt{a^{2}+b^{2}},\qquad z\bar{z}=|z|^{2}$$

$z$가 실수이면 $b=0$이므로 $|z|=\sqrt{a^{2}}=|a|$가 되어 1강의 실수 절댓값과 일치합니다. 새 정의가 기존 개념을 확장하되 어긋나지 않는다는 점을 확인합니다.

켤레와 절댓값의 성질을 정리합니다. 모두 정의를 대입해 계산하면 나옵니다.

| 성질 | 식 |
|---|---|
| 켤레의 켤레 | $\overline{\bar{z}}=z$ |
| 합과 곱의 켤레 | $\overline{z+w}=\bar{z}+\bar{w}$, $\overline{zw}=\bar{z}\bar{w}$ |
| 실수 판정 | $z=\bar{z}\;\Longleftrightarrow\;z$가 실수입니다 |
| 실수부와 허수부 | $\operatorname{Re}z=\dfrac{z+\bar{z}}{2}$, $\operatorname{Im}z=\dfrac{z-\bar{z}}{2i}$ |
| 절댓값의 곱 | $\lvert zw\rvert =\lvert z\rvert \lvert w\rvert $ |
| 역수 | $z^{-1}=\dfrac{\bar{z}}{\lvert z\rvert ^{2}}$ ($z\ne 0$) |

마지막 줄이 나눗셈의 일반 공식입니다. 방금 한 계산이 이 공식의 적용이었습니다.

$z=\bar{z}$가 실수 판정이 되는 이유도 확인해 둡니다. $a+bi=a-bi$이면 $b=-b$에서 $b=0$이므로 실수이고, 역도 성립합니다. 이 판정법은 어떤 식이 실수임을 보일 때 자주 쓰입니다.

**바로 확인.**

**확인 2-1.** $\dfrac{1}{2+3i}$를 $a+bi$ 꼴로 쓰세요.

*답.* 켤레 $2-3i$를 곱하면 분모가 $4+9=13$이므로 $\dfrac{2-3i}{13}=\dfrac{2}{13}-\dfrac{3}{13}i$입니다.

**확인 2-2.** $|3-4i|$를 구하세요.

*답.* $\sqrt{9+16}=\sqrt{25}=5$입니다.

**확인 2-3.** $z+\bar{z}$가 항상 실수임을 보이세요.

*답.* $z=a+bi$이면 $z+\bar{z}=2a$이고 이는 실수입니다. 켤레를 취해도 자기 자신이므로 실수 판정으로도 확인됩니다.

## 문제 3. 복소수를 그림으로 어떻게 보는가

> **문제.** $z=1+\sqrt{3}i$를 좌표평면 위의 점으로 나타내고, 원점에서의 거리와 $x$축 양의 방향과 이루는 각을 구하세요. 그리고 $z$를 그 거리와 각으로만 나타내세요.

**생각의 실마리.** 복소수가 실수부와 허수부라는 두 실수로 정해지므로 평면의 점 $(a,b)$와 대응합니다. 그 점을 나타내는 방법이 좌표 말고 또 있습니다. 15강에서 단위원 위의 점을 각으로 나타냈던 방식을 떠올립니다.

**풀이.** $z=1+\sqrt{3}i$를 점 $(1,\sqrt{3})$으로 놓습니다.

원점에서의 거리는 절댓값입니다.

$$|z|=\sqrt{1^{2}+(\sqrt{3})^{2}}=\sqrt{4}=2$$

각을 구합니다. $\tan\theta=\dfrac{\sqrt{3}}{1}=\sqrt{3}$이고 점이 제1사분면에 있으므로 15강의 특수각에서 $\theta=\dfrac{\pi}{3}$입니다.

이제 좌표를 거리와 각으로 되돌립니다. 15강에서 단위원 위의 점이 $(\cos\theta,\sin\theta)$였고 반지름 $r$인 원 위의 점은 $(r\cos\theta,r\sin\theta)$였습니다. 따라서

$$1=2\cos\frac{\pi}{3},\qquad \sqrt{3}=2\sin\frac{\pi}{3}$$

이고 $z$를 다음과 같이 적을 수 있습니다.

$$z=2\left(\cos\frac{\pi}{3}+i\sin\frac{\pi}{3}\right)$$

**이 문제에서 배우는 것: 복소평면과 극형식.**

복소수 $z=a+bi$를 평면의 점 $(a,b)$로 나타낸 것을 **복소평면**이라고 합니다. 가로축이 실수축, 세로축이 허수축입니다.

이 평면에서 복소수를 나타내는 방법이 두 가지입니다.

| 표현 | 모양 | 무엇에 편한가 |
|---|---|---|
| 직교형식 | $z=a+bi$ | 덧셈과 뺄셈 |
| 극형식 | $z=r(\cos\theta+i\sin\theta)$ | 곱셈과 나눗셈, 거듭제곱 |

여기서 $r=|z|$이고 $\theta$를 **편각**이라고 하며 $\arg z$로 씁니다. 두 표현 사이의 변환은 다음과 같습니다.

$$a=r\cos\theta,\quad b=r\sin\theta,\qquad r=\sqrt{a^{2}+b^{2}},\quad \tan\theta=\frac{b}{a}$$

편각을 구할 때 $\tan\theta=\dfrac{b}{a}$만 보면 안 됩니다. **점이 어느 사분면에 있는지 함께 확인해야** 합니다. $\tan$의 주기가 $\pi$이므로 $1+i$와 $-1-i$가 같은 $\tan$ 값을 가지지만 편각은 $\dfrac{\pi}{4}$와 $\dfrac{5\pi}{4}$로 다릅니다. 16강에서 탄젠트의 주기가 $\pi$였던 것이 여기서 주의사항이 됩니다.

편각은 $2\pi$를 더해도 같은 점을 가리키므로 하나로 정해지지 않습니다. 보통 $0\le\theta<2\pi$ 또는 $-\pi<\theta\le\pi$ 범위로 잡습니다.

덧셈은 직교형식에서 성분끼리 더하는 것이고, 이는 평면에서 화살표를 이어 붙이는 것과 같습니다. 62강에서 벡터의 덧셈을 배울 때 같은 그림이 다시 나옵니다.

**바로 확인.**

**확인 3-1.** $z=-1+i$의 절댓값과 편각을 구하세요.

*답.* $|z|=\sqrt{2}$입니다. 점 $(-1,1)$이 제2사분면에 있고 $\tan\theta=-1$이므로 $\theta=\dfrac{3\pi}{4}$입니다.

**확인 3-2.** $z=3\left(\cos\dfrac{\pi}{6}+i\sin\dfrac{\pi}{6}\right)$를 직교형식으로 쓰세요.

*답.* $\cos\dfrac{\pi}{6}=\dfrac{\sqrt{3}}{2}$, $\sin\dfrac{\pi}{6}=\dfrac{1}{2}$이므로 $z=\dfrac{3\sqrt{3}}{2}+\dfrac{3}{2}i$입니다.

**확인 3-3.** $\tan\theta$만 보고 편각을 정하면 안 되는 이유를 예로 설명하세요.

*답.* $1+i$와 $-1-i$는 모두 $\tan\theta=1$이지만 편각이 각각 $\dfrac{\pi}{4}$와 $\dfrac{5\pi}{4}$입니다. 사분면을 함께 봐야 구분됩니다.

## 문제 4. 복소수를 곱하면 무슨 일이 일어나는가

> **문제.** $z_{1}=r_{1}(\cos\alpha+i\sin\alpha)$이고 $z_{2}=r_{2}(\cos\beta+i\sin\beta)$일 때 $z_{1}z_{2}$를 극형식으로 나타내세요. 그리고 그 결과가 복소평면에서 무엇을 뜻하는지 말하세요.

**생각의 실마리.** 두 극형식을 그대로 곱해 전개합니다. 전개하면 $\cos\alpha\cos\beta$와 $\sin\alpha\sin\beta$ 같은 항이 나오는데, 17강에서 그런 조합을 하나의 삼각함수로 묶는 공식을 유도했습니다. 그 공식을 찾아 씁니다.

**풀이.** 두 식을 곱합니다.

$$z_{1}z_{2}=r_{1}r_{2}(\cos\alpha+i\sin\alpha)(\cos\beta+i\sin\beta)$$

괄호를 전개합니다.

$$=r_{1}r_{2}\big[\cos\alpha\cos\beta+i\cos\alpha\sin\beta+i\sin\alpha\cos\beta+i^{2}\sin\alpha\sin\beta\big]$$

$i^{2}=-1$이므로 실수부와 허수부로 묶습니다.

$$=r_{1}r_{2}\big[(\cos\alpha\cos\beta-\sin\alpha\sin\beta)+i(\sin\alpha\cos\beta+\cos\alpha\sin\beta)\big]$$

여기서 17강의 덧셈정리를 씁니다.

$$\cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta$$
$$\sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta$$

대입하면

$$z_{1}z_{2}=r_{1}r_{2}\big[\cos(\alpha+\beta)+i\sin(\alpha+\beta)\big]$$

입니다.

이 결과를 읽으면 **절댓값은 곱해지고 편각은 더해집니다.** 복소평면에서 $z_{2}$를 곱하는 일은 원점을 중심으로 $r_{2}$배 확대하고 $\beta$만큼 회전시키는 것입니다.

**이 문제에서 배우는 것: 곱셈의 기하학적 뜻과 드무아브르 정리.**

$$|z_{1}z_{2}|=|z_{1}||z_{2}|,\qquad \arg(z_{1}z_{2})=\arg z_{1}+\arg z_{2}$$

나눗셈은 반대입니다. 절댓값은 나누고 편각은 뺍니다.

이 결과를 같은 수에 반복 적용하면 거듭제곱 공식이 나옵니다. $z=r(\cos\theta+i\sin\theta)$일 때

$$z^{n}=r^{n}(\cos n\theta+i\sin n\theta)$$

이며 이것을 **드무아브르 정리**라고 합니다. 25강의 귀납법으로 정식 증명합니다. $n=1$이면 자명하고, $z^{k}=r^{k}(\cos k\theta+i\sin k\theta)$를 가정한 뒤 양변에 $z$를 곱하면 위 곱셈 규칙에 의해 절댓값이 $r^{k+1}$이 되고 편각이 $(k+1)\theta$가 됩니다.

이 정리의 쓸모는 직교형식으로 계산하기 어려운 거듭제곱을 한 줄로 처리하는 데 있습니다. $(1+i)^{10}$을 이항정리로 전개하면 항이 열한 개이지만, 극형식으로는 $r=\sqrt{2}$이고 $\theta=\dfrac{\pi}{4}$이므로

$$(1+i)^{10}=(\sqrt{2})^{10}\left(\cos\frac{10\pi}{4}+i\sin\frac{10\pi}{4}\right)=32\left(\cos\frac{\pi}{2}+i\sin\frac{\pi}{2}\right)=32i$$

로 끝납니다. 마지막에서 $\dfrac{10\pi}{4}=\dfrac{5\pi}{2}$가 $\dfrac{\pi}{2}$와 $2\pi$ 차이라는 16강의 주기성을 썼습니다.

**바로 확인.**

**확인 4-1.** $z=2\left(\cos\dfrac{\pi}{6}+i\sin\dfrac{\pi}{6}\right)$일 때 $z^{3}$을 구하세요.

*답.* $z^{3}=8\left(\cos\dfrac{\pi}{2}+i\sin\dfrac{\pi}{2}\right)=8i$입니다.

**확인 4-2.** $i$를 곱하는 것은 복소평면에서 어떤 변환입니까?

*답.* $|i|=1$이고 $\arg i=\dfrac{\pi}{2}$이므로 크기를 바꾸지 않고 반시계 방향으로 $90$도 회전시킵니다.

**확인 4-3.** $(1-i)^{8}$을 극형식으로 계산하세요.

*답.* $|1-i|=\sqrt{2}$이고 편각이 $-\dfrac{\pi}{4}$이므로 $(\sqrt{2})^{8}\big(\cos(-2\pi)+i\sin(-2\pi)\big)=16$입니다.

## 문제 5. 방정식의 근은 몇 개까지 있는가

> **문제.** $z^{3}=1$의 복소수 해를 모두 구하세요. 그리고 그 해들이 복소평면에서 어떻게 배치되는지 말하세요.

**생각의 실마리.** $z=1$이 해인 것은 바로 보입니다. 그러나 실수 범위를 벗어나면 더 있을 수 있습니다. 극형식으로 놓고 드무아브르 정리를 쓰면 절댓값과 편각에 대한 조건으로 나뉩니다. 편각 조건에서 $2\pi$의 정수배 차이를 잊지 않는 것이 관건입니다.

**풀이.** $z=r(\cos\theta+i\sin\theta)$로 놓습니다. 드무아브르 정리에 의해

$$z^{3}=r^{3}(\cos 3\theta+i\sin 3\theta)$$

이고, 오른쪽 $1$을 극형식으로 적으면 $1=1\cdot(\cos 0+i\sin 0)$입니다.

두 복소수가 같으려면 절댓값이 같고 편각이 $2\pi$의 정수배만큼만 차이 나야 합니다.

$$r^{3}=1,\qquad 3\theta=0+2k\pi\;(k\in\mathbb{Z})$$

$r$는 $0$ 이상의 실수이므로 $r=1$입니다. 편각은

$$\theta=\frac{2k\pi}{3}$$

입니다. $k=0,1,2$를 넣으면 $\theta=0,\dfrac{2\pi}{3},\dfrac{4\pi}{3}$이고, $k=3$이면 $\theta=2\pi$로 $k=0$과 같은 점이므로 새 해가 나오지 않습니다.

세 해를 직교형식으로 적습니다.

$$z_{0}=1,\qquad z_{1}=-\frac{1}{2}+\frac{\sqrt{3}}{2}i,\qquad z_{2}=-\frac{1}{2}-\frac{\sqrt{3}}{2}i$$

세 점 모두 절댓값이 $1$이므로 단위원 위에 있고, 편각이 $\dfrac{2\pi}{3}$씩 차이 나므로 **정삼각형의 꼭짓점**을 이룹니다.

**이 문제에서 배우는 것: $n$제곱근과 대수학의 기본정리.**

$z^{n}=w$의 해를 $w$의 **$n$제곱근**이라고 합니다. $w=\rho(\cos\varphi+i\sin\varphi)$이고 $w\ne 0$이면 해는 정확히 $n$개이며

$$z_{k}=\rho^{1/n}\left(\cos\frac{\varphi+2k\pi}{n}+i\sin\frac{\varphi+2k\pi}{n}\right),\qquad k=0,1,\ldots,n-1$$

입니다. 모든 해의 절댓값이 같으므로 **반지름 $\rho^{1/n}$인 원 위에서 정$n$각형의 꼭짓점**에 놓입니다.

$k$를 $0$부터 $n-1$까지만 잡는 이유는 $k=n$에서 편각이 $\dfrac{\varphi}{n}+2\pi$가 되어 $k=0$과 같은 점이 되기 때문입니다. **정확히 $n$개**라는 것이 여기서 나옵니다.

실수 범위에서는 사정이 달랐습니다. $x^{3}=1$의 실근은 $1$ 하나뿐이고 $x^{2}=-1$의 실근은 없습니다. 복소수로 넓히면 개수가 항상 차수와 같아집니다. 이것이 일반적으로 성립한다는 것이 **대수학의 기본정리**입니다.

> 복소수 계수를 가진 $n$차 다항식은 중근을 개수에 넣어 세면 복소수 근을 정확히 $n$개 가집니다.

이 정리의 증명은 이 커리큘럼의 범위를 넘습니다. 다만 그 뜻은 분명히 새겨 둡니다. **더 이상 수를 넓힐 필요가 없습니다.** 1강부터 이어진 확장의 사슬이 $\mathbb{C}$에서 끝납니다. $\mathbb{C}$ 안에서 만든 어떤 다항방정식도 $\mathbb{C}$ 안에서 풀립니다.

$1$의 $n$제곱근은 뒤에서 다시 만납니다. 59강의 푸리에 급수와 409강의 이산 푸리에 변환이 이 점들 위에서 계산됩니다.

**바로 확인.**

**확인 5-1.** $z^{4}=1$의 해를 모두 구하세요.

*답.* $r=1$이고 $\theta=\dfrac{2k\pi}{4}$이므로 $\theta=0,\dfrac{\pi}{2},\pi,\dfrac{3\pi}{2}$이고 해는 $1,i,-1,-i$입니다.

**확인 5-2.** $z^{2}=i$의 해를 구하세요.

*답.* $i=\cos\dfrac{\pi}{2}+i\sin\dfrac{\pi}{2}$이므로 $\theta=\dfrac{\pi}{4}+k\pi$입니다. 해는 $\dfrac{\sqrt{2}}{2}(1+i)$와 $-\dfrac{\sqrt{2}}{2}(1+i)$입니다.

**확인 5-3.** $1$의 $6$제곱근은 복소평면에서 어떤 모양을 이룹니까?

*답.* 단위원 위의 정육각형 꼭짓점을 이룹니다. 편각이 $\dfrac{\pi}{3}$씩 차이 납니다.

## 심화 문제

> **심화 1.** 실수에서 성립하던 성질 중 복소수에서 깨지는 것을 하나 찾고 반례를 드세요.

*답.* 대소 비교가 깨집니다. 그리고 $\sqrt{a}\sqrt{b}=\sqrt{ab}$도 깨집니다.

*풀이.* 복소수에는 실수처럼 크기 순서를 줄 수 없습니다. $i>0$이라 가정하면 양변에 $i$를 곱해 $i^{2}>0$이므로 $-1>0$이 되어 모순이고, $i<0$이라 가정해도 양변에 음수 $i$를 곱하면 부등호가 뒤집혀 $i^{2}>0$으로 같은 모순이 나옵니다.

근호 성질의 반례는 다음과 같습니다.

$$\sqrt{-1}\cdot\sqrt{-1}=i\cdot i=-1,\qquad \sqrt{(-1)(-1)}=\sqrt{1}=1$$

두 값이 다릅니다.

**남는 것.** 수를 넓히면 얻는 것도 있고 잃는 것도 있습니다. 얻은 것은 모든 다항방정식이 풀린다는 사실이고, 잃은 것은 대소 비교입니다. 24강 문제 5에서 반례가 명제의 경계를 알려 준다고 했는데, 여기서는 반례가 **정리를 쓸 수 있는 수 체계의 경계**를 알려 줍니다. 실수에서 배운 부등식 성질을 복소수에 그대로 옮기지 않도록 주의합니다.

> **심화 2.** 드무아브르 정리를 25강의 귀납법으로 정식 증명하세요.

*답.* 기초 단계와 귀납 단계로 나뉩니다.

*풀이.* $P(n)$을 "$z^{n}=r^{n}(\cos n\theta+i\sin n\theta)$입니다"로 둡니다.

기초 단계에서 $n=1$이면 양변이 $z$ 자신이므로 참입니다.

귀납 단계에서 $P(k)$를 가정합니다. 양변에 $z$를 곱하면

$$z^{k+1}=r^{k}(\cos k\theta+i\sin k\theta)\cdot r(\cos\theta+i\sin\theta)$$

이고, 문제 4의 곱셈 규칙에 의해 절댓값은 $r^{k}\cdot r=r^{k+1}$이 되고 편각은 $k\theta+\theta=(k+1)\theta$가 됩니다. 따라서 $P(k+1)$이 참입니다.

**남는 것.** 문제 4에서 유도한 곱셈 규칙이 귀납 단계의 전부입니다. 정리 하나를 세워 두면 그것을 반복 적용하는 정리가 귀납법으로 거의 자동으로 따라옵니다. 25강 문제 2에서 정리한 귀납 단계의 표준 절차 중 "앞의 $k$개와 새 조각으로 쪼갠다"가 여기서는 "$z^{k}$와 $z$로 쪼갠다"입니다.

> **심화 3.** $1$의 $n$제곱근을 모두 더하면 얼마입니까? ($n\ge 2$)

*답.* $0$입니다.

*풀이.* $\omega=\cos\dfrac{2\pi}{n}+i\sin\dfrac{2\pi}{n}$로 두면 $n$제곱근 전체는 $1,\omega,\omega^{2},\ldots,\omega^{n-1}$입니다. 이것은 첫째항이 $1$이고 공비가 $\omega$인 등비수열이므로 18강의 합 공식을 씁니다. $\omega\ne 1$이므로

$$1+\omega+\cdots+\omega^{n-1}=\frac{\omega^{n}-1}{\omega-1}$$

이고 $\omega^{n}=1$이므로 분자가 $0$입니다. 따라서 합은 $0$입니다.

**남는 것.** 기하학적으로 읽으면 정$n$각형의 꼭짓점 벡터를 모두 더하면 $0$이 된다는 뜻이며, 대칭성 때문에 서로 상쇄됩니다. 이 상쇄가 409강의 이산 푸리에 변환에서 결정적으로 쓰입니다. 서로 다른 주파수 성분이 정확히 $0$으로 지워지는 근거가 바로 이 합입니다.

> **심화 4.** $\lvert z+w\rvert\le\lvert z\rvert+\lvert w\rvert$를 증명하세요.

*답.* 삼각부등식이 복소수에서도 성립합니다.

*풀이.* 양변이 $0$ 이상이므로 제곱을 비교합니다. 왼쪽을 켤레로 전개합니다.

$$\lvert z+w\rvert^{2}=(z+w)\overline{(z+w)}=z\bar{z}+z\bar{w}+w\bar{z}+w\bar{w}=\lvert z\rvert^{2}+\lvert w\rvert^{2}+(z\bar{w}+\overline{z\bar{w}})$$

마지막 괄호는 확인 2-3에 의해 $2\operatorname{Re}(z\bar{w})$입니다. 그리고 어떤 복소수든 실수부는 절댓값을 넘지 않으므로

$$2\operatorname{Re}(z\bar{w})\le 2\lvert z\bar{w}\rvert=2\lvert z\rvert\lvert w\rvert$$

입니다. 따라서

$$\lvert z+w\rvert^{2}\le\lvert z\rvert^{2}+2\lvert z\rvert\lvert w\rvert+\lvert w\rvert^{2}=(\lvert z\rvert+\lvert w\rvert)^{2}$$

이고 양변에 제곱근을 취하면 결과가 나옵니다.

**남는 것.** 8강에서 실수의 삼각부등식을 경우 나누기로 증명했는데, 복소수에서는 경우를 나눌 수 없으므로 켤레를 써서 제곱을 전개하는 방식으로 바꿨습니다. **같은 정리라도 수 체계가 달라지면 증명 방법이 달라집니다.** 이 켤레 전개 방식은 62강 이후 벡터의 내적에서 그대로 재사용됩니다.

> **심화 5.** $\left(\dfrac{1+i}{1-i}\right)^{100}$을 계산하세요.

*답.* $1$입니다.

*풀이.* 먼저 괄호 안을 정리합니다. 분모의 켤레를 곱하면

$$\frac{1+i}{1-i}=\frac{(1+i)^{2}}{(1-i)(1+i)}=\frac{1+2i+i^{2}}{2}=\frac{2i}{2}=i$$

입니다. 따라서 구하는 값은 $i^{100}$이고, $100=4\cdot 25$이므로 $i^{100}=1$입니다.

극형식으로도 확인됩니다. 분자의 편각이 $\dfrac{\pi}{4}$, 분모가 $-\dfrac{\pi}{4}$이므로 나눗셈에서 편각이 $\dfrac{\pi}{2}$가 되고 절댓값은 $\dfrac{\sqrt2}{\sqrt2}=1$입니다.

**남는 것.** 큰 거듭제곱을 만나면 먼저 밑을 최대한 단순하게 만듭니다. $i$처럼 주기가 짧은 수로 줄이면 지수를 주기로 나눈 나머지만 보면 됩니다. 13강에서 지수법칙을 쓸 때 밑을 통일했던 것과 같은 요령입니다.

> **심화 6.** $\omega$가 $1$의 세제곱근 중 $1$이 아닌 것일 때 $\omega^{2}+\omega+1=0$임을 보이고, 이를 써서 $(1+\omega)^{3}$을 계산하세요.

*답.* $(1+\omega)^{3}=-1$입니다.

*풀이.* $\omega^{3}=1$이므로 $\omega^{3}-1=0$이고 3강의 인수분해로 $(\omega-1)(\omega^{2}+\omega+1)=0$입니다. $\omega\ne 1$이므로 $\omega-1\ne 0$이고 따라서 $\omega^{2}+\omega+1=0$입니다.

이 관계에서 $1+\omega=-\omega^{2}$입니다. 세제곱하면

$$(1+\omega)^{3}=(-\omega^{2})^{3}=-\omega^{6}=-(\omega^{3})^{2}=-1$$

입니다.

**남는 것.** $\omega^{2}+\omega+1=0$은 심화 3의 특수한 경우입니다. 세 제곱근의 합이 $0$이라는 사실을 $1+\omega+\omega^{2}=0$으로 적은 것뿐입니다. 이 관계식 하나로 $\omega$가 들어간 식을 차수 $2$ 이하로 계속 줄일 수 있어 계산이 간단해집니다. 관계식을 찾아 차수를 낮추는 이 방식은 다항식을 다룰 때 늘 쓰는 전략입니다.

```python
import numpy as np

# 문제 1: x^2 + 4x + 13 = 0 의 근
z = np.array([-2 + 3j, -2 - 3j])
print(np.abs(z**2 + 4*z + 13).max() < 1e-12)                 # True

# 문제 2: 나눗셈은 켤레를 곱하는 것과 같습니다.
a = (3 + 2j) / (1 - 1j)
print(a, np.isclose(a, 0.5 + 2.5j))                          # (0.5+2.5j) True

# 문제 3: 극형식 변환
w = 1 + np.sqrt(3) * 1j
print(round(abs(w), 10), round(np.angle(w), 10), round(np.pi/3, 10))
# 2.0 1.0471975512 1.0471975512

# 문제 4: 곱하면 절댓값은 곱해지고 편각은 더해집니다.
z1, z2 = 2 * np.exp(1j * np.pi / 6), 3 * np.exp(1j * np.pi / 4)
print(np.isclose(abs(z1 * z2), abs(z1) * abs(z2)))           # True
print(np.isclose(np.angle(z1 * z2), np.angle(z1) + np.angle(z2)))  # True

# 문제 4: (1+i)^10 = 32i
print(np.isclose((1 + 1j)**10, 32j))                         # True

# 문제 5: z^3 = 1 의 세 근은 단위원 위 정삼각형입니다.
k = np.arange(3)
roots = np.exp(2j * np.pi * k / 3)
print([(round(float(r.real), 6), round(float(r.imag), 6)) for r in roots])
# [(1.0, 0.0), (-0.5, 0.866025), (-0.5, -0.866025)]
print(np.abs(roots**3 - 1).max() < 1e-12)                    # True
print([round(float(v), 10) for v in np.abs(roots)])          # [1.0, 1.0, 1.0]

# 심화 3: 1의 n제곱근의 합은 0 입니다.
sums = [bool(abs(np.exp(2j * np.pi * np.arange(n) / n).sum()) < 1e-12)
        for n in (2, 3, 5, 8)]
print(sums)                                                  # [True, True, True, True]

# 심화 4: 삼각부등식
rng = np.array([1+2j, -3+1j, 0.5-0.5j, 4+0j])
p, q = rng[:, None], rng[None, :]
print(bool(np.all(np.abs(p + q) <= np.abs(p) + np.abs(q) + 1e-12)))   # True

# 심화 1: 근호 성질이 깨집니다.
print(np.sqrt(-1+0j) * np.sqrt(-1+0j), np.sqrt((-1)*(-1)+0j))   # (-1+0j) (1+0j)
```

출력이 주석과 모두 일치합니다. 마지막 줄이 심화 1의 반례를 그대로 보여 줍니다. $\sqrt{-1}\cdot\sqrt{-1}$은 $-1$이고 $\sqrt{(-1)(-1)}$은 $1$이므로 두 값이 다릅니다. 실수에서 익숙한 근호 규칙을 복소수에 그대로 쓰면 안 된다는 사실이 계산으로 확인됩니다.

## 스스로 점검

1. 허수단위 $i$는 무엇으로 정의됩니까?
2. $z=a+bi$의 켤레와 절댓값을 쓰세요.
3. 복소수 나눗셈은 어떻게 합니까?
4. 극형식을 쓰세요.
5. 두 복소수를 곱하면 절댓값과 편각은 각각 어떻게 됩니까?
6. 드무아브르 정리를 쓰세요.
7. $z^{n}=w$ ($w\ne 0$)의 해는 몇 개입니까?
8. 대수학의 기본정리는 무엇을 말합니까?

**정답.**
1. $i^{2}=-1$입니다.
2. $\bar{z}=a-bi$이고 $\lvert z\rvert=\sqrt{a^{2}+b^{2}}$입니다.
3. 분모의 켤레를 분자와 분모에 곱해 분모를 실수로 만듭니다.
4. $z=r(\cos\theta+i\sin\theta)$입니다.
5. 절댓값은 곱해지고 편각은 더해집니다.
6. $z^{n}=r^{n}(\cos n\theta+i\sin n\theta)$입니다.
7. 정확히 $n$개이며 원 위 정$n$각형 꼭짓점에 놓입니다.
8. $n$차 다항식은 중근을 세어 복소수 근을 정확히 $n$개 가집니다.
