# 106강. 삼중적분과 부피

103강에서 이중적분을 세우고, 104강에서 극좌표를 쓰고, 105강에서 임의의 변수변환으로 일반화했습니다.

**이 강의는 차원을 하나 더 올립니다.**

$$\iiint_{E}f(x,y,z)\,dV$$

**새로 배울 개념은 거의 없습니다.** 정의도 같고 반복적분도 같고 변수변환 공식도 같습니다. 야코비가 $3\times3$이 될 뿐입니다.

$$\iiint_{E}f\,dV=\iiint_{E'}f(\mathbf{g})\,\lvert\det J_{\mathbf{g}}\rvert\,du\,dv\,dw$$

**달라지는 것은 좌표계의 선택지가 늘어난다는 점**입니다. 평면에서는 직교와 극 두 가지였는데, 공간에서는 셋입니다.

| 좌표계 | $\lvert\det J\rvert$ | 어울리는 영역 |
|---|---|---|
| 직교 | $1$ | 직육면체 |
| 원기둥 | $r$ | 축 대칭 |
| 구면 | $\rho^{2}\sin\phi$ | 구 대칭 |

**셋째 줄의 $\rho^{2}\sin\phi$**가 이 강의에서 가장 중요한 계산이며, 여기서 $4\pi\rho^{2}$과 $\frac43\pi R^{3}$이 모두 나옵니다.

이것으로 03단원이 끝나고 04단원에서 최적화로 돌아갑니다.

## 이 강의에서 할 수 있게 되는 것
- 삼중적분을 반복적분으로 세우고 계산할 수 있습니다.
- 원기둥좌표를 쓰고 야코비를 말할 수 있습니다.
- 구면좌표의 야코비 $\rho^{2}\sin\phi$를 유도하고 쓸 수 있습니다.
- 질량과 무게중심을 적분으로 구할 수 있습니다.
- 영역에 맞는 좌표계를 고를 수 있습니다.

## 문제 1. 세 변수로 넘어가면 무엇이 달라지는가

> **문제.** 사면체 $E=\{x,y,z\ge0,\ x+y+z\le1\}$을 봅니다.
> (1) 반복적분으로 부피를 세우세요.
> (2) 계산하세요.
> (3) 수치로 확인하고 $n$차원으로 일반화하세요.

**생각의 실마리.** 103강 문제 4에서 안쪽 범위가 바깥 변수의 함수였습니다. **이제 가장 안쪽 범위가 바깥 두 변수의 함수**가 됩니다.

**풀이.** (1) $x$를 가장 바깥에 두면 $0\le x\le1$입니다. $x$를 고정하면 $y$는 $0$부터 $1-x$까지이고, 둘을 고정하면 $z$는 $0$부터 $1-x-y$까지입니다.

$$\int_{0}^{1}\!\!\int_{0}^{1-x}\!\!\int_{0}^{1-x-y}dz\,dy\,dx$$

(2) 안쪽부터 계산합니다.

$$\int_{0}^{1-x-y}dz=1-x-y$$

$$\int_{0}^{1-x}(1-x-y)\,dy=\left[(1-x)y-\frac{y^{2}}{2}\right]_{0}^{1-x}=\frac{(1-x)^{2}}{2}$$

$$\int_{0}^{1}\frac{(1-x)^{2}}{2}\,dx=\frac16$$

(3) 검산에서 $700^{3}$ 격자로 $0.16666633$이며 오차가 $3.401\times10^{-7}$입니다.

**$n$차원 단체의 부피는 $1/n!$**입니다. $n=3$에서 $1/6$이고 검산에서 확인됩니다.

**이 문제에서 배우는 것: 삼중적분.**

> **삼중적분.** 유계 입체 $E$와 그 위의 함수 $f$에 대해
> $$\iiint_{E}f\,dV=\lim\sum_{k}f(\mathbf{p}_{k}^{*})\,\Delta V_{k}$$
> 이며, $f=1$이면 $E$의 부피입니다.

**반복적분의 규칙이 그대로**입니다.

$$\text{가장 바깥은 상수, 안으로 갈수록 바깥 변수에 의존}$$

103강 문제 4에서 세운 규칙이 한 겹 더 깊어졌을 뿐입니다.

**순서는 $3!=6$가지**입니다. 이중적분에서 두 가지였던 것이 여섯 가지가 되며, 영역과 함수에 따라 편한 것을 고릅니다.

| 차원 | 반복적분의 순서 | 영역 유형 |
|---|---|---|
| $2$ | $2$가지 | I, II |
| $3$ | $6$가지 | 여섯 가지 사영 |

**$1/n!$이 나오는 이유**를 짚어 둡니다. 단위정육면체를 $x_{1},\dots,x_{n}$의 크기 순서로 나누면 $n!$개의 합동인 조각이 생기고, 각각이 단체와 부피가 같습니다. **대칭성으로 곧바로 나오는 결과**이며 계산 없이도 알 수 있습니다.

**바로 확인 1.**

**확인 1-1.** 삼중적분에서 $f=1$이면 무엇을 얻습니까?

*답.* 부피입니다.

**확인 1-2.** 반복적분의 순서는 몇 가지입니까?

*답.* $3!=6$가지입니다.

**확인 1-3.** $n$차원 단체의 부피를 쓰세요.

*답.* $1/n!$입니다.

## 문제 2. 축 대칭이면 어떤 좌표가 좋은가

> **문제.** (1) 원기둥좌표의 야코비 행렬식을 구하세요.
> (2) 반지름 $2$, 높이 $5$인 원기둥의 부피를 구하세요.
> (3) 포물면 $z=x^{2}+y^{2}$ 위쪽이면서 $z\le4$인 입체의 부피를 구하세요.

**생각의 실마리.** 극좌표에 $z$를 그대로 붙인 것이므로 **야코비도 극좌표와 같을 것**입니다.

**풀이.** (1) 변환이 $(x,y,z)=(r\cos\theta,\ r\sin\theta,\ z)$이므로

$$J=\begin{pmatrix}\cos\theta&-r\sin\theta&0\\\sin\theta&r\cos\theta&0\\0&0&1\end{pmatrix}$$

**셋째 행과 셋째 열이 단순**하므로 여인수 전개로

$$\det J=1\cdot\det\begin{pmatrix}\cos\theta&-r\sin\theta\\\sin\theta&r\cos\theta\end{pmatrix}=r$$

검산에서 $r=2$일 때 $2.000000$, $r=3$일 때 $3.000000$입니다.

(2) 영역이 $0\le r\le2$, $0\le\theta\le2\pi$, $0\le z\le5$인 직육면체이므로

$$\int_{0}^{2\pi}\!\!\int_{0}^{2}\!\!\int_{0}^{5}r\,dz\,dr\,d\theta=2\pi\cdot2\cdot5=20\pi$$

검산에서 $62.831853$입니다.

(3) $z$의 범위가 $r^{2}\le z\le4$이고 $r$은 $0$에서 $2$까지입니다.

$$\int_{0}^{2\pi}\!\!\int_{0}^{2}(4-r^{2})\,r\,dr\,d\theta=2\pi\left[2r^{2}-\frac{r^{4}}{4}\right]_{0}^{2}=2\pi(8-4)=8\pi$$

검산에서 $25.132741$입니다.

**이 문제에서 배우는 것: 원기둥좌표.**

> **원기둥좌표.** $(x,y,z)=(r\cos\theta,\ r\sin\theta,\ z)$이며
> $$dV=r\,dr\,d\theta\,dz$$
> 입니다.

**$z$ 방향이 변하지 않으므로 야코비가 극좌표와 같습니다.** 야코비 행렬이 블록 대각이고 아래 블록이 $1$이라, 행렬식이 위 블록의 것과 같습니다.

$$\det\begin{pmatrix}J_{2}&\mathbf{0}\\\mathbf{0}^{\top}&1\end{pmatrix}=\det J_{2}$$

**어울리는 영역**을 정리합니다.

| 영역 | 원기둥좌표에서 |
|---|---|
| 원기둥 | 직육면체 |
| 원뿔 | $z$가 $r$의 함수 |
| 포물면 | $z$가 $r^{2}$의 함수 |
| 회전체 | 축을 $z$로 잡으면 단순 |

**52강의 회전체 부피와 이어집니다.** 그때 원판법으로 $\pi\int r(z)^{2}dz$를 썼는데, 원기둥좌표로 쓰면

$$\int_{0}^{2\pi}\!\!\int_{0}^{r(z)}r\,dr\,d\theta=2\pi\cdot\frac{r(z)^{2}}{2}=\pi r(z)^{2}$$

**같은 식이 나옵니다.** 원판법이 원기둥좌표 적분의 안쪽 두 개를 미리 해 둔 것이었습니다.

**바로 확인 2.**

**확인 2-1.** 원기둥좌표의 부피 요소를 쓰세요.

*답.* $r\,dr\,d\theta\,dz$입니다.

**확인 2-2.** 극좌표와 야코비가 같은 이유를 쓰세요.

*답.* $z$ 방향이 변하지 않아 야코비가 블록 대각이고 아래 블록이 $1$이기 때문입니다.

**확인 2-3.** 원판법과 원기둥좌표의 관계를 쓰세요.

*답.* 원판법은 원기둥좌표 적분의 안쪽 두 개를 미리 계산한 것입니다.

## 문제 3. 구 대칭이면 어떤 좌표가 좋은가

> **문제.** (1) 구면좌표의 야코비 행렬식을 구하세요.
> (2) 반지름 $R$인 공의 부피를 구하세요.
> (3) 반지름 $\rho$인 구면의 넓이를 구하세요.

**생각의 실마리.** 원점에서의 거리와 두 각으로 잡습니다. **$\rho^{2}$은 구면의 넓이가 $\rho^{2}$에 비례하기 때문**이고, $\sin\phi$는 위도에 따라 경도선 간격이 달라지기 때문일 것입니다.

**풀이.** (1) 변환이

$$(x,y,z)=(\rho\sin\phi\cos\theta,\ \rho\sin\phi\sin\theta,\ \rho\cos\phi)$$

이며 $\phi$는 $z$축에서 잰 각($0\le\phi\le\pi$)이고 $\theta$는 경도($0\le\theta\le2\pi$)입니다. 야코비를 계산하면

$$\det J=\rho^{2}\sin\phi$$

검산에서 확인합니다.

| $\rho$ | $\phi$ | $\det J$ | $\rho^{2}\sin\phi$ |
|---|---|---|---|
| $2.0$ | $0.6$ | $+2.258570$ | $+2.258570$ |
| $1.5$ | $2.3$ | $+1.677837$ | $+1.677837$ |

(2) 공은 $0\le\rho\le R$, $0\le\phi\le\pi$, $0\le\theta\le2\pi$인 직육면체입니다.

$$\int_{0}^{2\pi}\!\!\int_{0}^{\pi}\!\!\int_{0}^{R}\rho^{2}\sin\phi\,d\rho\,d\phi\,d\theta=2\pi\cdot2\cdot\frac{R^{3}}{3}=\frac{4\pi R^{3}}{3}$$

$\int_{0}^{\pi}\sin\phi\,d\phi=2$입니다. 검산에서 $R=2$일 때 $33.510322$입니다.

(3) 부피 요소에서 $d\rho$를 빼면 넓이 요소입니다.

$$dS=\rho^{2}\sin\phi\,d\phi\,d\theta\quad\Longrightarrow\quad\int_{0}^{2\pi}\!\!\int_{0}^{\pi}\rho^{2}\sin\phi\,d\phi\,d\theta=4\pi\rho^{2}$$

검산에서 $\rho=2$일 때 $50.265482$입니다.

**이 문제에서 배우는 것: 구면좌표.**

> **구면좌표.** $(x,y,z)=(\rho\sin\phi\cos\theta,\ \rho\sin\phi\sin\theta,\ \rho\cos\phi)$이며
> $$dV=\rho^{2}\sin\phi\,d\rho\,d\phi\,d\theta$$
> 입니다.

**두 인자가 각각 뜻을 갖습니다.**

| 인자 | 뜻 |
|---|---|
| $\rho^{2}$ | 반지름이 커지면 구면이 넓어집니다 |
| $\sin\phi$ | 극지방에서 경도선이 모입니다 |

**$\sin\phi$를 지도로 이해**할 수 있습니다. 적도($\phi=\pi/2$)에서는 $\sin\phi=1$이라 경도 $1$도가 가장 긴 거리이고, 극($\phi=0$ 또는 $\pi$)에서는 $\sin\phi=0$이라 모든 경도가 한 점에 모입니다.

$$\text{같은 } d\theta \text{ 가 위도에 따라 다른 넓이를 만듭니다}$$

**104강 심화 3과 맞습니다.** 그때 $S_{2}(\rho)=4\pi\rho^{2}$이라 했고, 여기서 적분으로 확인했습니다.

**표기에 주의**해야 합니다. 물리학과 수학에서 $\phi$와 $\theta$의 역할이 반대인 경우가 있습니다.

| 관습 | $z$축에서 잰 각 | 경도 |
|---|---|---|
| 수학(이 강의) | $\phi$ | $\theta$ |
| 물리 | $\theta$ | $\phi$ |

**어느 쪽이든 야코비는 "$z$축에서 잰 각의 사인"**입니다. 기호가 아니라 뜻으로 기억하면 헷갈리지 않습니다.

**바로 확인 3.**

**확인 3-1.** 구면좌표의 부피 요소를 쓰세요.

*답.* $\rho^{2}\sin\phi\,d\rho\,d\phi\,d\theta$입니다.

**확인 3-2.** $\sin\phi$가 붙는 이유를 쓰세요.

*답.* 극지방에서 경도선이 모여 같은 $d\theta$가 좁은 넓이를 만들기 때문입니다.

**확인 3-3.** 구면의 넓이를 적분으로 구하면 무엇이 나옵니까?

*답.* $4\pi\rho^{2}$입니다.

## 문제 4. 부피 말고 무엇을 잴 수 있는가

> **문제.** 반구 $\rho\le1$, $z\ge0$에 밀도 $\delta(x,y,z)=z$를 줍니다.
> (1) 질량을 구하세요.
> (2) $z$ 모멘트를 구하세요.
> (3) 무게중심의 $z$좌표를 구하세요.

**생각의 실마리.** 103강 문제 5에서 이중적분이 넓이와 평균값과 질량을 잰다고 했습니다. **삼중적분도 같습니다.**

**풀이.** (1) $z=\rho\cos\phi$이고 반구이므로 $0\le\phi\le\pi/2$입니다.

$$M=\int_{0}^{2\pi}\!\!\int_{0}^{\pi/2}\!\!\int_{0}^{1}(\rho\cos\phi)\,\rho^{2}\sin\phi\,d\rho\,d\phi\,d\theta$$

세 적분이 분리됩니다.

$$=2\pi\cdot\left[\frac{\rho^{4}}{4}\right]_{0}^{1}\cdot\int_{0}^{\pi/2}\cos\phi\sin\phi\,d\phi=2\pi\cdot\frac14\cdot\frac12=\frac{\pi}{4}$$

검산에서 $0.7853981634$입니다.

(2) 피적분함수에 $z$를 하나 더 곱합니다.

$$M_{z}=2\pi\cdot\left[\frac{\rho^{5}}{5}\right]_{0}^{1}\cdot\int_{0}^{\pi/2}\cos^{2}\phi\sin\phi\,d\phi=2\pi\cdot\frac15\cdot\frac13=\frac{2\pi}{15}$$

검산에서 $0.4188790205$입니다.

(3) 무게중심은 모멘트를 질량으로 나눈 것입니다.

$$\bar z=\frac{2\pi/15}{\pi/4}=\frac{8}{15}$$

검산에서 $0.5333333333$입니다.

**이 문제에서 배우는 것: 적분이 재는 물리량들.**

| 피적분함수 | 재는 것 |
|---|---|
| $1$ | 부피 |
| $\delta$ | 질량 |
| $z\delta$ | $z$ 모멘트 |
| $(x^{2}+y^{2})\delta$ | $z$축 관성모멘트 |
| $p$ | 확률 |

> **무게중심.** $\displaystyle\bar z=\frac{1}{M}\iiint_{E}z\,\delta\,dV$이며 $x,y$도 같습니다.

**밀도가 균일하면 기하적 중심**이 됩니다. 이 문제에서 밀도가 $z$에 비례하므로 위쪽에 무게가 쏠려 $\bar z$가 커집니다.

**비교해 봅니다.** 균일한 반구의 무게중심은 $\bar z=3/8=0.375$입니다. 여기서는 $8/15\approx0.533$으로 **더 높습니다.** 밀도가 위로 갈수록 커지니 당연합니다.

**분리가 잘 되는 이유**를 짚어 둡니다. 피적분함수가 구면좌표에서 $\rho$만의 함수와 $\phi$만의 함수의 곱으로 갈리고 영역이 직육면체였습니다. **104강 문제 3에서 본 분리의 조건**이 그대로 적용됩니다.

**바로 확인 4.**

**확인 4-1.** 무게중심의 정의를 쓰세요.

*답.* 모멘트를 질량으로 나눈 것입니다.

**확인 4-2.** 밀도가 $1$이면 무게중심은 무엇입니까?

*답.* 기하적 중심입니다.

**확인 4-3.** $z$축 관성모멘트의 피적분함수를 쓰세요.

*답.* $(x^{2}+y^{2})\delta$입니다.

## 문제 5. 좌표를 어떻게 고르는가

> **문제.** 반지름 $1$인 공의 부피를 세 좌표계로 각각 계산하세요.
> (1) 직교좌표
> (2) 원기둥좌표
> (3) 구면좌표

**생각의 실마리.** 같은 답이 나와야 합니다. **어느 쪽이 쉬운지**를 봅니다.

**풀이.** (1) $z$를 바깥에 두면 각 $z$에서 단면이 반지름 $\sqrt{1-z^{2}}$인 원판이므로

$$\int_{-1}^{1}\pi(1-z^{2})\,dz=\pi\left[z-\frac{z^{3}}{3}\right]_{-1}^{1}=\pi\cdot\frac43$$

검산에서 $4.188790$입니다. **단면이 원판임을 이미 알고 써야** 이만큼 간단하며, 정직하게 세 번 적분하면 근호가 두 번 나옵니다.

(2) 원기둥좌표에서 $-\sqrt{1-r^{2}}\le z\le\sqrt{1-r^{2}}$이므로

$$\int_{0}^{2\pi}\!\!\int_{0}^{1}2\sqrt{1-r^{2}}\,r\,dr\,d\theta=2\pi\cdot\frac23=\frac{4\pi}{3}$$

**근호가 한 번 나오지만 $r$ 덕분에 치환이 됩니다.** 검산에서 $4.188790$입니다.

(3) 구면좌표에서 영역이 직육면체이므로

$$2\pi\cdot2\cdot\frac13=\frac{4\pi}{3}$$

**근호가 없고 세 적분이 모두 분리됩니다.** 검산에서 $4.188790$입니다.

**이 문제에서 배우는 것: 대칭이 좌표를 고릅니다.**

## 심화 문제

> **심화 1.** 구면좌표의 야코비를 손으로 유도하세요.

변환이 다음과 같습니다.

$$x=\rho\sin\phi\cos\theta,\quad y=\rho\sin\phi\sin\theta,\quad z=\rho\cos\phi$$

야코비 행렬을 세웁니다. 열이 $\rho,\phi,\theta$에 대한 편미분입니다.

$$J=\begin{pmatrix}
\sin\phi\cos\theta&\rho\cos\phi\cos\theta&-\rho\sin\phi\sin\theta\\
\sin\phi\sin\theta&\rho\cos\phi\sin\theta&\rho\sin\phi\cos\theta\\
\cos\phi&-\rho\sin\phi&0
\end{pmatrix}$$

**셋째 행에 $0$이 있으므로 그 행으로 전개**하면 편합니다.

$$\det J=\cos\phi\cdot M_{31}-(-\rho\sin\phi)\cdot M_{32}$$

여기서 부호까지 포함해 계산하면

$$M_{31}=\det\begin{pmatrix}\rho\cos\phi\cos\theta&-\rho\sin\phi\sin\theta\\\rho\cos\phi\sin\theta&\rho\sin\phi\cos\theta\end{pmatrix}=\rho^{2}\sin\phi\cos\phi$$

$$M_{32}=\det\begin{pmatrix}\sin\phi\cos\theta&-\rho\sin\phi\sin\theta\\\sin\phi\sin\theta&\rho\sin\phi\cos\theta\end{pmatrix}=\rho\sin^{2}\phi$$

여인수의 부호를 붙여 정리하면

$$\det J=\cos\phi\cdot\rho^{2}\sin\phi\cos\phi+\rho\sin\phi\cdot\rho\sin^{2}\phi=\rho^{2}\sin\phi(\cos^{2}\phi+\sin^{2}\phi)=\rho^{2}\sin\phi$$

**$\cos^{2}+\sin^{2}=1$이 마지막에 쓰입니다.** 검산에서 두 점 모두 소수 여섯째 자리까지 일치합니다.

**더 빠른 방법**이 있습니다. 야코비의 세 열이 서로 직교합니다.

| 열 | 방향 | 길이 |
|---|---|---|
| $\partial/\partial\rho$ | 지름 방향 | $1$ |
| $\partial/\partial\phi$ | 위도 방향 | $\rho$ |
| $\partial/\partial\theta$ | 경도 방향 | $\rho\sin\phi$ |

**직교하는 세 벡터가 만드는 직육면체의 부피는 길이의 곱**이므로

$$\lvert\det J\rvert=1\cdot\rho\cdot\rho\sin\phi=\rho^{2}\sin\phi$$

**104강 심화 1에서 극좌표에 쓴 방법과 같습니다.** 직교좌표계에서는 이 방법이 훨씬 빠르며, 각 방향의 척도인자만 곱하면 됩니다.

$$\text{직교곡선좌표에서 } \lvert\det J\rvert = h_{1}h_{2}h_{3}$$

| 좌표계 | $h_{1}h_{2}h_{3}$ |
|---|---|
| 직교 | $1\cdot1\cdot1$ |
| 원기둥 | $1\cdot r\cdot1$ |
| 구면 | $1\cdot\rho\cdot\rho\sin\phi$ |

> **심화 3.** 삼중적분의 순서 선택이 왜 중요한지 예로 보이세요.

문제 5에서 좌표 선택을 봤습니다. **같은 좌표 안에서도 순서가 중요합니다.**

원뿔 $E=\{\sqrt{x^{2}+y^{2}}\le z\le1\}$을 봅니다. 원기둥좌표로 쓰면 두 가지 순서가 있습니다.

**$r$을 먼저 하면** $z$를 고정했을 때 $0\le r\le z$이므로

$$\int_{0}^{2\pi}\!\!\int_{0}^{1}\!\!\int_{0}^{z}r\,dr\,dz\,d\theta=2\pi\int_{0}^{1}\frac{z^{2}}{2}dz=\frac{\pi}{3}$$

**$z$를 먼저 하면** $r$을 고정했을 때 $r\le z\le1$이므로

$$\int_{0}^{2\pi}\!\!\int_{0}^{1}\!\!\int_{r}^{1}r\,dz\,dr\,d\theta=2\pi\int_{0}^{1}r(1-r)\,dr=2\pi\left(\frac12-\frac13\right)=\frac{\pi}{3}$$

**둘 다 쉽고 값이 같습니다.** 이 예에서는 차이가 없습니다.

**차이가 큰 경우**를 봅니다. 밀도가 $\delta=e^{z^{3}}$이라면 어떨까요. $z$를 먼저 적분하면 $\int e^{z^{3}}dz$가 나와 막힙니다. $r$을 먼저 하면

$$2\pi\int_{0}^{1}e^{z^{3}}\frac{z^{2}}{2}dz=\pi\int_{0}^{1}z^{2}e^{z^{3}}dz=\frac{\pi(e-1)}{3}$$

**$z^{2}$이 생겨 치환이 됩니다.** 103강 문제 3에서 본 현상과 같습니다.

$$\text{안쪽 적분이 바깥에 필요한 인자를 만들어 줍니다}$$

**순서 선택의 요령**을 정리합니다.

| 상황 | 대응 |
|---|---|
| 어떤 변수의 부정적분이 없습니다 | 그 변수를 바깥으로 |
| 영역이 한 변수로 단순합니다 | 그 변수를 바깥으로 |
| 안쪽 적분이 인자를 만들어 줍니다 | 그 순서를 씁니다 |

**세 변수면 $6$가지를 다 따져 볼 수도 있지만**, 대개 영역의 모양이 한두 가지로 좁혀 줍니다.

> **심화 4.** 삼중적분이 확률에서 어떻게 쓰이는지 예고하세요.

103강 심화 5에서 이중적분과 확률의 대응을 봤습니다. **삼중적분도 같습니다.**

$$P\bigl((X,Y,Z)\in A\bigr)=\iiint_{A}p(x,y,z)\,dV$$

**변수가 셋인 결합분포**이며, 실제로는 훨씬 많은 변수를 다룹니다.

| 이 강의 | S6에서 |
|---|---|
| 부피 | 사건의 확률 |
| 밀도 $\delta$ | 확률밀도 $p$ |
| 질량 $M$ | 전체 확률 $1$ |
| 무게중심 | 기댓값 $\mathbb{E}[\mathbf{X}]$ |
| 관성모멘트 | 분산과 공분산 |

**넷째 줄과 다섯째 줄의 대응이 정확합니다.**

$$\bar z=\frac{1}{M}\iiint z\,\delta\,dV\quad\longleftrightarrow\quad\mathbb{E}[Z]=\iiint z\,p\,dV$$

$$I_{z}=\iiint(x^{2}+y^{2})\,\delta\,dV\quad\longleftrightarrow\quad\operatorname{Var}(X)+\operatorname{Var}(Y)$$

**질량 분포와 확률 분포가 같은 수학**입니다. 그래서 물리의 관성텐서와 통계의 공분산행렬이 같은 형태를 갖습니다.

$$I=\iiint\bigl(\lVert\mathbf{r}\rVert^{2}I-\mathbf{r}\mathbf{r}^{\top}\bigr)\delta\,dV\quad\text{vs}\quad\Sigma=\int(\mathbf{x}-\boldsymbol{\mu})(\mathbf{x}-\boldsymbol{\mu})^{\top}p\,d\mathbf{x}$$

**둘 다 대칭행렬이고 고유벡터가 주축**입니다. 86강의 스펙트럼 정리가 양쪽에 적용되며, 물리에서는 주관성축이고 통계에서는 주성분입니다. **89강의 주성분분석과 강체의 관성주축이 같은 계산**입니다.

$$\text{같은 대수적 대상이 분야마다 다른 이름을 가집니다}$$

**140강의 다변량 정규분포**에서 이 대응이 완성됩니다. 밀도의 등고선이 타원체이고 그 축이 $\Sigma$의 고유벡터이며, 105강의 변수변환으로 정규화 상수가 $(2\pi)^{n/2}\sqrt{\det\Sigma}$가 됩니다.

> **심화 5.** 곡면 위의 적분을 예고하세요.

이 강의에서 **부피**를 쟀습니다. 문제 3에서 구면의 넓이도 구했는데, 그것은 부피 요소에서 $d\rho$를 뺀 편법이었습니다.

**곡면 위의 적분을 제대로 세우려면** 곡면의 넓이 요소가 필요합니다.

곡면을 $\mathbf{r}(u,v)$로 매개화하면 접벡터 두 개가 나옵니다.

$$\mathbf{r}_{u}=\frac{\partial\mathbf{r}}{\partial u},\qquad\mathbf{r}_{v}=\frac{\partial\mathbf{r}}{\partial v}$$

**두 벡터가 만드는 평행사변형의 넓이**가 넓이 요소이고, 65강의 외적이 그것을 줍니다.

$$dS=\lVert\mathbf{r}_{u}\times\mathbf{r}_{v}\rVert\,du\,dv$$

**구면에서 확인합니다.** $\mathbf{r}(\phi,\theta)=\rho(\sin\phi\cos\theta,\sin\phi\sin\theta,\cos\phi)$이면 심화 1의 계산에서

$$\lVert\mathbf{r}_{\phi}\rVert=\rho,\qquad\lVert\mathbf{r}_{\theta}\rVert=\rho\sin\phi$$

이고 두 벡터가 직교하므로

$$dS=\rho^{2}\sin\phi\,d\phi\,d\theta$$

**문제 3에서 쓴 것과 같습니다.** 편법이 아니라 정당한 결과였습니다.

**이 방향의 확장**을 적어 둡니다.

| 대상 | 넓이 요소 | 쓰는 도구 |
|---|---|---|
| 곡선 | $\lVert\boldsymbol{\gamma}'\rVert\,dt$ | 노름 |
| 곡면 | $\lVert\mathbf{r}_{u}\times\mathbf{r}_{v}\rVert\,du\,dv$ | 외적 |
| 입체 | $\lvert\det J\rvert\,du\,dv\,dw$ | 행렬식 |

**셋이 같은 것의 차원별 판**입니다. 일반적으로는 $\sqrt{\det(J^{\top}J)}$이며, $J$가 정방행렬이면 $\lvert\det J\rvert$가 됩니다.

$$\sqrt{\det(J^{\top}J)}$$

**82강의 정규방정식에 나온 $A^{\top}A$**가 여기서 다시 나타납니다. 직사각 행렬로 부피를 재는 일반적인 방법이며, 그람 행렬식이라 부릅니다.

이 방향을 끝까지 밀면 벡터장의 선적분과 면적분, 그린 정리와 스토크스 정리, 발산 정리가 나옵니다. **이 과목에서는 다루지 않지만** 398강의 부피 렌더링 방정식과 402강의 미분 가능 래스터화에서 곡면 적분을 씁니다.

import numpy as np

# --- 문제 1: 삼중적분과 부피 --------------------------------------------
print("  사면체 x,y,z>=0, x+y+z<=1 의 부피")
print("  = int_0^1 int_0^{1-x} int_0^{1-x-y} dz dy dx = int_0^1 (1-x)^2/2 dx = 1/6")
print("   = %.10f" % (1/6))
N = 700
g = (np.arange(N) + 0.5)/N
X, Y, Z = np.meshgrid(g, g, g, indexing='ij')
print("  수치(격자 %d^3) %.8f  오차 %.3e" % (N, ((X+Y+Z) <= 1).mean(), abs(((X+Y+Z) <= 1).mean() - 1/6)))
print("  n 차원 단체의 부피는 1/n! 입니다: 1/3! = %.10f" % (1/6))
#   사면체 x,y,z>=0, x+y+z<=1 의 부피
#   = int_0^1 int_0^{1-x} int_0^{1-x-y} dz dy dx = int_0^1 (1-x)^2/2 dx = 1/6

# --- 문제 2: 원기둥좌표 --------------------------------------------------
print("  원기둥좌표 (r cos th, r sin th, z),  |det J| = r")
Jc = lambda r, th: np.array([[np.cos(th), -r*np.sin(th), 0.0],
                             [np.sin(th),  r*np.cos(th), 0.0],
                             [0.0,          0.0,         1.0]])
for r, th in [(2.0, 0.7), (3.0, 2.1)]:
    print("   r=%.1f th=%.1f  det = %.6f  (= r)" % (r, th, np.linalg.det(Jc(r, th))))
print("  반지름 2, 높이 5 인 원기둥의 부피 = 2pi * [r^2/2]_0^2 * 5 = %.6f" % (np.pi*4*5))
print("  포물면 z = x^2+y^2 아래, z <= 4 인 부피")
print("  = int_0^{2pi} int_0^2 (4 - r^2) r dr dth = 2pi*[2r^2 - r^4/4]_0^2 = %.6f" % (2*np.pi*(8-4)))
#   원기둥좌표 (r cos th, r sin th, z),  |det J| = r
#    r=2.0 th=0.7  det = 2.000000  (= r)
#    r=3.0 th=2.1  det = 3.000000  (= r)
#   반지름 2, 높이 5 인 원기둥의 부피 = 2pi * [r^2/2]_0^2 * 5 = 62.831853
#   포물면 z = x^2+y^2 아래, z <= 4 인 부피
#   = int_0^{2pi} int_0^2 (4 - r^2) r dr dth = 2pi*[2r^2 - r^4/4]_0^2 = 25.132741

# --- 문제 3: 구면좌표 ----------------------------------------------------
def Js(rho, ph, th):
    return np.array([
      [np.sin(ph)*np.cos(th),  rho*np.cos(ph)*np.cos(th), -rho*np.sin(ph)*np.sin(th)],
      [np.sin(ph)*np.sin(th),  rho*np.cos(ph)*np.sin(th),  rho*np.sin(ph)*np.cos(th)],
      [np.cos(ph),            -rho*np.sin(ph),             0.0]])
print("  구면좌표 |det J| = rho^2 sin(phi)")
for rho, ph, th in [(2.0, 0.6, 1.0), (1.5, 2.3, 0.4)]:
    print("   rho=%.1f phi=%.1f  det = %+.6f   rho^2 sin phi = %+.6f"
          % (rho, ph, np.linalg.det(Js(rho, ph, th)), rho**2*np.sin(ph)))
print("  반지름 R 인 공의 부피 = int_0^{2pi} int_0^{pi} int_0^R rho^2 sin ph drho dph dth")

#   구면좌표 |det J| = rho^2 sin(phi)
#    rho=2.0 phi=0.6  det = +2.258570   rho^2 sin phi = +2.258570

#   반지름 R 인 공의 부피 = int_0^{2pi} int_0^{pi} int_0^R rho^2 sin ph drho dph dth
#    = 2pi * 2 * R^3/3 = 4 pi R^3 / 3.  R=2 이면 33.510322
#   구면의 넓이: int_0^{2pi} int_0^{pi} rho^2 sin ph dph dth = 4 pi rho^2
#    rho=2 이면 50.265482

# --- 문제 4: 질량과 무게중심 --------------------------------------------
print("  반구 rho <= 1, z >= 0 에 밀도 rho(x,y,z) = z 를 줍니다")
print("  질량 = int int int (rho cos ph) rho^2 sin ph drho dph dth")
print("   = 2pi * [rho^4/4]_0^1 * int_0^{pi/2} cos ph sin ph dph = 2pi*(1/4)*(1/2) = %.10f" % (np.pi/4))
print("  z 모멘트 = 2pi * [rho^5/5]_0^1 * int_0^{pi/2} cos^2 ph sin ph dph = 2pi*(1/5)*(1/3) = %.10f" % (2*np.pi/15))
print("  무게중심 z = (2pi/15)/(pi/4) = %.10f" % ((2*np.pi/15)/(np.pi/4)))
#   반구 rho <= 1, z >= 0 에 밀도 rho(x,y,z) = z 를 줍니다
#   질량 = int int int (rho cos ph) rho^2 sin ph drho dph dth
#    = 2pi * [rho^4/4]_0^1 * int_0^{pi/2} cos ph sin ph dph = 2pi*(1/4)*(1/2) = 0.7853981634
#   z 모멘트 = 2pi * [rho^5/5]_0^1 * int_0^{pi/2} cos^2 ph sin ph dph = 2pi*(1/5)*(1/3) = 0.4188790205
#   무게중심 z = (2pi/15)/(pi/4) = 0.5333333333
# 균일한 반구는 3/8 = 0.375 인데 밀도가 z 이라 위로 쏠려 8/15 가 됩니다.

# --- 문제 5: 좌표 선택 ---------------------------------------------------
print("  같은 부피를 세 좌표로 계산: 반지름 1 인 공")

print("   원기둥: int_0^{2pi} int_0^1 2 sqrt(1-r^2) r dr dth = 2pi*(2/3) = %.6f" % (2*np.pi*2/3))

#   같은 부피를 세 좌표로 계산: 반지름 1 인 공
#    직교: int_{-1}^{1} pi(1-z^2) dz = pi[z - z^3/3] = 4.188790
#    원기둥: int_0^{2pi} int_0^1 2 sqrt(1-r^2) r dr dth = 2pi*(2/3) = 4.188790
#    구면: 2pi * 2 * 1/3 = 4.188790
# 세 좌표가 같은 값을 냅니다. 구면좌표만 근호 없이 완전히 분리됩니다.
