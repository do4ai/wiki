# 118강. 선형 미분방정식과 안정성

117강은 **한 개의 방정식**을 다뤘습니다. 이제 여러 개로 넓힙니다.

$$\frac{d\mathbf{x}}{dt}=A\mathbf{x}$$

**여기서 S4가 통째로 도구가 됩니다.** 해가 이렇게 생겼기 때문입니다.

$$\mathbf{x}(t)=e^{At}\mathbf{x}_{0}$$

행렬의 지수함수를 어떻게 다룰지가 문제인데, **86강의 대각화**가 답을 줍니다. $A=V\Lambda V^{-1}$이면

$$\mathbf{x}(t)=\sum_{i}c_{i}e^{\lambda_{i}t}\mathbf{v}_{i}$$

**각 고유방향이 자기 속도로 움직입니다.** 109강 문제 1에서 이산 점화식을 성분별로 분해한 것과 정확히 같은 구조입니다.

| 강의 | 대상 | 성분별 인자 |
|---|---|---|
| 109 | $(I-\eta H)^{k}$ | $(1-\eta\lambda_{i})^{k}$ |
| 118 | $e^{At}$ | $e^{\lambda_{i}t}$ |

**새로 나타나는 것이 하나 있습니다.** 실수 행렬이어도 고유값이 복소수일 수 있고, 그러면 **진동**이 생깁니다. 117강 심화 1에서 1차원 자율계는 진동할 수 없다고 했는데, 2차원부터 가능해집니다.

## 이 강의에서 할 수 있게 되는 것
- 선형계의 해를 $e^{At}\mathbf{x}_{0}$로 쓸 수 있습니다.
- 대각화로 성분별 분해를 할 수 있습니다.
- 고유값의 실수부로 안정성을 판정할 수 있습니다.
- 복소 고유값이 만드는 진동을 설명할 수 있습니다.
- 경사흐름의 안정성이 임계점 분류와 같음을 압니다.

## 문제 1. 여러 개의 방정식을 어떻게 푸는가

> **문제.** $\dfrac{d\mathbf{x}}{dt}=A\mathbf{x}$를 $A=\operatorname{diag}(-1,-3)$, $\mathbf{x}_{0}=(2,1)$에서 봅니다.
> (1) 성분별로 풀어 해석해를 구하세요.
> (2) $e^{At}\mathbf{x}_{0}$를 계산해 비교하세요.
> (3) 두 성분의 감쇠 속도를 비교하세요.

**생각의 실마리.** $A$가 대각이면 **두 방정식이 서로 간섭하지 않습니다.** 각각 117강의 문제입니다.

**풀이.** (1) 성분별로

$$\dot x_{1}=-x_{1},\qquad\dot x_{2}=-3x_{2}$$

이므로 $x_{1}=2e^{-t}$, $x_{2}=e^{-3t}$입니다.

(2) 검산에서

| $t$ | 해석해 | $e^{At}\mathbf{x}_{0}$ |
|---|---|---|
| $0.0$ | $[2,1]$ | $[2,1]$ |
| $0.5$ | $[1.213061,0.223130]$ | $[1.213061,0.223130]$ |
| $1.0$ | $[0.735759,0.049787]$ | $[0.735759,0.049787]$ |
| $2.0$ | $[0.270671,0.002479]$ | $[0.270671,0.002479]$ |

(3) **둘째 성분이 훨씬 빨리 죽습니다.** $t=2$에서 첫 성분은 $0.27$인데 둘째는 $0.0025$입니다.

**이 문제에서 배우는 것: 행렬 지수함수.**

> **행렬 지수함수.**
> $$e^{At}=\sum_{k=0}^{\infty}\frac{(At)^{k}}{k!}=I+At+\frac{A^{2}t^{2}}{2}+\cdots$$

**54강의 지수 급수를 행렬로 옮긴 것**이며, 모든 행렬에 대해 수렴합니다. 90강의 준곱셈성으로

$$\left\lVert\frac{(At)^{k}}{k!}\right\rVert\le\frac{\lVert A\rVert^{k}t^{k}}{k!}$$

이고 오른쪽이 수렴하는 급수라 절대수렴합니다.

> **해의 공식.** $\dot{\mathbf{x}}=A\mathbf{x}$, $\mathbf{x}(0)=\mathbf{x}_{0}$의 해는 $\mathbf{x}(t)=e^{At}\mathbf{x}_{0}$이며 유일합니다.

**확인이 급수 미분으로 됩니다.**

$$\frac{d}{dt}e^{At}=A+A^{2}t+\frac{A^{3}t^{2}}{2}+\cdots=Ae^{At}$$

**대각행렬이면 계산이 쉽습니다.**

$$A=\operatorname{diag}(\lambda_{1},\dots,\lambda_{n})\quad\Longrightarrow\quad e^{At}=\operatorname{diag}(e^{\lambda_{1}t},\dots,e^{\lambda_{n}t})$$

**대각이 아니면 대각화**합니다. 문제 2에서 다룹니다.

**주의할 점이 하나 있습니다.** 일반적으로

$$e^{A+B}\ne e^{A}e^{B}$$

이며 **$AB=BA$일 때만** 성립합니다. 66강에서 행렬 곱이 교환법칙을 어긴다고 한 것이 여기서 나타납니다.

**바로 확인 1.**

**확인 1-1.** 선형계의 해를 쓰세요.

*답.* $\mathbf{x}(t)=e^{At}\mathbf{x}_{0}$입니다.

**확인 1-2.** 대각행렬의 지수함수를 쓰세요.

*답.* 대각 성분을 각각 지수화한 것입니다.

**확인 1-3.** $e^{A+B}=e^{A}e^{B}$는 언제 성립합니까?

*답.* $AB=BA$일 때입니다.

## 문제 2. 대각이 아니면 어떻게 하는가

> **문제.** $B=\begin{pmatrix}0&1\\-2&-3\end{pmatrix}$과 $\mathbf{x}_{0}=(1,0)$을 봅니다.
> (1) 고유값과 고유벡터를 구하세요.
> (2) $\mathbf{x}_{0}$을 고유기저로 표현하세요.
> (3) 각 성분의 기여를 더해 해와 비교하세요.

**생각의 실마리.** 86강에서 대각화하면 좌표가 분리된다고 했습니다. **고유기저로 옮기면 문제 1이 됩니다.**

**풀이.** (1) 검산에서 고유값이 $-1$과 $-2$이고 고유벡터가

$$\mathbf{v}_{1}=(0.707107,-0.707107),\qquad\mathbf{v}_{2}=(-0.447214,0.894427)$$

(2) $\mathbf{x}_{0}=c_{1}\mathbf{v}_{1}+c_{2}\mathbf{v}_{2}$를 풀면 검산에서

$$\mathbf{c}=(2.828427,\ 2.236068)$$

(3) 검산에서

| $t$ | $c_{1}e^{\lambda_{1}t}\mathbf{v}_{1}$ | $c_{2}e^{\lambda_{2}t}\mathbf{v}_{2}$ | 합 | 직접 $e^{Bt}\mathbf{x}_{0}$ |
|---|---|---|---|---|
| $0.0$ | $[2,-2]$ | $[-1,2]$ | $[1,0]$ | $[1,0]$ |
| $0.5$ | $[1.2131,-1.2131]$ | $[-0.3679,0.7358]$ | $[0.845182,-0.477302]$ | $[0.845182,-0.477302]$ |
| $1.0$ | $[0.7358,-0.7358]$ | $[-0.1353,0.2707]$ | $[0.600424,-0.465088]$ | $[0.600424,-0.465088]$ |
| $2.0$ | $[0.2707,-0.2707]$ | $[-0.0183,0.0366]$ | $[0.252355,-0.234039]$ | $[0.252355,-0.234039]$ |

**두 성분의 합이 정확히 해입니다.**

**이 문제에서 배우는 것: 고유기저 분해.**

> **분해 정리.** $A$가 대각화 가능하면
> $$\mathbf{x}(t)=\sum_{i}c_{i}e^{\lambda_{i}t}\mathbf{v}_{i},\qquad\mathbf{x}_{0}=\sum_{i}c_{i}\mathbf{v}_{i}$$
> 입니다.

**절차가 세 단계**입니다.

| 단계 | 하는 일 |
|---|---|
| $1$ | 고유값과 고유벡터를 구합니다 |
| $2$ | 초기조건을 고유기저 좌표로 바꿉니다 |
| $3$ | 각 좌표에 $e^{\lambda_{i}t}$를 곱하고 되돌립니다 |

**75강의 기저 변환**이 그대로 쓰입니다. 고유기저에서 문제가 대각이 되고, 풀고 나서 원래 좌표로 되돌립니다.

$$\mathbf{x}=V\mathbf{y}\quad\Longrightarrow\quad\dot{\mathbf{y}}=\Lambda\mathbf{y}$$

$$\text{좌표를 바꿔 문제를 분리합니다}$$

**이 예의 방정식이 어디서 왔는지**도 볼 만합니다. $\ddot u+3\dot u+2u=0$을 $x_{1}=u$, $x_{2}=\dot u$로 두면 이 $B$가 나옵니다.

$$\text{고차 방정식을 1계 계로 바꿉니다}$$

**특성방정식이 고유값 방정식**입니다. $\lambda^{2}+3\lambda+2=0$의 근이 $-1,-2$이며 검산과 맞습니다. 32강의 선형 점화식과 111강 심화 1의 모멘텀 해석이 같은 구조입니다.

**대각화가 안 되면** 조르당 형이 필요하고 해에 $te^{\lambda t}$ 같은 항이 나타납니다. 85강에서 본 결손 행렬의 경우이며, 이 과목에서는 다루지 않습니다.

**바로 확인 2.**

**확인 2-1.** 대각화 가능할 때 해의 형태를 쓰세요.

*답.* $\sum c_{i}e^{\lambda_{i}t}\mathbf{v}_{i}$입니다.

**확인 2-2.** $\ddot u+3\dot u+2u=0$을 1계 계로 바꾸는 방법을 쓰세요.

*답.* $x_{1}=u$, $x_{2}=\dot u$로 두면 됩니다.

**확인 2-3.** 특성방정식과 고유값의 관계를 쓰세요.

*답.* 같은 것이며 특성방정식의 근이 고유값입니다.

## 문제 3. 안정성을 어떻게 판정하는가

> **문제.** 다섯 행렬의 고유값을 구하고 안정성을 판정하세요.
> (1) $\operatorname{diag}(-1,-3)$, $\operatorname{diag}(-1,2)$
> (2) $\begin{pmatrix}0&1\\-1&0\end{pmatrix}$, $\begin{pmatrix}-0.2&1\\-1&-0.2\end{pmatrix}$
> (3) $\begin{pmatrix}0&1\\-2&-3\end{pmatrix}$

**생각의 실마리.** 문제 2의 분해에서 각 성분이 $e^{\lambda_{i}t}$입니다. **$\lambda$가 복소수여도 크기는 $e^{\operatorname{Re}\lambda\cdot t}$**입니다.

**풀이.** 검산에서

| 행렬 | 고유값 | 실수부 최대 | 판정 |
|---|---|---|---|
| $\operatorname{diag}(-1,-3)$ | $[-1,-3]$ | $-1.0000$ | 안정 |
| $\operatorname{diag}(-1,2)$ | $[-1,2]$ | $+2.0000$ | 불안정 |
| $[[0,1],[-1,0]]$ | $[i,-i]$ | $+0.0000$ | 경계(중립) |
| $[[-0.2,1],[-1,-0.2]]$ | $[-0.2\pm i]$ | $-0.2000$ | 안정 |
| $[[0,1],[-2,-3]]$ | $[-1,-2]$ | $-1.0000$ | 안정 |

**이 문제에서 배우는 것: 실수부가 안정성을 정합니다.**

> **안정성 판정.** $\dot{\mathbf{x}}=A\mathbf{x}$의 원점이
>
> | 조건 | 판정 |
> |---|---|
> | 모든 $\operatorname{Re}\lambda_{i}<0$ | 점근안정 |
> | 어떤 $\operatorname{Re}\lambda_{i}>0$ | 불안정 |
> | 최대가 $0$ | 경계, 추가 분석 필요 |

**$\lvert e^{\lambda t}\rvert=e^{\operatorname{Re}\lambda\cdot t}$**이기 때문입니다. 허수부는 진동을 만들 뿐 크기에 영향을 주지 않습니다.

$$e^{(\alpha+i\beta)t}=e^{\alpha t}\bigl(\cos\beta t+i\sin\beta t\bigr)$$

**117강 문제 3의 1차원 조건 $F'<0$의 일반화**입니다.

**셋째 줄의 경계 경우**를 봅니다. 고유값이 순허수이면 크기가 유지되며, 해가 원 위를 돕니다. **감쇠도 발산도 하지 않습니다.**

| 물리 | 예 |
|---|---|
| 마찰 없는 진자 | 영원히 진동 |
| 무손실 LC 회로 | 에너지 보존 |
| 해밀턴 계 | 위상공간 부피 보존 |

**비선형 계에서는 이 경우가 위험**합니다. 선형화가 판정을 주지 못하고 고차 항이 결정하며, 101강의 준정치 상황과 같습니다.

**$2\times2$에서 대각합과 행렬식으로 판정**할 수 있습니다. 84강에서

$$\lambda_{1}+\lambda_{2}=\operatorname{tr}A,\qquad\lambda_{1}\lambda_{2}=\det A$$

이므로

| 조건 | 판정 |
|---|---|
| $\operatorname{tr}A<0$이고 $\det A>0$ | 안정 |
| $\det A<0$ | 안장, 불안정 |
| $\operatorname{tr}A>0$이고 $\det A>0$ | 불안정 |

**101강의 이변수 판정법과 형태가 같습니다.** 그때도 $\det$와 대각합으로 갈랐습니다.

**바로 확인 3.**

**확인 3-1.** 안정성 판정 조건을 쓰세요.

*답.* 모든 고유값의 실수부가 음수면 점근안정입니다.

**확인 3-2.** 허수부는 무엇을 정합니까?

*답.* 진동수를 정하며 크기에는 영향이 없습니다.

**확인 3-3.** $2\times2$에서 대각합과 행렬식으로 판정하세요.

*답.* $\operatorname{tr}A<0$이고 $\det A>0$이면 안정입니다.

## 문제 4. 복소 고유값은 무엇을 만드는가

> **문제.** $C=\begin{pmatrix}-0.2&1\\-1&-0.2\end{pmatrix}$와 $\mathbf{x}_{0}=(1,0)$을 봅니다.
> (1) 고유값의 실수부와 허수부를 구하세요.
> (2) 여러 $t$에서 $\mathbf{x}(t)$와 그 크기를 구하세요.
> (3) 크기의 거동을 설명하세요.

**생각의 실마리.** 실수부가 음수이니 줄어들 텐데, **허수부가 있으면 어떻게 줄어드는지**가 문제입니다.

**풀이.** (1) 검산에서 고유값이 $-0.2\pm i$이므로 실수부가 $-0.2$이고 허수부가 $1$입니다.

(2) 검산에서

| $t$ | $\mathbf{x}(t)$ | $\lVert\mathbf{x}(t)\rVert$ | $e^{-0.2t}$ |
|---|---|---|---|
| $0.0$ | $[1,0]$ | $1.000000$ | $1.000000$ |
| $1.5$ | $[0.0524,-0.7390]$ | $0.740818$ | $0.740818$ |
| $3.0$ | $[-0.5433,-0.0774]$ | $0.548812$ | $0.548812$ |
| $6.0$ | $[0.2892,0.0842]$ | $0.301194$ | $0.301194$ |
| $12.0$ | $[0.0766,0.0487]$ | $0.090718$ | $0.090718$ |

**크기가 정확히 $e^{-0.2t}$입니다.**

(3) **크기는 지수적으로 줄고 방향은 계속 돕니다.** 나선을 그리며 원점으로 감깁니다.

**이 문제에서 배우는 것: 복소 고유값과 진동.**

$$\lambda=\alpha\pm i\beta\quad\Longrightarrow\quad\mathbf{x}(t)=e^{\alpha t}\bigl(\mathbf{a}\cos\beta t+\mathbf{b}\sin\beta t\bigr)$$

**실수부가 봉투이고 허수부가 진동수**입니다.

| 부분 | 역할 |
|---|---|
| $e^{\alpha t}$ | 크기의 증감 |
| $\cos\beta t,\sin\beta t$ | 회전 |

**실수 행렬인데 고유값이 복소수**인 것이 처음에는 이상해 보입니다. 그러나 해는 실수이며, 켤레쌍이 짝을 이뤄 허수부가 상쇄됩니다.

$$e^{\lambda t}\mathbf{v}+e^{\bar\lambda t}\bar{\mathbf{v}}\ \text{는 실벡터}$$

**상평면의 분류**가 고유값에 따라 정해집니다.

| 고유값 | 이름 | 그림 |
|---|---|---|
| 실수, 둘 다 음수 | 안정 마디 | 곧장 모입니다 |
| 실수, 둘 다 양수 | 불안정 마디 | 곧장 퍼집니다 |
| 실수, 부호 다름 | 안장 | 한 방향 모이고 한 방향 퍼집니다 |
| 복소, 실수부 음수 | 안정 나선 | 감기며 모입니다 |
| 복소, 실수부 양수 | 불안정 나선 | 풀리며 퍼집니다 |
| 순허수 | 중심 | 닫힌 궤도 |

**셋째 줄이 101강의 안장**과 같은 이름인 것이 우연이 아닙니다. 문제 5에서 확인합니다.

**111강 심화 1과 정확히 대응**합니다. 그때 모멘텀의 특성방정식이 복소근을 가지면 수렴률이 $\sqrt\beta$로 균일해진다고 했는데, 여기서는 그것이 **감쇠 나선**입니다.

$$\text{진동을 대가로 균일한 감쇠를 얻습니다}$$

**감쇠 진동의 분류**도 정리합니다. $\ddot u+2\zeta\omega\dot u+\omega^{2}u=0$에서

| $\zeta$ | 이름 | 고유값 |
|---|---|---|
| $<1$ | 과소감쇠 | 복소 |
| $=1$ | 임계감쇠 | 중근 |
| $>1$ | 과대감쇠 | 실수 |

**임계감쇠가 가장 빠르게 정지**하며, 111강 심화 4에서 최적 모멘텀이 이 조건이라 한 것과 같습니다.

**바로 확인 4.**

**확인 4-1.** 복소 고유값의 실수부와 허수부가 각각 무엇을 정합니까?

*답.* 실수부가 크기의 증감을, 허수부가 진동수를 정합니다.

**확인 4-2.** 실수부가 음수인 복소 고유값의 상평면 이름을 쓰세요.

*답.* 안정 나선입니다.

**확인 4-3.** 순허수이면 어떤 궤도입니까?

*답.* 닫힌 궤도이며 중심이라 부릅니다.

## 문제 5. 경사흐름은 어떤 계인가

> **문제.** $f=\tfrac12(x^{2}+100y^{2})$의 경사흐름 $\dot{\mathbf{x}}=-\nabla f$를 봅니다.
> (1) 계수행렬과 그 고유값을 구하세요.
> (2) 해의 거동을 보세요.
> (3) 안장인 경우와 비교하세요.

**생각의 실마리.** $\nabla f=H\mathbf{x}$이므로 $\dot{\mathbf{x}}=-H\mathbf{x}$입니다. **계수행렬이 $-H$**입니다.

> **심화 1.** 행렬 지수함수의 성질을 정리하세요.

급수 정의에서 여러 성질이 나옵니다.

| 성질 | 조건 |
|---|---|
| $e^{A\cdot0}=I$ | 언제나 |
| $\dfrac{d}{dt}e^{At}=Ae^{At}=e^{At}A$ | 언제나 |
| $(e^{A})^{-1}=e^{-A}$ | 언제나 |
| $e^{A+B}=e^{A}e^{B}$ | $AB=BA$일 때 |
| $e^{PAP^{-1}}=Pe^{A}P^{-1}$ | 언제나 |
| $\det e^{A}=e^{\operatorname{tr}A}$ | 언제나 |

**셋째 줄이 중요합니다.** $e^{A}$는 언제나 가역이며, 이는 **해가 시간을 거슬러 올라갈 수 있다**는 뜻입니다.

$$\mathbf{x}_{0}=e^{-At}\mathbf{x}(t)$$

**궤적이 교차하지 않는 근거**이며, 117강 심화 1에서 언급한 성질의 일반화입니다.

**다섯째 줄이 대각화의 근거**입니다. $A=V\Lambda V^{-1}$이면

$$e^{At}=Ve^{\Lambda t}V^{-1}$$

이고 $e^{\Lambda t}$가 대각이라 계산됩니다.

**여섯째 줄은 야코비 공식**이며 79강과 이어집니다. $\det e^{At}=e^{t\operatorname{tr}A}$이므로

| $\operatorname{tr}A$ | 위상공간 부피 |
|---|---|
| 음수 | 줄어듭니다 |
| $0$ | 보존됩니다 |
| 양수 | 늘어납니다 |

**둘째 줄이 해밀턴 계**입니다. 부피가 보존되며 리우빌 정리라 부릅니다.

**경사흐름에서는 $\operatorname{tr}(-H)=-\Delta f$**입니다. 99강 심화 3의 라플라시안이 여기서 **부피 수축률**로 나타납니다.

$$\text{골짜기에서는 부피가 줄고 봉우리에서는 늡니다}$$

**계산 방법**도 여럿 있습니다.

| 방법 | 조건 |
|---|---|
| 대각화 | 대각화 가능할 때 |
| 조르당 형 | 언제나, 복잡함 |
| 급수 절단 | 작은 $\lVert At\rVert$ |
| 스케일링과 제곱 | 실무 표준 |

**넷째 줄이 표준 알고리즘**입니다. $e^{A}=(e^{A/2^{k}})^{2^{k}}$를 이용해 지수를 작게 만든 뒤 제곱을 반복하며, 92강의 수치 안정성 고려가 들어갑니다.

> **심화 2.** 비선형 계의 선형화 정리를 소개하세요.

실제 계는 대개 비선형입니다.

$$\dot{\mathbf{x}}=\mathbf{F}(\mathbf{x})$$

평형점 $\mathbf{x}^{*}$에서 $\mathbf{F}(\mathbf{x}^{*})=\mathbf{0}$이고, 95강의 선형근사를 쓰면

$$\dot{\boldsymbol{\varepsilon}}\approx J_{\mathbf{F}}(\mathbf{x}^{*})\,\boldsymbol{\varepsilon}$$

**98강의 야코비가 계수행렬**입니다.

> **하르트만-그로브만 정리.** 평형점에서 야코비의 고유값이 모두 실수부가 $0$이 아니면(쌍곡적), 그 근방에서 비선형 계의 궤적이 선형화 계의 궤적과 위상적으로 같습니다.

**"쌍곡적"이 조건**이며, 실수부가 $0$인 고유값이 있으면 정리가 적용되지 않습니다.

$$\text{선형화가 국소 그림을 정확히 그립니다}$$

| 야코비 | 비선형 계의 국소 거동 |
|---|---|
| 모든 $\operatorname{Re}\lambda<0$ | 점근안정 |
| 어떤 $\operatorname{Re}\lambda>0$ | 불안정 |
| 실수부 $0$ 존재 | 판정 불가 |

**셋째 줄에서 고차 항이 결정**합니다. 117강 심화 1의 반안정 평형점과 101강의 준정치 상황이 같은 자리입니다.

**예를 봅니다.** $\dot x=y$, $\dot y=-x+\mu(1-x^{2})y$인 반데르폴 방정식에서 원점의 야코비가

$$J=\begin{pmatrix}0&1\\-1&\mu\end{pmatrix}$$

이고 고유값이 $\bigl(\mu\pm\sqrt{\mu^{2}-4}\bigr)/2$입니다.

| $\mu$ | 원점 | 전역 거동 |
|---|---|---|
| $<0$ | 안정 | 원점으로 |
| $>0$ | 불안정 | 극한주기로 |

**$\mu>0$에서 극한주기**가 나타납니다. 원점에서 밀려나지만 무한히 커지지도 않고, 닫힌 궤도로 수렴합니다.

$$\text{선형계에는 없는 현상입니다}$$

선형계의 닫힌 궤도는 중심 주변에 연속체로 있는데, 극한주기는 **고립된 하나**이며 주변 궤도가 그것으로 모입니다. 비선형성이 만드는 구조입니다.

> **심화 3.** 리아푸노프 방법을 소개하세요.

선형화가 판정을 주지 못할 때 쓰는 방법입니다.

> **리아푸노프 정리.** 평형점 $\mathbf{x}^{*}$의 근방에서 $V(\mathbf{x}^{*})=0$이고 $V>0$($\mathbf{x}\ne\mathbf{x}^{*}$)이며 $\dot V\le0$인 함수 $V$가 있으면 $\mathbf{x}^{*}$가 안정합니다. $\dot V<0$이면 점근안정입니다.

**"에너지가 줄어들면 안정하다"**는 물리적 직관의 수학적 형태입니다.

$$\dot V=\nabla V\cdot\mathbf{F}(\mathbf{x})$$

**97강의 연쇄법칙 한 줄**로 계산됩니다.

**경사흐름에서 $V=f-f(\mathbf{x}^{*})$**를 잡으면

$$\dot V=\nabla f\cdot(-\nabla f)=-\lVert\nabla f\rVert^{2}\le0$$

**자동으로 만족**합니다. 문제 5에서 본 그대로이며, 퍼텐셜이 있는 계의 큰 이점입니다.

**선형계에서는 이차형식을 씁니다.**

$$V=\mathbf{x}^{\top}P\mathbf{x},\qquad P\succ0$$

$$\dot V=\mathbf{x}^{\top}(A^{\top}P+PA)\mathbf{x}$$

**$\dot V<0$이려면** $A^{\top}P+PA\prec0$이어야 하고, 이를 **리아푸노프 방정식**이라 합니다.

$$A^{\top}P+PA=-Q,\qquad Q\succ0$$

> **정리.** $A$가 안정이면 임의의 $Q\succ0$에 대해 이 방정식의 해 $P\succ0$이 유일하게 존재합니다.

**87강의 양정치성 판정**이 여기서 쓰이며, 제어이론의 기본 도구입니다.

**리아푸노프 함수의 값어치**는 선형화 없이도 판정한다는 점입니다.

| 상황 | 선형화 | 리아푸노프 |
|---|---|---|
| 쌍곡적 평형점 | 가능 | 가능 |
| 경계 경우 | 불가 | 가능할 수 있음 |
| 전역 안정성 | 불가 | 가능 |
| 함수 찾기 | 자동 | 어려움 |

**넷째 줄이 대가**입니다. 적절한 $V$를 찾는 일반적 방법이 없고, 문제마다 궁리해야 합니다. 다만 **퍼텐셜이 있으면 그것을 쓰면 됩니다.**

**280강의 강화학습**에서도 이 발상이 나타납니다. 벨만 잔차가 리아푸노프 함수 역할을 하며 수렴 증명에 쓰입니다.

> **심화 4.** 비제차 계와 변수변화법을 다루세요.

$$\dot{\mathbf{x}}=A\mathbf{x}+\mathbf{b}(t)$$

117강 문제 2의 적분인자를 행렬로 옮깁니다. 양변에 $e^{-At}$를 곱하면

$$\frac{d}{dt}\bigl(e^{-At}\mathbf{x}\bigr)=e^{-At}\mathbf{b}(t)$$

적분하면

$$\boxed{\ \mathbf{x}(t)=e^{At}\mathbf{x}_{0}+\int_{0}^{t}e^{A(t-s)}\mathbf{b}(s)\,ds\ }$$

**변수변화 공식** 또는 뒤아멜 공식이라 합니다.

**해의 구조가 두 부분**입니다.

| 항 | 뜻 |
|---|---|
| $e^{At}\mathbf{x}_{0}$ | 초기조건의 응답 |
| 적분항 | 입력의 응답 |

**둘째 항이 합성곱**입니다. 59강의 푸리에와 이어지며, 신호처리에서 $e^{At}$를 **충격 응답**이라 부릅니다.

$$\text{선형계의 출력은 입력과 충격 응답의 합성곱입니다}$$

**$A$가 안정이면 정상상태**가 존재합니다. $\mathbf{b}$가 상수이면

$$\mathbf{x}(\infty)=-A^{-1}\mathbf{b}$$

이며 117강 문제 2의 $y=3$이 이 형태입니다.

**주기 입력이면 주파수 응답**이 나옵니다. $\mathbf{b}=\mathbf{b}_{0}e^{i\omega t}$이면 정상해가

$$\mathbf{x}=(i\omega I-A)^{-1}\mathbf{b}_{0}e^{i\omega t}$$

**$(i\omega I-A)^{-1}$이 전달함수**이며, $i\omega$가 고유값에 가까우면 크기가 폭발합니다.

$$\text{공진은 특이성에 가까워지는 현상입니다}$$

**91강의 조건수와 같은 이야기**입니다. 행렬이 특이에 가까우면 역행렬이 크고, 작은 입력이 큰 출력을 만듭니다.

| $=1$ | 기억 유지 |
| $>1$ | 기울기 폭발 |

**97강 문제 3에서 본 기울기 소실**이 이 언어로 설명됩니다. 그리고 249강의 대책들이 $\lvert\lambda\rvert\approx1$을 유지하려는 시도입니다.

**셋째, 신경 상미분방정식**입니다. 은닉 상태를 연속 시간의 흐름으로 봅니다.

$$\frac{d\mathbf{h}}{dt}=\mathbf{F}_{\theta}(\mathbf{h},t)$$

**잔차 연결의 연속 극한**이며, 250강에서 $\mathbf{h}_{t+1}=\mathbf{h}_{t}+F(\mathbf{h}_{t})$가 오일러 한 걸음임을 봅니다.

$$\text{층을 쌓는 것이 시간을 흐르는 것입니다}$$

**넷째, 확산모형**입니다. 266강의 전방 과정이 확률미분방정식이고

$$d\mathbf{x}=-\tfrac12\beta_{t}\mathbf{x}\,dt+\sqrt{\beta_{t}}\,d\mathbf{w}$$

**결정론적 부분이 이 강의의 선형계**입니다. 270강의 확률흐름 ODE가 잡음 항을 없앤 형태이며, 120강의 수치해법으로 풉니다.

**다섯째, 상태공간모형**입니다. 309강에서 다룰 구조가

$$\dot{\mathbf{h}}=A\mathbf{h}+B\mathbf{u},\qquad\mathbf{y}=C\mathbf{h}$$

**정확히 심화 4의 비제차 선형계**입니다. $A$를 특별한 형태로 잡아 긴 문맥을 효율적으로 다루며, $e^{At}$의 구조가 성능을 정합니다.

$$\text{이 강의의 선형계가 최신 구조의 뼈대입니다}$$

> **심화 6.** 119강으로 어떻게 이어지는지 정리하세요.

이 강의에서 **선형계와 안정성**을 세웠습니다. 119강이 그것을 최적화에 적용합니다.

$$\frac{d\mathbf{x}}{dt}=-\nabla f(\mathbf{x})$$

문제 5에서 이미 봤습니다. **119강이 더 나아가는 것**을 예고합니다.

**첫째, 수렴 속도를 연속시간에서 봅니다.** 이차함수에서

$$f(\mathbf{x}(t))-f^{*}=e^{-2\mu t}\bigl(f(\mathbf{x}_{0})-f^{*}\bigr)$$

**110강의 이산 결과와 대응**합니다. $\eta$가 시간 간격이므로 $k$걸음이 $t=k\eta$이고

$$(1-\eta\mu)^{k}\approx e^{-\mu k\eta}=e^{-\mu t}$$

**이산과 연속이 맞아떨어집니다.**

**둘째, 모멘텀이 이차 방정식임을 정식화합니다.**

$$\ddot{\mathbf{x}}+\gamma\dot{\mathbf{x}}+\nabla f(\mathbf{x})=\mathbf{0}$$

**이 강의 문제 4의 감쇠 진동**이며, 최적 $\gamma$가 임계감쇠 조건에서 나옵니다.

**셋째, 다른 흐름들을 봅니다.**

| 흐름 | 방정식 |
|---|---|
| 경사흐름 | $\dot{\mathbf{x}}=-\nabla f$ |
| 뉴턴 흐름 | $\dot{\mathbf{x}}=-H^{-1}\nabla f$ |
| 자연경사 흐름 | $\dot{\mathbf{x}}=-F^{-1}\nabla f$ |
| 미러 흐름 | 쌍대공간에서의 흐름 |

**96강 심화 3의 노름 선택**이 흐름의 선택으로 나타납니다.

**넷째, 리아푸노프 관점으로 수렴을 증명합니다.** 심화 3에서 본 대로 $f$ 자신이 리아푸노프 함수이며, 이 관점이 가속법의 수렴 증명을 단순하게 만듭니다.

**120강이 이산화를 다룹니다.** 그리고 **관문 3이 62강부터 120강까지**를 묻습니다.

import numpy as np

def expm(A, t, N=200000):
    """급수 대신 세밀한 오일러로 e^{At} 근사 대신, 대각화 가능하면 정확히"""
    w, V = np.linalg.eig(A)
    return (V @ np.diag(np.exp(w*t)) @ np.linalg.inv(V)).real

# --- 문제 1: 해가 e^{At} x0 이다 ----------------------------------------
A = np.array([[-1.0, 0.0], [0.0, -3.0]])
x0 = np.array([2.0, 1.0])
print("  dx/dt = A x,  A = diag(-1, -3),  x0 = (2, 1)")
print("       t        x(t) 해석          e^{At} x0 (수치)")
for T in [0.0, 0.5, 1.0, 2.0]:
    ex = np.array([2*np.exp(-T), 1*np.exp(-3*T)])
    print("  %7.1f   %-22s %s" % (T, np.array2string(np.round(ex,6)),
                                   np.array2string(np.round(expm(A,T) @ x0, 6))))
print("  성분마다 e^{lam_i t} 로 줄어듭니다")
#   dx/dt = A x,  A = diag(-1, -3),  x0 = (2, 1)
#        t        x(t) 해석          e^{At} x0 (수치)
#       0.0   [2. 1.]                [2. 1.]
#       0.5   [1.213061 0.22313 ]    [1.213061 0.22313 ]
#       1.0   [0.735759 0.049787]    [0.735759 0.049787]
#       2.0   [0.270671 0.002479]    [0.270671 0.002479]
#   성분마다 e^{lam_i t} 로 줄어듭니다

# --- 문제 2: 대각화로 분해한다 ------------------------------------------
B = np.array([[0.0, 1.0], [-2.0, -3.0]])
w, V = np.linalg.eig(B)
print("  B = [[0,1],[-2,-3]] 의 고유값 %s" % np.round(w.real, 6))
print("  고유벡터(열) =\n", np.round(V.real, 6))
z0 = np.array([1.0, 0.0])
c = np.linalg.solve(V.real, z0)
print("  x0 = (1,0) 을 고유기저로 쓰면 c = %s" % np.round(c, 6))
print("       t      성분 c1 e^{l1 t}   성분 c2 e^{l2 t}      합            직접 e^{Bt}x0")
for T in [0.0, 0.5, 1.0, 2.0]:
    t1 = c[0]*np.exp(w.real[0]*T)*V.real[:,0]
    t2 = c[1]*np.exp(w.real[1]*T)*V.real[:,1]
    print("  %6.1f   %-16s %-16s %-16s %s"
          % (T, np.array2string(np.round(t1,4)), np.array2string(np.round(t2,4)),
             np.array2string(np.round(t1+t2,6)), np.array2string(np.round(expm(B,T) @ z0, 6))))
#   B = [[0,1],[-2,-3]] 의 고유값 [-1. -2.]
#   고유벡터(열) =
#  [[ 0.707107 -0.447214]
#  [-0.707107  0.894427]]
#   x0 = (1,0) 을 고유기저로 쓰면 c = [2.828427 2.236068]
#        t      성분 c1 e^{l1 t}   성분 c2 e^{l2 t}      합            직접 e^{Bt}x0
#      0.0   [ 2. -2.]        [-1.  2.]        [1. 0.]          [1. 0.]
#      0.5   [ 1.2131 -1.2131] [-0.3679  0.7358] [ 0.845182 -0.477302] [ 0.845182 -0.477302]

#      2.0   [ 0.2707 -0.2707] [-0.0183  0.0366] [ 0.252355 -0.234039] [ 0.252355 -0.234039]
# 두 고유방향의 기여를 더하면 정확히 해가 됩니다.

# --- 문제 3: 안정성은 고유값의 실수부 -----------------------------------
print("      행렬                  고유값                실수부 최대   판정")

         ("diag(-1, 2)   ", np.array([[-1.,0.],[0.,2.]])),
         ("[[0,1],[-1,0]]", np.array([[0.,1.],[-1.,0.]])),

    kind = "안정" if r < -1e-12 else ("불안정" if r > 1e-12 else "경계(중립)")

                                                np.linalg.norm(xt), np.exp(-0.2*T)))
print("  크기는 e^{-0.2t} 로 줄고 방향은 계속 돕니다")
#   C 의 고유값 [-0.2+1.j -0.2-1.j]  (실수부 -0.2, 허수부 1.0)
#   해는 e^{-0.2 t}(cos t, sin t) 조합이라 감쇠 진동입니다

#      12.0   [0.0766 0.0487]            0.090718     0.090718
#   크기는 e^{-0.2t} 로 줄고 방향은 계속 돕니다
# 크기가 정확히 e^{-0.2t} 입니다. 실수부가 봉투를 정합니다.

# --- 문제 5: 경사흐름의 야코비는 -H 다 ----------------------------------
print("  f = (x^2 + 100y^2)/2 의 경사흐름 dx/dt = -grad f = -H x")
H = np.array([[1.0, 0.0], [0.0, 100.0]])
