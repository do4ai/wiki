# 02. 계정 발급과 회수

이 섹션은 연구실 구성원 계정을 만들고, 권한을 부여하고, 필요 시 회수하는 절차 문서를 모아 둔다.

접근 권한 변경은 흔적과 검증이 중요하므로 실제 작업 절차 중심으로 관리한다.

아직 개별 절차 문서는 없다. 현재 계정(GitHub org·Infisical·Harbor·Discord 등) 발급·회수는 담당자에게 직접 요청해 처리하며, 절차가 정리되는 대로 이 섹션에 문서를 추가한다.
